# 高教联盟双轨重构

## Report

## [S1] Problem

《全国高等教育设定(2026).md》现行「联盟五档」为单轨嵌套（C9 ⊂ 世界一流45 ⊂ 全国一流95 ⊂ 全国一流学科230），与作者新提纲冲突：

1. 提纲要求拆成**国际轨**（W45 世界一流大学联盟、世界一流学科联盟、长安集团联盟）与**国内轨**（C9、国立大学教育联合体、国内一流大学、国内一流学科）。
2. 现文「国立大学联合体 420」把军校／警校／政治学院算作正式成员；作者要求**只把中央／教育部直属算进去**，且**不再使用 G420 代号**。
3. C9、国立大学教育联合体、W45、长安集团均缺成立史与组织章程级描写（1920s 电气化「中央大学联盟」、1840 后季维幸提案、二战后教科文评定、1986 长安集团）。
4. 「全国一流」命名与提纲「国内一流」不一致。

## [S2] Design

### 双轨映射（已定）

| 轨 | 名称 | 规模 | 角色 |
| --- | --- | --- | --- |
| 国际 | **W45 世界一流大学联盟** | 全球约 135；中华帝国 45 席 | 教科文组织战后评定；中国席次名单＝现 45 所 |
| 国际 | **世界一流学科联盟** | 学科点维度 | 同源评定，按学科建制 |
| 国际 | **长安集团联盟** | 十余所 | 1986 年学历互认精英联盟 |
| 国内 | **C9 中央科学教育联盟** | 9 | 学术顶峰；嵌在国内一流大学内 |
| 国内 | **国立大学教育联合体** | 正式成员 293 | 行政联合体；仅中央／教育部直属 |
| 国内 | **国内一流大学联盟** | 95 | 现「全国一流」95 名单 |
| 国内 | **国内一流学科联盟** | 230 | 现「全国一流学科」230 名单 |

嵌套（国内水平轨）：**C9（9）⊂ W45 中国席（45）⊂ 国内一流大学（95）⊂ 国内一流学科（230）**。  
国立大学教育联合体为**平行行政口径**（按主办与隶属划分）。

### G420 → 国立大学教育联合体（已定）

- **正式名称**：国立大学教育联合体（简称「国教联」）。**废止代号 G420**。
- **正式成员**：中央／教育部直属——国立大学本部 12 ＋ 分校 86 ＋ 中央直属专科与行业学院 195 ＝ **293**。
- **系统协作单位**（不入联合体）：国防与军种院校 21、警务 53、政治学院系统 53 ＝ **127**。全国国立总规模仍为 **420**。
- **史源**【推演】：1840 年后，时在中央行政学院高等研习班学习的江南州教育厅长**季维幸**提出联合教学方案，经中央及教育部批准成立；**国立皇家理工大学**牵头，各国立院校响应加入。

### 史源锚点【推演】（与编年史互证）

| 时点 | 事件 | 互证 |
| --- | --- | --- |
| 1840s 后 | 季维幸提案，国教联前身「国立大学联合教学会」成立 | 总设定 1840s 中西碰撞 |
| 1920s | 电气化；皇家理工／中央翰林院／长安大学组「中央大学联盟」 | 编年史 1919—1930 高教与电网大投资 |
| 1939—1945 | 二战；战后重建 | 编年史二战条 |
| 战后 | 联合国成立；教科文组织牵头评定 W45 与世界一流学科；中央大学联盟扩充为 **C9** | 编年史联合国五常 |
| 战后黄金期 | 和平互贸；国内一流大学／学科同步统计 | 总设定战后双极 |
| 1986 | 长安集团联盟（皇家理工／翰林院等＋MIT／莫斯科理工等），学历互认 | 总设定 80s 技术跃迁 |

### W45 国际配额【推演】

全球评定「一百余所」（取 **约 135**）：中华帝国约 1/3（**45 席**）、美国约 1/3、苏联与欧盟（英国未脱欧）合计约 1/4、其余国家约 1/6。比例为约数，允许加总偏差。

### 文件边界（已定）

- **只改** `设定/全国高等教育设定(2026).md`。
- 不改合订本、不重建 PDF。
- 全书数量校验（4,117、420、区域表）保持不变；仅联盟命名、隶属口径与史源深度化。

## [S3] Out of Scope

- 合订本同步与 PDF 重编。
- 新增／删减具体院校名单（45／95／230 校名列表保留，仅挂靠轨道与更名）。
- 官员名录补季维幸现职（其为 1840s 历史人物，不入现职名录）。
- 军校／警校／政治学院从国立 420 总表挪出（仅从联合体正式成员中剔除）。
