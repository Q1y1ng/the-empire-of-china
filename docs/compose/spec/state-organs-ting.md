# 州级行政机关「部」→「厅」命名重构

## Report

## [S1] Problem

中央政府组成机关与州政府组成机关同用「○○部」，主官同称「部长」。口头简称「财政部」「公安部」时分不清中央还是州；「部长」头衔亦撞车。省、市已分别用「署」「局」区分，唯独州与中央糊在一起。

## [S2] Design

### 命名链（已定）

| 层级 | 组成机关后缀 | 主官 | 例 |
| --- | --- | --- | --- |
| 中央 | **部**（不变） | 部长 | 中央/国务院财政部、公安部 |
| 州 | **厅**（原部） | **厅长** | 州财政厅、州公安厅 |
| 省 | **署**（不变） | 署长 | 省财政署 |
| 市 | **局**（不变） | 局长 | 市财政局 |

直属机关命名不变：州直属仍为「○○署」（州税务署、州统计署、州民族宗教事务署）。

### 改与不改（已定）

**改为「厅」**——州政府行政组成机关（原 24 个「部」）：

州经济发展厅、州财政厅、州教育厅、州科技工业厅、州公安厅、州民政厅、州司法厅、州人力资源和社会保障厅、州自然资源与生态环境厅、州住房与城乡建设厅、州交通运输厅、州水利与农业粮食厅、州商务与贸易厅、州宣传厅、州文化旅游厅、州卫生健康厅、州应急管理厅、州市场监督管理厅、州国有资产监督管理厅、州审计厅、州医疗保障厅、州退役军人事务厅、州国防动员厅

及总设定中散见的「州级行政单位对外贸易厅」；审计链「帝国审计院 → 州审计厅 → 省审计署 → …」。

**保留「部」**：

- 中央一切「○○部」与中央部长
- 政治口：州组织部（及省/市/区组织部）——非行政机关
- 州政府办公厅（办公厅不是「部」）
- 品级名 **「州部级」**（三品，涵盖州长≈中央部长；不随后缀改动）
- 军队、司法、监察、国安、议会等非行政组成机关专名

**官称**：州行政厅主官 **厅长**（州审计厅厅长、州宣传厅厅长）；州组织部部长不变。

### 文件边界（已定）

- 同步范围：`设定/` 目录全量（总设定 v2.0、官员名录各卷、合订本、编年史、城市志、高教设定等）。
- 不重建 PDF；不改 `华北风暴` 正文与 `tools/`。
- 改写规则：只动州级行政机关名与对应官称；中央机构、省署、市局、政治口、品级名不动。匹配时用「州」前缀限定，禁止全局把「○○部」批量替换。

## [S3] Out of Scope

- 品级名「州部级」更名。
- 政治口机构（组织部等）更名。
- 省「署」/ 市「局」体系调整。
- 合订本/官员名录 PDF 重编。
- 华北风暴正文与工具脚本。
