## 说明

1. 取用区间为第 589—616 行，全批共用 27 名。第 595 行「刘秉忠」与元代同名历史人物重名，取用时避让，该职由第 616 行「刘允济」补位；其余各行按行序对号入座。取名前已在 `docs/baike/src/` 与 `设定/` 全库检索，27 名均无占用。
2. 卷号归属：部委副职（生态环境部、退役军人事务部、教育部第一副部长与副部长，含国务院副秘书长、国资委副主任、审计院副院长与特派办主任）归卷二《中央副职与内设序列》；部委与直属机构的内设司局、直属机构副职（最高检公诉厅与办公厅、国资委产权管理局）归卷三十六；国家安全局内设（教育训练基地）归卷三十九；州级厅署与州常委会席位归卷十一《江南州》；军种副负责人位列军事系统纵深，归卷三十五。
3. 品级列照词条与所引卷册口径填写：部委副职、州级厅署主官三品；司局级、特派办主任、州常委会秘书长四品；国安局副局长三品；教育训练基地主任《卷三十九》未单列品级，填「—」。
4. 未新增虚构名的两条及理由：
   - `cfec`：本委《卷一》只列主任一人，副主任一职 2019 年起空置（词条两处明文），会务与文书不另设编制，《卷三十六》未列内设司局；唯一有岗位而无具名者的「规划编制组组长」在《卷一》已有具名者——国家发展改革委员会主任段怀瑾（三品），故只作具名补录，不计入新造人数。
   - `fuhe-zhiwu`：概念词条，所述岗位均为制度举例，且所举人物已在别处具名（政治学院两位分管副校长李子衡、李尔康见 `yipin-xianzhi`；国防大学副校长李之沐见 `he-bingyi`；中央组织委员会干部局局长张仲谦见 `cheng-musong`），故只作具名补录，不另拟名。
5. 其余未补名的岗位及理由：
   - 最高检「其余内设机构」只作「侦查监督、执行监督、控告申诉等条线」的非穷尽表述，《卷三十六》未列司名，依《编撰规范》四·「名录无载者不得自造」，不具名。
   - 江南州二十四厅三署中，教育、民政、司法、人社、卫健、审计、统计等厅署本轮未进入两词的叙述（词条只提到会签、报数与口岸配套环节的经手岗位），不另补，以免同一厅署在别处具名时口径相左。
   - 海军、空军军种的舰队与军区空军序列已有具名（舰队司令见卷二，基地司令郭戍海、骆戍波、林戍涛见卷三十五），本轮只补军种本级的副职，不重复命名下级主官。
   - 中央财经委副主任、国务院办公厅副主任、国资委「考核与收益口」「企业领导人员口」均无对应职名可据（前者空置，后三者《卷三十六》只列到「口」而未列司局名），一并留白。
   - 各人物词条中未被提及的前任与继任者一律不补，避免为叙述方便虚构履历。
