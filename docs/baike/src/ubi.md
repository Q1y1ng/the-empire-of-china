## 概述

**全民基本补贴**是帝国的普惠式现金补贴：每人每月 620 元、每年 7,440 元，年度总规模 13.24 万亿元（占 GDP 6.1%）。它不设家计审查，全体国民一律发放——这既是分配政策，也是一种政治表态：**技术带来的收益，按人头分**。

## 社会契约的第三次升级

帝国政治理论把社会契约分成三段：

1. 传统：劳动 → 工资 → 生活
2. 工业：劳动 → 工资＋社会保障
3. **AI 时代：生产 → 社会财富 → 公共分配 → 全民基本补贴**

第三段的关键在于：补贴不与劳动挂钩。这条改变在议会里始终有争论——福利议题会认为 620 元太低（只相当于平均工资的 6.3%），主张提至 3% 赤字率上限；财政部则坚持先稳住三衡比例。

## 与总理的关系

[[李先念]]把补贴与基金绑在一起审：**基金先报、预算后审**。他的逻辑是——如果补贴的增长快于基金的增长，差额就要由一般预算兜；预算兜不住，就得动三衡。所以他每年先问一句：「今年基金能分多少？」
