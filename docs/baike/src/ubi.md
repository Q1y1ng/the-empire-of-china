## 概述
**全民基本补贴**是帝国普惠式现金补贴：每人每月 620 元，年度总规模 13.24 万亿元（占 GDP 6.1%），其中 4.82 万亿元由[[国家自动化红利基金]]承担（36.4%），其余 8.42 万亿元由一般预算列支。

## 已定口径

- **换算**：补贴约相当于城镇单位平均工资 9,850 元的 6.3%。
- **政策意义**：社会契约第三次升级——生产 → 社会财富 → 公共分配 → 全民基本补贴。
