## 概述

**皇权—制度—绩效循环**是帝国自我更新的机制图：皇权产生政治领导，政治领导推动制度运行，制度运行带来国家治理，治理换来经济与社会发展，发展让人民获得公共利益，公共利益增强国家合法性，合法性增强皇室威望，威望使皇权稳定，稳定的皇权继续推动制度改革，进入下一轮。

两头是关键：一头是**皇权受制度约束**（宪法、组织法、议会监督、[[皇权冻结程序]]），另一头是**绩效必须可被社会看见**。制度不是皇权的装饰，而是皇权兑现绩效的机器；绩效也不是制度的自评，而是社会认可度的来源。

## 正向环的五个环节

| 环节 | 制度装置 |
| --- | --- |
| 皇权 | 只保留六项元权力（[[皇帝权力六分法]]） |
| 制度运行 | 宪法十章四十二条与七部组织法 |
| 国家治理 | 国务院 22 个组成部门、[[六级行政体系]] |
| 公共利益 | 全民基本补贴、全国医保、免费教育 |
| 合法性 | [[五重合法性]]中的绩效一层 |

## 负向危机与出口

负向环同样清晰：制度僵化→治理能力下降→社会不满→皇室威望下降→政治危机。此时皇帝真正正确的选择是主动推动改革，因为**改革本身就是维护皇权合法性的工具**。1978—1986 年的[[大革命（第二次建国）]]，就是这条负向环走到尽头之后的强制重启。

## 2026 落点

约束的一端是中央政治委员会 80% 同意可冻结或罢免皇帝，否决法案须十日内书面说明理由；绩效的一端是[[五年规划]]的年度复盘与[[帝国审计院]]年度报告提交议会审议。两端都失守，循环才会真的断。
