## 概述

**皇帝权力六分法**是帝国把传统皇权拆开再重组的结果。传统皇帝的权力是一团混合物——军权、政权、财权、人事权、司法权、礼仪权混在一起；现代帝国将其拆分，皇帝只保留其中最核心的六种「元权力」，其余一律制度化交出。

六种元权力是：战略权、最高人事权、最高政治协调权、最高国防政治权、国家安全最高决策权、国家象征与连续性权。日常行政交给政府，立法交给议会，审判交给法院，财政监督交给议会与[[帝国审计院]]，公职监察交给纪委与监委，军事执行交给[[中央军事委员会]]。

## 六项元权力与边界

| 元权力 | 内涵 | 边界 |
| --- | --- | --- |
| 战略权 | 决定国家长期走向 | 经[[中央政治委员会]]与[[五年规划]]程序落地 |
| 最高人事权 | 决定谁进入国家最高领导层 | 政治局委员与常委由政委会选举、皇帝任命 |
| 最高政治协调权 | 解决国家机构之间的重大政治冲突 | 权限争议由[[帝国宪法法院]]裁决，皇帝不代裁 |
| 最高国防政治权 | 决定战争与和平的政治方向 | 军事执行归军委，不得越军务系统调基层部队 |
| 国家安全最高决策权 | 决定重大安全威胁的总体战略 | 经国家安全委员会与国防与安全委员会 |
| 国家象征与连续性权 | 保证三百多年国家制度连续性 | 不得废除宪法、不得解散所有机构 |

## 三层次与不能做的事

方向权、政策权、执行权构成一条链：**皇帝【方向权】→ 中央政治局【政策权】→ 中央政府【执行权】→ 全国行政体系**。皇帝决定往哪里走，政治局把方向转成路线，政府把路线变成政策，官僚体系把政策执行下去。

不能做的四件事同样明确：不能随意绕过行政机构处理普通事务；不能随便越过军务系统调动基层部队；不能无限制绕开预算体系；不能在不说明理由的情况下否决法案。紧急状态也有期限，一次不超过六个月。

这条概念真正约束的，是「皇帝可以决定什么、不可以决定什么」。皇帝拥有的是制度内最高权力，不是制度外无限权力——改变基本制度必须走宪法修正程序。
