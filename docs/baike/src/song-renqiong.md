## 概述

**宋任穷**，[[国家发展改革委员会]]主任，三品州部级。发改委是「长周期」部门：产业政策、区域协调、重大项目布局与[[五年规划]]编制，都从这里出图。

## 2026 年的两副担子

**一是规划编制组组长**。按《非常设机构通则》，五年规划编制组由发改委主任任组长，期限 12—18 个月，成员含[[财政部]]、[[国家统计局]]、科技部、工信部与地方代表；2026 年正在编制新一轮（2026—2030），上一轮为 2021—2025。

**二是项目闸门**。所有项目必须带**工期表与还款表**，没有现金流测算的不得列入年度计划——这是[[李先念]]任副总理时为[[欧亚大陆桥]]立的规矩，如今成了发改委的日常门槛。

## 与财经委、财政部的关系

| 环节 | 谁定 |
| --- | --- |
| 总量与比例 | [[中央财政经济委员会]] |
| 项目与年度计划 | 发改委 |
| 钱与科目 | [[财政部]] |
| 批钱 | [[国民议会]] |

发改委夹在中间：上面的比例不能破，下面的钱不能超，项目还要能开工。

## 与总理的关系

[[李先念]]对发改委只有一句要求：**项目先有表，再谈要不要**。宋任穷的做法是把这句话变成流程——立项表、工期表、还款表三表齐全，才进年度计划。
