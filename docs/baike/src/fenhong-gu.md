## 概述

**分红股**，指国有企业向市场发行的份额凭证：以该企业第五年起连续三年（第 5、6、7 年）平均净利润的一部分（上限二成）为分配池，平均分为若干份，持有人在第五年起按份领取分红，第七年末终止。持有人分享的是未来三年的经营成果，募集资金用于扩大生产、技术改造与研发投入。

三条性质界定其边界：**权益工具**，计入其他权益工具，不计息、定期限、池子封顶；**期限固定**，七年为限，到期自动终止；**上限固定**，池子以发行时承诺数的二成为顶，超收不多付。三条合起来，把「借钱」与「卖股份」中间的空白地带占住：企业拿到现金，财政拿到投资，百姓拿到一份看得见的未来收益。

制度目的在于解决一个老问题：国有企业的利润全部上缴财政，再投资靠预算安排，投资周期与考核周期错位，管理层倾向短期报表。分红股把未来三年的利润提前定价，市场对未来的判断直接压在股价上，管理层短视即被市场识别，见「市场预期作为监管信号」一节。

## 定义与内涵

| 要素 | 口径 |
| --- | --- |
| 分配池 P | 第 5—7 年平均净利润 B 的二成以内，即 P＝0.20×B |
| 份数 N | P／1 元，每份面值 1 元 |
| 发行价 p0 | 按折现率 r、流动性折扣 λ、波动惩罚 σ 折算未来三年现金流 |
| 存续期 | 7 年；分红自第 5 年起支付 |
| 终止 | 第 7 年末自动终止，余额清算 |
| 会计 | 计入其他权益工具；支付时冲减；审计报告单列「未来利润让渡规模」 |

与债券的分野在三点：本息无保证、期限有定、池子封顶；与普通股的分野也在三点：无表决权、有到期日、只分未来三年不分公司残余。故其定价介于两者之间，市场以折现率、流动性折扣与波动惩罚三项调节。

## 历史渊源

国有企业的利润分配制度历经三段。第一段为全额上缴，利润进财政，投资靠预算，企业无留成；第二段为比例上缴，企业留一部分自主投资，上缴比例按行业分档；第三段即 2024 年 9 月《企业分红股管理办法》之后的双轨：既按比例上缴，又可把未来三年利润的一部分卖给市场换取当期投资。

第三段的动因是 2022 年审计。审计查出九点四二万亿元问题金额，其中「闲置土地」与「利润转移」两类指向同一件事：账上有钱，投不出去。2023—2025 年清退与重组完成之后，一批盈利稳定的企业面临扩产窗口，财政又须守住赤字率，分红股遂成第三条融资渠道。

2024 年试点三家、四百二十亿份、募资三百零二亿元；2025 年扩至七家、一点一二万亿份、募资八千零六十亿元，均价零点七二元；2026 年目标十一家、一点八万亿份、一点三万亿元。

## 制度内容

**发行六条件**：近三年连续盈利且最近一年净利润不低于十亿元；资产负债率低于行业均值五个百分点；近三年审计意见为标准无保留；未来三年资本开支计划已获董事会与出资人批准；无重大未决诉讼与监管立案；分红股专项审计意见为可持续或基本可持续。

**定价公式**：

```
B_hist = 近五年净利润均值
g      = 近五年净利润复合增速（上限 15%）
B_fcst = 发行时承诺的第 5—7 年平均净利润（经审计院复核）
B_cap  = 发行前净资产 × 行业 ROE 上限（能源 12%、通信 10%、机械 14%）
B = min(B_fcst, B_hist × (1+g)^3, B_cap)
P = 0.20 × B
N = P / 1
p0 = Σ(k=5..7)[(P/3)/N] / (1+r)^k × (1−λ) × (1−σ)
r = 无风险利率 + 行业风险溢价；λ = 流动性折扣 5%—15%；σ = 波动惩罚 0—20%
```

**五条可持续性约束**（任一不满足即不得发行）：

| 代号 | 约束 | 含义 |
| --- | --- | --- |
| S1 | 资产负债率不高于行业上限减 5 个百分点 | 不靠加杠杆发分红股 |
| S2 | 分红后留存收益覆盖未来三年资本开支与法定公积 | 不挤压再生产 |
| S3 | 分红覆盖率不低于 5 | 池子不超过净利润二成 |
| S4 | 滚动五年累计池不超过累计净利润二成 | 防寅吃卯粮 |
| S5 | 未到期分红股池现值不超过净资产一成五 | 单一企业总量控制 |

**补足与追责**：实际第 5—7 年平均净利润低于承诺八成时，以法定公积补足或延长分红期至第 8—10 年；触发当年绩效薪酬减半，连续两年触发者主官调整、班子重组。审计院每年出具《分红股可持续性意见》，五档为可持续、基本可持续、关注、预警、不可持续，与年报同时披露。

## 运行与实例

**市场预期作为监管信号。** 分红股在二级市场交易，价格反解出市场对企业未来利润的隐含预期：

```
B̂_t = p_t × N × (1+r)^5 / [ (1−λ)(1−σ) × (1/3) × Σ(k=5..7)(1+r)^(5−k) ]
D_t = | B̂_t − 报告净利润 × (1+g_report)^5 | / [ 报告净利润 × (1+g_report)^5 ]
```

| 偏离指数 D | 处置 |
| --- | --- |
| 低于 10% | 正常 |
| 10%—15% | 列入观察名单，季度跟踪 |
| 15%—30% | 审计院问询，企业三十日内书面说明 |
| 高于 30% | 专项审计，必要时暂停发行资格 |
| 连续两期高于 15% | 列入预期异常名单，主官约谈 |

此机制的分量在于两个数对不上：企业报给监管的是账面利润，企业卖给市场的是未来利润。2025 年全年触发问询四十一次、专项审计七次，查出提前确认收入三起。

**交易规则**：帝国公民优先认购，每人五万份为限；养老金、[[国家自动化红利基金]]、保险资金可认购；帝国股权交易所分红股板集中交易，涨跌幅正负一成，T＋1；季度经营数据、年度审计报告、可持续性意见、重大事项按期披露。

**首单与扩围**：2024 年首单为帝国机械，池比例一成一，均价零点七二元；2025 年扩至能源、通信、冶金、船舶、化工、医药、粮食七条线。七家池比例均值为一成三点四，未触发补足条款。

## 意义与评价

其一，**融资渠道从财政移到市场**。国有企业的扩产资金由财政拨款改为市场定价，赤字节制与企业扩张各得其所；市场愿意买，说明对未来三年利润的判断成立，财政无须替企业担保。

其二，**考核周期与投资周期对齐**。七年存续、五年锁定，管理层的任期与分红股的存续期重叠，短期报表与长期利润两边都要交代。

其三，**一行数字换来一条监管线**。偏离指数把市场预期变成审计线索，审计院不必逐户查账，即可从价格异动锁定可疑企业；2025 年四十一次问询、三起提前确认收入，成本低于全面审计。

其四，**让百姓分得一份国资收益**。公民优先认购、每人五万份为限，是收益分配的一次制度化尝试；与全民基本补贴并行，前者分享未来，后者守住当下。分配的口径见[[国家自动化红利基金]]。
