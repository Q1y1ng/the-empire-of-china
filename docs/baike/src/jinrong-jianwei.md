## 概述

**帝国金融监督管理委员会**是帝国的金融监管机关，三品直属机构，主任龚守规，副主任韦金融，机构监管局局长荆察行。帝国的金融受严格监管，且有一条硬规矩：**任何金融活动，须经国家金融机关同意并全程监察**——这条规矩的日常执行者就是本委。

「一行一委」不是两个平级衙门平分金融，而是把钱的两半切开：[[帝国中央银行]]管货币的**量**（发行、利率、信贷投放），本委管机构的**行为**（准入、治理、销售、风险处置）。发行权只有一家，监管权也只有一家，谁也不兼另一家的活。

## 一行一委的分工

| 事项 | 帝国中央银行 | 本委 |
| --- | --- | --- |
| 货币发行与利率 | 定 | 不问 |
| 机构准入与退出 | 提供流动性意见 | 定 |
| 国有商业银行 | 出资人 | 监管者 |
| 跨境资金与外汇 | 外汇局（曹兑衡）对口径 | 查跨境业务合规 |
| 风险处置 | 最后贷款人 | 接管、托管、报国务院 |

## 职能

- **机构监管**：银行、保险、证券、支付机构一体准入，股东穿透至最终受益人
- **行为监管**：销售误导、乱收费、捆绑搭售，罚单与整改一并公开
- **垂直**：八州分局四品、省办事处五品，人财物归中央，不受州政府节制
- **被监督**：[[帝国审计院]]查经费与处罚台账，[[国家监察委员会]]查人，处罚决定可诉至[[帝国宪法法院]]

## 与央行的边界

两边每年吵一次的是「流动性算不算监管工具」：央行认为放水是它的活，本委认为放水救不了治理。[[华铸民]]与本委的共识只有一条：**先分清是缺钱还是缺规矩**，缺钱找央行，缺规矩找本委。

> 「金融的胆子不是管出来的，是知道有人会查才收住的。」
