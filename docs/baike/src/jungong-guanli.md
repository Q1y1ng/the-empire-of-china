## 概述

**国家军工管理总局**是[[国务院]]国防军事系统的直属机构，三品州部级，局长陈赓，管军工企业与产能：哪家厂造什么、一年能造多少、配套件到几级供应商、交付晚一天谁担责。研制出来只是第一步，**造得出来、造得齐、造得起**是第二步——这一步归本局。

它和[[国防科技工业总局]]（张爱萍）是一对，分界只有一句：一个管研制，一个管生产与管理。型号定型之后，本局接手批量与产能；定型之前，本局只管一件事——产能预研，即提前把生产线、工装与配套名单排出来，免得图纸定了厂子跟不上。

## 三张表：企业、产能、配套

| 事项 | 谁管 | 本局的角色 |
| --- | --- | --- |
| 研制与定型 | [[国防科技工业总局]] | 提前对接工艺与产能，不参与设计 |
| 军工企业股权 | [[帝国国有资产监督管理委员会]]（侯守业） | 提保供要求，不动股权 |
| 产能与批产计划 | 本局 | 编年度产能表，随[[五年规划]]与年度预算上报 |
| 钱与合同 | [[国防部]]（[[贺龙]]）、[[财政部]] | 报产能账，按合同交付 |
| 军工配套与民口协作 | [[工业和信息化部]] | 二级、三级配套进名单 |

- **企业**：央企十二家由国资委以出资人身份管股权，其中帝国航天工业集团、帝国船舶工业集团是本局最主要的两个对口企业。
- **产能**：按型号、按厂、按产线三级台账；产能不是产值，报的是「一年最多交付多少件」。
- **配套**：一家总装厂背后是一串配套厂，名单一年核一次，掉出名单的须补审。
- **安全**：厂区保密与生产安全由企业负责，本局查流程，出事按事故口径移交。

## 与研制口、出资人怎么分开

三家坐在同一张桌上，各自带一本账：研制口带型号进度，本局带产能与交付，国资委带股权与考核。**谁都不替别人签字**——型号能不能定，本局说了不算；产能能不能扩，国资委不替企业答应；股权动不动，本局不开口。这条界线在急订货时最容易被压弯，所以每年由[[国防部]]牵头对一次表，对完各自归档。

> 「图纸是科学家的事，零件是厂长的事；两件事都成了，装备才算有了。」
