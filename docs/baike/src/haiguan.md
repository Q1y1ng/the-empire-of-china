## 概述

**帝国海关总署**是帝国的口岸管理与关税征收机关，三品直属机构，署长姚镇关，副署长巡查关，缉私局局长厉缉私。2026 年关税 3.65 万亿元，占税收收入 52.20 万亿元的 7.0%；这一档税率里含欧亚共荣体系的优惠安排，**政治账先于税率表**。

它在同一个关口上干三件互相牵制的事：征税、监管、缉私。这不是省人手，是刻意的设计——**关口只有一个，责任才追得到一个人**；分三个衙门守同一道门，出事时谁都能说自己只管一段。关员按关区轮岗，一届三年，同一关口不许连任两届。

## 口岸与关区

| 类型 | 内容 |
| --- | --- |
| 六大对外港口 | 河内、珠三角、长三角、环渤海、首尔湾、海参崴 |
| 三大陆路口岸 | 乌鲁木齐（中亚／苏联通道）、藏南（印度通道）、万象（中南亚通道） |
| 关区层级 | 八州关区（关长四品）→ 省支关（五品），垂直管理 |
| 贸易站 | 租借贸易站、商业港口、外交据点——不是殖民地 |

## 职能与分工

- **征税**：关税与进口环节税代征，汇总后并入[[国家税务局]]的税收总量，考核各算各的
- **监管**：舱单、原产地、许可证、检验检疫一口对外；跨境数据「先审后出」的边界由[[中央网信与人工智能委员会]]定
- **缉私**：海上、陆路、货运三线并查，移送按走私、逃汇、洗钱分口
- **贸易体制**：海外贸易由中央把控、经州级对外贸易厅执行，利润全部收回中央；私人贸易经审批可入海军护航编队
- **金融接口**：跨境资金申报与[[帝国金融监督管理委员会]]对表，海关只管货与税

## 与欧亚通道

[[欧亚大陆桥]]的过境货量与税则谈判，是海关每年最重的两件事：桥上的箱子走一条线，税则却要八州共用一个版本——**一条通道只能有一套税则**，这是帝国把贸易站连成网络的技术前提。

> 「关口上最难的不是查出走私，是让守规矩的人不比走私的人慢。」
