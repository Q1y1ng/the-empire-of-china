## 概述

**樊问枢**（1963年— ），江南州浙江省绍兴人，中华帝国现任[[中央政治局]]特殊委员（科技界）、[[中央政治委员会]]委员，二品副国级。

他是气象与地理出身的技术官僚：1984 年国立皇家理工大学资源与环境学院毕业，入中央气象局气候资料室任技术员；1992 年任气候预测司司长；1998 年任帝国科学院地学学部主任，2002 年起兼科学院副院长；2002 年至 2006 年任[[国家科研基金委员会]]主任；2006 年起任中央政治局特殊委员，代表科技界，2026 年连任；另兼[[皇储国政教育院]]院长。

特殊委员不进职能口序列，没有分管部门，只有两样东西：会上的一票，评审意见末尾的一支笔。他那一栏的题目常年是气候与农业。在科研基金委时，他管的是「钱往哪一类题目上放」；转任特殊委员之后，这支笔的性质变了——由提议题改为删题目。

他的工作方式可以概括为两条：用数据说服人，用沉默拒绝人。会上他不反驳，散会后把反对意见写成三页纸：第一页结论，第二页数据，第三页「若照原案执行，第五年会出现什么」。

其中央政治委员会委员资格属[[选举委员]]：随[[全国政治代表会议]]选举其担任现职而取得；本届以续任者身份经政代会确认。

## 生平

### 早年与求学（1963—1984）

出生于绍兴一个教书人家。浙北平原水网密布，绍兴一带的农事历法与观测笔记在民间流传甚广；他少年时随祖父记过几年的雨量与物候，后来在规划会议上被问「这组数据从哪来」，他答「从记天气的本子上来」。

1980 年入国立皇家理工大学资源与环境学院，学气象与气候专业。1984 年毕业，毕业论文做的是浙北双季稻的积温分区，结论被浙江省农业部门采用。

### 入仕与历练（1984—1998）

1984 年分配至中央气象局气候资料室任技术员（吏级），做的是气候序列的整编：把各站的观测记录按统一口径归并，缺测的补、错记的改、仪器换代的做订正。这段工作养成了他此后一切主张的底子——结论可以争，序列不能断。

1992 年任气候预测司司长，四品，时年二十九岁。任内他主持编制全国气候区划的第二版，把降水、积温与无霜期三项分区标准统一到一套图上，并第一次把「五十年序列」作为分区的最低要求写进技术规程。该司现任司长张秉正（四品），仍按这三项标准出图，序列不足五十年的站点不上区划图。

1998 年任帝国科学院地学学部主任，三品，2002 年起兼科学院副院长。科学院现任副院长张秉忠（三品）、地学学部主任张秉清（三品），序列整编与订正的规矩一仍其旧；学部每年报一次台站序列的完整率，缺测补记的说明随表附上。

### 主政一方（2002—2006）

2002 年任国家科研基金委员会主任，三品。基金委管的是科研经费的分配口径：题目怎么分类、评审怎么排期、额度怎么定。他任内做的最主要一件事是把题目分类表改成两级：一级按学科，二级按问题；评审按二级分类排期，跨类题目须两名不同学科的评审人。

他给自己划了一条界：题目分类表由基金委定，额度由[[财政部]]定，两边从不通融。这条界后来成为基金委的惯例。

### 现职（2006— ）

2006 年起任中央政治局特殊委员，代表科技界，二品。任内的固定动作有三个。

**一是规划的一页纸。** 每轮[[五年规划]]编制前，他固定交一页纸：未来五年的降水区间、积温区间、可耕地增减的上下限。发改委的起草组可以补，不能改；要改，须再走一次他那三页纸。

**二是评审组的排序。** 2018 年[[长安核聚变示范堆]]选址评审，他是那一届的组长。他的排序是先看水文与地震带资料，再看技术方案，理由是「堆可以挪，水不能挪」；这一条后来写进了评审细则的第一条。

**三是联席会的到场规则。** 他不列席中央政治委员会的日常会，只在涉及科技预算的联席会上到场。他自己把这叫「有事到，无事不到」。

## 主要工作

### 一、规划的气候假设签字制

主持五年规划农业章节的气候假设：降水区间、积温区间与可耕地增减的上下限，三项由他签字后才进主线。签字制的实质是把气候假设从「附录的一段话」变成「主线的一行数」；一旦签了字，规划中所有与农业相关的指标都要与这三项相容。2026 年这一轮他把降水区间按流域拆成七段，逐段给区间。

### 二、核聚变示范堆的选址评审

主持 2018 年[[长安核聚变示范堆]]选址评审。评审排序为水文与地震带资料、技术方案、配套条件三段，第一段不过，后两段不再评。评审细则第一条写的是他的原话：「堆可以挪，水不能挪。」2026 年示范堆进入调试，首次并网发电的目标定在 2027 年，选址阶段的这份评审意见仍是工程档案的第一卷。

### 三、科研题目分类与经费口径分离

主持国家科研基金委员会的题目分类表：一级按学科、二级按问题，跨类题目须两名不同学科的评审人。分类表定题目怎么归类，额度由财政部定钱怎么给，两条线互不通融。这套分法使基金委的评审可以按类排期，也把「先定题目、再找钱」改成「先分类、再排期、后定额」。

### 四、反对意见的三页纸格式

主持形成特殊委员意见的格式：第一页结论、第二页数据、第三页「若照原案执行，第五年会出现什么」。三页纸的用意是把反对从态度变成测算；他从不投反对票之后再发言，而是把三页纸交会议秘书处，由秘书处随会议纪要一并分发。2026 年科技预算联席会上，他一次交过两份三页纸。

### 五、皇储国政教育院的课程口径

以[[皇储国政教育院]]院长身份主持皇储与皇子的国政教育课程：课程按「制度、财政、军事、外事、科技」五门排列，每门配一名主讲与一份必读书目；考核采用答辩制，答辩记录存档。他把科技一门的位置排在第四位，理由是「先懂钱，再懂技术什么时候该用」。

## 人物风格

| 场合 | 表现 |
| --- | --- |
| 评审会 | 先看基础资料，再看技术方案；基础资料不过，方案不评 |
| 联席会 | 有事到、无事不到；到会只带三页纸，不带汇报稿 |
| 会上发言 | 不反驳，只记；散会后写成三页纸交秘书处 |
| 被问数据来源 | 只答序列出处与年限，不作解释；序列一摆，话就说完 |

| 对年轻研究员 | 常问一句「这条序列有多长」；答不出年限的题目不给排期 |

## 评价

- **皇帝[[朱昭文]]**（2024 年科技预算联席会后）：「他的三页纸，我每次都读完；读完不一定照办，但一定知道第五年会怎样。」
- **[[中央财政经济委员会]]主任[[金慎余]]**：「他从不争额度，只争口径；口径定了，额度自然就少了。」
- **[[国家发展改革委员会]]主任[[段怀瑾]]**：「他那一页纸交来，起草组只能补不能改；补完的稿子，比他原稿还硬。」
- **[[长安核聚变示范堆]]工程总师**（2026 年调试前）：「选址评审第一条是他写的，工程照做了八年，没出过一次水情问题。」
