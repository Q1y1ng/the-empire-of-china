## 概述

**帝国航天总局**是帝国的民用航天机关，三品直属机构，局长裴凌霄，副局长胥航天。它的谱系是一条由近及远的线：先做气象、通信、测绘，再做载人航天，最后指向深空探测——每一步都以「国家用得上的能力」为起点，至今没变，只是每两步之间的间隔在缩短。

它的定位是**民用口径**：太空与网络力量在帝国是军民结合的一块，军用一端归[[中央军事委员会]]的战略力量，安全事项经[[国家安全委员会]]协调；本局管的是工程、许可、数据与对外合作，不管作战。这条界线在编制上也写得很清楚：本局的任命走国务院序列，军用一端的人事走军委序列。

## 军民分口

| 领域 | 归口 | 说明 |
| --- | --- | --- |
| 气象、通信、测绘卫星 | 本局 | 数据对社会开放，是公共基础设施 |
| 载人航天与深空探测 | 本局 | 成果公开，国际合作以本局名义签 |
| 侦察、导航增强、太空态势 | 军委战略力量 | 本局只提供技术接口与发射窗口 |
| 发射许可与轨道频率 | 本局 | 一箭一证，频率协调对外统一口径 |

## 职能

- **工程**：重大工程按[[五年规划]]立项，概算经[[财政部]]、进度经[[国家统计局]]口径核
- **许可**：发射许可、轨道与频率申报、残骸落区通报，一件不许漏
- **数据**：遥感与气象数据分级开放，涉密图层单列，调阅留痕
- **产业**：与[[帝国国有资产监督管理委员会]]分工——研制订货归集团，任务总体与验收归本局
- **技术**：基础研究与人才培养同[[科学技术部]]体系衔接，型号队伍按项目制编成

## 与战略力量的关系

第九编把太空与网络写成「军民结合」，这句话在编制上落成两条线：一条是军委的战略力量，一条是本局的民用工程。两边共用厂房、靶场与测控站，但**预算分列、指挥分列、成果分列**——合建不合帐，是帝国处理军民两用技术的一贯做法。

> 「先能上天，再谈上天的用处——顺序不能倒过来。」
