## 概述

**帝国政治哲学八个关键词**是统一、皇权、制度、责任、选拔、监督、改革、绩效。它在《中华帝国世界观总设定 v2.0》第二十编被写成一行，随后逐条解释功能。八个词不是八条并列的口号，而是首尾相接的一条链：每一个词都在回答前一个词留下的问题。

链条的起点是「统一」，终点是「绩效」，而绩效又回头决定统一能否维持，所以它被称作闭环。有统一而无皇权，最高政治就没有连续性；有皇权而无制度，权力没有边界；有制度而无责任，程序会变成无人负责的集体动作；有选拔而无监督，选拔就会变成合法的软世袭。断一环，其余七环同时松动。

## 八个词各管一件事

| 关键词 | 功能（原文） | 它防的失效 |
| --- | --- | --- |
| 统一 | 保证国家不碎 | 分裂与割据 |
| 皇权 | 保证最高政治连续性 | 最高权力的真空与更替动荡 |
| 制度 | 限制权力滥用 | 皇帝与官僚的任意性 |
| 责任 | 要求皇帝和官僚承担治理后果 | 无人负责的集体决策 |
| 选拔 | 解决世袭能力问题 | 血缘世袭与教育—信息—人际的「软世袭」 |
| 监督 | 解决官僚腐化问题 | 层层过滤的信息与利益网络 |
| 改革 | 解决制度僵化问题 | 制度老化之后的僵死 |
| 绩效 | 决定整个体系能否继续获得社会认可 | 合法性耗尽 |

## 2026 落点

八个词在 2026 年各有装置：统一对应[[中央集权型单一制]]；皇权对应[[皇帝权力六分法]]与[[皇权冻结程序]]；制度对应宪法十章四十二条与七部组织法；责任对应定期述职与[[标准政策生命周期]]；选拔对应[[科举制度]]与[[政治学院]]；监督对应[[中央纪律检查委员会]]、[[国家监察委员会]]与[[帝国审计院]]；改革对应[[五年规划]]与政策复盘；绩效落到[[五重合法性]]。

> 「统一保证国家不碎，皇权保证最高政治连续性，制度限制权力滥用。」
