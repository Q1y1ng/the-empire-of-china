## 概述

**AI时代社会契约升级**是帝国对自动化替代劳动的制度回应。它把社会契约分成三段：传统社会是「劳动 → 工资 → 生活」；工业时代是「劳动 → 工资＋社会保障」；AI 时代是「**生产 → 社会财富 → 公共分配 → 全民基本补贴**」。

第三段的关键变化在于：分配不再以就业为唯一入口。补贴不与劳动挂钩，因此当机器承担了大部分生产，人的基本消费能力也不随岗位消失。契约的写法也随之变了——不再是国家向劳动者承诺一份工作，而是国家向公民承诺一份不随岗位消失的分配。

## 三段契约

| 阶段 | 契约结构 | 分配入口 |
| --- | --- | --- |
| 传统 | 劳动 → 工资 → 生活 | 就业 |
| 工业 | 劳动 → 工资＋社会保障 | 就业＋保险 |
| AI 时代 | 生产 → 社会财富 → 公共分配 → 全民基本补贴 | 公民身份 |

## 配套的三件事

- **钱**：[[国家自动化红利基金]]年度可分配 4.82 万亿元，承担[[全民基本补贴]]的 36.4%；补贴 620 元／月／人，年度 13.24 万亿元
- **工作意义**：工作逐渐变成收入、社会贡献、兴趣、成就、身份认同的混合体；可能出现四天工作制、六小时工作制与更长带薪休假，配终身教育与中年再培训
- **决定权**：AI 可帮议会分析预算、可建政策模拟系统，但法律规定「算法可以提供意见，不得代替法定权力主体作出最终政治决定」
- **分层**：劳动收入、基本补贴、社会保障构成[[三层收入结构]]，补贴保基本消费能力，不替代劳动收入

> 「劳动创造财富，但技术进步也应当让劳动者获得更多自由。」
