## 概述

**财政部**是[[国务院]]经济财政系统的核心组成部门，三品州部级。它管四件事：预算编制、国库收支、税政、政府债务。帝国的年度账本——收入 60.48 万亿元、支出 66.53 万亿元、赤字 6.05 万亿元——第一个签字的地方就在这栋楼里。

## 收入结构

2026 年税收收入 52.20 万亿元（占财政收入 86.3%），非税 8.28 万亿元：

| 税类 | 占比 | 金额（万亿元） |
| --- | --- | --- |
| 增值税 | 34.0% | 17.75 |
| 所得税（企业＋个人） | 31.0% | 16.18 |
| 资产税（房产、遗产、资本利得） | 12.0% | 6.26 |
| 资源税 | 9.0% | 4.70 |
| 关税 | 7.0% | 3.65 |
| 其他 | 7.0% | 3.65 |

> 资产税占比 12% 是帝国税制的标志：比现实世界更重资本、更轻劳动。财政辩论戏里最常被引的就是这一行。

## 支出与红线

支出 66.53 万亿元中，社保就业 14.64 万亿元（22.0%）、国防 8.64 万亿元（13.0%）、基建水利 7.32 万亿元（11.0%）、卫生 5.99 万亿元（9.0%）、教育 4.32 万亿元（6.5%）、科技 3.59 万亿元（5.4%）。

**赤字率红线 3%** 是财政部自己立的规矩：2026 年赤字率 2.8%，距红线 0.2 个百分点——这个数字由财政部按月向[[中央政治局常务委员会]]报送缺口。

## 与总理的关系

[[李先念]] 1992—2001 年任预算司司长，主持分税制改革后的首轮预算编制，推行「预算说明不超过两页」；任总理后，他仍以「三个数」管财政部：钱从哪来、谁签字、几时到。
