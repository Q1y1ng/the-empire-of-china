## 概述

**权力不下放，事务可以下沉**是帝国处理中央与地方关系的操作原则：权不下放，事可以下沉（国体表述见[[中央集权型单一制]]）。它把「权」和「事」当成两样东西——权是主权性质的、排他的、只能往上；事是执行性质的、可分解的、可以往下沉。

所以地方手里有大量事务，却没有一件事能转成政治权力：地方可以做、可以管、可以被问责，但不能自己决定这活该不该由国家来做。核心概括是一句：**中央统一决策，地方负责执行与具体治理**；政策统一，执行多样。

## 两张清单

| 中央负责 | 地方负责 |
| --- | --- |
| 国防、外交、货币、国家财政、国家安全 | 城市管理、地方交通、地方公共设施 |
| 全国法律、重大基础设施 | 地方经济执行、地方文化事务 |
| 全国社会保障、全国教育标准、全国医疗体系、国家工业战略 | 基层公共服务、中央政策的具体实施 |

## 下沉的是执行，不下沉的是权

- 下沉执行：同一政策，各地按本地区条件执行——政策统一，执行多样
- 下沉事务：城市管理、地方交通、公共设施、基层公共服务归地方
- 不下沉权力：地方不得自行外交、建军、发行货币、征税设关或变更省界（宪法第三十五条）

## 2026 落点

在[[六级行政体系]]里，越往下越是事务：州统筹跨省，省管本省财政与教育，市管城市建设，区管公共服务，街道办管户籍、治安、民政与基层税务。中央保留「定」的权力，地方承担「办」的过程，两张清单之间没有第三张。

> 「中央统一决策，地方负责执行与具体治理。」
