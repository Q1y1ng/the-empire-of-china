## 概述

**帝国铁路总公司**是[[帝国国有资产监督管理委员会]]出资的中央企业，位列国资委旗下十二家央企之一，经营铁路路网、客运、货运与重载运输。公司设董事长、总经理各一人，按企业序列叙三品衔；另设副总经理三人与总工程师一人，分管路网与建设、客运、货运与重载、技术标准四条线。直任高管列品级，市场化聘用的经理列职不列品。

2026 年，全国铁路营业里程 24.0 万公里，其中高速铁路 9.2 万公里，城市轨道交通 18,600 公里。前两项由本公司承运，第三项属地方事权，不进全国路网这张表。高速铁路自 1995 年贯通八州州府，此后三十年，州府之间的一日往返成为帝国行政的常态节奏。

铁路在帝国治理中的位置由三条线标明：中央对地方的总体控制，靠铁路、审计、干部三条线并行，铁路是其中唯一看得见、摸得着的一条。人员与物资的流动、命令与文书的送达、灾年的赈济与战时的调动，都落在这张网上。公司因此承担的是经营，国家保留的是方向。

## 历史沿革

帝国的铁路自 1770—1790 年间进入雏形阶段。蒸汽机械与大型水利机械同期成熟，矿区与港口的短途轨道先通，随后向干线延伸。此期形成一条沿用至今的惯例：经济下行时国家上基建，铁路以工代赈，既稳就业，也加强中央对地方的掌控。

1830 年代，第一条商用铁路长安—郑州通车。1865 年，长安—上海—广州电报干线与铁路干线同步贯通，全国价格体系首次实现日内联动——同一天里，长安的粮价与广州的丝价可以并到一张报价单上。1870—1890 年代，全国铁路网与电报网建成，八州—省—市行政体系全面现代化，城市化随之加速。

1919—1930 年的黄金时代，铁路与电网、高等教育、化工、汽车、航空、无线电并列为大投资方向。1930 年代大萧条期间，帝国以「以工代赈＋国家投资」应对，公共工程、铁路、水利、住房四项同时上马，铁路再度成为吸纳失业与稳定社会的主渠道。

1968 年，高速铁路动工，晚于日本新干线通车四年；1995 年，高铁网贯通八州州府。此后三十年间，路网的重心由「通不通」转向「快不快、重不重」：客运看速度与准点，货运看重载与联运，两条线在同一张运行图上分配通道能力。

现行体制下，公司按出资关系与行业管理两条线受管：产权登记、董事派出与年度考核在国资委，行业规划、时刻表与调度在[[国家铁路总局]]。2026 年，公司管内营业里程 24.0 万公里，高铁 9.2 万公里，两项均含普速与重载口径。

## 机构设置

央企内设机构在《全国官员名录》中未列，名录只载企业主官与品级口径。下表按业务板块列出，属职能叙述，不作内设机构名称使用。

| 业务板块 | 主要职责 | 对口机关 |
| --- | --- | --- |
| 路网 | 线路、桥隧、信号的养护、扩能与安全 | 国家铁路总局；交通运输部 |
| 客运 | 列车开行、票务组织与站车服务 | 国家铁路总局（调度指挥中心） |
| 货运与重载 | 大宗货物运输、重载列车编组与联运衔接 | 交通运输部；国家发展改革委员会 |
| 建设 | 新线建设、既有线改造与枢纽扩建 | 国家发展改革委员会（规划） |
| 国际班列 | 过境班列的时刻安排、换装与口岸衔接 | 帝国海关总署 |
| 资本与考核 | 产权登记、董事派出、资产保值与收益上缴 | 帝国国有资产监督管理委员会 |

公司高管的官员属性按名录口径处理：董事长、总经理为直任高管，列三品企业衔；副总经理三人与总工程师同为直任高管，分管四条线——杨秉直分管路网与建设，杨秉正分管客运，杨秉忠分管货运与重载并兼管国际班列，杨秉清任总工程师，主管线路、桥隧与信号的技术标准。经理层中的市场化岗位按合同取酬，列入职业经理人序列。运输主业的技术岗位另有一套等级，司机、调度、检车等工种按技能等级叙级，与行政品级互不折算。《全国官员名录·卷四十一》于本公司列企业名称与董事长、总经理两栏，上述高管姓名据该卷登记。

## 主要职能

- 经营全国铁路路网，承担线路、桥隧、信号与站场的养护、扩能与安全管理。
- 组织客运开行，按[[国家铁路总局]]排定的运行图发车，承担票务与站车服务。
- 组织货运与重载运输，承担大宗物资、集装箱与重点保供物资的运输。
- 承担新线建设与既有线改造，按[[五年规划]]的项目库申报与实施。
- 承运[[欧亚大陆桥]]的过境班列，与[[帝国海关总署]]对表时刻与换装。
- 编制年度经营预算与投资计划，报国资委核定，收益按规定上缴。
- 执行国家核定的运价，申报成本核算资料，配合价格主管机关的审核。
- 接受[[帝国审计院]]的财务审计与[[国家监察委员会]]的公职监察。

## 运行机制

公司与[[国家铁路总局]]的分工写在「表」与「车」两个字上。总局管全路一张运行图，分界口按分钟交接，调度指挥中心统一指挥；公司按表开车，管车、管人、管设备。公司可以申报加开、申报调价、申报新线，运行图的最终排定权在总局。这条界一松，八州就会各修各的轨、各定各的价，全国一张网随即瓦解。

公司与[[交通运输部]]的关系在综合交通的口径上。公路、水运、民航与铁路的衔接、枢纽的共建、多式联运的规则，由交通运输部统一协调；公司的枢纽改造方案须与部分对接，集装箱中心站与港口支线的接口按统一标准建设。[[国家发展改革委员会]]在规划一端把关，新线入规划、项目立项、投资规模核定，均经该委汇总平衡。

国际班列另有一套对表机制。[[欧亚大陆桥]]的班列时刻、口岸换装能力与关务手续，由公司与[[帝国海关总署]]逐条对接；口岸一堵，内陆几个州的账都要重排，因此班列的时刻表按季度会商一次，遇口岸施工或季节性问题随时加会。这条线上，公司管运力，海关管通关，两边共用一张时刻表，各签各的字。

资本与赈济两条线并行。国资委管产权、管董事、管考核，考核指标集中在资产保值、主业集中度与收益上缴三项；以工代赈的项目由[[财政部]]认账，工役与沿线地方配套一并核算，投资与赈济在同一本预算里列支。铁路的投资规模大、回收期长，账算得清与算不清，往往决定一条线修与不修。

安全责任按线路等级分级落实。干线、支线、专用线各定巡检周期，重大隐患限期整改，整改结果报总局备案；整改方案由总工程师杨秉清签署，技术标准与验收口径一并附卷。客运安全与危险货物运输另立专章，事故调查由总局牵头，公司配合取证并承担整改。安全一票否决写进每年的经营责任书，与资产保值、收益上缴并列为考核的硬指标。
