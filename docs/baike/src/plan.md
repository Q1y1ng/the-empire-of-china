## 概述
**五年规划**是帝国产业政策的主工具：政府制定 → [[国民议会]]审议 → 皇帝批准。规划编制组按《非常设机构通则》设立，期限 12—18 个月，组长为[[国家发展改革委员会]]主任。

## 已定口径

- **工具位置**：产业政策工具之一，与科研基金、政府采购、动态预算并列。
- **2026**：启动下一轮规划（2026—2030）编制；上一轮为 2021—2025。
- **与总理的关系**：规划主线由总理定调，他 2021—2025 轮把「AI 替代—财政转移—基本补贴」写成三段式。
