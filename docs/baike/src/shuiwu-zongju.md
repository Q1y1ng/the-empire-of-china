## 概述

**国家税务局**是帝国的中央税收征收机关，三品直属机构，局长屠有衡，副局长梧衡税，征管科技司司长简稽征。2026 年组织税收收入 52.20 万亿元，占财政收入 60.48 万亿元的 86.3%——帝国的账本有多大，第一行就写在它这里。

税政与征收在这栋楼里是两件事：**税率与税种归[[财政部]]，征收与稽查归税务局**。所以它能说「收不上来」，不能说「不该收」；反过来说，减税的口子也轮不到它自己开。[[三衡国策]]的「民生不误国」压到税制上，就是这条结构问题——资产税多收一分，劳动所得才能少收一分。

## 税源结构（2026）

| 税类 | 占比 | 金额（万亿元） |
| --- | --- | --- |
| 增值税 | 34.0% | 17.75 |
| 所得税（企业＋个人） | 31.0% | 16.18 |
| 资产税（房产、遗产、资本利得） | 12.0% | 6.26 |
| 资源税 | 9.0% | 4.70 |
| 关税 | 7.0% | 3.65 |
| 其他（消费税、印花税、环境税等） | 7.0% | 3.65 |

> 资产税占 12%，是帝国税制「重资本、轻劳动」的标志：基本居住房屋低税甚至免税，累进落在多套房产、豪宅、商业地产与大型庄园。

## 征收与边界

- **垂直**：八州税务局四品、省分局五品，人财物归中央，州政府只协调、不代管
- **代征**：关税由[[帝国海关总署]]代征，计入税收总量，考核各算各的
- **非税**：8.28 万亿元走财政专户，罚没与行政事业性收费不列本局收入
- **口径**：税源分母一律用[[国家统计局]]的法定口径，税务局不自立分母
- **直隶州**：中央直接控制农业税、商税、盐税与粮食相关税收，核心区高比例直供中央

> 「税不是收出来的，是长出来的。地里没有，征管科技也变不出来。」
