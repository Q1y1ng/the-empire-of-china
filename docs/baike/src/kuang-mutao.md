## 概述

**邝慕陶**（1957年— ），江南州湖南省湘阴县人，现任[[中央办公厅]]主任兼[[中央政治局常务委员会]]秘书长，二品副国级，[[中央政治局]]委员。其[[中央政治委员会]]委员资格属**选举委员**：随[[全国政治代表会议]]选举其担任现职而取得；本届以续任者身份经政代会确认。中央办公厅与政治局秘书处是一套机构、两个名号：办公厅管机关运转与文务，秘书处管常委会的会务、议程与决议落实，人事与编制不分家。

他是科举行政科出身的内廷干部：1975 年入中央办公厅秘书局任科长，1987 年任办公厅副主任，1999 年转任国务院副秘书长，2010 年回任办公厅主任兼政治局秘书处秘书长。中间那十一年在[[国务院]]，使他成了政府与内廷之间最省事的一条通道——政府的请示从他这里进，批示从他这里出，中间不设第二道解释。

2026 年 3 月的《政制精简案》把常委会改为九人，最高法院、最高检察院、帝国审计院三长退出中枢、改归口领导；他与另三名原常委一同由政治局常委转任政治局委员，品级降为二品，仍兼常委会秘书长。他的工作可以概括成一句话：帝国的信息在他手上过一道，什么文件先到、什么文件后到，都在他排的那道顺序里。

## 生平

### 早年与求学（1957—1975）

生于湖南湘阴。湘阴在洞庭湖南岸，科举传统深厚，行政科是帝国取士最正的一途——行政科出身的官员，多从文书、簿记与条例入手，先在机关里学会办事，再谈主张。

他走的就是这一途。帝国三级科举自 1726—1735 年制度化，此后一直是社会流动的主渠道；行政科的课业以律例、簿记、公文程式为主，考取后按序补官。1975 年，他入中央办公厅秘书局任科长，从此没有离开过文务系统。

### 入仕与历练（1975—1999）

中央办公厅秘书局管三件事：公文的收发编号与时限、会议的材料与纪要、批件的转递与归档。他从科长做起，1987 年任办公厅副主任，十二年里把这三件事的顺序摸清了：一份文件在什么位置停多久，取决于它在谁的桌上；一份纪要怎么写，取决于谁的名字排在第一行。

1986 年宪制定型后，中央与地方的事权划分逐渐固定，报批的层级、会签的部门与文号的规则随之成套。他在这一期主持了办公厅的公文规程修订：退文只写一行理由，转发不改原文，跨部门事项先在办公厅对一遍口径再上会。

1999 年转任国务院副秘书长，在政府系统做了十一年。这一段经历有两项用处：一是熟悉了政府部门报批的实际节奏，二是让他此后成为两套系统之间的通用接口。

### 主政内廷（2010—2026）

2010 年，他接张之澄的任，回任中央办公厅主任兼政治局秘书处秘书长。办公厅的职能分五块：文务、会务、决议落实、机要与统筹。他在这一任上把五块各自立了规矩：

文务按「编号—时限—归档」三段办，退文只写一行理由；会务按议程排，有争议的排在前面，必然通过的排在后面；决议落实分解成督办单，按季度回告；机要管密码、印信、档案与要害部门值班；统筹则是在上会之前把跨部门的口径对一遍。

[[中央政治委员会]]不设独立会务编制，每年春季的全体会议由办公厅承办，文号「政发〔年〕X 号」由此发出——《中央政治委员会组织法》把这条写成了一句「会务由中央办公厅承办」。2026 年 6 月第九届议会选举后，首届九名常委与二十七名政治局委员以「政发〔2026〕9 号」公布，文号即出自他这一层。

### 现职（2026— ）

2026 年 3 月以后，政治局常务委员会九人，不设委员长，皇帝为常委之一并召集会议，议程由皇帝确定；秘书长承办会务，议程的材料、次序与时限由秘书处排。他同时以政治局委员身份分管文务系统，中央办公厅的副主任柯定远（常务）、白慎行与机要局局长屠存简、秘书局局长张之涣分任其职。

现职之下，他管的是三道关：进来的文件先过口径，上会的材料先过格式，出去的批件先过编号。三道关都不作判断，只保证判断发生在该发生的那一层。

## 主要工作

- **主持公文规程**：公文按「编号—时限—归档」三段办，退文只写一行理由，转发不改原文；跨部门事项先在办公厅对一遍口径再上会，防止同一件事在两张表上出现两个数。
- **排定会议议程**：常委会与政治委员会的议程、材料与纪要由秘书处排；有争议的议题排在前面，必然通过的排在后面，会议按议程结束，不拖到饭点。
- **督办决议落实**：决议分解成督办单，按季度回告办理进度；逾期未回的，办公厅以书面形式催办一次，催办记录入档。
- **承办政治委员会会务**：依《中央政治委员会组织法》，政治委员会全体会议的会务由办公厅承办，「政发」文号由此发出；2026 年「政发〔2026〕9 号」公布首届九名常委与二十七名政治局委员，即由本厅经办。
- **管理机要与印信**：密码、印信、档案与要害部门值班归机要局；文件的等级、流转范围与解密时限按年度核定一次。

## 人物风格

| 场合 | 表现 |
| --- | --- |
| 批文件 | 只加一行批注，写完签名；不复述、不评价、不给建议 |
| 会上被问 | 问什么答什么，不问的一句不提；答完即止 |
| 排议程 | 有争议的排前面，必然通过的排后面；从不替人调整先后 |
| 遇口头传话 | 一律要求写成书面；没写的一律答「没收到」 |
| 对下属 | 只说「几时到」，不说「尽量」；时限写进督办单才算数 |
