## 概述

**帝国国际发展合作署**是外交与国际事务系统里的直属机构，三品州部级，署长凌志远，副署长广济外。帝国自认是「商业型全球强国」而不是「殖民征服型全球帝国」，援外因此不带领地要求：给出去的是路、港、电、学校与医院，换回来的是商路上的一段长期通行。

它的钱与账都是单列的。国家贸易的利润**全部收回中央**；私人贸易利润归私人、税归中央与地方；护航费入海军专项财政。援外预算也照此办理——项目款由[[财政部]]按年拨付，本署只管花在哪个项目上、花完有没有验收，年末由[[帝国审计院]]对账。

## 与四家的分工

| 事项 | 归谁 | 边界 |
| --- | --- | --- |
| 条约、协定、国书 | [[外交部]] | 本署只报项目清单，不签文本 |
| 重大跨国基建的政治排序 | [[中央外事委员会]] | [[欧亚大陆桥]]这类工程，工期与还款表另归国家发展改革委员会 |
| 受援国的商号与侨民 | [[帝国海外事务总局]] | 出事先找总局，本署只管工程本身 |
| 预算、审计与清算 | 财政部、帝国审计院 | 一年一清算，项目烂尾即停拨 |

## 三条不做的事

- **不做殖民地**：铺开的是租借贸易站、商业港口与外交据点，不是领地；全球六大对外港口、三大陆路口岸之外，都按这一条办
- **不干涉内政**：不主导他国战争，不替人换政府，援助附的是验收标准，不是政治条件
- **不越外交**：政治口径由[[中央外事委员会]]与外交部定，本署在别人定好的方向上选项目、算工期

因此本署的档案室里最厚的不是合同，是**验收单**：一条路修到哪、一座码头能靠多大的船、一所学校的教师从哪来。援外这件事在帝国从来不是恩惠，是一笔要能说清楚去向的支出。

> 「援助不是把钱送出去，是把一条路修到能走车。」
