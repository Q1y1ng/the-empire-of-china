## 概述

**五重合法性**是中华帝国关于皇帝统治资格的正式理论，指血统、历史、宪制、能力、绩效五种来源叠加并用，共同构成皇位的正当性基础。这套说法出自《中华帝国世界观总设定 v2.0》第二十一编「合法性理论」，是该编的核心段落，回答的是一个具体问题：一个家族凭什么在三百年间持续占据国家最高政治职位。

五层叠加之后的结论写在同编首段：皇帝为国家最高政治职位的世袭承担者。这个表述的关键在「承担者」三字——最高政治职位属于国家，皇帝是这一职位的承担人；资格来自世袭，行使依于宪法。宪制一层由此与血统一层互为条件：血统给出「谁来做」，宪制给出「怎么做」。

制度地位上，五重合法性是[[皇权—制度—绩效循环]]的理论底座，也是[[帝国宪法法院]]在处理皇位继承争议时援引的观念依据。适用面首先及于皇位与皇统，其次及于国家统一——总设定把统一合法性另列一层，理由是：在横跨东亚、内亚与东南亚的超级国家中，分裂意味着战争与经济崩溃，中央统一因此具有独立的历史合理性。

## 定义与内涵

**字面义**。「五重」指五种来源并列，「合法性」指被统治者对统治资格的承认。五重之说区别于单一来源论：血统论只答「谁生下来该做」，绩效论只答「做得好不好」，五重之说不承认其中任何一层可以单独成立。

**制度义**。五层各有对应的法条与制度装置，条列如下：

| 层 | 内容 | 制度装置 |
| --- | --- | --- |
| 血统 | 皇室继承传统 | 《皇位继承法》嫡长子优先；废立须经中央政治委员会备案 |
| 历史 | 1700 年开国、明王朝正统继承、三百余年国家连续性 | 皇宫、城墙等国家象征；皇储须通晓本朝制度史 |
| 宪制 | 皇权依法行使，受宪法、法律、议会与司法确认及约束 | 宪法十章四十二条；七部组织法；[[帝国宪法法院]] |
| 能力 | 皇储经国家筛选与长期培养 | 三层筛选：皇室提名—国家评议—皇帝最终确认 |
| 绩效 | 安全、教育、医疗、养老金、基本补贴、住房、就业、基础设施、科技 | 年度预算与议会审议；[[全民基本补贴]]等可核对支出 |

**实践义**。五层在实践中分量不同。血统、历史、宪制三层随制度存续而自动成立，能力一层在[[皇储制度]]的培养期内逐段检验，绩效一层每年重新结算一次。总设定第二十一编因此把评价落点写得很窄：对皇帝的评价落在「这位皇帝治理得好不好」，即施政成效本身。这一句同时说明了五重合法性的运行方式——前四层给资格，第五层给续期。

## 历史渊源

血统与历史两层的源头在开国。1700 年，朱承乾以治理能力自明末大乱中胜出，建立中华帝国，国号与皇室由此确立；此后三百余年，皇位在同一皇统内传承，皇宫与城墙成为国家连续性的物化象征。编年史把 1805 年记作一个节点：当年完成帝国史上第一次制度化皇位交接，皇储经政治学院、基层、地方、省、州、中央部门与军财法监察轮训后，经中央政治委员会考核继位。能力一层自此有了可循的先例。

宪制一层在 1986 年定型。当年《中华帝国宪法》颁布，第三条写定「皇帝为国家最高政治领导人；皇权为国家所有，皇帝依宪法行使」，第六条写定皇帝兼任中央政治委员会主席与中央军事委员会主席，第七条列举六项元权力，第十条列出三项禁止。皇权由「皇帝个人拥有国家」转为「皇帝依宪法领导国家制度」，[[大革命（第二次建国）]]的历史意义即在此处。

能力一层在 1984 年获得单行法依据。《皇位继承法》第三条规定三层筛选——皇室提名、国家评议、皇帝最终确认，政治委员会确认后公告；第四条规定培养路线为国立中央政治学院、基层、地方、州级、中央部门，再经军事、财政、司法、监察轮训。宪法第四十二条补上最后一环：皇储继位前须完成中央政治学院与[[皇储国政教育院]]培养、担任过中央政治局委员，继位由宪法法院院长监誓。

## 制度内容

五重的构成要件与检验方式如下。

1. **血统**：继承顺序嫡长子优先；皇帝得废立，废立须经中央政治委员会备案。资格要件为皇室成员、年满十八、无重大违法记录、通过资格考核。
2. **历史**：以 1700 年开国、明王朝正统继承与三百余年连续性为内容；皇储须通晓本朝制度沿革，这是「历史」一层在培养环节的落点。
3. **宪制**：皇权依宪法行使，六项元权力有明文；皇帝对议会法案有否决权，须于十日内书面说明理由，议会得以三分之二多数再议。
4. **能力**：三层筛选加完整培养路线；宪法第四十二条把「担任过中央政治局委员」写成继位的硬条件。
5. **绩效**：以治理成果为内容，年度预算、议会审议与审计报告是它的检验场。
6. **统一**：另列一层，指国家统一本身构成正当性来源；总设定把它与五重并列，注明「统一合法性」。

六条之中，前五条为五重本义，第六条为附加层。总设定另有一份「制度理论解释」把来源细分为九项（王朝正统、历史连续性、国家统一、皇室、宪制、政治参与、治理绩效、社会福利、皇储能力筛选），九项是五重的展开，层级仍归五重。

## 运行与实例

**其一，皇储培养路线。**皇帝[[朱昭文]]走的是皇储考核正途：政治学院制度系毕业后，先下陕北富县任副县长三年，此后历任京畿州委政策研究室副主任、延安行政区副区长、京畿州委副主席兼长安市长，2012 年入中央政治局任中央办公厅副主任，2015 年继位改元继文。这条履历把能力一层写成可查的年份与岗位，也让「担任过中央政治局委员」这一硬条件有例可循。

**其二，2026 年的绩效证据。**继文十一年，绩效一层最容易被看见：[[全民基本补贴]] 1,030 元／月／人、年度 22.00 万亿元；国内生产总值 360.0 万亿元，全球占 40.0%；人均预期寿命 82.8 岁，高等教育毛入学率 76%。这些数字属于绩效一层的证据，五层之中只有绩效需要每年重新挣一次。

**其三，外部学界的读法。**《世界近代史推演》列过一张对照表，记西方学界对五层的常见误读：血统被读成「就是君主专制」，历史一层被忽略，宪制被读成「宪法是装饰」，能力被读成「还是看血统」，唯独绩效一层「无法否认」。帝国学界的回应被记在同一处：「你们用选举解决合法性，我们用绩效；你们用政党轮替纠错，我们用监察审计宪法法院加皇权冻结程序。工具不同，问题相同。」

## 意义与评价

官方口径把五重合法性定位为「叠加式正当性」：五种来源互不替代，任何一层失守都会在其余四层留下痕迹。总设定第二十一编的表述是，普通人支持帝国，理由在于「这个制度确实能够让国家运行得很好」；皇室的威望来自治理成果，治理成果又回过来支撑皇权，[[皇权—制度—绩效循环]]即由此闭合。

学界一般将其概括为「绩效与选拔并重的世袭制辩护」，并指出它的说服力集中在一处：五层之中四层可以核验——血统查谱牒，历史查编年，宪制查条文，能力查履历，绩效查预算。批评意见认为，绩效一层的评价标准由在位者参与设定，独立性与可比性有限；支持意见指出，预算、审计与议会审议三道程序使绩效无法单方自评，[[皇权冻结程序]]的 80% 门槛则表明制度为极端情形留了出口。
