## 概述
朱昭文，帝国今上，穆宗长子，1976 年生，2015 年继位改元**继文**；兼任[[中央政治局常务委员会]]委员长、议会常委会主席、军委主席，是国家连续性、历史传统与最终仲裁权的象征核心。

## 已定口径

- **皇储考核正途**：政治学院制度系毕业，先下陕北富县任副县长三年，不直接入部委。
- **履历**：2001 年京畿州委政策研究室副主任 → 2006 年延安行政区副区长 → 2010 年京畿州委副书记兼长安市长 → 2012 年入政治局任中央办公厅副主任 → 2015 年继位。
- **风格**：问得极细、答得极短，惯以「照制度办」四字结案。
- **与总理的关系**：以「照制度办。钱尤其要照制度办」定调政府系统；人事上只看考核，不问圈子。
