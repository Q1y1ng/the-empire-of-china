## 概述

**皇储制度**是帝国处理世袭与能力矛盾的方案：皇位仍按嫡长子优先继承，但「皇子」不等于「储君」。皇储必须接受长期、系统、严格的国家治理教育与政治历练，走完国立中央政治学院→基层→地方→省→州→中央部门→军事财政司法监察轮训的整条路线。

它要解决的是世袭制最大的风险——继承人的能力不可选。帝国的回答不是取消世袭，而是把继承资格与储位分开：皇室成员享有继承资格，但不享有自动成为皇储的权利。培养与考核因此都在公开制度里进行，皇储到三四十岁才正式成为继承人，非常正常。

## 三层筛选与淘汰

| 层 | 主体 | 作用 |
| --- | --- | --- |
| 一 | 皇室提名 | 提出储位人选，血缘只给资格 |
| 二 | 国家评议 | 以国家名义考核能力，避免皇帝一人偏私 |
| 三 | 皇帝最终确认 | 保留最终决定权，政治委员会确认后公告 |

- **淘汰**：阶段性考核不合格者退出皇储竞争；能力明显不足者可依法取消皇储资格
- **落选不等于除籍**：皇帝子女分为皇储、皇储候选人、普通皇室成员三档，落选者保留皇室身份
- **评价标准**：考核结果不是「皇帝英明神武」，而是「具备履行皇帝职责之能力」
- **继位门槛**：须完成中央政治学院与皇储国政教育院培养，且至少担任过一定时期的[[中央政治局]]委员

## 与皇权—制度—绩效循环的关系

皇储制度是[[皇权—制度—绩效循环]]的输入端。正向循环是：皇权 → 政治领导 → 制度运行 → 国家治理 → 经济与社会发展 → 公共利益 → 合法性增强 → 皇权稳定 → 继续改革；负向危机则从制度僵化开始，经治理能力下降到皇室威望下降。皇储训练中专门设有「反方政府」与危机模拟，正是为了在源头压住负向循环。
