## 概述

**法律产生流程**的起点是五种议案来源：皇帝提出、中央政府提出、中央政治委员会提出、议会提出、地方委员会联合提出。五条入口，但进入[[国民议会]]之后只有一条通道，议案不能绕过专门委员会直接上会，也不能以内部文件代替立法。

通道的收口有三处：议会表决、皇帝签署、宪法法院审查。一般法案以过半数通过，宪法修正案须三分之二多数；皇帝可以否决，但必须于十日内书面说明理由，议会得以三分之二多数再议。三道门槛各管一段，标准并不统一。

## 从议案到生效

| 步骤 | 规则 |
| --- | --- |
| 专门委员会审议 | 议会九个专门委员会先行审议，可要求官员到会说明、调阅不涉密材料 |
| 议会表决 | 一般法案过半数；宪法修正案三分之二多数 |
| 皇帝签署 | 十日内否决须书面说明理由；议会三分之二再议通过后生效 |
| 公布 | 议会审议／公布，进入政府执行环节 |
| 合宪性审查 | [[帝国宪法法院]]裁决法律合宪性，裁决为终局 |

## 与政委会、宪法法院的关系

- **政委会**：可提出法律案；修宪须经其三分之二确认；《中央政治委员会组织法》的修正同此程序
- **宪法法院**：裁决法律合宪性、中央与地方权限争议、机构间权限争议；机构间争议由宪法法院裁决，政委会不代裁
- **位阶**：宪法＞组织法＞部门法＞行政法规＞地方条例；下位法抵触上位法者无效，由宪法法院宣告
- **同位阶**：特别法优于一般法，新法优于旧法

流程真正约束的是「谁最后签字」。皇帝能否决，但不能不写理由；议会能再议，但要凑到三分之二；政委会能确认修宪，但不能代替法院裁权限——三道锁各管一段，任何一道都不能被另一道绕过。
