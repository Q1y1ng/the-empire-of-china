## 概述

**中央政治局常务委员会**是帝国最高政治协调与决策核心，共 **9 席**，不设委员长：[[朱昭文|皇帝]]是**常委之一**，以[[中央政治委员会]]主席身份召集并主持常委会会议，**议程由皇帝确定**。常委**不排序**，按职务分工各管一线，重大事项集体议、皇帝定。

它不是行政机关，不直接管事；它管的是「谁跟谁对不上」——把政府、军队、纪律、监察、政法、财经、组织、宣传八条线的边界在开会时对齐。

## 三长归口：不列席，但都有人代表

| 机构 | 归口到 |
| --- | --- |
| 最高法院、最高检察院 | 中央政法委员会主任（政治工作与干部协管；个案不受干预） |
| 帝国审计院 | 议会常务委员会（主席由皇帝兼）——审计院本来就对议会负责 |
| 帝国宪法法院 | 无归口，独立 |

需要三长陈述时，开**常委会扩大会议**，或由对应常委**单独会见后传达**——**不设常设列席**。

## 议事规则

- 不设委员长：皇帝以政治委员会主席身份召集会议，与其他八人同为常委，无排序
- **皇帝缺席时（出访、病重、皇位空缺），由国务院总理代为主持**；皇帝保留最终决定权，可事后否决
- **六人到会方得开会**；到会者过半数通过；因缺席出现平票时由皇帝裁定
- 常委会向政治局全体会议报告工作，政治局向政治委员会报告工作
- **六职不兼**：纪委主席、监委主席、审计院长、法院院长、检察长、宪法法院院长，一人只得任其一（《政治局组织法》第四条）
- 纪委与监委分别向常委会汇报，也可分别单独向皇帝汇报

## 与总理的关系

[[李先念]]是常委会中唯一的政府系统席位，[[曾山]]的财经委是第二个经济口。他的三条线要向常委会报：**赤字率**（按月）、**五年规划主线**（年度）、**重大项目的还款表**（逐项）。反过来，常委会定下的盘子，由他带回[[国务院]]拆成部门预算。

> 继文改制后一品正国只有九个位子：**常委会九席即全部一品**，皇帝的议长、军委主席身份为兼任，不另计。「出核心即降级」是这次改革的卖点——席位不是终身的，待遇不是世袭的。
