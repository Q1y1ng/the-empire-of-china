## 概述

**街道委员会**是帝国官府的最末端，也是「官」与「吏」的分界线。主任是一级吏长，正科级，**由居民直接选举产生，一届五年**；副主任二级吏长，科室负责人二级，办事员三级——[[十品官阶]]到这里就断了，十品以下是吏，不是官。

街道之下还有社区委员会，但社区既非官也非吏：主任 1 名、委员 5～7 名，居民直选、三年一任，配便民服务站与社工编制。所以帝国的基层是两截——街道是国家机关的最后一节，社区是居民自己的组织。[[六级行政体系]]写的是前六层，社区不在这六层里。

## 一个街道的编制

| 机构 | 职能 |
| --- | --- |
| 政务办公室 | 综合协调、文秘 |
| 政治工作科 | 组织、宣传、统战 |
| 社会事务科（民政） | 低保、优抚、婚姻 |
| 卫生健康科 | 基层卫生、防疫 |
| 综合治理办公室 | 综治、信访、调解 |
| 退役军人服务科 | 退役服务 |
| 网格化服务中心 | 网格管理 |
| 社区服务中心 | 便民服务 |

## 派驻机构不占编制

- 派出所、税务所、市场监管所、司法所由上级机关垂直派驻，干部编制不在街道
- 街道巡回法庭是司法纵向体系的末梢，审的是家长里短，判的是街坊之间的事
- 一个街道辖区 3 万～15 万人；全国乡镇、街道 44,600 个（推演）

## 官与吏的那道门

吏经事务考试或聘任产生，官经科举—[[政治学院]]—选举产生，两条轨不自动换轨。吏中优秀者可以升官，但要考：入职（≥22 岁，吏三）→ 满 2 年升吏二 → 满 3 年考核优秀升吏一 → 吏一任满一届（5 年）＋州级考试＋省级政治学院一年＋基层履历 2 年 → 转官十品。[[吏制]]的分量就在这里：它是阶梯，不是椅子。

> 「街道主任是选出来的，官是考出来的；两件事不能混。」
