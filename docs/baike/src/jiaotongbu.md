## 概述

**交通运输部**是[[国务院]]科技与基建系统的组成部门，三品州部级，管公路、水运、民航、邮政四类的行政归口：线路怎么定、标准怎么立、安全怎么查。部长[[滕代远]]，粤汉铁路工人出身，从扳道房做到调度台，2001 年任铁道部副部长，2016 年随「铁水公空」合并转入本部，是合并后的第二任部长。

它管的并不是「所有的交通」。铁路的科技与基建在[[国家铁路总局]]，航天在[[帝国航天总局]]，两家都是科技与基建系统的直属机构，与本部没有行政隶属。这条分界在部里被叫作「路水空邮归部、铁轨归局」：修什么由[[国家发展改革委员会]]排，钱由[[财政部]]给，账由[[国民议会]]的[[资源环境与基建委员会]]审。

## 归口与分家

| 事权 | 归口 | 2026 口径 |
| --- | --- | --- |
| 公路 | 本部公路局 | 国道网、省界接口、养护考核 |
| 水运 | 本部 | 六大对外港口：河内、珠三角、长三角、环渤海、首尔湾、海参崴 |
| 民航 | 本部 | 机场布局与航线时刻 |
| 邮政 | 本部 | 普遍服务与网点覆盖 |
| 铁路 | [[国家铁路总局]]（吕正操） | 直属机构；营业里程 19.8 万公里、高铁 6.4 万公里 |
| 航天 | [[帝国航天总局]] | 军民结合，与本部无隶属 |

分家的理由只有一条：铁路是唯一自成运行图、自成调度、自成院校的行业，把它并进部里的司局，等于让一张图去管另一张图。国铁总局局长与部长同为三品，两家只能分工，不能代管——这也解释了为什么「铁水公空合并」之后，铁始终是合并进来又分出去的那一半。

## 运行图与口岸

[[欧亚大陆桥]]的国内段，发改委给通道与投资，本部给口岸换装的时间与回程货源的组织方案。部里验收一条通道的标准不是里程，而是**口岸换装能不能在两小时内完成**：换装拖一小时，整条线的时效承诺就作废。

> 「图上排不进去的，外事上就不要答应。」
