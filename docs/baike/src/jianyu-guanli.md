## 概述

**国家监狱管理局**是[[国务院]]政法与公共安全系统的直属机构，三品州部级，局长夏侯持正，副局长窦狱正，管刑罚执行与监所管理：收押、管束、劳动与教育、减刑假释的材料报送、刑满释放与安置衔接。它手里有一道高墙，没有一支法槌——**判决不在这里，改判也不在这里**。

业务归口[[司法部]]（[[史良]]），归口不代管：部里定执行标准、场所规范与干警培训口径，本局主官同为三品，具体到某个监所怎么管，部里不替它拍板。这条安排的用意，是让执行这一段留在行政系统内，同时把裁判与监督留在系统外。

## 三段程序，三个机关

| 环节 | 谁定 | 本局做什么 |
| --- | --- | --- |
| 定罪量刑 | [[最高人民法院]]与四级法院 | 凭生效判决收押，判决不明退回问 |
| 刑期变更（减刑、假释） | 法院裁定 | 出考核材料与评审意见，不自作决定 |
| 执行监督 | [[最高人民检察院]] | 开放场所、卷宗与监控，接受检查 |
| 释放与安置 | 本局会同地方 | 出释放证明，衔接安置与就业 |

- **与法院**：判决书写几年就执行几年；刑期折抵算不清、文书不齐的，一律退回补，不自行推定。
- **与检察院**：检察院管监狱、看守所与社区矫正的合法性检查；本局不设「内部复议」来挡这条线。
- **与[[公安部]]**：抓捕与侦查是公安的事，收押之后是监所的事；同一个人在两处之间只走一张移交单。
- **与[[国家监察委员会]]**：公职人员职务犯罪另走监察程序，本局只接生效判决的执行那一段。

## 高墙内的两本账

一本是**时间账**：刑期起算、折抵、减刑、假释、刑满，每一格都要有文书支撑，错一天就是错一天。一本是**人账**：劳动、教育、医疗、通信与探视，按规范走，不按人情走。两本账每年由[[司法部]]对一次，对不上的当场改，不留到第二年。干警的纪律问题由[[中央纪律检查委员会]]与监委按公职人员口径查，本局不搞内部消化。

> 「高墙里面只有两种时间：判决写的，和考核记的。」
