## 概述

**州议政会**是州级议会，会期制、非常设——它不是一年三百六十天坐在那里的机关，而是按会期集合、议完即散的代表机构。主席由[[州人民政治委员会常务委员会]]主席兼任，京畿直隶州是[[宁崇岳]]（二品，兼政治局委员）。

它的位置很明确：这是「地方人民参与地方治理」的口子，不是地方主权机关。帝国是[[中央集权型单一制]]，地方议会没有主权性立法权，本质上是国家行政体系在地方的制度化组织；议政会能审预算、能质询、能调查、能提建议，唯独不能决定州长——州长由中央任命，地方考察，议会监督。

## 会期与组成

- 非常设：按会期集合，闭会期间由常委会与秘书长办日常事务
- 主席兼任：州议政会主席即州人民政治委员会主席；京畿[[宁崇岳]]、华北[[冯秉常]]（各三品本职，京畿按二品计）
- 京畿规模不大：直隶州议政会由各市、各区代议人组成，不逐一列名；秘书长白清议（三品）
- 选举分层：街道办级直接选举，区级由代议人选举，市级及以上间接选举
- 议政会与州议会常委会是一套机构两个层面：常委会主席兼议长，秘书长管文书与会期

## 能做什么、不能做什么

| 能做 | 不能做 |
| --- | --- |
| 审议州预算，盯钱怎么花 | 决定州长（中央任命） |
| 监督粮政、水利工程 | 单方面罢免州长 |
| 就州级政策展开讨论 | 制定违背中央法律的地方基本法 |
| 对州政府提出质询 | 拒绝执行中央政策 |
| 组织地方公共事务调查 | 自行外交、建军、发行货币 |

## 一本账的两道关

州议政会审的是州预算。省一级的预算另走一条线：省人民政治委员会常务委员会审议、州长批准——审议权在常委会，财政审核权在州长，议政会盯的是钱花得对不对，不是钱该不该花。[[国民议会]]批的是国家的钱，州议政会批的是本州的账；两者不是上下级，是各管一层，这也正是[[中央集权型单一制]]在预算上的写法。

> 「议政会管账本，不管官帽。」
