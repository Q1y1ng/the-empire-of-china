## 概述

**强监督**是八个关键词中「监督」一环的执行口径，防的是**层层过滤的信息与利益网络**。它与[[强中央]]、[[强纠错]]并称「三件套」。

## 装置

纪委（党的纪律）、国家监委（国家监察）、帝国审计院（财政穿透）三条纵线；议会质询、预算审议与调查权；御史与巡视定期评价。四类装置互不兼任：纪委与监委主官不得互相兼任，审计院归口议会常委会。

## 边界

强监督只查「权与钱」，不代替司法裁判；案件进入司法程序后，监察机关只提供证据与移送，不作出判决。
