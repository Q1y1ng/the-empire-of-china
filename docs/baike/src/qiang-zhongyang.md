## 概述

**强中央**是帝国政治哲学八个关键词中「统一」一环的执行口径，指中央对**人事、财政、军事、监察**四条线的集中统一领导。它与[[强监督]]、[[强纠错]]并称「三件套」：强中央防分裂，强监督防腐化，强纠错防僵化。

## 装置

中央政治委员会（人事与战略）、中央组织委员会（干部与轮岗）、财政部与中央财政经济委员会（财政）、中央军委（军事）、国家监察委员会与中央纪委（监察）。四线之上是皇帝主持的中央政治委员会全体会议。

## 边界

强中央不等于「集而不分」：财政分账、州权清单、议会同意权、宪法法院裁决权同时存在；强中央只保证四条线的最终决定权在中央，不替代地方的日常治理。
