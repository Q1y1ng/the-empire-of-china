## 概述

**任职资格**是帝国对高级职务设的履历与品行门槛：**先过门槛，再谈选举**。资格为被选举或被提名的前置条件，与任命无关——门槛不过，政代会不选、议会不同意、政委会不提名。

帝国无政党，没有党龄、党职可以筛人；于是把「干过什么」写成明码门槛：干过几年、在哪条线上干过、有没有带过队伍。

## 八类职务的门槛

| 职务 | 门槛 |
| --- | --- |
| 外交部长／外事委主任 | 5 年以上外交外事经历、通晓一门外语 |
| 财政部长／央行行长 | 5 年以上财政金融经历 |
| 国防部长／军区司令 | 10 年以上军事经历、现役 |
| 教育部长 | 5 年以上教育管理或教学 |
| 卫生部长 | 5 年以上医疗卫生管理或临床 |
| 政法委主任 | 5 年以上政法经历 |
| 州委主席／州长 | 5 年以上省级或州级治理、跨省经历优先 |
| 所有高级职务 | 无违法犯罪记录、无未撤销处分、政审（直系三代）、财产申报合规 |

第八行是通行条款：四项有一项不过，履历再漂亮也不能上名单。

## 审核程序

1. 中央组织委员会初审履历与档案
2. 中央组织委员会＋中央政治委员会联合审核
3. 名单于选举前**公示七日**
4. 报[[全国政治代表会议]]备案

审核决定的是「谁能上名单」，不改变选举结果；公示期内的异议由中央组织委员会核办。

## 为什么门槛写在选举之前

资格门槛与[[选举委员]]是一套的两面：前者管「够不够格」，后者管「怎么进来」。先审资格、再投票，避免了「选上了才发现履历不够」的返工，也让政代会的选举集中在对人的判断上，履历核对在资格审查阶段完成。
