## 概述

**国家公务员管理总署**是[[国务院]]政务行政系统的吏治机关，三品直属机构，署长姜允直。帝国官制的下半段——[[十品官阶]]以下的[[吏制]]——由它一家管到底：谁能当吏、怎么考、怎么聘、怎么考核、怎么升到吏长，规程都出自这里。

它与管官的几条线刻意分开：官走[[科举制度]]—[[政治学院]]—选举，吏走事务考试与聘任；官的位置由[[中央组织委员会]]掌任用，吏的编制由本署掌规程。分开的意思是——**门有两道，台阶只有一级**：吏要成为官，必须重新考一次。

## 管什么（2026）

| 事项 | 本署定 | 不由本署定 |
| --- | --- | --- |
| 事务考试科目与合格线 | 定 | — |
| 聘任、政审与试用 | 试用一年 | 岗位由用人单位报 |
| 三等吏长序列 | 吏一正科／吏二副科／吏三科员 | 品级口径归[[十品官阶]] |
| 基层编制 | 街道办与乡镇（全国 44,600 个） | 经费归[[财政部]]预算 |

## 与组织委员会、与科举的分工

| 环节 | 国家公务员管理总署 | 中央组织委员会 |
| --- | --- | --- |
| 吏的入口 | 事务考试、聘任、试用考核 | 名册备案 |
| 官的入口 | 不介入 | 资格审查、提名、任用 |
| 吏转官 | 组织州级考试 | 考核与备案 |
| 档案 | 吏的履历与年度考核 | 官的考核档案（官籍） |

- [[科举制度]]定**资格**：帝国公职资格考试分文科、理工、行政三类，考完不授职
- [[政治学院]]养**政治官**：省级学 1～2 年，中央政治学院分初、中、高三级课程
- 本署管**事务序列**：不设课程、不发资格证，只认考试、聘任与规程

> 「官的门是考出来的，吏的门也是考出来的；只是两道门不通着走。」
