## 概述

**帝国军事法院**是军队系统内的审判机关，院长陈奇涵三品。它审现役军人的犯罪，审涉军的财产、军事秘密与装备后勤案件，也审军事指挥关系引出的刑责；它不审平民——平民的案子走最高人民法院那条四级线，这是帝国司法里一条不打折扣的分界。

军事法院不在普通法院的四级序列里——最高法院、州高级法院、省（市）法院、区（县）法院——但法律只有一部：法官依法独立审判，非经弹劾或法定事由不得免职，薪酬不得削减。军队可以有专门的法庭，不可以有专门的罪名，这一条是《司法制度改革法》写死的。

## 管辖的四条边界

| 案件 | 归谁 |
| --- | --- |
| 现役军人犯罪 | 帝国军事法院一审 |
| 军队财产、军事秘密、装备后勤刑责 | 帝国军事法院 |
| 平民犯罪、普通民事纠纷 | 普通法院四级序列（最高→州高级→省（市）→区（县）） |
| 外籍人士特别案件 | 特别法庭（另行设立） |
| 机构间权限争议 | [[帝国宪法法院]]裁决 |

## 三院一线

- 对[[帝国军事检察院]]：检方批捕、起诉，法院审判；两院分立，同一案件不同衙署，谁也不能代谁用印
- 对[[最高人民法院]]：机构在军委系统，法律适用与解释统一于最高人民法院；天子犯法与庶民同罪，军籍不是减刑的理由
- 对[[帝国宪法法院]]：审计院与财政部、监委与检察院这类机构间权限争议由宪法法院裁决，政治委员会不代裁
- 对[[中央军事委员会]]：编制、经费与人事归军委，审判业务不归军委表态

## 一份判决的分量

军队的判决要同时经得起两种目光：军内的服从与军外的法律。所以军事法院的文书一律写明法律条文，不写「依军令」；独立审判落在每一份判决的落款处——署名的是法官，不是长官。

> 「军籍改变管辖，不改变法律。」
