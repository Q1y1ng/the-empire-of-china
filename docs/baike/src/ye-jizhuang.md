## 概述

**叶季壮**，[[商务部]]部长，三品州部级。商务部管对外贸易、市场秩序与共荣圈内的结算安排，是帝国对外经济承诺落地的那一端。

## 业务重心

| 事项 | 2026 年口径 |
| --- | --- |
| 关税 | 3.65 万亿元，占税收 7.0%（含欧亚共荣体系优惠税率） |
| 出口秩序 | 与共荣圈成员国的配额与结算安排 |
| 对外采购 | 战略物资、能源与粮食的进口通道 |
| 投资协定 | [[欧亚大陆桥]]沿线贸易与投资协定的谈判配套 |

## 与财经系统的关系

商务部不批钱，但对外承诺的每一笔采购与投资，最终要回到[[财政部]]的预算与[[中央财政经济委员会]]的盘子里。

因此商务部的工作有两道约束：**上头有比例**（财经委定的总量），**下头有还款表**（[[李先念]]立的规矩，没有现金流测算的项目不得列入年度计划）。

## 与前任的关系

[[李先念]] 2001—2013 年任商务部部长，任内经历 2008 年金融危机与[[欧亚大陆桥]]开局。叶季壮接任后延续了那套做法：对外承诺先算结算通道，再谈规模。

> 商务部内部流传一句前任留下的话：「国际贸易最容易变成没有时刻表的空话——所以先问几时到。」
