## 概述

**复合职务体系**回答一个登记问题：一个人身兼数职时，写哪一个、按哪一级算。帝国的写法是把政治身份与国家职务并列书写，例如「中央政治局常务委员会委员／中央政府主席／京畿州州长」——两者属于两个不同的权力来源，不能互相替代。

计级口径只有一句：**品级按本人最高职务计**，即兼者从高。名录里的标准写法是「本职三品·入局高配二品」：前半句记本职，后半句记高配后的实际待遇，两项都留在名录上，不合并成一项。于是同一个人在不同场合会有两个数字，却始终只有一个身份——读名录的顺序是先看本职，再看高配。

## 登记口径

| 情形 | 名录写法 | 计级 |
| --- | --- | --- |
| 部长入政治局 | 二品（本职三品·入局高配） | 高配一级 |
| 政治局常委兼任部长 | 一品（常委兼任高配） | 按常委计 |
| 京畿直隶州州委主席兼政治局委员 | 二品（本职三品） | 按政治局委员计 |
| 军区司令授上将 | 三品·授上将者高配二品 | 职位三品、待遇二品 |
| 皇帝 | 不列品级（超一品） | 不纳入对照序列 |

## 兼任边界

- **可以**：皇帝＋中央政治委员会主席；政治局常委＋政府主席；州军区司令＋州人民政治委员会常务委员会委员
- **不应**：政府主席＋中央议会议长＋最高法院院长——直接破坏分权
- **禁兼**：政治局委员不得兼任纪委、监委、审计院、最高法院等制衡机关主官
- **宪法口径**：国家权力分政治、行政、立法、司法、监察、军事六系，不得兼任相互制衡之职

原则是那句「**人员可以高度重叠，机构权力不能高度重叠**」。同一个人可以兼任多个政治职务，但不能同时控制相互制衡的独立监督机关——这也是[[一品官限制]]能与兼任规则同时成立的缘故。
