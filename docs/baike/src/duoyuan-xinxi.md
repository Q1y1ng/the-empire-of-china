## 概述

**多源信息原则**是大革命后确立的信息规则：任何重大问题不能只依赖一个部门的数据。传统王朝的致命问题是皇帝不知道真实情况——报喜不报忧；帝国把这条教训写成一道程序要求，而不是写成一句劝诫。它的形式很硬：同一件事，必须由两个以上互不隶属的系统各自报一次。

它的目标不是让皇帝什么都知道，而是建立一套让他**尽可能**知道真实情况的制度，这比前者更重要。1972 年河套省瞒报粮食案是一次预演：地方虚报产量骗取中央补贴，被国安—审计联合查处；此后「信息—权力集团」作为正式罪名写入《监察法》。

## 八类信息源

| 信息源 | 交叉验证什么 |
| --- | --- |
| 国家统计 | 总量与结构：人口、产值、财政 |
| 议会调查 | 政策在地方的实际落地 |
| 审计系统 | 钱的流向与账目 |
| 纪委与监委 | 官员行为与利益网络 |
| 国安系统 | 跨区域、跨系统的异常 |
| 学术机构 | 独立研究与长期观测 |
| 社会舆情 | 不满在哪里积累 |
| 社会红利系统数据 | 补贴发放到人到户的记录 |

## 2026 落点

八条线在 2026 年各有落点：[[国家统计局]]的年度数据、[[国民议会]]九个专门委员会的调查权、[[帝国审计院]]驻八州特派办、[[中央纪律检查委员会]]与[[国家监察委员会]]的双轨、[[国家安全局]]的跨区报告、学术机构的长期观测、舆情汇总，以及[[国家自动化红利基金]]支撑的补贴到户记录。同一件事，往往能在四五个来源里对上。

> 「建立让皇帝尽可能知道真实情况的制度，比『皇帝什么都知道』更重要。」
