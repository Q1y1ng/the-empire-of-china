## 概述

**司法部**是[[国务院]]政法与公共安全系统的组成部门，三品州部级，管的是司法行政：律师与法律服务机构、监狱刑罚执行、司法行政保障，以及同法院、检察院的程序对接。审判权在[[最高人民法院]]，检察权在[[最高人民检察院]]——司法部一个字也不判。

部长[[史良]]。帝国的司法从行政系统里「半独立」出来：法院、检察院独立运作，天子犯法与庶民同罪；司法部留在行政这一侧，管的是独立司法之外的一应杂事——律师的执业资格、监狱的高墙、送达与执行的后勤。**司法行政 ≠ 审判，这是这一条最要紧的一句。**

## 司法行政与审判的分界

| 事项 | 归司法部 | 归法院／检察院 |
| --- | --- | --- |
| 律师 | 执业资格、事务所与执业纪律 | 出庭资格与庭审秩序 |
| 刑罚 | 监狱执行、释放与安置衔接 | 定罪、量刑、减刑裁定 |
| 程序 | 送达、执行协助、司法行政保障 | 立案、批捕、起诉、审判 |
| 法治 | 法律服务体系与法治宣传 | 司法解释与裁判统一 |

- 法院链：最高法院（院长[[董必武]]，常委）→ 州高级法院 → 省法院 → 市法院 → 区法院 → 街道巡回法庭；司法部不入这条链。
- 检察链：最高检察院（检察长[[谢觉哉]]，常委）→ 州高级检察院 → 省检察院 → 市检察院 → 区检察院。
- 权力边界之争（中央对州、议会对政府、法律对宪法）归[[帝国宪法法院]]（院长[[彭真]]）裁断，也不归司法部。

## 与监督线、议会的关系

[[国家监察委员会]]与[[中央纪律检查委员会]]管的是公职人员的纪律与职务违法，不代法院审案；两案相接处只在证据移交，司法部连这道门都不进。议会侧由[[监察与司法委员会]]（主任帅孟奇，三品）审议司法类法案、听取司法行政报告——它问的是制度跑得顺不顺，不问某个案子判得对不对。

> 「司法部的权力，止于法庭门口那道台阶。」
