## 概述
李富春，[[帝国审计院]]院长、政治局常委，对[[国民议会]]负责；做过厂长、司长、统计官，一辈子活在数字里。

## 已定口径

- **出身**：铁路与计划系统。
- **履历**：1974 年国家铁路总局计划处处长 → 1985 年经济发展部综合司司长 → 1996 年国家统计局副局长 → 2008 年审计院院长。
- **风格**：报表一眼看出缺口，从不听解释；常说「数目不对就是人不对」。
