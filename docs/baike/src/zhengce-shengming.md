## 概述

**标准政策生命周期**是帝国所有大型政策共用的一条主流程：问题发现 → 部门研究 → 专家论证 → 财政评估 → 监察审查 → 中央政治局常委会讨论 → 中央政治委员会审议 → 皇帝最终决定 → 议会审议／公布 → 政府执行 → 地方落实 → 监察评估 → 复盘修改。

它不是一个比喻，而是十三段的顺序要求：任何一段缺失，政策都不能进入下一段。顺序还有方向——研究与评估在前，决定在后；地方落实与复盘修改排在末位，意味着政策的生命周期不以「公布」为终点。真正稀缺的不是提出政策的权力，而是走完这条链的耐力。

## 各段与责任机关

| 阶段 | 主要责任机关 |
| --- | --- |
| 问题发现 | 主管部委、地方常委会与政府、[[国民议会]]专门委员会 |
| 部门研究与专家论证 | 主管部委；跨部门事项由[[国务院]]常务会议协调，专家论证归[[科技教育文化委员会]] |
| 财政评估 | [[财政部]]、[[国家发展改革委员会]]、[[中央财政经济委员会]] |
| 监察审查 | 中央纪委、[[国家监察委员会]]、[[帝国审计院]] |
| 三会审议与决定 | [[中央政治局常务委员会]] → [[中央政治委员会]] → 皇帝 |
| 议会审议与公布 | [[国民议会]]（一般过半数，宪法事项三分之二） |
| 执行与落实 | [[国务院]]及组成部门；州、省、市、区（县）常委会与政府落实 |
| 监察评估与复盘 | 监察机关、审计院；主管部委回写[[五年规划]]与下一年度预算 |

## 两点制度逻辑

一是**决策权分散在链条上**：常委会管讨论、政委会管审议、皇帝管最终决定、议会管通过与否，没有单一节点可以独立完成一项政策。二是**十三段里有四段是监督**——监察审查、监察评估、复盘修改、议会审议，监督不是事后追责，而是流程内的固定工序。

责任机关的对应按 2026 年机构职能归口，原文只列阶段、不逐段点名。这条概念真正约束的是速度：它让任何一项大政策都慢下来，慢到每一个可能出错的地方都有人签过字。
