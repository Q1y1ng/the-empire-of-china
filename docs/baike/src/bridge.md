## 概述

**欧亚大陆桥**是帝国 2013 年提出的跨国基建计划，为欧亚共荣体系的陆上骨架：铁路、能源通道、港口与数字通道沿欧亚大陆两侧铺开，形成自帝国境内出发、贯通内亚与欧洲的陆上运输与结算走廊。计划由皇帝提出，载于《中华帝国编年史 1700—2026》第七编·四。

计划的制度意义在于三件套的组合：基建、贸易、结算同步推进，通道修到哪里，贸易协定与中华元结算就跟到哪里。2013 年以后，[[商务部]]承担沿线贸易与投资协定的谈判配套，[[国家发展改革委员会]]承担立项与年度计划编制，[[财政部]]承担资金与还款测算。适用面覆盖跨境交通、能源、港口与数字四类通道，投资规模在财政盘子里归入基础设施与水利一栏。

## 定义与内涵

**字面一层**，「大陆桥」指以陆路运输替代海运绕行的通道组合：一条铁路干线加若干支线，两端接港口，中段接能源管道与光纤。名称中的「桥」取连接两端之意，与本国的桥梁工程无关。

**制度一层**，计划是一套项目制度。立项须备三张表——立项表、工期表、还款表；三表齐备方可进入年度计划，无现金流测算的项目不得列入。计划的年度安排与[[五年规划]]衔接，跨境项目另需与沿线国家签署贸易与投资协定，协定由商务部谈判、报[[国民议会]]审议。

**实践一层**，计划是一套审批逻辑。原部委申报制按「谁报得响、谁先动工」排序，2013 年以后改为还款表前置：先算现金流，再排工期，最后定投资。审批顺序的改变使计划的资金约束前移，地方「先上车后补票」的空间随之收窄。

## 历史渊源

计划的制度前史从贸易协定开始。1997 年，亚洲共荣圈贸易协定签署，成员为帝国、日本、暹罗、柬埔寨、缅甸与南洋诸港；协定以贸易与结算安排为主，通道建设为辅。2010 年至 2020 年，帝国成为全球产业中心，亚洲共荣圈制度化，2013 年欧亚大陆桥基建计划提出，通道建设由区域扩展到欧亚大陆。

2020 年代，欧亚共荣体系成形，2024 年《欧亚数字主权协定》签署，数字通道与实体通道并列；世界格局明确为多极。2026 年，体系处于运转状态，帝国与美国维持「竞争但不脱钩」，AI 治理条约谈判以帝国原则为基础。

国内制度侧的配套同期完成。2013 年至 2019 年，[[沈叙衡]]任国务院副总理，分管经济、财政、金融，主持把计划的项目审批从部委申报制改为还款表前置；[[交通运输部]]与[[帝国铁路总公司]]承担干线建设与运营，高铁网 1995 年已贯通八州州府，为陆桥国内段提供了现成骨架。

## 制度内容

| 环节 | 要件 | 主管机关 |
| --- | --- | --- |
| 立项 | 立项表、工期表、还款表三表齐备 | 国家发展改革委员会 |
| 资金 | 现金流测算与还款安排，纳入年度计划 | 财政部 |
| 谈判 | 沿线贸易与投资协定、结算安排 | 商务部 |
| 建设 | 干线、能源管道、港口与数字通道 | 交通运输部、帝国铁路总公司 |
| 审议 | 协定与预算报议会审议 | 国民议会 |

四条规则分条列明：

1. **还款表前置**：项目先出还款表，再排工期与投资；无现金流测算者不列入年度计划。
2. **计划衔接**：年度安排纳入[[五年规划]]，与三衡国策的预算口径一致——基础设施与水利支出单列一栏，不与民生、国防科目互挤。
3. **协定先行**：跨境项目以贸易与投资协定为前提，协定谈成后方可开工；协定文本报议会审议。
4. **结算配套**：通道沿线的贸易结算以中华元与数字元为主渠道，2026 年全球外汇储备约 32% 以中华元计价。

贸易侧的配套另有两条口径：一是关税，2026 年关税水平 7.0%，其中含欧亚共荣体系优惠税率；二是汇率，1 美元约合 6.00 中华元，为年均中间价，凡以美元列示的贸易与投资额均按此折算。两条口径合起来，构成计划「以通道换贸易」这一段的计价基础。

## 运行与实例

**例一，审批逻辑的改动**。沈叙衡任副总理期间，把计划的项目审批从部委申报制改为还款表前置，没有现金流测算的项目不得列入年度计划；[[国家发展改革委员会]]的立项表、工期表、还款表由此成为标准三件套。副总理[[齐允中]]对这一习惯的评语是：「他批项目只看两张表——工期表和还款表。表上没有的数，他一句不问。」

**例二，国内段的既有骨架**。1995 年高铁网贯通八州州府，2026 年高铁营业里程 9.2 万公里、铁路营业里程 24.0 万公里、城市轨道交通 18,600 公里。陆桥国内段因此以既有干线为基，新增投资集中在跨境的衔接段与能源、港口、数字三类配套。

**例三，财政盘子里的位置**。2026 年基础设施与水利支出 12.20 万亿元，占财政支出 11.0%；同期国防 14.41 万亿元占 13.0%，社会保障与就业 24.39 万亿元占 22.0%。基础设施一项在财政支出中居第三位，是三衡预算里「工业不废农」之外最容易被削减的科目。

## 意义与评价

官方口径把计划定位为「欧亚共荣体系的陆上骨架」：以通道换贸易，以贸易换结算，以结算换货币地位，三段依次推进。编年史将其列入 2010 年至 2020 年的全球产业中心期，与世界格局的多极化同条记载。

学界一般将其概括为「带还款约束的对外基建」：还款表前置把项目的现金流要求提到立项之前，因而与单纯的口号式援建相区别。批评意见集中在两点：跨境项目回本周期长，沿线国家的政治风险由谁承担尚无统一口径；国有投资占比偏高，民间资本进入的门槛未明。支持意见指出，计划的三表制度已把「钱从哪来、几时回」写成前置条件，且基础设施支出占财政支出 11.0%，比例受预算约束，扩张空间有限。
