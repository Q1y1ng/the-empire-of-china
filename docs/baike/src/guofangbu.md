## 概述

**国防部**是[[国务院]]国防军事系统的组成部门，三品州部级，管的是国防的行政面：预算与装备订货、军工行业管理、国防动员、军务手续与对外军事交往的行政安排。作战指挥不在这栋楼里——按[[皇帝权力六分法]]，军事执行归[[中央军事委员会]]，国防部只是政府这一侧的口子。

部长[[贺龙]]为[[中央政治局]]委员，本职三品、按二品高配。国防部与军委共用同一批人与同一套数据，却从不共用一个印章：国防部长在国务院的预算与订货文件上签字，军委主席（皇帝[[朱昭文]]兼）在军委命令上签字。**国防部是行政口径，作战指挥归中央军事委员会，两者不得混同。**

## 行政与军令：两条线怎么分开

| 事项 | 行政口径（国防部） | 指挥口径（中央军委） |
| --- | --- | --- |
| 钱与物 | 国防开支 8.64 万亿元的部门预算、装备订货、军工产能 | 编制表与装备配备标准，由军委下达 |
| 人 | 军务司管军务手续；动员委员会管征集与预备役登记 | 军官授衔、任免、调动 |
| 兵 | 兵役制度：志愿与征兵结合，志愿兵够用即不征兵 | 部队编成：班—连—营—旅—军—军区 |
| 令 | 无 | 军委主席（皇帝兼）→ 军区 → 军；副主席[[刘伯承]]主持常务 |

- 军委层人事：副主席[[刘伯承]]（常委），委员[[粟裕]]、[[叶剑英]]（总参谋长）；陆海空三军种负责人各为军委委员。
- 军力概数：陆军 300 万人（[[八大军区]]对应八州）、空军作战飞机 12,800 架、海军主力舰 720 艘（三大舰队）。
- 地方不碰兵：州军区司令是州人民政治委员会常务委员会委员，但不负责地方行政，军区无调兵权；州级重大军事行动依[[双钥匙原则]]，须中央军事系统与地方行政系统同时许可。
- 国防部不掌兵：它可以问「这笔钱买什么」，不能问「这支部队往哪开」。

> 「国防部管的是账本与订单，军委管的是命令与阵地。」
