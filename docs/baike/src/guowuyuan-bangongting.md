## 概述

**国务院办公厅**是国务院的日常运转枢纽：[[国务院]]定下的政策要变成文件、会议与督办单，都从这里发出。它在中央政府机构总表里排在政务行政系统的直属机构一栏，正式名号是「中央政府办公厅」，实际管的是政府这一口的全部事务性流程。办公厅不发政策，只发承载政策的公文。

它之上只对一个人负责——总理[[李先念]]（一品·政治局常委）。办公厅不管方向，只管方向落地时不出岔子：哪份文件先走、哪个部门先报、哪条指示三个月后还没回音，都记在它的台账上。级别上它是三品·州部级，可它经手的事横跨二十二个组成部门，部委主官与它对表时，礼数按中央机关走。

## 两个办公厅的分工

帝国中枢有两套办公厅，一套管政治口，一套管政府口，彼此不隶属：

| 事项 | 中央办公厅 | 国务院办公厅 |
| --- | --- | --- |
| 主官 | [[任弼时]]（政治局常委·一品） | 由总理直接领导，随政府任期进退 |
| 管谁的会 | 政治局、常委会、政治委员会 | 国务院常务会议与部委联席会 |
| 管谁的文 | 政治口公文、政发〔年〕X号决议 | 政府序列公文、部委请示与批复 |
| 归档去向 | 中央政治机构档案 | 政府系统档案 |

两个名号、两套台账，人员可以互调，编制从不合并。《中央政治委员会组织法》把政委会的会务写成一句「由中央办公厅承办」，政府这边的会务则从不越过这条线——这不是分权，是分工：一个管政治口，一个管政府事务。

## 公文、会议、督查

- **公文流转**：收文编号、时限、承办部门、归档，四栏缺一栏就退文；退文只写一行理由
- **会议筹备**：常务会议议程由办公厅排，谁先报、报几条，都在这一层定；跨部门口径先在会前对平
- **督查督办**：会议决定拆成督办单，按季度回告，未办结的挂账跨年
- **协调**：部门职责边界由《中央政府组织法》附表规定，边界不清的由办公厅召集对表，对不齐再上会

这四件事对应[[标准政策生命周期]]的中段：部门研究之后的财政评估、监察审查与上会讨论，材料都在办公厅这一关装订成册。它手里没有决定权，只有排序权——而排序权在帝国中枢从来不是小事。

> 「国务院的文件不怕慢，怕的是发出去没人办——所以每一份都要有人签字销号。」
