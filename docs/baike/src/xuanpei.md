## 概述

**选培生**是 1986 年《政治学院法》设立的直通车：本科应届毕业生考进来，三年读成一个学位，毕业即定吏级官阶，不必再走「吏三→吏二→吏一→转官」那条慢道。两轨——

- **中央选培生（央选）**：面向 C9 九校与中央政治学院本科毕业生。
- **地方（州）选培生（州选）**：面向本州州立重点大学与州立政治学院本科毕业生。

## 两轨对照

| 项 | 央选 | 州选 |
| --- | --- | --- |
| 名额 | 一届 25 人左右（C9 各 2～3 名＋央政 5 名） | 一州一年 25 人（八州共 200 人） |
| 学历终点 | 博士（三年直博） | 硕士 |
| 培养方式 | 半任职半读，灞桥区基层轮值 | 半任职半读，本州轮职 |
| 毕业定级 | **一级吏长（正科）** | **二级吏长（副科）** |
| 免培 | 基培＋中培 | 基培 |
| 服务期 | 8 年（原籍州优先分配） | 8 年（本州） |
| 民间说法 | **半只脚踏进四品** | **一只脚踏进七品** |

## 七道闸

考试 → 政审（本人及**直系三代**）→ 背调 → 征信 → 体检 → 面试 → 公示五个工作日。帝国政界叫「过七道闸」，过完的人自己都说不清是考进来的还是查进来的。

## 制度后果

- 央选 1987 年首招，四十年累计约 985 人；州选约 8,000 人。两系在州一级常有摩擦。
- **央选系的天花板停在四品／三品之交**——最快的一批 2026 年约 61 岁，多在州委常委、副州长一级。政界自嘲：「央选只管到四品，再往上是另一套筛子。」
- 政审查三代让「家世清白」成为硬通货；征信查得细，寒门子弟的助学贷款记录也会成为把柄——这是新制自己长出来的新门第。
- 央选免中培，也等于少了一条中培同窗的人脉；这是它与传统路径的隐性差距。
