## 概述

**选培生**是中华帝国依《政治学院法》（1986）设立的两轨干部直通车，指本科应届毕业生考入中央或州级培养序列、三年读成一个学位、毕业即定吏级官阶并免除相应培训环节的任用方式。两轨并行：**中央选培生**（央选）面向 C9 九校与[[政治学院|国立中央政治学院]]本科毕业生，**地方（州）选培生**（州选）面向本州州立重点大学与州立政治学院本科毕业生。

它在仕途结构中的位置由一组对比确定。常规路径是「入职吏三—满二年升吏二—满三年考核优秀升吏一—吏一任满三年加州级考试加州立政治学院（省学区）一年—转官十品」，全程约需八至十年，出仕多在三十岁前后。选培生把这条链条压缩为三年：毕业即定一级吏长或二级吏长，免去基培、中培或基培，并免「吏→官」的学院一年。学历、定级、免培三项一次给足，是这项制度被称作「直通车」的由来。

适用面限于两段学历的入口。央选由[[中央组织委员会]]主持，一届二十五人左右，名额分到 C9 各二至三名与中央政治学院五人；州选由各州州委组织部主持，一州一年二十五人，八州合计每年约二百人。两轨的服务期同为八年，央选按原籍州优先分配，州选在本州任职。

## 定义与内涵

**字面义**。「选」指经考试与审查选拔，「培」指三年培养期，「生」指其身份属于学生序列。三字合起来，指一类带培养期与定向分配的预备干部：在册时是学生，毕业时定官阶。

**制度义**。《政治学院法》第五至第八条把两轨的要件逐条写定：

| 项 | 中央选培生（央选） | 地方（州）选培生（州选） |
| --- | --- | --- |
| 主持 | 中央组织委员会 | 各州州委组织部 |
| 生源 | C9 九校与中央政治学院本科毕业生 | 本州州立重点大学与州立政治学院本科毕业生 |
| 名额 | 一届 25 人左右（C9 各 2～3 名＋央政 5 名） | 一州一年 25 人 |
| 学制 | 三年直博 | 三年授硕士 |
| 培养方式 | 半任职半读，灞桥区基层轮值 | 半任职半读，本州轮职 |
| 毕业定级 | 一级吏长（正科） | 二级吏长（副科） |
| 免培 | 基培、中培 | 基培 |
| 服务期 | 八年，原籍州优先分配 | 八年，本州任职 |

**实践义**。两轨的差别落在学位与起点两处。央选三年直博，学位序列走到博士一级；州选三年授硕士，学位止于硕士。起点相差一级：一级吏长为正科，二级吏长为副科。民间对这条差距有固定说法——央选「半只脚踏进四品」，州选「一只脚踏进七品」。两句俗称说的都是保底：四品与七品是两轨在正常年资下可望企及的上限附近，与到期即得的位置尚有距离。

## 历史渊源

选培生制度是 1986 年宪制定型的产物，也是当年三部单行法中的第三部。立法过程在编年史里有完整记录：1986 年 7 月，[[中央政治委员会]]以 76:4 通过《政治学院法》法律案（80 人，过半数 41）；同月第一届议会第一次会议以 668:52 通过（720 席，须不少于 361）；因涉及四十四所省立政治学院撤并，宪法第十八条要求必经议会立法；8 月穆宗批准并公布；9 月新学年起施行。

施行当日的三项变更同时生效：政治学院只留中央一所与州立八所，四十四所省院改设省学区；首设本科（四组十专业）与三级培训班（硕士、博士、博士后）；首设央选、州选两轨。同一部法还把最低任职年限由「每级五年」改为「副职升正职二年、正职升副职三年」，选培生的三年压缩期正是架在这套新年限之上。

《法律要目(2026)》对这部法有一句定评：四十一年未经修正，与七部组织法并称「不动的法」。两轨的名额、学制与定级自 1986 年起未变，变动只发生在承办单位与生源范围的细节上。

## 制度内容

两轨的入口是同一道七关。第七条规定，选培生须过考试、政审（直系三代）、背调、征信、体检、面试、公示七项；公示期为五个工作日，名单公示无异议方得入选。七关的次序固定，任何一关未过即退出当届选拔。

七关之中，政审与征信两项最有帝国特色。政审查直系三代，查的是家庭背景与政治忠诚；征信查个人信用与负债记录，查的是财务清白。两项叠加，使「家世清白」与「账目干净」同时成为硬门槛。

四条配套规则：

1. **学位层级**：帝国学位序列为学士、硕士、博士、博士后四级；央选三年直博，走到第三级；州选三年授硕士，走到第二级。
2. **免培范围**：央选免基层干部培训班与中级干部培训班，州选免基层干部培训班；两轨均免「吏→官」所需的州立政治学院一年。
3. **分配原则**：央选按原籍州优先分配，州选在本州任职；两轨均须服务满八年，未满服务期离职按违约处理。
4. **身份转换**：入学第一天起建立[[吏制|官籍]]，记录科举成绩、学院成绩、任职地点、任期、政绩与评价；毕业按[[十品官阶]]定级，转为正式官员。

## 运行与实例

**其一，苏锐的履历。**[[苏锐]] 1988 年为华北州高考第二，入中央政治学院政治与法律组；1992 年入选中央选培生，三年直博；1993 年任[[灞桥政教园区|灞桥区]]法院学员科员，1995 年定一级吏长、任石家庄基层法院科长，此后历任十品二庭庭长、九品副院长、八品院长、七品市长、六品成都市人民检察院检察长、五品长安市副主席、四品长安市委主席，2025 年入中央政治学院高培班，2026 年任三品京畿直隶州州长。他被记作「半只脚踏进四品」那句俗话的第一个反例——四品是保底，他五十六岁已到三品。

**其二，七关的实际淘汰。**七关中前六关为资格审查与能力测试，第七关公示为异议期。公示期内任何单位或个人可提出异议，异议由主持单位核查，核查期间入选资格中止。五个工作日的公示期不长，但足以让政审与征信两关的结论接受外部复核——这是两轨选拔中唯一向体制外开放的环节。

**其三，服务期与原籍分配。**央选按原籍州优先分配，意味着一名学生物归本州，服务满八年；州选在本州任职，服务期同为八年。八年之设与两个任期相合：基层政治官五年一届、可连任一次，八年恰好覆盖一届加一段，使受训者至少经历一次完整的基层治理周期，再谈晋升。

## 意义与评价

官方口径把选培生定位为「入口前移」的制度设计：常规路径先做吏再考转，选培生先读学位再定级，把选拔与培养并作一段。[[政治学院]]专卷把这层意思写成三句——[[科举制度]]给资格，政治学院给学历，选举给职位；选培生跨在这三句之间，学历与定级一次给足，职位仍须经选举或任命取得。

学界一般将其概括为「压缩年资的精英通道」，并指出它的三重代价：政审查三代使寒门背景成为隐性劣势，征信查得细使助学贷款记录也可能成为把柄，免中培则少了一段中培同窗的经历。支持意见认为，八年的服务期与原籍分配把人才送回本州，抵销了一部分起点不公；苏锐一例则说明上限由入口之后的每一级决定——直通车只给第一段路，后面的每一级仍要经选举、考核与任期。
