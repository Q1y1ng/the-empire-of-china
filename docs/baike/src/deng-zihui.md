## 概述

**邓子恢**，[[财政部]]部长，三品州部级。财政部是「长安财经系」这条业务线的起点：预算口径在哪一版上定下来，全系统的数字就得跟着走。

## 在预算链条上的位置

| 环节 | 角色 |
| --- | --- |
| 编预算 | 财政部定科目与口径（部长签字） |
| 借钱与放贷 | [[帝国中央银行]]按财政口径配信贷 |
| 出数据 | [[国家统计局]]按同一口径出统计 |
| 查账 | [[帝国审计院]]按同一口径做审计 |

四个环节用一套口径，是帝国「数出一门」的制度基础；口径打架，先由[[中央财政经济委员会]]裁定，再由部长签字落版。

## 与总理的关系

[[李先念]] 1992—2001 年任财政部预算司司长，是这条线的上一代人。两人共事的默契是：**部长报总量，司长报科目**；总量与科目对不上，先改科目，不改总量——因为总量是常委会定的盘子。

## 圈子的边界

外界把财政部、央行、审计院、统计局称作「长安财经系」。邓子恢从不承认这种说法，他的标准回答是：「财政部的同事，都是照口径办事。」

> 事实上，这条线的黏合力来自**同一套科目语言**，而不是某个人的号召：会看同一张表的人，自然说得上话。
