## 概述

**国家禁毒与枪支管理总局**是[[国务院]]政法与公共安全系统的直属机构，三品州部级，局长蒙镇，副局长蒯缴枪，管两样东西：毒品与枪支。这两样在帝国是同一条底线上的两件事——**都不许流到街上**。局名把「禁毒」写在前面，是因为毒品那头线长、跨境、要常年盯。

设定原文对这一条给得很干脆：帝国开国早期经历剿匪、扫黑除恶等大规模治安行动，「工业革命后严格控制枪支、毒品等等高风险社会问题」；历史年表里的写法是「工业革命后严控枪支毒品」。所以本局的权限不是临时授权，而是**工业革命以来一路收紧的结果**。

## 四条线：禁种、禁贩、禁持、查缉

| 环节 | 主责 | 谁配合 |
| --- | --- | --- |
| 境内制贩与种植 | 本局 | [[公安部]]刑事侦查局（卜靖刑）立案办案 |
| 口岸与边境查缉 | [[帝国海关总署]]缉私局（厉缉私） | 本局出鉴定与线索研判 |
| 跨境线索与境外网络 | [[国家安全局]]（[[李克农]]） | 本局出境内落地核查 |
| 市场流通与化工前体 | [[国家市场监督管理总局]]（仇正纲） | 本局定管制清单 |
| 持枪许可与收缴 | 本局 | 公安执行强制措施 |

- **枪支是许可，不是权利**：谁可以持、持什么、放在哪、什么情形收回，一律进册；超范围持有按非法持有办。
- **毒品按清单管**：列管物质一张表，新增一种走公告程序；前体化学品同步列管，堵的是原料而不是成品。
- **办案不越界**：本局管管制、查缉与鉴定，抓人、讯问、移送起诉仍归公安；起诉与审判归检察院与法院。
- **不碰军队与武警**：军械与部队枪弹不在本局册内，部队的枪由军队自己管。

## 与公安、国安的分工

三家最容易混：公安办「案子」，国安办「情报」，本局办「东西」——毒品与枪支这两类物流到哪、谁在管、册子清不清。撞上同一个案子时的顺序是：国安先给线索，本局做鉴定与查缉，公安立案抓人。**线索可以共用，卷宗不能共用**，这是管制领域的老规矩。真正难的不是抓人，是前体化学品与改装枪械——两头都在往「不像毒品、不像枪」的方向走，所以清单一年一修。

> 「毒品和枪，一样都不许有第二条路进城。」
