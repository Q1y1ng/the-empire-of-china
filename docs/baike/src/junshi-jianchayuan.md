## 概述

**帝国军事检察院**是军队系统内的检察机关，检察长傅钟三品。它的活是两件：对军内刑事案件批准逮捕、提起公诉，对军事司法活动本身进行监督。它不审判、不定罪，也不替监察机关查案——三件事分给三个衙署，谁也不兼。

检察系统的规矩是垂直领导：检察官由[[最高人民检察院]]统一管理、统一调配，不受地方行政机关干涉。军事检察院把这条推到极致——检察长的乌纱不在军区，也不在州里。军区司令管不了本区的军检，正如州长管不了省法院。

## 一条垂直的线

| 层级 | 机关 |
| --- | --- |
| 中央 | [[最高人民检察院]] |
| 专门 | 帝国军事检察院（军内分支） |
| 州 | 州高级检察院 |
| 省 | 省检察院 |
| 市 | 市检察院 |
| 区（县） | 区检察院 |

军事检察院不排在州、省、市那一串中间，而是挂在最高检名下的专门分支：军内案件的批捕与公诉由它办，对上口径仍归最高检。州以上各级检察院的核心人物进本级常委会，军事检察院的检察长则与总参谋长、总政治部主任同列军委机关主官。

## 与军事法院、国家监委的分工

| 机关 | 办什么 | 不办什么 |
| --- | --- | --- |
| 帝国军事检察院 | 批捕、公诉、军事司法活动监督 | 不审、不判 |
| [[帝国军事法院]] | 审判、定罪量刑 | 不侦查、不公诉 |
| [[国家监察委员会]] | 公职人员（含军队违法）职务违法与职务犯罪调查、留置 | 不提起公诉、不判刑 |
| 最高人民检察院 | 检察官统一管理调配、法律解释口径 | 不代下级办案 |

[[国家监察委员会]]可以调查军队违法，但限制人身自由须在四十八小时内报同级检察院备案。《监察制度改革法》把这条写成硬约束：查人的手和诉人的手，不能是同一只手。

> 「起诉书上的名义是国家，不是长官。」
