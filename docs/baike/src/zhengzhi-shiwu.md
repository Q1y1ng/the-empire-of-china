## 概述

**政治官与事务官二元体系**把帝国官员分成两类：政治官通过科举资格、[[政治学院]]与选举获得职位，负责制定政策、分配资源、政治决策，对选民与上级委员会负责；事务官通过专业考试与大学教育进入政府，负责执行政策、财政核算、工程、教育行政、医疗、法律事务与技术工作，不直接参与政治竞争。

二元的意思不是两套地位，而是两套规则：同一间办公室里，政治官为「做什么」负责，事务官为「怎么做、做得对不对」负责。前者会因选举与考核换人，后者靠专业资格与年资留下——帝国借此把政治波动与行政连续分开。

## 四条差异

| 维度 | 政治官 | 事务官 |
| --- | --- | --- |
| 入口 | 科举资格 → 政治学院 → 选举／任命 | 专业考试 → 大学教育 → 聘任 |
| 考核 | 政绩考核、居民评价、御史评价 | 年度考核、专业资格 |
| 任期 | 基层五年一届，可连任一次 | 随职务与年资延续 |
| 退出 | 居民评价差者不再担任政治职务，可转入事务官体系 | 按公务规程处理，不因政见进退 |

## 两条互通的路

- 事务官 → 政治官：持资格证＋政治学院一年＋选举，进入十品起步（见[[十品官阶]]）
- 政治官 → 事务官：居民评价差者不再担任政治职务，但**可进入事务官体系**；两道门都要考试，二元不是隔离墙

## 2026 落点

官籍从进入政治学院第一天建立，记录科举成绩、政治学院成绩、任职地点、任期、政绩、财政责任、居民评价、同僚评价、御史评价、处分、参与过的工程与管理过的人口。这份档案是二元体系能运转的技术前提：换人的时候，制度记得住前一个人的账。

> 「政治失败不等于人生失败。」
