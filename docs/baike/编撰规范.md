# 《帝国百科》编撰规范（2026）

> 本规范是百科词条的体例与语言标准。所有条目的扩写、修订、审校一律照此执行。
> 配套工具：`py -3 tools/build_baike.py [--check]`（构建与链接校验）、`py -3 tools/check_baike.py`（体例与口径校验）。
> 口径来源：`docs/baike/口径基线.md`（由《帝国高层人物小传（2026）》自动生成）。

---

## 一、性质与目标

帝国百科是帝国公共知识库的条目录，以《中华帝国设定集·全卷合订本（2026）》《全国官员名录》《帝国主数据表（2026）》为底本，按通行网络百科体例编成。

一条合格的词条同时具备五项：

| 项 | 要求 |
| --- | --- |
| 定义 | 首段第一句即给出「是什么、归谁管、什么级别」 |
| 沿革 | 有年份可循的设立、改组、现行三段以上 |
| 构成 | 内设机构、职数、主官具体到可查 |
| 运行 | 与相邻机构的分工、程序环节写清 |
| 数字 | 2026 年关键数据与《帝国主数据表（2026）》一致 |

读者对象是「第一次查这个词、想一次读完」的人。因此词条要能独立成篇，不依赖上下条。

## 二、篇幅与结构

| 类别 | 正文字数（不含前置信息，含表格） | 节数 |
| --- | --- | --- |
| 机构 | 2,600–5,000 | 6–8 节 |
| 人物 | 1,800–3,500 | 6–8 节 |
| 概念 | 2,400–4,500 | 6–8 节 |

- 现有词条平均约 980 字，本轮一律补足到上述区间下限以上。
- 长条目不靠堆形容词，靠**具体**：职数、年份、品级、数字、程序步骤、地名、文件名。
- 同一事实只讲一次；后文引用前文时用「前述」或链接，不复述整段。

## 三、语言：官话正述

### 3.1 主干句一律正面定义

| 误 | 正 |
| --- | --- |
| 国务院不是议事机构，也不是协调机构。 | 国务院是中华帝国最高国家行政机关，统一领导全国行政工作。 |
| 政委会不决策具体政策，只作人事与重大事项的确认。 | 中央政治委员会行使人事确认与重大事项审议权，具体政策由国务院及其部门制定。 |
| 这个机构的职能不是审批，而是备案。 | 这个机构对有关事项实行备案管理，审批权在上级机关。 |

写法：主语＋「是／为／负责／承担／行使／归口／统筹」＋宾语＋依据（法条或文件）。

### 3.2 排除句的两种合法用法

排除句只在下列两种情形使用，每篇合计不超过 2 处：

1. **法条明文排除**：照抄法条式表述——「下列事项不列入本院职权范围：……」（后接项目列表）。
2. **机构分工的界分**：写「A 负责……，B 负责……」，让分工本身完成排除，不使用「不是……而是……」。

禁止：以否定句作首段定义；连续否定排比（「不是 A，不是 B，也不是 C」）；反问句说理。

### 3.3 书面语规范

- 用词：负责、承担、归口、统筹、依照……行使、报……批准、会同、备案、核定、下达、督导。
- 不用：搞、抓、弄、盯、顶、卡（作动词时）、老百姓、上面、下面、一把手。
- 不用第一人称、不用感叹号、不用「我们可以看到」「众所周知」「值得一提」。
- 称谓：首次出现用全称（中央政治局常务委员会），后文可用简称；简称首次出现时括注。
- 数字：千分位（1,030 元、9.2 万公里）；比率保留一位小数；年份用公元纪年，必要时括注年号（继文十一年）。
- 时间表述：以 2026 年为「本年」「截至 2026 年」，不写「目前」「现在」。

### 3.4 评价的位置

- 事实性叙述不进评价；评价集中在「评价」或「意义」一节。
- 评价用第三人称转述：「官方口径称……」「学界一般将其概括为……」「编制说明将其定位为……」。
- 不作作者抒情，不用「伟大」「辉煌」「令人振奋」一类修饰。
- 引语每篇不超过 2 条，须写明说话人身份；无出处的传闻不入条。

## 四、事实等级

事实冲突时按下列顺序取舍，上位覆盖下位：

| 级 | 来源 | 管辖范围 |
| --- | --- | --- |
| 1 | 《帝国主数据表（2026）》 | 全部数字与比率 |
| 2 | 《帝国高层人物小传（2026）》／`docs/baike/口径基线.md` | 57 人的现职、品级、生年、籍贯 |
| 3 | 《全国官员名录》各卷 | 内设机构、人名、职数、驻地 |
| 4 | 《中华帝国编年史 1700—2026》 | 年份、事件、世系 |
| 5 | 《法律要目（2026）》《中华帝国世界观总设定 v2.0》 | 法条编号、制度定义 |
| 6 | 百科旧稿 | 叙述文风与既有结构 |

- 上位无载、下位亦无载者**不得自造**。确需过渡叙述时，写「据《……》记载」或径行省略。
- 机构内设司局名称一律取自《全国官员名录·卷三十六·中央部委内设司局级序列》等卷；名录无载者，该表只列到「办公厅（室）」「综合司」一类通用层级，或整表略去。
- 新增年份必须能在《编年史》或既有卷册中找到依据；不能确定年份时，写「20 世纪中叶」一类区间，不虚指具体年。

## 五、结构模板

范式样本：`docs/baike/src/shen-xuheng.md`（人物）为全库体例基准，扩写时对照其密度与节序。

### 5.1 机构

```
## 概述            2–3 段：定义句 → 隶属、级别、编制 → 2026 年关键数字或状态
## 历史沿革        3–6 段，带年份；无载者按「设立—改组—现行」三段式
## 机构设置        表格：内设机构｜主要职责｜负责人／职数（取自名录）
## 主要职能        5–8 条，正面动词起句（负责……／承担……／依法行使……）
## 运行机制        3–5 段：与相邻机构的分工、程序环节、会签与备案
## 2026 年要项     数据表 3–6 行
## 参考资料        编号引用，3–6 条
```

### 5.2 人物

```
## 概述            2–3 段：姓名括注生年、籍贯、现职、品级 → 出身与晋升线 → 施政特征
## 生平            4–6 段，h3 分期：早年与求学 / 入仕与历练 / 主政一方 / 现职
## 履历表          表格：时间｜职务｜官阶／身份｜备考
## 主要工作        3–5 条或分目，正面叙述主持、推动、签发、核定的事项
## 人物风格        表格或分条：场合｜表现
## 家庭            表格：关系｜姓名｜简况；末附回避与财产公开口径一句
## 评价            3–5 条转述，标明说话人与出处
## 参考资料        编号引用，4–8 条
（可选）## 争议    表格：争点｜一方｜另一方；争议须有双方口径，不作判词
```

### 5.3 概念

```
## 概述            2 段：定义句 → 制度地位与适用面
## 定义与内涵      分层：字面义 → 制度义 → 实践义
## 历史渊源        年份、文件、立法依据
## 制度内容        表格或分条（构成要件、等级、比例）
## 运行与实例      1–3 个具体例证，须有出处
## 数据            表格 3–6 行
## 意义与评价      1–2 段，转述式
## 参考资料        编号引用，3–6 条
```

### 5.4 参考资料

每条词条末尾必须有「参考资料」，为通行百科的必备项。写法：

```
## 参考资料

1. 《帝国高层人物小传（2026）》三·2「沈叙衡」。
2. 《全国官员名录·卷一·中央与京畿直隶州》二·中央政治局常委会表。
3. 《帝国主数据表（2026）》D-01—D-16；《经济数据切片（2026）》一—三。
4. 《中华帝国编年史 1700—2026》第六编、第七编。
```

- 只引实体卷册与章节，编号连续，句末用句号。
- 引用卷册必须是 `设定/` 下真实存在的文件；章节号照该卷实际编号写，不确定时只写卷名。
- 不引「参考网络」「编者按」一类，不写访问日期。

节名以模板为准；对象特殊时可另拟一至两节（如「委员资格」「与皇帝的关系」），但「概述」与「参考资料」两节名不得改动，节序不得倒置。「相关条目」由前置信息 `related` 自动生成，正文不写。

```yaml
---

summary: 院长霍明诚（政治局委员，二品）；判词只引条文不引情理
updated: 2026-11-08
infobox:
  性质: 最高审判机关（依法独立行使审判权）
  级别: 二品（院长由政治局委员兼任）
  院长: 霍明诚（中央政治局委员）
  职能: 终审、死刑复核、审判监督与统一裁判口径
  依据: 宪法第二十四条、第二十五条
related: 中央政治局常务委员会, 国民议会, 邵允恭, 中央政治委员会

```

| 字段 | 规则 |
| --- | --- |
| slug | 小写连字符，与文件名一致，一经发布不改 |
| title | 全库唯一；机构用全称，人物用本名，概念用定名 |
| subtitle | ≤ 24 字，定语式短语，不加句末标点 |
| summary | ≤ 30 字，检索用，不重复 title |
| updated | 本轮统一写 2026-11-08 |
| infobox | 8–16 行；键名 2–4 字，按下列固定键序取用，无载者略去 |
| related | 4–8 个，须与正文 `[[...]]` 相合，且均为已存在词条 |

### 6.1 基本信息栏（infobox）键序

人物：中文名、性别、国籍、民族、籍贯、出生、现年、学历、现职、官阶、任期、前任、分管、绰号、名言。

机构：中文名、简称、性质、级别、现任、设立、驻地、编制、职能、依据。

概念：中文名、别称、定名、依据、适用面、主管。

说明：

- 「国籍」一律「中华帝国」；「民族」按籍贯所在州填写（汉族、蒙古族、藏族、维吾尔族等）。
- 「出生」写「1958 年（革鼎二十九年）」，须与 `口径基线.md` 一致；「现年」由 2026 减生年得出。
- 「官阶」写「一品（正国级）」式样，品级字样不得混用「部级」「副部级」。
- 人物「生年」若另设单键（旧稿体例），一律四位数字，不加 †、不写「史实原型」。

## 七、链接与表格

- `[[条目名]]` 只在词条内首次出现处加；每篇 8–20 个；不指向自身。
- 链接目标必须是已存在词条的 title，错一个字构建即失败。
- 表格 3–6 列；表内不嵌链接；表头行后必须有分隔行。
- 正文不用一级标题；`##` 为节，`###` 只用于「生平」「历史沿革」内的分期。

---

## 八、禁忌

1. 现实政治名词：社会主义、共产党、新民主主义、马克思主义、改革开放。
2. 溯源标注：「史实原型」「†」「（原型生年）」。
3. 未定状态：筹建中、拟设、计划成立、有望。
4. 否定式主干定义与连续否定排比。
5. 与《帝国主数据表（2026）》不一致的数字。
6. 作者口吻的评论、感叹号、第一人称。
