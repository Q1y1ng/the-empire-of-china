# 《中华帝国设定全书（2026）》编纂说明

> 本文件记录《中华帝国设定全书》的体例、去重规则与同步约定。**正文与 PDF 里不再印这些工程性说明**，只在仓库留档。

## 一、性质

- 《中华帝国设定全书》是**整编可读本**：由 `tools/build_readable_book.py` 从 `设定集/中华帝国设定集·全卷合订本(2026).md` 生成，输出到 `设定集/`。
- 它以 `设定/` 下各分册（含题头、26 编、两个附录与分类索引所在的 `总设定·*.md`）为唯一来源；重跑即覆盖，**要长期改动请改分册后重跑脚本**，不要只改全书。
- 分册与全书冲突时，以分册为准；重跑脚本即可消除差异。

## 二、与《设定集·全卷合订本》的关系

- 《合订本》是零遗漏全文本（含全国官员名录），供归档与完整性校验（`check_completeness` 断言逐行可比）。
- 全书是它的「可读、去重」版本：移除全国官员名录（42 卷），并对已有独立分卷的摘要编做指针化处理。

## 三、体例

- 卷为一级标题、单元为二级标题、单元内标题整体降一级；各单元保留原编/卷编号，便于与分册及文内交叉引用对照。
- 人物只保留有人物小传者（第五卷《帝国高层人物小传》57 人：政治局 27＋六州州委主席 6＋八州州长 8＋八大军区司令 8，另 2026.12 新设副国级 8 人）。

## 四、去重规则

- 摘要单元（第十八编、第十九编、第三编、第十六编、第二十六编、第九编）正文替换为「本编为摘要，全文见本卷后文《…》」＋节名索引。
- 其余〔总设定〕单元保留全文。

## 五、同步约定

1. 改动分册后，重跑 `py -3 tools/build_readable_book.py`（可加 `--pdf 输出.pdf`）。
2. 每次重跑在 `CHANGELOG.md` 的「### 变更 / ### 修复」记录一行。
3. 全书不写工程性前言与附录；需要说明时改本文件。
