# 《中华帝国设定集·全卷合订本（2026）》编纂说明

> 本文件记录合订本的体例与收录范围。**正文与 PDF 不再印这些工程性说明**，只在仓库留档。
>
> **目录约定**：`设定/` 为单章源与分卷（唯一可改的地方）；`设定集/` 为脚本拼成的成品（本合订本、名录合订本、设定全书），**勿手改**。

## 一、体例

- 本册为**混编重编本**：全部设定打散到编/卷级单元、按主题重排为十卷（总纲→历史→世界→疆域首都→皇室政制→军事→经济民生→文教科技→理论推演→官员名录）。
- 单元正文逐字保留，不改写、不删减；※、【推演】、【冻结】标注照录。
- 卷为一级标题、单元为二级标题、单元内标题整体降一级；各单元保留原编/卷编号（如「第九编：军事体系」），便于与分册及文内交叉引用对照。
- 同主题「摘要编在前作导读、专卷全文殿后展开」（军事、教育、世界、首都四处）；两见内容为设定层与全文层互备，零删减。

## 二、收录范围

《中华帝国世界观总设定 v2.0》《中华帝国编年史（约1360—2026）》《世界近代史推演（约1360—2026）》《长安城市志》《全国高等教育设定（2026）》《全国军事编制设定（2026）》《全国官员名录（总索引＋42 卷）》等全部分册。

**不含**：小说《华北风暴》正文（单独成册；其人物与空间锚点见卷四十二及城市志卷九）。

## 三、生成与校验

- 由 `tools/build_setting_book.py` 生成，内置**零遗漏断言**（`check_completeness`）：每个分册的每一非空行都必须出现在成品中。
- 改分册后重跑 `py -3 tools/build_setting_book.py`；加 `--pdf 输出.pdf` 可同时出 PDF。
- 分册仍是权威源；合订本与分册冲突时以分册为准。

## 四、符号约定

- ※＝推演创作（可替换）
- 【推演】＝可调整的推演项（非冻结）
- 【待定】＝尚未裁决（遇此即问作者）
- 【冻结】＝作者已拍板，不再改动
