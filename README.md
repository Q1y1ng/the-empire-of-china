## 写作规范（硬规则·后来 agent 必读）

### 一、否定式表述

**规则：非必要、非禁令，不得使用否定式表述。** 正文写「是」「有」「在哪」「多大」「谁在里面」，不写「不是」「不属于」「不归」「不设」。

**两种例外**（只有这两种）：

1. **禁令本身**——法律规定、使用禁令、禁止事项。例：「国歌不得截取片段作铃声、背景音乐或商业广告」「勋章不得买卖、不得继承」。
2. **否定即事实核心**——否定本身是制度设计的一部分。例：「皇帝不亲自处理日常行政」「算法不得代替法定权力主体作出最终决定」。

**自检一句话**：把句中的「不」删掉，如果信息量一点没变，这句就是废话，应当删掉或改成正面清单。

**例（本项目真实发生过的错）**：

| 反面写法（已删） | 为什么错 | 正面写法 |
| --- | --- | --- |
| 「三线不入皇城」「军不入宫」「官不居宫」 | 三条全是「不」，读完仍不知道议会、军委、官员在哪 | 「议会、两高、监察、审计在内城；军委与国防部在皇城北；皇城的居民是皇室与值班宿舍」 |
| 「龙是国家的符号，**不是某个人的符号**」 | 后半句删掉信息量不变 | 「龙是国家的符号（宪法法院 1991 年释例）」 |
| 「沿用帝制最高等级，**但不再与『天子』叙事绑定**」 | 同上 | 「帝制礼制中的最高等级；1986 年后纳入国家礼仪序列」 |
| 「皇宫广场**不举行**商业演出」 | 读者要知道广场用来干什么 | 「皇宫广场用于仪典与集会；演出与赛事在国家体育场建筑群」 |
| 「不要把国旗写成『皇帝的旗』」（三条禁令整节） | 写作禁令不是设定，占篇幅且全是否定 | 直接删掉；正面口径已写进「国旗·寓意」一节 |

> 同一条规则也适用于表格、小标题与括注——小标题写「（龙为国家符号）」，不写「（不得改写成龙＝皇帝）」。

## 说明

正文与设定均为创作稿，剧情、对白、人设定稿；扩写稿只增加环境、动作、神态、心理与群像描写。

设定集·全卷合订本为**混编体例**（2026-09-26 重编）：全部设定打散到编/卷级单元、按主题重排为十卷（总纲→历史→世界→疆域首都→皇室政制→军事→经济民生→文教科技→理论推演→官员名录），单元正文逐字保留，原编/卷编号不变；**《口径台账》属工具卷，不入合订本**（构建脚本 `BOOK_EXCLUDE` 排除，源文件仍留在 `设定/`）；由 `tools/build_setting_book.py` 生成并内置零遗漏断言，改分卷后重跑即可。

《中华帝国设定全书（2026）》为合订本的**整编可读本**：脚本 `tools/build_readable_book.py` 生成（2026-11-08 起重跑覆盖，取代此前的手工整编本）；对已有独立分卷的摘要单元去重（只留一句指针＋节名索引）、移除全国官员名录，正文只保留标题、符号约定与十卷文本，工程说明另见 `docs/全书编纂说明.md`。

## 重新生成 PDF

```bash
py -3 tools/build_novel_book.py          # 《华北风暴》→ 桌面/华北风暴(2026).pdf
py -3 tools/check_novel_pdf.py           # 35 项格式检查
py -3 tools/build_setting_book.py \
    --pdf "%USERPROFILE%/Desktop/中华帝国设定集(2026).pdf" \
    --roster-pdf "%USERPROFILE%/Desktop/全国官员名录·全卷合订本(2026).pdf"
py -3 tools/build_readable_book.py \
    --pdf "%USERPROFILE%/Desktop/中华帝国设定全书(2026).pdf"
```

> 本机桌面实际在 `E:\桌面`，生成时把上面 `%USERPROFILE%/Desktop` 换成该路径即可。
