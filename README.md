## 说明

正文与设定均为创作稿，剧情、对白、人设定稿；扩写稿只增加环境、动作、神态、心理与群像描写。

设定集·全卷合订本为**混编体例**（2026-09-26 重编）：全部设定打散到编/卷级单元、按主题重排为十卷（总纲→历史→世界→疆域首都→皇室政制→军事→经济民生→文教科技→理论推演→官员名录），单元正文逐字保留，原编/卷编号不变；由 `tools/build_setting_book.py` 生成并内置零遗漏断言，改分卷后重跑即可。

## 重新生成 PDF

```bash
py -3 tools/build_novel_book.py          # 《华北风暴》→ 桌面/华北风暴(2026).pdf
py -3 tools/check_novel_pdf.py           # 35 项格式检查
py -3 tools/build_setting_book.py \
    --pdf "$USERPROFILE/Desktop/中华帝国设定集(2026).pdf" \
    --roster-pdf "$USERPROFILE/Desktop/全国官员名录·全卷合订本(2026).pdf"
```
