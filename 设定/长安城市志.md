# 《长安城市志》

**性质**：世界观专史·首都城市志。基于《中华帝国世界观总设定 v2.0》长安／西安城市规划核心设定，以及《编年史》《世界近代史推演》互证，按「地理—沿革—城池—功能—人口—礼制—市井—小说用法」体例编写。

**别称**：长安（正式／历史／礼仪）；西安（现代语境常用）；关中首都都市区（都市圈口径）

**一句话定位**：

> **帝国唯一首都、全国最高政治中心、国家机关总部所在地；城墙内是「国家客厅」，城墙外是超级都市圈；外国元首入城，城市骤然安静。**

# 卷一：地理与山河

## 一、关中形胜

| 要素 | 内容 |
| --- | --- |
| 位置 | 渭河平原（关中）中部，京畿直隶州核心 |
| 四塞 | 东潼关、西散关、南武关、北萧关——「四塞之国」 |
| 水系 | 渭河横贯；泾、沣、浐、灞等八水绕长安（历史意象延续） |
| 粮仓 | 关中平原＋四川盆地（经汉中）构成帝国永远的核心腹地 |
| 战略纵深 | 深居内陆，远离海上威胁；可「统大政于腹心」 |

**史臣曰**（承编年史）：朱元璋迁都成功，使政治中心不必贴边。此后六百年，长安之于帝国，犹如大脑之于身体——四肢可以受伤，大脑必须安稳。

## 二、与诸京对照

| 城市 | 角色 | 与长安关系 |
| --- | --- | --- |
| **长安** | **唯一首都**；政治、教育、国家文化、科技中心之一 | — |
| 上海 | 经济金融中心 | 江南州州府；「帝国钱包」 |
| 北京 | 华北政治经济中心 | 华北州州府；与长安形成「双首都」政治张力（小说重要张力源） |
| 沈阳 | 东北中心 | 东北州州府 |
| 乌鲁木齐 | 欧亚大陆贸易中心 | 西北州州府 |
| 南宁 | 东南亚陆桥中心 | 云贵州州府 |
| 拉萨 | 高原政治文化中心 | 青藏州州府 |

> **【核心】帝国的政治中心唯一：长安。** 北京为华北州府，因其离京畿近、体量大，在政治文化中常被写成「另一个权力场」。

# 卷二：城市沿革

## 一、远古至明初（背景）

| 时期 | 状态 |
| --- | --- |
| 周秦汉唐 | 东亚最大都市之一；政治符号的「原型空间」 |
| 唐以后 | 政治中心东移／北移，长安降为区域城市 |
| 明初 | **朱元璋迁都成功，定名长安**【核心】——政治中心回归关中 |

## 二、帝国时期（1700—1900）

| 时代 | 城市大事 |
| --- | --- |
| 开统（太祖） | 皇宫与中央政务区定址城墙内；七州州长述职制度使长安成为每年冬天的政治舞台 |
| 绍统—格致 | 皇家格物院、皇家典籍馆设于城南；城墙外开始出现工场与铁路附属地 |
| 咸熙—拓疆 | 铁路（长安—郑州等）通车；电报干线起点；城墙军事功能逐渐消失但完整保存 |
| 承平（宣宗） | 全国铁路电报网枢纽；报纸《京华日报》创刊于长安；城市人口突破百万级【推演】 |

## 三、20世纪

| 时期 | 城市大事 |
| --- | --- |
| 维新—革鼎前半 | 一战黄金时代大投资；现代市政、下水道、大学区扩展 |
| 1930s—1970s | 长安—上海双城人口先后破千万；城中村改造与单位大院解体同步 |
| **革鼎四十八年（1978）** | **全国政策大辩论在国家大会堂召开**——长安成为大革命的政治心脏 |
| 革鼎五十一年（1981） | 肃宗驾崩于长安皇家医院；三派在中央政治委员会扩大会议辩论 |
| **承宪五年（1986）** | 《中华帝国宪法》在长安颁布；宪法日成为国家法定纪念日 |
| 承宪十年（1990） | 华北风暴：工作组自长安南站出发；城墙标语「让每一代人都有改变命运的机会」入镜 |

## 四、21世纪

| 时期 | 城市大事 |
| --- | --- |
| 承宪后期—继文 | 高铁网八州州府贯通；长安都市圈一体化；渭河生态带严格保护 |
| 继文十一年（2026） | 核聚变示范堆（调试）；国家政策模拟系统大屏成为「新政治景观」；都市圈约6800万 |

## 二、城墙内：长安中央政务区【核心】

### 功能定位

> **完整保留政治中心功能，疏散其他功能；低商业化；限高；古建＋现代办公混合。**

### 机构清单（2026确认）

| 类别 | 机构 |
| --- | --- |
| 皇室 | 皇宫及皇室办公机构；皇室事务委员会；皇储办公室 |
| 政治 | 中央政治委员会；中央政治局常委办公机构；中央办公厅／政治局秘书处 |
| 政府 | 中央政府各部委（七大系统组成部门与直属机构总部） |
| 议会 | 中华帝国国民议会（国家大会堂） |
| 司法 | 最高法院、最高检察院、帝国宪法法院 |
| 监察 | 中央纪律检查委员会、国家监察委员会 |
| 军事 | 中央军事委员会 |
| 审计／国安 | 帝国审计院；国家安全委员会（值班室可转接紧急越级报告） |
| 文化 | 国家档案馆、国家博物馆、帝国历史档案馆（含大革命展厅） |
| 经济 | 部分中央直属国企、事业单位总部 |

### 城墙内限制【核心】

| 禁止 | 允许 |
| --- | --- |
| 大型工厂 | 小型餐饮 |
| 大型物流中心 | 书店、传统商业 |
| 高耗能产业 | 博物馆、国家文化机构 |
| 大型仓储 | 公共服务 |
| 大型商业综合体 | 少量住宅 |
| 大规模房地产开发 | |

### 住宅政策【核心】

城墙内住宅**极少**，主要保留：

- 皇室居所
- 高级公务员住宅
- 外交人员住所
- 国家工作人员宿舍

### 建筑风貌【核心】

- 中央机关尽量使用**古典建筑＋现代办公建筑**
- **高度严格限制**，不能让现代建筑压过古都历史景观
- 大型商业中心全部迁出城墙

### 入城礼仪【核心细化】

外国元首：

```
机场 → 专车 → 抵城墙门 → 换乘或步行入城
→ 城市骤然安静 → 古建筑之间列布中央机关 → 皇宫觐见
```

> **视觉效果极其强烈**——这是帝国最独特的外交名片。

本州干部进京述职：

> 需在城墙外下车步行入内——**仪式感拉满**（小说美术规范）。

# 卷五：国家礼制空间

## 一、皇宫【核心】

| 属性 | 内容 |
| --- | --- |
| 政治 | 皇帝主持常委会、听取汇报（紫光阁等） |
| 文化 | 逐渐从传统政治空间转化为**国家文化象征** |
| 开放 | 普通人可预约参观部分区域；重大节日扩大开放 |
| 广场 | 阅兵等重大国家仪式；国民集会 |

**紫光阁**：小说中皇帝每月末听取常委会汇报之地；只见红笔批示，不见皇帝亲自打电话到华北——**「不忙」的戏剧化表达**。

## 二、国家大会堂【核心】

| 属性 | 内容 |
| --- | --- |
| 政治 | 议会全体会议、宪法日特别会议、全国政策大辩论 |
| 文化 | 大型演唱会、电竞赛事、音乐会 |
| 容量 | 大场馆可容纳几万人 |
| 席位 | 中央议会720席时充分利用 |

> **「人民的殿堂」**——政治仪式与文化盛事共用。

### 中央政治委员会会议厅（2026）

| 属性 | 内容 |
| --- | --- |
| 位置 | 国家大会堂三层，独立入口，与国家大会堂共用安检与外墙 |
| 席位 | 委员 **80** 席（半圆三层；含主席皇帝在内计 1 席）；列席席 40（副职、专门委副主任、州长、审计特派办；**八大军区司令与三大舰队司令不列席**） |
| 座次 | 皇帝主席位居中；政治局 **27** 席居前两排；州委主席、州长、部委主官、议会专门委、**三军种负责人与总政治部主任**按系统分区（军职合计六席） |
| 会议 | 全体会议每年至少一次（春季）；临时会议与扩大会议 |
| 礼仪 | 皇帝入席时全体起立；决议以「政发〔年〕X号」发布，公报在会后两小时内公布议题与结论 |
| 保密 | 涉密议题闭门审议，公报只写议题与结论 |

### 换届周（五年一次·国家大会堂）【核心】

> 议会、政治委员会、政治代表会议**同日换届**，七日在国家大会堂建筑群内跑完全流程，新旧交接不停摆（《换届程序法》1986）。

| 日 | 万人厅（全政会） | 议会厅／主厅（国民议会） |
| --- | --- | --- |
| 第 1 日 | 双会同时开幕；皇帝以政委会主席、议会常委会主席双重身份致《国家方向与换届动员讲话》；下午听取上届政委会工作报告 | 同；下午听取审计院、国家监委年度报告 |
| 第 2—3 日 | 确认当然委员资格、对上一届选举委员信任投票；中央政委会提差额候选人（含届满者以普通候选人身份参选），闭门酝酿 | 各专委会审议上届政府预算执行与政府工作报告 |
| 第 4 日 | 秘密投票选举选举委员、确认新一届政委会；政委会全体会议随即选举政治局 27 与常委 9 | — |
| 第 5 日 | 皇帝于**紫光阁**接见新一届政委会并颁任命状；下午向议会提交总理、副总理、部长、两高与监委首长名单 | 接收名单、进入审议 |
| 第 6 日 | — | 全体会议对总理及内阁名单信任投票；如有修宪确认案一并表决 |
| 第 7 日 | 万人厅联合闭幕，皇帝发表《告国人书》；官方媒体头版发布新一届名单 | 同 |

**僵局规则**：出现票数不足或人选被否时设**七十二小时加时调解期**，由皇帝协调、政委会与议会领导层重提折中名单再表决；同一人选连续两次被否决，报政委会与议会常委会联合裁决；换届须于三十日内完成，逾期由皇帝径行任命过渡班子。

> 灞桥区（原「长安区」）在高等教育与科研之外，另扛一块功能：**政治教育与意识形态**。园区以中央政治学院与京畿直隶州立政治学院共用的校区为核，四周环绕政治口的研究、出版、报刊与史志机构。

| **京畿直隶州立政治学院** | 四品 | 与央政**同校区**，建制独立、学籍独立；本科三组八专业、基培 |
| **中央政策调研室** | 三品 | 政治局直属，决策前预研；主任由政治局委员兼任 |

| **《帝国政治报》报社** | 四品 | 政治局机关报；头版只登中央与州级人事、决议 |

园区中轴是「政书堂」，合班上课与结业典礼都在这里；东侧是两家出版社与报社，西侧是调研室与社会工程院。两校共用图书馆、礼堂、体育场，但从不联办开学典礼——**建制独立这件事，在细节上不含糊**。

## 二、国家政策模拟系统【推演·小说意象】
