# 《长安城市志》

**性质**：世界观专史·首都城市志。基于《中华帝国世界观总设定 v2.0》长安／西安城市规划核心设定，以及《编年史》《世界近代史推演》互证，按「地理—沿革—城池—功能—人口—礼制—市井—空间承载」体例编写。

**别称**：长安（正式／历史／礼仪）；西安（现代语境常用）；关中首都都市区（都市圈口径）

**一句话定位**：

> **帝国唯一首都、全国最高政治中心、国家机关总部所在地；回字四重城（宫城—皇城—内城—外城）层层包裹，四道砖城墙完整保存；外国元首车队穿城而过，城市骤然安静。**

# 卷一：地理与山河

## 一、关中形胜

| 要素 | 内容 |
| --- | --- |
| 位置 | 渭河平原（关中）中部，京畿直隶州核心 |
| 四塞 | 东潼关、西散关、南武关、北萧关——「四塞之国」 |
| 水系 | 渭河横贯；泾、沣、浐、灞等八水绕长安（历史意象延续） |
| 粮仓 | 关中平原＋四川盆地（经汉中）构成帝国永远的核心腹地 |
| 战略纵深 | 深居内陆，远离海上威胁；可「统大政于腹心」 |

**史臣曰**（承编年史）：朱元璋迁都成功，使政治中心不必贴边。此后六百年，长安之于帝国，犹如大脑之于身体——四肢可以受伤，大脑必须安稳。

## 二、与诸京对照

| 城市 | 角色 | 与长安关系 |
| --- | --- | --- |
| **长安** | **唯一首都**；政治、教育、国家文化、科技中心之一 | — |
| 上海 | 经济金融中心 | 江南州州府；「帝国钱包」 |
| 北京 | 华北政治经济中心 | 华北州州府；与长安形成「双首都」的政治张力 |
| 沈阳 | 东北中心 | 东北州州府 |
| 乌鲁木齐 | 欧亚大陆贸易中心 | 西北州州府 |

| 拉萨 | 高原政治文化中心 | 青藏州州府 |

> **【核心】帝国的政治中心唯一：长安。** 北京为华北州府，因其离京畿近、体量大，在政治文化中常被写成「另一个权力场」。

# 卷二：城市沿革

## 一、远古至明初（背景）

| 时期 | 状态 |
| --- | --- |
| 周秦汉唐 | 东亚最大都市之一；政治符号的「原型空间」 |
| 唐以后 | 政治中心东移／北移，长安降为区域城市 |
| 明初 | **朱元璋迁都成功，定名长安**【核心】——政治中心回归关中；按明南京之制营建回字四重城（宫城、皇城、内城、外城） |

## 二、帝国时期（1700—1900）

| 时代 | 城市大事 |
| --- | --- |
| 开统（太祖） | 宫城、皇城与中央政务区定址内城墙以内；七州州长述职制度使长安成为每年冬天的政治舞台 |
| 绍统—格致 | 皇家格物院、皇家典籍馆设于城南；城墙外开始出现工场与铁路附属地 |
| 咸熙—拓疆 | 铁路（长安—郑州等）通车；电报干线起点；城墙军事功能逐渐消失但完整保存 |
| 承平（宣宗） | 全国铁路电报网枢纽；报纸《京华日报》创刊于长安；城市人口突破百万级【推演】 |

## 三、20世纪

| 时期 | 城市大事 |
| --- | --- |
| 维新—革鼎前半 | 一战黄金时代大投资；现代市政、下水道、大学区扩展 |
| 1930s—1970s | 长安—上海双城人口先后破千万；城中村改造与单位大院解体同步 |
| **革鼎四十八年（1978）** | **第一届三千人大会在国家大会堂召开**——长安成为大革命的政治心脏 |
| 革鼎五十一年（1981） | 肃宗驾崩于长安皇家医院；三派在中央政治委员会扩大会议辩论 |
| **承宪五年（1986）** | 《中华帝国宪法》在长安颁布；宪法日成为国家法定纪念日 |
| 承宪九年（1990） | 查贪查腐专项斗争：中央工作组自长安南站出发；城墙标语「让每一代人都有改变命运的机会」 |

## 四、21世纪

| 时期 | 城市大事 |
| --- | --- |
| 承宪后期—继文 | 高铁网八州州府贯通；长安都市圈一体化；渭河生态带严格保护 |

# 卷三：城池与空间结构

## 一、总体结构（2026）：回字四重城

长安是明初营建、帝国沿用的回字四重城，四道砖城墙自内而外层层包裹：

| 层 | 东西×南北 | 面积 | 周长 | 墙高 | 一句话 |
| --- | --- | --- | --- | --- | --- |
| **宫城** | 753×961 m | 0.72 km² | 3.43 km | 10 m（护城河宽 52 m） | 皇帝起居与决策 |
| **皇城** | 2,000×1,950 m | 3.90 km² | 7.90 km | 10 m | 中央各部委与核心机构 |
| **内城** | 4,200×2,700 m | 11.34 km² | 13.80 km | 12 m | 国家广场、使馆区、顶级商业与住宅 |
| **外城** | 14,100×14,100 m | 198.81 km² | 56.40 km | 12 m | 市井居住、天坛地坛 |

四层面积比 **1 : 5.4 : 15.8 : 276**。城墙高度分两档：外城墙与内城墙为城防墙，各 12 m；皇城墙与宫城墙为禁卫墙，各 10 m。

「回」字的形状：外城把内城整个包住，内城把皇城整个包住，皇城把宫城整个包住——从任何一道门进城，都要穿过外面几道墙的同一根中轴。

## 二、国家大会堂【核心】

建筑群主体由三块构成：中厅是体量最大的主体建筑，左右两厅较小，分别贴靠在中厅东西两侧。

| 厅 | 构成 | 用途 |
| --- | --- | --- |
| **左厅** | 八州厅 8 间（京畿、华北、东北、蒙古、西北、江南、云贵、青藏），中小型；**宣政厅** 1 间，约 140 席 | 八州厅供州代表团、专门委员会与分组审议；宣政厅为左厅主会议厅，中央政治委员会全体会议（80 席）与扩大会议（80 席＋列席 40）在此举行，联席会、听证会与签署仪式亦在此 |
| **中厅** | 无立柱万人大礼堂，约 10,000 席 | 全国政治代表会议全体会议、宪法日特别会议 |
| **右厅** | 无立柱大型宴会厅，约 3,000 席 | 国宴、授勋与颁状礼、大型招待会 |

广场东侧另设单体建筑**国家议会议事大楼**，约 1,100 席（议员 720 席＋列席与旁听），国家议会全体会议与九个专门委员会在此举行；议会常委会例会在宫城紫光阁侧殿举行。

> 三厅同属大会堂建筑群，共用安检与外墙，各自设独立入口；议事大楼在广场东侧，与大会堂隔广场相望。**「人民的殿堂」**——政务会议、国宴与仪典共用同一建筑群；演出与赛事归国家体育场建筑群。

### 换届周（五年一次·国家大会堂）【核心】

> 议会、政治委员会、政治代表会议**同日换届**，七日在国家大会堂建筑群内跑完全流程，新旧交接不停摆（《换届程序法》1986）。

## 一·补、灞桥政教园区【核心·2026-11】

> 灞桥区（原「长安区」）在高等教育与科研之外，另扛一块功能：**政治教育与意识形态**。两所政治学院与政治口的研究、出版、报刊、史志机构集中在**同一块地皮、同一片建筑群**：一道围墙、一套门禁、一条中轴，机构之间只隔楼与廊，不隔街。

| 机构 | 级别 | 说明 |
| --- | --- | --- |
| **中央政治学院** | 三品 | 本科四组十专业；中培、高培；皇储培养主渠道（三品级单位；校长三品，现由二品以上者高配兼任） |
| **京畿直隶州立政治学院** | 四品 | 与央政**同院区**，建制独立、学籍独立；本科三组八专业、基培 |
| **中央政策调研室** | 三品 | 政治局直属，决策前预研；主任由政治局委员兼任 |
| **《帝国》杂志社** | 四品 | 政治局主办的最高理论刊物：正栏作者三品以上，**四品及以下入「基层来信」——包括省长** |
| **《帝国政治报》报社** | 四品 | 政治局机关报；头版只登中央与州级人事、决议 |
| **帝国社会工程院** | 四品 | 社会治理工程与政策仿真；与皇家理工国家政策模拟中心合建「制度仿真联合实验室」 |
| **帝国史编撰办公室** | 四品 | 国史、编年、政治文献的编纂与定本 |
| **帝国政治出版社** | 五品 | 政治文献、法规汇编、皇帝著作与讲话集 |
| **中央政治学院出版社** | 六品 | 教材、学报、政治学专著 |
| **中央政治学院高级行政研究部** | 三品 | 高培承办 |
| **中央政治学院附属中学** | 九品 | 全帝国唯一在招生简章上写明「政审三代」的中学 |

院区中轴是「政书堂」，合班上课与结业典礼都在这里；东侧是两家出版社与报社，西侧是调研室与社会工程院，南侧是两校共用的图书馆、礼堂与体育场。两校从不联办开学典礼——**建制独立这件事，在细节上不含糊**。

- 舆论监督是「多源信息原则」的社会端；受法律保护，但不得煽动暴力推翻体制
