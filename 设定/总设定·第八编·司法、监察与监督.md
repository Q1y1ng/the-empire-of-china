# 第八编：司法、监察与监督

## 一、司法体系

### 【核心正式设定】

- 中央设最高法院，负责全国最高审判、重大刑事案件、官员犯罪、地方司法监督、统一解释法律
- 司法从行政系统中半独立出来
- 天子犯法与庶民同罪
- 有军事法庭/对待外籍人士的特别法庭
- 地方条例不能违反中央旨意

### 【核心正式设定：地方司法】

- 州级法院
- 省级法院
- 市级法院
- 基层法院

## 二、监察体系

### 【核心正式设定】

- 中央纪委与国家监委分别独立于中央议会，互不隶属、分别向中央政治局常委会负责
- 可以调查：贪污、滥权、地方官暴政、皇帝直属官员违法、军队违法、官员结党营私
- 可以弹劾一品官
- 向中央政治局常委会汇报，也可单独向皇帝汇报
- 中央纪委与国家监委原则上不得兼任其他核心委员会，且纪委、监委主官不得互相兼任

## 三、审计体系

### 【核心正式设定】

- 存在独立审计机构
- 审计系统独立运作

## 四、权力分权体系

### 【核心正式设定：多链条运行】

这个帝国不同权力沿不同的垂直链条运行：

- **行政链**：中央 → 州 → 省 → 市 → 区 → 街道
- **人事链**：皇帝/中央 → 各级干部系统
- **军事链**：皇帝 → 中央军委 → 军区 → 军 → 旅 → 营 → 连 → 班
- **财政链**：中央 → 州 → 省市
- **民意链**：居民 → 基层选举 → 代议机构 → 上级政治机构
- **监察链**：中央监察 → 州监察 → 地方监察

这些链条故意不完全重合。因此：

- 州长不能控制军队
- 军队不能任命州长
- 省长不能自己决定继任者
- 议院不能直接控制军队
- 皇帝也不亲自管理每一级行政
