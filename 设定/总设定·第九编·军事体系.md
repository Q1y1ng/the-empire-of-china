# 第九编：军事体系

## 一、军事组织架构

### 【核心正式设定】

```
皇帝（国家最高统帅·中央军委主席）
    │
中央军事委员会
    ├─陆军：八大军区（对应八州）→ 军 → 旅 → 营 → 连 → 班
    ├─海军：北海舰队／东海舰队／南海舰队 → 支队 → 舰艇（舰内设连/班）
    ├─空军：八军区空军（每军区1个空军军）→ 旅 → 大队 → 中队 → 小队
    └─战略力量（火箭军）·太空与网络力量·院校科研联勤（直属军委，不隶属军区）
```

### 【核心正式设定：编制总纲（摘要·2026冻结版）】

三军编制链（作者草案；详细编制、装备核算与待定清单见《全国军事编制设定(2026)》分卷）：

| 军种 | 编制链（由小到大） |
| --- | --- |
| 陆军 | 班（15人）→连（10班）→营（10连）→旅（10营，标准重装旅15,000人）→军（10旅，150,000人）→军区（约2个军）→中央军委 |
| 空军 | 小队（15人≈5机）→中队（3小队，15机）→大队（4中队，60机）→旅（5大队，300机）→军（4旅，1,200机）→军区（每军区1个空军军）→中央军委 |
| 海军 | 水兵班（5人）→连（3班）→舰艇（护卫舰45人/驱逐舰75人/巡洋舰150人）→支队（40艘主力舰）→舰队（6个支队，共三大舰队）→中央军委 |

- 陆军班型：战斗班6种（一般步兵/重装/防空/工兵/运火/远支）＋专业班5种（炊事/医疗/航空/运输/航空运输），每班15人。
- 军衔独立于文官品级；指挥岗位标准衔：班＝少尉、连＝上尉、营＝少校、旅＝大校、军＝中将、军区＝中将（职位三品）、军委＝上将/元帅（皇帝特授）。
- 规模概数：陆军约300万人（八大军区野战16个军约240万＋边海防、院校、预备役转服等约60万）；空军全军约12,800机、空勤约38,400人；海军三大舰队合计约720艘主力舰。

## 二、军区与州的关系

### 【核心正式设定】

- 八州对应八大军区
- 海军另有三大舰队
- 州军区司令在州人民政治委员会常务委员会中担任委员
- 州军区没有独立调兵权
- 军队最终属于中央军事委员会

## 三、海军

### 【核心正式设定】

- 海军不直接参与对外贸易
- 只提供护航/武力保护
- 海军隶属中央军事委员会，由中央统一指挥与建设
- 海军核心任务：国土与海疆防卫、海外商路保护、护航、打击海盗、海外侨民/商人保护、战争时期封锁与军事行动
- 海军不得直接经营商业贸易

## 四、军事教育

### 【核心正式设定】

- 存在中央军委直属军校
- 军官在军校基层训练一年并顺利毕业后产生
- 士官从士兵中产生

## 五、兵役制度

### 【核心正式设定】

- 志愿+征兵结合
- 志愿兵够用就不征兵

## 六、三大舰队防区（冻结版）

| 舰队 | 防区 | 覆盖 |
| --- | --- | --- |
| **北海舰队** | 渤海、黄海、日本海、鄂霍次克海 | 华北、东北、朝鲜半岛、海参崴、库页岛 |
| **东海舰队** | 东海、台湾海峡、琉球、西太平洋 | 江南、台湾、琉球、福建、日本方向 |
| **南海舰队** | 南海、南沙、中沙、中南半岛南部海域 | 岭南、河内、南宁、海南、南沙、中沙 |

陆军八大军区与八州高度对应。

## 七、军衔与军官体系（2026修订）

- 军官分**士官**与**军官**两轨：士官从优秀士兵中选拔；军官经军委直属军校基层训练一年毕业授衔
- 军校体系：中央军委直属各军种军校＋国立海军工程大学等军民结合院校
- 军官职业化：服役年限、轮换、退役安置（退役军人事务机构归口政府国防系统）
- **指挥岗位标准衔（2026冻结）**：班长＝少尉、连长＝上尉、营长＝少校、旅长＝大校、军长＝中将、军区司令＝中将（职位三品）、军委＝上将/元帅（元帅为皇帝特授荣衔）；完整12阶军官军衔与9等士官/士兵军衔见附录二及《全国军事编制设定(2026)》第二编

## 八、战略力量（推演细化）

- **战略威慑体系**：直属中央军委，不隶属军区；二次打击能力为国防基石
- 帝国核政策：防御性威慑，不首先使用（推演）
- 太空与网络力量：军民结合，归口科技发展与基础建设系统＋国家安全委员会协调

## 九、军事战略

### 【核心正式设定】

- 帝国是防御性强国
- 不主动建立军事同盟控制世界
- 不允许其他大国破坏帝国核心利益
- 海军重点保护帝国港口、商船航线、海峡、岛屿、海盗高发区、战略补给港
- 战略目标为"控制航道"
