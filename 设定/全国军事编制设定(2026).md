# 《全国军事编制设定（2026）》

> **依据**：《中华帝国世界观总设定 v2.0》第九编「军事体系」、第六编「中央军事委员会」与附录二「帝国军队层级与军衔表」；作者2026年9月提供的编制草案（三军链条、11种班型装备、标准重装旅编成、航母编成）为**第一优先级**，按原样入典；《全国官员名录》卷一（军委名单）、卷二（军委内设）、卷三十三（政治委员会军职委员）、卷三十五（三大舰队与八大军区纵深）职务品级互证；《中华帝国编年史》「文官十品与武官十二阶并行」；《全国高等教育设定(2026)》军事院校编。
> **版本**：继文十一年（2026）· 首版。
> **符号约定**：※＝推演创作；【推演】＝待作者定夺；【核心】＝作者草案原样或总设定冻结项；【待定】＝尚未拍板。
> **时间线**：继文十一年（2026）现役编制。
> **术语说明**：设定文件统一用「军区」（本卷新编后总设定附录二旧「八大战区」已同步修订）；小说《华北风暴》中口语「战区」为人物用语，不改。

## 第一编 总纲与指挥链

### 一、指挥体系【核心】

```
皇帝（国家最高统帅·中央军委主席）
    │
中央军事委员会
    ├─陆军：八大军区（对应八州）→ 军 → 旅 → 营 → 连 → 班
    ├─海军：北海舰队／东海舰队／南海舰队 → 支队 → 舰艇（舰内设连/班）
    ├─空军：八军区空军（每军区1个空军军）→ 旅 → 大队 → 中队 → 小队
    └─战略力量（火箭军）·太空与网络力量·院校科研联勤体系（直属军委，不隶属军区）
```

### 二、三军编制链总表【核心】

| 军种 | 编制链（由小到大） | 链条性质 |
| --- | --- | --- |
| **陆军** | 班 → 连 → 营 → 旅 → 军 → 军区 → 军委 | 合成战斗链条：连＝10班、营＝10连、旅＝10营、军＝10旅、军区＝约2个军 |
| **空军** | 小队 → 中队 → 大队 → 旅 → 军 → 军区 → 军委 | 航空兵链条：与陆军平行，末端为小队而非班 |
| **海军** | 班 → 连 → 舰艇 → 支队 → 舰队 → 军委 | 舰内编制（班/连）＋舰艇战术编成（支队/舰队）两层结构 |

- 军委为全军最高领导机关，主席由皇帝兼任【核心，总设定第六编】。
- 三军链条终点均为中央军委；八州设八大军区（陆军），海军另有三大舰队【核心，总设定第九编】。

### 三、军政关系与指挥纪律【核心·沿用总设定】

- 州军区司令担任州人民政治委员会常务委员会第10席委员，但不负责地方行政。
- **州军区没有调兵权**；可调动次一级相当于武装警察的部队，但须上一级军队长官批准，特殊情况先行动后必须立刻补交报告。
- **双钥匙原则**：州级重大军事行动必须同时获得中央军事系统＋地方行政系统的许可；战争时期中央军委可以直接下令。
- 州长不能越级指挥军队；军队宣誓对象为帝国（国家），而非个人。

## 第四编 空军编制

### 一、链条与倍率【核心·作者确认缩比口径】

| 层级 | 编成 | 标准兵力 | 标准机数 |
| --- | --- | --- | --- |
| **小队** | — | **15人** | 约5机（3人/机，同陆军航空班口径） |
| **中队** | 3个小队 | 45人 | **15机** |
| **大队** | 4个中队 | 180人 | **60机** |
| **旅** | 5个大队 | 900人 | **300机** |
| **军** | 8个旅 | 7,200人 | **2,400机** |
| **军区** | 1个空军军 | 7,200人 | 2,400机 |
| **全军** | 8个军（八军区各一） | 空勤**57,600人** | **约19,200机** |

- 作者原草案「15 ×10 ×10 ×5 约八个」的等比放大（中队＝10小队、大队＝10中队）经核算为全军约48万空勤/16万架，与陆军约240万人的比例失衡；经作者确认采用**缩比口径**入典。
- 空勤57,600人为链条内口径；加地勤、机关、院校等总计约**30万人**【推演】。

### 二、组织称谓【推演】

- 各军区编1个空军军，通称「××军区空军」（如华北军区空军）。
- 旅以下为大队→中队→小队；旅为基本战术兵团，与陆军旅平行但规模较小。
- 机种细分（歼击、轰炸、运输、预警、电子战等在小队/中队层的配比）【待定】。

## 第六编 战略力量与太空网络力量

- **战略力量（火箭军）**：直属中央军委，**不隶属军区、不入三军编制链**；二次打击能力为国防基石；核政策为防御性威慑、不首先使用【核心·沿用总设定第九编/编年史】。
- **太空与网络力量**：军民结合，作战力量直属军委，民用归口科技发展与基础建设系统＋国家安全委员会协调【核心·沿用】。
- 两支力量的内部编制（基地、旅/团层级、人数）【待定】。
- 院校衔接：火箭军3所、太空与网络3所军事院校已按军种单列（见《全国高等教育设定(2026)》军事院校编）。

## 第七编 军事教育、兵役与动员

### 一、兵役制度【核心·沿用】

- 志愿＋征兵结合，志愿兵够用就不征兵。

### 二、军官与士官两轨【核心·沿用】

- 士官从士兵中产生；军官经报考各地由军委直隶的军校，在基层训练一年并顺利毕业后产生。

### 三、军事院校体系

- 中央军委直属各军种军校＋军民结合院校（国立海军工程大学等）【核心】。
- 全军院校清单（帝国国防大学、国防科技大学、陆/海/空/火箭军/太空网络各3所、军医4所、士官学校与训练基地约30所）见《全国高等教育设定(2026)》第四至六编，本卷不重复列名。

### 四、国防动员体系

- 州设**州国防动员厅**（州政府组成机关，州厅制口径）；省设**省国防动员委员会**（主任任省常委第10席，五品）；市设**市国防动员办公室**（主任任市常委第10席，八品）——沿用官员名录卷二十二/卷三十口径【核心】。
- 州军区司令（州常委第10席）与省以下国防动员主任（同为第10席）分衔，体现「州管行政，军权归中央」。
