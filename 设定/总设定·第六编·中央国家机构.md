# 第六编：中央国家机构

## 〇、宪法法院与三条监督线

### 【核心正式设定：国家根本法命名规则（冻结版）】

- **1986年以前**：帝国根本性法律文件称**《中华帝国宪典》**（历史文献统称）
- **1986年大革命第三阶段**：颁布**《中华帝国宪法》**——现行国家根本法，此后不再称"根本法"或"宪典"
- 《中华帝国宪法》核心十条：①帝国国家主权统一 ②皇帝为国家最高政治领导人 ③皇帝任中央政治委员会主席（不设常委会委员长） ④政府依法行政 ⑤议会依法行使立法、预算及监督权 ⑥司法依法独立行使审判权 ⑦监察机关依法独立履行监察职能 ⑧地方接受中央和上级领导 ⑨特殊民族地区依法实行自治 ⑩皇位继承必须符合国家继承制度

### 【核心正式设定：帝国宪法法院】

- 最高司法体系下设：**最高法院、最高检察院、帝国宪法法院**
- 宪法法院尤其重要：大革命最大的制度遗产就是明确权力边界，因此中央政府vs州政府、议会vs政府、国家机关vs国家机关、法律vs宪法等权力边界冲突，交由宪法法院裁决
- 这使"大革命后的权力边界"真正具有法律上的最终保障

### 【核心正式设定：帝国审计院】

- **帝国审计院**直接对中央议会负责，形成三条监督线：
  - 中央议会 → 政治监督
  - 审计院 → 财政监督
  - 中央纪委、国家监委 → 公职监督
- 三者互不替代

### 【核心正式设定：国家安全委员会】

- 国安局是**国家安全情报机关**
- 上级协调机构为**国家安全委员会**：负责国家安全战略、风险评估、跨部门协调
- 下辖：国安局、军事情报、外务情报
- 国安局能力很强，职权由法律明确界定；向中央政治局常委会负责，受监察机关监督

## 一、中央军事委员会

### 【核心正式设定】

- 中央军委领导全国武装力量
- 皇帝兼任中央军委主席
- 设军委副主席
- 军队由依附于政治局常委和皇帝的中央军事委员会管理
- 军队宣誓对象为帝国（国家）

### 【核心正式设定：军政关系】

- 州级主管行政，军队由中央军事委员会管理
- 军队的州级长官可以在本州的委员会里当委员以进行军队与政府的沟通交流，但主要还是由中央控制
- 州长不能越级指挥军队
- 州军区没有调兵权
- 双钥匙原则：州级重大军事行动必须同时获得中央军事系统 + 地方行政系统的许可
- 战争时期中央军事委员会可以直接下令

### 【核心正式设定：军队构成】

- 志愿+征兵结合，志愿兵够用就不征兵
- 军队军官分为士官和军官
- 士官经由士兵中产生
- 军官则在报考各地由军委直隶的军校在基层训练一年并顺利毕业后产生
- 八州对应八大军区
- 另有北海、东海、南海舰队

### 【核心正式设定：州军区调动权】

- 州军区没有调兵权
- 可以调动次一级相当于武装警察的军队
- 但还是要上一级的军队长官批准
- 特殊情况除外，但必须事后立刻补交报告

## 二、中央监察机关（中央纪委与国家监委）

### 【核心正式设定】

- 存在中央纪律检查委员会与国家监察委员会（两个独立机构）
- 监察机关向全国最高权力机关中央政治局常委会汇报
- 也可以单独向皇帝汇报
- 中央纪委与国家监委原则上不得兼任其他核心委员会，且纪委、监委主官不得互相兼任

### 【核心正式设定：监察机关的权力】

- 调查贪污、滥权、地方官暴政、皇帝直属官员违法、军队违法、官员结党营私
- 可以弹劾一品官
- 但皇帝不能直接撤掉正在调查自己的御史（推演）
- **紧急越级报告权**：正常情况下监察→中央政治局常委会；但若发现中央政府首脑涉嫌重大腐败且常委会本身存在利益冲突，可直接报告皇帝

## 三、司法系统

### 【核心正式设定】

- 有法典，法院检察院
- 天子犯法与庶民同罪，所有人都一样
- 有军事法庭/对待外籍人士的特别法庭
- 存在独立审计机构

### 【核心正式设定：司法独立】

- 有法典，法院检察院独立运作
- 地方条例不能违反中央旨意
- 设立地方条例由地方委员会通过后上报中央审批

## 四、中央组织机构

### 【核心正式设定】

- 负责中央组织与干部任用
- 重要干部跨级管理
- 干部选拔体系是整个制度的核心

## 五、国家安全机构

### 【核心正式设定】

- 存在中央独立国安/情报机构

## 六、中央政治口机构（中央政治局常委会配套）

### 【核心正式设定·2026确认版】

帝国政治口机构属于中央政治委员会体系，不由任何组织设立——任何组织（含非正式圈子）不得直接控制官职，官方机构的设立、编制与人事只依法律与干部制度。

| 机构 | 级别 | 职能 |
| --- | --- | --- |
| 中央办公厅 | 二级·二品副国 | 中央政治机构日常运转、文秘、统筹协调 |
| 政治局秘书处 | 二级（与中央办公厅一套机构、两个名号） | 常务委员会会务、议程与决议落实 |
| 中央组织委员会 | 二级·二品副国 | 干部任用、跨级管理、考核档案 |
| 中央宣传部 | 二级·二品副国 | 意识形态、宣传、舆论与文化（部长兼任中央政治局常委） |
| 中央民族与宗教委员会 | 二级 | 多民族共治与宗教事务顶层协调 |
| 中央政法委员会 | 二级 | 协调公检法（仅协调，不办案，不得干预独立司法） |
| 中央财政经济委员会 | 二级 | 经济、财政、金融、五年规划顶层决策 |
| 中央外事委员会 | 二级 | 重大外交战略决策协调（主任郁文清，**2026.12 起独立设人、二品副国**；此前由议会外事委主任巩叙远兼任） |
| 中央网信与人工智能委员会 | 二级 | 网络安全、数字元、AI跨部门协调 |
| 中央巡视委员会 | 二级 | 政治考核、巡视监督、御史评价联动 |

## 七、中央议会专门委员会

### 【核心正式设定·2026确认版】

国家议会设九个专门委员会，负责日常立法审议、预算审议、监督与调查：

- 财政经济委员会、宪法与法律委员会、监察与司法委员会、科技教育文化委员会、社会民生委员会、外事委员会、国防与安全委员会、民族事务委员会、资源环境与基建委员会
