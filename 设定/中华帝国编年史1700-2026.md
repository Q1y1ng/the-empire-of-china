# 《中华帝国编年史（约1360—2026）》

**性质**：世界观正史编年·深度扩写版。基于《中华帝国世界观总设定 v2.0》冻结版设定，按「编年体通史」体例编写：以年系事，一事多维（政制／经济／军事／文教／社会／科技／外交／民族），关键节点附「史臣曰」。

**体例说明**：

- 【核心】＝作者冻结设定，不可更改
- 【推演】＝依据总设定逻辑推演，可调整
- 【制度】＝制度理论解释，帮助理解因果
- 纪年：公历为主；皇帝年号并用（例：公元1990年／穆宗承宪十年）。世系与年号见**附三**
- 回答四问：①这套制度为何出现 ②哪些战争塑造疆域 ③工业革命为何未导致政体崩溃 ④1978年为何发生大革命、1986年后如何成型

# 序章：明末乱世与制度起源（约1360—1699）

## 一、地理论：为什么是长安

### 约1360年代：迁都成功【核心】

本世界线最早、也最关键的分叉，不是1700年，而是**朱元璋时期成功迁都西安，并重新定名「长安」**。

| 维度 | 影响 |
| --- | --- |
| 战略 | 政治中心深居关中腹地，远离东北边患与海上威胁；「关中＋四川」成为帝国永远的核心粮仓与战略纵深 |
| 政治 | 后来帝国「京畿直隶州」的地理基础；皇帝不必亲临前线，可「统大政于腹心」 |
| 文明 | 长安重新成为东亚政治符号——城墙、皇宫、政务区构成延续六百年的国家仪式空间 |
| 对照 | 现实世界线：迁都未成，后定北京，政治中心贴边，17世纪被东北方向力量叩关 |

**史臣曰**：迁都一事，使后来朱承乾不必「在边患与内乱之间做选择」，而可以「在腹地慢慢把制度养大」。地理给了制度时间，时间给了制度生命。

## 二、明末总危机（1610s—1640s）【推演】

| 时间 | 政制 | 社会经济 | 军事 |
| --- | --- | --- | --- |
| 1610s | 党争白热化，内阁与六部权责不清 | 小冰期：北方连年旱蝗，流民四起 | 辽东战事吃饷，内地卫所空额 |
| 1620s | 厂卫与文官互噬，信息管道失真 | 驿站瘫痪，政令不出京畿 | 军阀化苗头：将官私兵 |
| 1630s | 财政崩溃：加派三饷，民变遍地 | 豪强兼并，自耕农锐减 | 流寇与边军互相转化 |
| 1640s | 中央权威碎裂，地方各自为政 | 水旱叠加，人相食记载频现 | 无一支力量同时具备「军力＋治理能力」 |

**制度病灶**（后来太祖反复引用的三句话）：

1. 「人才不是没有，是**发现不了、用不稳**。」
2. 「信息不是没有，是**层层过滤后皇帝看不见真相**。」
3. 「军队不是不能打，是**打下来之后不会治**。」

## 三、朱承乾：从问题意识到治理能力（约1630s—1690s）

### 少年与问题意识【推演】

- 出身：旁支皇族／军功家族（具体出身待定），家庭并不特别显赫
- 核心提问（贯穿一生）：**「为什么一个国家明明有那么多人、那么多土地、那么多聪明人，却总是治理不好？」**
- 读书方法：不是「背圣贤书」，而是「把书拿到现实中验证」

### 青年基层历练（约1650s）【推演】

亲见三种人：

| 真才实学者 | 清廉者 | 善逢迎者 |
| --- | --- | --- |
| 一辈子小吏 | 被行政关系拖死 | 反而一路升迁 |

由此产生一生最重要的思想：

> **「国家不能只依赖皇帝识人。」**

### 研究历代制度（约1650s—1660s）【推演】

| 他研究什么 | 吸取什么 | 警惕什么 |
| --- | --- | --- |
| 秦汉 | 郡县、律令、驰道 | 秦法过苛、二世而斩 |
| 隋唐 | **把庞大异质地区整合进一个政治体系** | **藩镇：地方军事力量过强** |
| 宋 | 文官分权、财政精细 | 军事积弱 |
| 明 | 里甲、卫所、科举规模 | 卫所腐化、厂卫乱政、党争亡国 |
| 海外资料 | 火器、航海、度量、贸易 | 不盲目照搬 |

**直接催生的两条设计**：

1. 「州负责行政，军权归中央」
2. 「科举只授资格，不直接授官」

### 聚拢人才（约1660s）【推演】

30岁前后组织第一批团队：农家子弟、商人子弟、工匠、读书人、军人、水利员、医师。

> 实践口号：**「治理国家的人不应该按照出生决定。」**

### 「先夺治理，后夺天下」（1660s—1690s）【核心＋推演】

| 一般枭雄 | 朱承乾 |
| --- | --- |
| 先抢地盘 | **先建治理能力** |
| 军队以抢掠补给 | **军队必须买粮或政府统一征收登记** |
| 打下城池再想怎么治 | **粮食组织、水利队、基层行政、新式军队、临时学校、地方财政先行** |

普通人第一次觉得：**「这支军队和过去的军队不一样。」**

### 1690s：统一战争胜利【核心】

- 凭借治理能力优势在明末大乱中最终胜出
- **继承中华王朝正统合法性**——明朝法统终结，中华文明皇统未断
- 此时疆域已大致包含：中原及关中、江南、四川、东北、蒙古高原部分地区、新疆及中亚部分地区、朝鲜半岛、中南半岛北部及部分地区

**史臣曰**：历代开国，多以「马上得天下」。太祖独以「治理得天下」。故其登基之后，面对的首要敌人不是残余割据，而是**「制度本身会老化」**——他把皇帝本人也设计成制度的一部分，此为三百年帝国最深的原创性。

# 第一编：开国与制度奠基（1700—1749）

> **本编主旨**：这套制度为什么会出现——因为开国皇帝面对的敌人不是外敌，而是「制度本身会老化」。

## 1700年：制度元年【核心】

**朱承乾登基，国号中华帝国，定都长安。** 后世定为「制度元年」。

### 颁布新制度核心清单

| 领域 | 内容 |
| --- | --- |
| 最高政治 | **中央政治局常委会（七人制雏形）**：皇帝＋政府首脑＋军委副主席＋司法负责人＋监察负责人＋检察负责人＋组织人事负责人 |
| 行政 | **六级体系**：中央—州—省—市—区—街道办 |
| 品级 | **十品官阶＋三等吏制**：官经科举—政治学院—选举；吏经事务考试；优秀吏可考升为官 |
| 科举 | **只授公职资格，不直接授官**；官职＝地方选举＋上级考核＋中央任命 |
| 文官 | **政治官／事务官二元制** |
| 监察 | 监察、检察、司法相对独立 |
| 皇帝 | **「统而不包」**：天子亲统大政，不亲治细务 |
| 军制 | 文官十品与武官十二阶（元帅至少尉）并行，军衔独立于文官品级 |

### 1700年的世界环境【推演】

| 地区 | 状态 |
| --- | --- |
| 欧洲 | 科学革命后期；英、荷、法发展海运、贸易、金融、殖民 |
| 奥斯曼 | 仍然强大 |
| 印度 | 莫卧儿体系与地方势力并立 |
| 日本 | 德川幕府锁国 |
| 俄国 | 彼得大帝改革前夜，正向东扩张 |
| **中华帝国** | 刚完成制度整合，主动制度化的超级国家 |

**关键差异**：本世界线的中国不是「等待被叩关的停滞帝国」，而是**主动制度化的超级国家**。这决定此后三百多年的一切。

**史臣曰**：1700年，欧洲人还在争论「政府能否像机器一样被设计」，长安已经把整台机器画好了图纸，并把皇帝本人也画进了零件图。

## 1702—1710年：第一次行政改革【推演】

### 政制

- 建立**七州体系**（大区制）：中央面对七州而非四十省，信息与指挥层级减半
- 中央直接掌握：军队、货币、外交、盐铁、核心粮食区、大型水利、高级官员任命
- **京畿直隶制度萌芽**：关中＋四川核心粮区收归中央直接治理

### 经济与基建

| 年份（约） | 事件 |
| --- | --- |
| 1701—1705 | 全国度量衡统一 |
| 1701—1705 | 货币「中华元」雏形：宝钞改革后定银铜并行（19世纪纸币化→现代法币） |
| 1705—1710 | 开国剿匪完成；驿站改制为官办驿传＋民间邮驿双轨 |

### 民生

- 战乱区复耕、流民安置、里甲重建
- 基层「保甲—乡老—胥吏」三轨，胥吏纳入事务官考试管理

## 1711—1725年：基础教育革命【推演】

**《全国基础教育保障条例》**：

- 县、乡村建公共学校
- 贫困儿童减免学费
- 孤儿国家供养

**历史意义**：帝国第一次拥有**大规模受教育人口**——这是后来一切官僚体系、工业化、社会流动的地基。

**教育结构（雏形）**：

```
村塾/社学 → 县学 → 州学 → （科举）政治人才资格
                ↘ 职业学堂（水利、算学、医、匠）
```

## 1712年：述职制度开端【推演】

第一届七州州长同时进京述职。

> **「述职制度」自此成为每年冬天长安的政治景观。**

述职内容雏形：财政、人口、农业、军政、官员五账。

**史臣曰**：述职之制，使州长「不得不每年面对中央一次」。权力可以集中，但必须能够被制度纠错——纠错的第一步，是让下级无法永远不出现。

## 1718年：《推恩封令》【推演】

- 功臣爵位：嫡长继承多分、余子均分
- **爵位与行政权彻底切割**

**制度效果**：

| 旧贵族 | 帝国贵族 |
| --- | --- |
| 爵位＝土地＝行政权＝军队 | 爵位＝身份＋俸禄＋礼遇 |
| 尾大不掉 | 「有爵者不得凭爵直接做官」 |

## 1720年：《国政六策》【核心】

| 策 | 内容 | 后世回响 |
| --- | --- | --- |
| 一 | 全国基础教育保障 | 1780实践教育令、现代免费教育 |
| 二 | 限制各级政府编制 | 「小政府大社会」的最早财政纪律 |
| 三 | 技术官员行政化培养 | 事务官专业化 |
| 四 | 机械、冶金、火器、水利、航海五大科技战略 | 1764皇家理工大学 |
| 五 | **政党自由发展但禁止直接控制官职** | 四党体系的法理源头 |
| 六 | 海贸扩张＋盐铁官营＋严查贪腐 | 国家贸易体系 |

**史臣曰**：六策之中，第五策最超前——允许政治竞争，但竞争的是**政策**，不是**官位**。三百年后四党并立而国体不动，其根在此。

## 1723年：朝鲜省首次科举放榜【推演】

半岛士子及第入仕——**融合政策的首个标志性成果**。

**融合政策原则（贯穿三百年）**：

> **「使其同政，不必使其同俗。」**

手段：官话、汉字、帝国法律、帝国教育、帝国行政；不强迫改变民族身份；几代人自然融合。

## 1726—1735年：政治人才体系形成【推演】

### 三级科举制度化

| 类型 | 去向 |
| --- | --- |
| A类 | 政治学院（日后政治官） |
| B类 | 州立大学（技术与中级行政） |
| C类 | 职业教育（事务吏、匠、医） |

### 帝国第一社会流动机制

```
农村儿童 → 教育 → 考试 → 基层 → 官员/技术人员
```

**制度意义**：贫穷可以存在，但贫穷不能意味着没有未来。

## 1729年：治水立国工程高峰【推演】

- 京杭大运河全线疏浚完成
- 长江中游堤防体系建成

**国家能力宣言**：大型公共工程由国家组织、皇家格物院技术支撑、以工代赈吸纳劳动力——此模式沿用三百年。

## 1733年：第一次全国人口普查【推演】

约 **3.1亿人**。

> **统计能力即国家能力的宣言。**

此后人口、田亩、仓储、兵额「四账合一」成为州长述职标配。

## 1736—1749年：国家科研体系萌芽【推演】

| 机构 | 前身意义 |
| --- | --- |
| **皇家格物院** | 国立皇家理工大学前身——自然科学与工程 |
| **皇家典籍馆** | 国立中央翰林院大学前身——人文、法律、历史 |

国家投资方向：水利、冶金、火器、机械、造船、数学、天文、医学。

## 本期疆域战争【核心＋推演】

| 方向 | 内容 |
| --- | --- |
| 东北 | 控制辽东与松花江流域 |
| 漠南 | 蒙古归附 |
| 青藏 | 册封与驻军结合纳入 |
| 新疆 | 与准噶尔长期拉锯 |
| 朝鲜 | 半岛全境入版图，设官治理，低烈度融合开始 |
| 中南 | 控制红河流域与老挝方向；澜沧江—长山山脉成南部边界地理基础 |

**史臣曰**：开国五十年，太祖所做之事，归结为一句：**把「能打」变成「能治」，把「能治」写成「制度」，把「制度」教给下一代。** 其后工业化之所以不导致政体崩溃，根子全在此五十年。

# 第二编：第一次工业化（1750—1809）

> **本编主旨**：工业革命为什么没有导致政体崩溃——因为帝国工业化是「国家科研→国立大学→国家企业→私营跟进」的自上而下路径，不存在被新兴资本阶级颠覆政权的结构动力；且福利与工会把劳资矛盾制度化吸纳。

## 1740年：《三衡国策》【核心】

> **工业不废农，海军不挤民，民生不误国。**

三衡原则成为其后所有五年规划与预算审议的隐性标尺。

## 1750年代：蒸汽时代开启【推演】

蒸汽机械、大型水利机械、新式纺织机、机械化冶炼、标准化火器出现。

> **帝国与欧洲几乎同时开始工业化**——世界史上「西方＝现代、东方＝传统」的二元格局从根本上没有形成【核心】。

### 双源工业化对照

| 维度 | 欧洲道路 | 中华道路 |
| --- | --- | --- |
| 资本 | 私人资本→企业→国家 | **国家科研→国立大学→国家企业→私营跟进** |
| 政治 | 议会政治＋殖民掠夺 | 皇权＋委员会政治＋国家主导市场＋有限代议 |
| 社会 | 先撕裂后补救 | **福利与工会先行制度化**（1780/1790） |
| 结果 | 三大工业中心：欧洲、中华帝国、北美 | 同左 |

## 1760年：新税制改革【推演】

| 税种 | 设计意图 |
| --- | --- |
| 富人特别税（累进） | 抑制财富世袭 |
| 房产税 | 基本住宅免税、多套豪宅重税 |
| 遗产税 | 断「富不过三代」的反向——财富不能自动变成政治权力 |

**制度名言落地**：

> **「财富可以存在，但财富不能自动变成政治权力。」**

同年前后：铁路建设**以工代赈**启动。

## 1764年：国立皇家理工大学成立【推演】

- 五大院系：机械、冶金、水利、火器、航海
- 同年，**帝国海军与皇家理工大学联合开启环球探索**
- 建立全球**贸易站网络**（租借贸易站而非殖民地）【核心】

**对外原则（此后三百年）**：

> 帝国不干涉他国内政、不主导他国战争、不搞殖民征服——但**不允许其他大国破坏帝国核心利益**。

## 1770—1790年：铁路雏形【推演】

- 长安—郑州等早期线路
- 铁路以工代赈成为惯例：经济下行时国家上基建，既稳就业又加强中央对地方的掌控

## 1780年：《国民实践教育令》【核心】

| 条款 | 内容 |
| --- | --- |
| 实践年 | 大学生毕业前必须一年基层实践（国民实践年／上山下乡） |
| 干部 | 选拔看重基层治理经历 |
| 福利 | 失业保险、养老视同缴费、工农养老金趋同 |

> **现代福利制度比现实世界早了一个半世纪。**

**「上山下乡」细则【推演】**：

- 工科进考察过的工厂实习
- 农学进田间巷尾参与农业劳动
- 不合格不予毕业

## 1790年：工会制度建立【推演】

《工人团体管理条例》：

- 政府监管＋企业经营＋**工会谈判**三方格局
- 工会可谈：工资、工时、工伤赔偿、工作环境、企业福利
- **禁止工会干预政治**——如有干预予以重罚

**制度意义**：工业化带来的劳资矛盾被制度化吸纳——这是工业革命不导致政体崩溃的**第二根支柱**（第一根是国家主导的工业化路径）。

## 1790年前后：盛世制度定型【核心】

开国近百年，以下制度被后世视为「第一次帝制时代」的完成形态：

- 七州运转成熟
- 科举—政治学院—选举复合体系稳定
- 监察、审计、司法分立
- 盐铁官营＋累进税制
- 基础教育覆盖县乡
- 三舰队雏形护航全球商路

## 1805年：第一次制度化皇位交接【核心】

**皇储培养路线首次完整走通**：

```
中央政治学院 → 基层实践 → 地方轮职 → 省级 → 州级
→ 中央部门 → 军、财、法、监察体系学习
→ 中央政治委员会最终考核 → 继位
```

考核评语：**「具备履行皇帝职责之能力。」**

（不是「英明神武」，是**务实的能力评价**。）

### 帝制与工业化的兼容逻辑就此确立【制度】

```
皇帝不需要是天才，只需要不昏庸并依靠制度
        +
官僚体系提供专业治理
        +
选举与监察提供纠错
        +
福利与流动提供社会稳定
        ↓
四者咬合 → 工业革命带来的社会剧变被制度吸收，而非积累为革命
```

**史臣曰**：1805年一事，比任何一场战役都更能解释这个帝国为何没有变成「工业化的旧王朝」。皇位交接从「宫廷密室」变成「国家考试」，世袭的风险被制度对冲了一半。

# 第三编：现代国家形成（1810—1899）

> **本编主旨**：哪些战争塑造了疆域；全国市场如何形成；「合法的不平等」如何在盛世中悄悄发芽。

## 一、疆域定型战争（1810s—1860s）【核心＋推演】

| 战争 | 结果 |
| --- | --- |
| **西征与准噶尔—哈萨克战争**（18世纪末—19世纪初） | 边界推进至**巴尔喀什湖—天山—帕米尔**；设新疆省、帕米尔方向军政体系 |
| **北方边界战争（对俄）**（19世纪中叶） | 黑龙江流域对俄获胜；**沙俄失去外东北**；边界推至**外兴安岭—库页岛**；海参崴纳入版图设滨海省 |
| **南方战争（中南半岛整合）**（18世纪末—19世纪初） | **老挝全境并入**（澜沧省）；**越南北部及中部大部并入**（河内省）；柬埔寨、缅甸为受支配邻国而非本土 |
| **海上疆域整合** | 台湾（江南州）、琉球群岛、南海诸岛（含曾母暗沙战略极点）行政化 |

### 现代疆域完全定型【核心】

- **北**：库页岛—外兴安岭—贝加尔湖—阿萨彦岭—阿尔泰山
- **西**：巴尔喀什湖—天山—帕米尔—兴都库什—喜马拉雅
- **南**：横断山—澜沧江—长山山脉—曾母暗沙
- **东**：巴士海峡—台湾—琉球—朝鲜半岛

### 犬牙交错的兑现

辽南（华北）与辽宁（东北）渤海对峙；安徽跨江辖武汉方向；江西跨流域辖长沙；北部湾跨海辖海南；康巴入青藏管川西——**44省边界在此阶段基本走完实地勘定**。

| --- | --- |

## 四、与西方的碰撞（1840s—1860s）【推演】

- 欧洲殖民主义依然存在（非洲、南亚、美洲）
- 但欧洲殖民体系与帝国主导的自由贸易体系发生**结构性冲突**
- 帝国以「商业型全球强国」应对：不建殖民帝国，以海军保护全球贸易网络
- **西方无法复制鸦片战争式的对华胜利**——帝国是世界一流工业强国
- 欧洲转而与帝国达成贸易妥协，形成两大体系并立

## 五、铁路、电报与国家整合（1870s—1890s）【推演】

全国铁路网、电报网建成；八州—省—市行政体系全面现代化；城市化加速。

### 1880年代：官僚体系固化的最初征兆【推演】

> **「合法的不平等」萌芽。**

| 表象 | 实质 |
| --- | --- |
| 科举仍然公平 | 起跑线越来越不公平：国立大学、政治学院、家庭信息优势 |
| 官员仍然考试产生 | 「国立大学→地方干部→州级→中央→下一代」封闭循环出现 |
| 没有大规模贪腐丑闻 | 问题不是贪污，是**准入通道被中上层家庭事实垄断** |

**史臣曰**：此为帝国最深的讽刺——太祖消灭了血缘贵族，却未能消灭**权力本身形成贵族的能力**。要再等九十年，肃宗才会用一场大革命回答这个问题。

## 六、1900年前后：世界第一工业强国【核心】

| 钢铁、机械、铁路、船舶、化工 | 产量世界第一 |
| 社会保障 | 养老、工伤、失业、基础医疗建成 |
| 普通人的一生 | **成为其他国家普通群众的梦想**【核心】 |

# 第四编：世界大战时代（1900—1949）

> **本编主旨**：帝国如何在两场世界大战中既保持强盛，又避免「以战争重塑政体」；日本为何仍然走上军国主义并最终战败。

## 1904—1905年：日俄冲突的帝国仲裁【推演】

- 没有朝鲜半岛的俄国与强大的帝国相邻
- 日本在帝国海军威慑下**暂时**放弃大陆扩张
- 军部「南进论」埋下种子——仲裁延缓而未根除日本扩张冲动

## 1914—1918年：第一次世界大战【推演】

| 事件 | 内容 |
| --- | --- |
| 爆发 | 欧洲列强矛盾照常爆发 |
| 帝国 | **宣布武装中立**：向各方出售民用物资、海军护航全球商路、加强边防 |
| 结果 | 欧洲大规模消耗；美国与帝国成为两个超大型经济中心；**帝国黄金时代开启**（1919—1930：铁路、电网、高等教育、化工、汽车、航空、无线电大投资） |

### 1919年凡尔赛与「第二凡尔赛」【推演】

- 帝国以「战胜国＋中立调停国」双重身份与会
- **无「山东问题」**：帝国自1720年代起已收回列强一切在华租界企图
- 帝国在长安另设 **「万国东方和平会议」（1919.08）**：邀请暹罗、安南、缅甸代表与英法谈判
- **凡尔赛覆盖欧洲，长安体系覆盖亚洲**——两大秩序并立
- 亚洲民族主义者此后赴长安留学，而非仅赴伦敦巴黎

## 1929—1933年：大萧条【推演】

- 帝国受出口下滑冲击
- 应对：**「以工代赈＋国家投资」**（公共工程、铁路、水利、住房）
- **未发生社会崩溃**——政府主导型市场的第一次全球性验证
- 帝国模式国际声誉在此确立

## 1939—1945年：第二次世界大战（日本参战·同盟苦战版）【推演】

### 为何日本仍然参战

> 无中国战场牵制 → 日军全力南进西攻 → 太平洋战争烈度倍增。

1937年起军部少壮派以「南方资源自给」压倒文官政府；1940年与德意缔结三国同盟；1941年《帝国国防方针》将「夺取南洋—澳洲—夏威夷」列为国策。

### 战争进程要点

| 时间 | 事件 |
| --- | --- |
| 1939.09 | 德国入侵波兰；帝国宣布武装中立 |
| 1941.12.07 | 日本偷袭珍珠港（投入全部6艘航母＋2艘超战列舰） |
| 1941.12.08—12 | 日军闪击帝国南海诸岛、炮击河内湾与珠三角外海；帝国**对日宣战** |
| 1942上半年 | 日军席卷菲律宾、印尼、逼近澳洲；中途岛与南海海战首次止住攻势 |
| 1942—1943 | 同盟最黑暗一年：**无中国战场牵制**，澳美濒临封锁；帝国云贵—华南防线岿然不动 |
| 1943.07 | 阿拉伯海海战：帝国双航母编队夺回印度洋航线 |
| 1943.11 | **长安会晤**：皇帝与罗斯福元首会晤；此后长安多次主办同盟国元首会议 |
| 1944.03 | **南沙决战**：帝国三舰队主力击沉日航母3艘——太平洋战争公认转折点 |
| 1944—1945 | 缅甸—河内大反攻；日军被逐出中南半岛 |
| 1945.08 | 日本投降 |

### 战争代价与结果【推演】

| 项目 | 数据／结果 |
| --- | --- |
| 帝国阵亡 | 约95万人（远低于现实中国3500万，但歼敌比约1:1.2） |
| 本土 | 广州、河内、海口遭轰炸，**无一省会沦陷** |
| 战后地位 | 工业产值达美国约91%；海军总吨位世界第二 |
| 联合国 | 五常：美、帝国、苏、英、法 |
| 日本 | 与同盟国共同占领；帝国主占九州—濑户内—琉球；**常设驻军延续至2026** |

**史臣曰**：帝国之强韧，不在「未流血」，而在「流血而不失序」。1942年若无云贵防线，自由世界离失败最近的一年或将变为失败之年——此言虽为后世史家修辞，却点出帝国在同盟体系中不可替代的陆上支点地位。

## 四、1972年：河套省瞒报粮食案【推演】

地方虚报产量骗取中央补贴，被国安—审计联合查处。

> **「信息—权力集团」首次作为正式罪名入《监察法》。**

**制度预兆**：官僚层级层层过滤信息，可能绑架皇权——此后「多源信息原则」的历史前奏。

## 五、1970年代：制度老化【核心】

### 官僚阶层事实世袭化

> **「法律上没有世袭，实际上存在准世袭」**——国立大学→地方干部→州级→中央→下一代的封闭循环。

| 旧问题 | 新问题 |
| --- | --- |
| 贪污腐败 | **合法的不平等** |
| 血缘贵族 | **教育—信息—人际的「软世袭」** |
| 皇帝昏庸 | **制度本身已经被人学会了** |

### 肃宗朱弘宪：五次改革被消解【核心】

**姓名冻结**：**肃宗朱弘宪**。「弘宪」＝弘扬国家制度＋重建宪制。

**生平要点**【核心＋推演】：

- 约1900年出生；父亲中高级地方官员，母亲教师
- 少年即发现「公平并不等于平等」
- 按祖制基层任职：偏远省份，百姓只关心「水有没有来？孩子有没有学校？粮食够不够？」
- 关键发现：洪灾拨款层层分配后基层所得远低于预期——**没有一个人明显违法，每一层都有合法理由，但真正需要钱的人没有得到足够的钱**
- 中年：技术官僚，主管水利、财政、工业、教育、科技

**五次改革与被消解的方式**：

| 尝试 | 被消解的方式 |
| --- | --- |
| 限制高级官员任期 | 被规避 |
| 加强监察 | 监察机关自己形成利益网络 |
| 扩大基层选举 | 地方官僚影响候选人 |
| 国立大学扩招 | 上层家庭获得优势 |
| 官员财产公开 | 亲属、信托等方式规避 |

> **「如果只依靠现有官僚机构改革官僚机构，改革本身就会被官僚机构消解。」**

**史臣曰**：肃宗一生证明了两件事：第一，**制度可以被学会，也可以被武器化**；第二，**正常程序若已被既得利益集团占领，最高政治权威必须直接诉诸社会**。大革命不是野心，是绝望之后的责任。

# 第六编：大革命（1978—1986）【核心】

> **本编主旨**：1978年为何最终发生大革命——正常程序已被学会并武器化；大革命能以「改革」而非「改朝换代」收场，靠皇储制度培养出的接班人与军队国家化两大保险。

## 理论定位【核心】

| 表述 | 含义 |
| --- | --- |
| 传统王朝周期 | 开国→盛世→腐败→财政危机→社会危机→战争→改朝换代 |
| **帝国改造后** | 开国→制度化→发展→**制度老化→改革→制度更新**→再发展 |
| 大革命 | 把王朝周期**内部化**：王朝没有换，制度发生近似「换代」的大更新 |
| 历史意义 | **把「皇帝个人拥有国家」转变成「皇帝领导国家制度」**——从「统治」变成「领导」 |
| 名称 | **第二次建国** |

**第一帝制**：皇权＋官僚＋科举＋中央集权  
→ 大革命（制度断裂点）→  
**第二帝制**：皇权＋职业官僚＋议会监督＋地方参与＋政党竞争＋社会保障＋现代法治

## 三阶段

| 阶段 | 时间 | 内容 |
| --- | --- | --- |
| 一 | 1978—1980 | **政治危机**：权力边界模糊、中央机构重叠、地方责任不清、社会要求参与决策 |
| 二 | 1981—1984 | **制度重构**：七部组织法 |
| 三 | 1985—1986 | **宪制定型**：颁布《中华帝国宪法》，大革命结束 |

## 逐年大事记【核心＋推演细化】

### 1978年

| 月 | 事件 |
| --- | --- |

## 《中华帝国宪法》核心十条【核心】

1. 帝国国家主权统一  
2. 皇帝为国家最高政治领导人  
3. 皇帝兼任中央政治局常委会委员长  
4. 政府依法行政  
5. 议会依法行使立法、预算及监督权  
6. 司法依法独立行使审判权  
7. 监察机关依法独立履行监察职能  
8. 地方接受中央和上级领导  
9. 特殊民族地区依法实行自治  
10. 皇位继承必须符合国家继承制度  

## 十项大革命成果入宪【核心】

禁止官员事实世袭、亲属回避、高级官员强制轮岗、任期限制、大学招生开放、财产透明、政治献金制度化、议会强监督、监察受监督、公民常态化政策参与。

## 大革命禁忌（后世政治教材）【核心】

> 「第二次制度危机证明，任何政治体系都会产生利益固化；但同样证明，**群众动员不能成为常态政治工具**。帝国必须通过法律、选举、监察、议会和行政改革持续解决社会矛盾。」

形成的政治传统：

- 皇帝拥有发动重大改革的权力  
- 皇帝也负有**在改革完成后主动结束群众动员、恢复正常法治秩序**的义务  

## 历史讽刺【制度】

> 「我当年消灭的是血缘贵族，但没有消灭权力本身形成贵族的能力。」

改革成功后，帝国完成第二次制度升级：

> **从防止血缘世袭，走向防止任何形式的权力世袭。**

**史臣曰**：大革命之成败，不在杀多少人、倒多少官，而在**皇储制度终于证明了自己**。若无数十年国家治理教育，1981年权力真空期的帝国，极可能走上「改朝换代」的老路。制度养人，人守制度——此为第二帝制的第一课。

### 二、逐帝纪要

#### 1. 太祖 朱承乾（开统 1700—1742）

- **1700** 登基，国号中华帝国，定都长安，改元**开统**——后世定为「制度元年」
- 在位期间：七州体系、《国政六策》（开统二十年，1720）、基础教育革命、《推恩封令》
- 驾崩前完成：科举—政治学院—选举复合体系框架；监察、检察、司法分立
- **遗诏要义**：「朕所立之制，非为朕子孙永据大位，乃为天下英才皆可治国。」【推演】

#### 2. 太宗 朱承祐（绍统 1742—1771）

- 太祖第三子；开统朝即入州级历练，继位时已主政关中十年
- 主政要务：行政「去人格化」——使七州运转不依赖开国君臣个人威望
- 绍统二十二年（1764）：国立皇家理工大学成立；海军—理工大学环球探索开启
- 驾崩前将皇位传孙（世宗），跳过有足疾的次子——**开「择贤可越嫡」先例**【推演】

#### 3. 世宗 朱载文（格致 1771—1805）

- 年号「格致」，取「格物致知」——工业化时代的第一位皇帝
- 格致九年（1780）：《国民实践教育令》——上山下乡与福利制度先于欧洲一个半世纪
- 格致十九年（1790）：工会制度建立
- **格致三十四年（1805）：完成帝国史上第一次制度化皇位交接**——皇储经政治学院→基层→地方→省→州→中央部门→军财法监察→政治委员会考核后继位
- 评语：「具备履行皇帝职责之能力。」

#### 4. 仁宗 朱载安（咸熙 1805—1836）

- 世宗之弟；因世宗诸子早殇，以「皇储考核第一」继位——**旁支择贤的制度化样本**
- 主政：全国市场形成、废厘金、《帝国商法典》、黄河大治理
- 咸熙朝政治文化：皇帝「少而重要」的工作模式定型；日常文件量从数百份/日降至数十份

#### 5. 宪宗 朱翊武（拓疆 1836—1868）

- 仁宗子；少年即入军校与边疆轮职
- 拓疆朝三大战争：西征准噶尔—哈萨克；北方对俄（**沙俄失去外东北**）；南方中南半岛整合
- 1860年代：现代疆域完全定型；44省犬牙交错实地勘定基本完成
- 军事原则入典：「州管行政，军权归中央」；双钥匙原则成文

#### 6. 宣宗 朱翊明（承平 1868—1902）

- 宪宗子；技术官僚型皇帝，主管过财政与铁路
- 承平朝：全国铁路电报网贯通；第一次工业普查；识字率过半
- 1900年前后：钢铁、机械、铁路、船舶、化工产量世界第一；现代社会保障体系建成
- **暗流**：1880年代起「合法的不平等」萌芽——承平帝晚年已有察觉，但未及系统改革【推演】

#### 7. 恭宗 朱弘基（维新 1902—1930）

- 宣宗孙；弘字辈
- 维新朝：一战武装中立；帝国黄金时代（1919—1930大投资）；长安「第二凡尔赛」
- 1929大萧条以工代赈软着陆
- 驾崩时官僚固化已深——**将「必须改革」的遗训留给从弟弘宪**【推演】

#### 8. 肃宗 朱弘宪（革鼎 1930—1981）【核心】

- 约1900年生；恭宗从弟；按祖制基层出身，技术官僚路径
- 革鼎四十八年：前半生正常治理与五次改革被消解；后半生发动大革命
- **革鼎四十八年（1978）**：宣布「帝国进入非常时期」
- **革鼎五十一年（1981）**：驾崩；遗训「朕可以发动这场改革，但朕不能替后世决定改革的终点」
- 历史定位：**大革命时代皇帝；第二次建国**

#### 9. 穆宗 朱弘远（承宪 1981—2015）

- 肃宗长子；约1942年生
- 1981年以皇储身份领导制度改革派，赢得三派斗争
- 1982—1984：七部组织法；1986：《中华帝国宪法》
- **1990年（承宪十年）：中发〔1990〕7号，华北风暴**——大革命后第一次全国性执刀体检
- 1991：见证苏联「中苏共同现代化」渡过解体危机
- 承宪朝后半：制度红利期、高铁网、亚洲共荣圈
- 2015年禅位（或驾崩）于长子昭文——**又一次制度化交接**【推演】

#### 10. 今上 朱昭文（继文 2015— ）

- 穆宗长子；约1976年生；继位前已任中央政治局委员
- 继文朝：AI治理、自动化红利基金、核聚变示范堆、欧亚共荣体系
- 2026年约五十岁——「**权力很大，但看起来并不忙**」【核心】
- 兼任：中央政治局常委会委员长、中央议会常务委员会主席、中央军委主席
