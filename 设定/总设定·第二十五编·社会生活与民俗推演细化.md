# 第二十五编：社会生活与民俗（推演细化）

## 一、婚姻与家庭

- 婚姻自由，一夫一妻制（自开国即入律，皇室亦然——皇储制度以能力为筛选基础）
- 家庭结构：核心家庭为主＋孝道传统（重阳敬老、养老国家化后"孝"从经济义务转为情感伦理）
- 妇女地位：女性与男性同等受教育、同等科举、同等任职；帝国历史中女性常委、女性州长、女性将军均出现过（推演）
- 姓名文化：公民自由取名；皇族按字辈排行（推演）

## 二、日常生活（2026年标准周）

| 项目 | 状态 |
| --- | --- |
| 工作 | 四天工作制试点／标准五天；AI替代后工时趋势性下降 |
| 收入 | 劳动收入＋国家基本补贴（月发）＋社保 |
| 住房 | 基本住房保障＋商品房市场并行；多套房征房产税 |
| 医疗 | 全国医保统一统筹统交，基层首诊＋转诊 |
| 教育 | 免费基础教育＋国立/州立/省立大学竞争入学 |
| 出行 | 全国高铁网＋城市轨道＋个人交通；身份证全国通用无地域歧视 |
| 信息 | 全国高速网络；数字元支付；强监管下商业创新自由 |

## 三、社会问题与治理

- 老龄化：AI替代劳动力＋自动化红利基金缓解养老压力；延迟退休与弹性退休并行（推演）
- 官僚专业化：政府复杂化与公民理解之间的差距，靠政府信息公开与议会通俗化质询弥合
- 巨型企业监管：防止新型资本集团取代旧官僚集团——反垄断＋政治干预重罚（延续"财富不能购买政治权力"原则）
