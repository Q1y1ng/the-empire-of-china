# 《世界近代史推演（约1360—2026）》

**性质**：世界观国际史推演·深度扩写版。以「中华帝国的存在」为第一变量，建立完整因果链，推演全世界自明末以来的近代史。

**方法论**：不写「某国会变得怎样」的孤立结论，而写因果链：

> **中华帝国的存在 → 改变地区力量平衡 → 改变日本选择 → 改变俄国远东战略 → 改变欧洲列强亚洲政策 → 改变社会主义思想传播 → 改变20世纪国际体系。**

**体例**：

- 【核心】＝已冻结设定
- 【推演】＝逻辑推演
- 编年体：以年代为纲，分区域、分领域展开
- 与《中华帝国编年史》互为表里：那边写「帝国内部怎么长」，这边写「外部世界怎么被改写」

# 第一编：起点——明末的世界（1360—1700）

## 一、原始分叉

| 变量 | 本世界线 | 现实世界 |
| --- | --- | --- |
| 明朝首都 | **朱元璋迁都成功，定西安（长安）** | 迁都未成，后定北京 |
| 17世纪中叶 | 明末大乱，**朱承乾力量胜出**，以「治理能力」而非单纯武力统一 | 清朝入关 |
| 1700年 | **中华帝国建立**，继承中华王朝正统 | 清康熙朝 |

## 二、1360—1700：分叉如何慢慢改变世界【推演】

### 14—16世纪：欧洲尚未感知

迁都本身对当时欧洲无直接影响。真正开始产生外部性的是**后续连锁**：

| 时间 | 帝国侧 | 世界侧 |
| --- | --- | --- |
| 1400s—1500s | 关中政治中心稳定；海上朝贡贸易仍走东南 | 欧洲大航海；葡萄牙抵东亚 |
| 1500s—1600s | 明末危机中，政治中心仍在长安，**边患压力小于现实世界线** | 荷兰、英国东来；日本战国→德川锁国 |
| 1600s | 朱承乾集团在中原积累治理能力 | 欧洲科学革命；俄国开始东扩 |

**关键差异雏形**：现实世界线中，17世纪东亚的「权力真空」被清朝填补，随后与欧洲碰撞时处于制度老化期。本世界线中，填补真空的是**一套尚未老化的新制度**——欧洲将在18世纪撞上的是「正在上升的超级国家」，而不是「等待被叩关的停滞帝国」。

## 三、1700年的世界全景

| 地区 | 状态 | 与帝国的关系雏形 |
| --- | --- | --- |
| **欧洲** | 科学革命后期；英、荷、法发展海运、贸易、金融、殖民；走向中央集权 | 即将成为「中华研究」大客户 |
| **奥斯曼** | 仍然强大 | 陆上丝路的旧霸主，将被帝国贸易站网络绕开 |
| **印度** | 莫卧儿与地方势力并立 | 欧洲殖民的主战场；帝国只设贸易站 |
| **日本** | 德川幕府锁国 | **朝鲜半岛已是帝国领土**；帝国海军巡弋日本海 |
| **俄国** | 彼得大帝改革前夜，正向东扩张 | 东扩将撞上帝国墙 |
| **美国** | 尚不存在 | — |
| **中华帝国** | 刚完成制度整合；疆域含朝鲜、部分中亚、部分中南半岛【核心】 | **主动制度化的超级国家** |

**史臣曰**：1700年，世界并不知道长安刚颁布了一部「把皇帝也写进去」的制度机器。此后三百年，这台机器输出的不是商品，而是**一整套关于「政府应当如何被设计」的观念**。

# 第二编：18世纪——中华思想改变欧洲（1700—1800）【核心】

## 因果链一：中华制度 → 欧洲启蒙运动变形

```text
中华帝国建立（1700）
  ↓
帝国科举、文官制、监察制、国家教育体系稳定运行
  ↓
欧洲传教士、商人、使团系统翻译《中华律典》《官制》《科举条例》
《地方治理条例》《监察条例》《教育条例》
  ↓
欧洲出现专门的「中华研究」学术领域
  ↓
启蒙思想家的新论据：「如果中国可以通过考试选拔官员，欧洲为什么不能？」
  ↓
「功绩政治」成为18世纪欧洲核心政治思潮
  ↓
启蒙运动方向改变：从单纯反教会、反专制
→ 增加「政府可以像大型工程一样通过制度设计提高效率」的工程学政治观
```

### 1700—1750：译介与震惊【推演】

| 年代 | 欧洲侧事件 |
| --- | --- |
| 1700s初 | 耶稣会士书简陆续译介「中国考试取官」制度，欧洲知识界半信半疑 |
| 1710s—1720s | 帝国《国政六策》（1720）部分内容经海商与使团传入，「政党不得直接控制官职」原则令欧洲争论不休 |
| 1720s—1730s | 柏林、巴黎、伦敦出现「中华制度研究会」；大学开设相关讲座 |
| 1740s | 「功绩政治」（meritocracy 一词的早期形态）进入政治 pamphlet 争论 |

### 1750—1800：制度移植与变形【推演】

#### 英国【核心】

| 现实世界 | 本世界线 |
| --- | --- |
| 《权利法案》（1689）后，文官体系仍长期贵族庇护制 | 帝国模式传入后，辉格党人以「中华例」论证考试取官 |
| 1720年南海泡沫后官僚腐败饱受诟病 | 帝国监察—审计双轨制被译介为《御史条例》 |
| 18世纪「恩庇制」盛行 | 「官职≠爵位」成为托利与辉格共同的反庇护制话语——**「托利的传统＋辉格的功绩」合流** |
| 文官考试制度19世纪中后期才成型 | **1705年《文官考试试行条例》**（比现实早约150年）【推演细化】 |
| 公共账目委员会1834年才常设 | **1721年设立常设化**【推演细化】 |

**因果**：帝国没有「创造」光荣革命，但使革命后的英国**用更短时间走完从「贵族议会」到「现代文官国家」的路**，并以此为母版影响法国和德意志。

#### 法国【核心】

- 启蒙思想更强调**「公民＋功绩＋国家行政效率」**，而非单纯「贵族vs平民」
- 法国大革命的思想武器多了一件：**废除世袭官职、考试取官**
- 伏尔泰式「中国颂」从美学赞叹转为**制度论据**

#### 德意志诸邦【推演】

- 普鲁士最早引入考试选官
- 官僚国家化程度更高
- 「开明专制」的理论资源中，中华帝国是重要参照

#### 欧洲美学【推演】

> 中国审美＋欧洲古典主义＋科学革命＝**「东方主义美学」**新潮流

瓷器、园林、漆器、科举题材绘画进入宫廷与市民阶层。

## 因果链二：帝国存在 → 欧洲殖民主义的边界【核心】

```text
帝国是全球最大市场＋世界一流海军
  ↓
欧洲无法在东亚复制殖民胜利（没有鸦片战争式的机会）
  ↓
欧洲殖民方向被压缩至：非洲、南亚、美洲、东南亚海岛
  ↓
欧洲殖民体系与帝国自由贸易体系长期并立、摩擦、妥协
  ↓
欧洲列强被迫与帝国「贸易妥协」——亚洲大陆基本成为帝国势力范围
```

**18—19世纪国际体系基本规则**【核心】：

> **大陆亚洲属于帝国秩序，海洋与西方属于欧洲秩序。**

## 因果链三：帝国存在 → 日本的开国方向【核心】

```text
朝鲜半岛＝帝国领土；帝国海军巡弋日本海
  ↓
日本面对的不是一个停滞农业帝国，而是工业化、强海军、巨大市场的超级邻居
  ↓
德川幕府的锁国体制在18世纪末难以为继
  ↓
日本的「开国」对象首先是中华帝国，其次才是西方
  ↓
日本学习对象：帝国制度＋技术（而非单纯兰学/西学）
```

### 18世纪日本年表【推演】

| 年代 | 事件 |
| --- | --- |
| 1700s—1750s | 锁国体制下，对马—朝鲜渠道仍有官方贸易与情报 |
| 1750s—1780s | 「兰学」与「华学」并行；有识之士开始讨论「隔壁帝国为何如此」 |
| 1780s—1790s | 幕府内部争论：继续锁国，还是对帝国开放以制衡西方？ |
| 1790s—1800s | 锁国体制出现裂缝；「开国」议题从禁忌变为政策选项 |

**史臣曰**：日本之现代化，本世界线的第一推动力不是黑船，而是**一衣带水的超级邻居已经工业化**。「避免被殖民」的焦虑仍在，但排在第一位的是「如何在中欧两个巨大工业文明之间保持独立和竞争力」。

## 因果链四：俄国东扩撞墙【推演】

```text
1700s俄国继续东扩
  ↓
帝国巩固东北、外东北、蒙古、新疆方向
  ↓
俄国东扩被锁死在外兴安岭—巴尔喀什湖一线
  ↓
俄国失去远东出海口（海参崴属帝国）
  ↓
俄国战略重心被迫全面西移（巴尔干、中亚）
```

【核心】**沙俄失去外东北；俄罗斯没有现实世界中的朝鲜半岛影响力。**

## 18世纪末世界格局小结【推演】

| 体系 | 范围 | 逻辑 |
| --- | --- | --- |
| 帝国自由贸易体系 | 东亚大陆、东南亚大陆、部分中亚、全球贸易站 | 商业型强国，不殖民征服 |
| 欧洲殖民体系 | 非洲、南亚、美洲、东南亚海岛 | 领土殖民＋种植园＋奴隶贸易 |
| 奥斯曼—波斯旧秩序 | 中东 | 正在被上述两体系挤压 |
| 美洲 | 正在独立或即将独立 | 照常发展 |

# 第三编：19世纪——两条现代化道路（1800—1900）【核心】

## 一、工业革命的双源竞争【核心】

| 维度 | 欧洲道路 | 中华道路 |
| --- | --- | --- |
| 资本 | 私人资本→企业→国家 | 国家科研→国立大学→国家企业→私营跟进 |
| 政治 | 议会政治＋殖民掠夺＋工业革命 | 皇权＋委员会政治＋国家主导市场＋有限代议 |
| 社会成本 | 先撕裂后补救（童工、贫民窟、宪章运动） | 福利与工会先行（1780/1790） |

**结果**：19世纪世界形成**三大工业中心——欧洲、中华帝国、北美**。  
「西方＝现代」的单一现代化叙事从未成立【核心】。

## 二、1800—1850：欧洲在帝国阴影下改革【推演】

### 1848年革命的帝国回响【推演细化】

| 地点 | 帝国影响 |
| --- | --- |
| 巴黎 | 「考试取官」请愿书直接引用《中华科举条例》译本 |
| 维也纳 | 官僚改革派以「中华例」对抗贵族特权 |
| 柏林 | 普鲁士文官改革加速 |
| 法兰克福议会 | 甚至提出「设中华式文官学院」 |

虽革命多告失败，但**「功绩取代血统」自此成为欧洲保守派亦无法公开反对的政治正确**——为1860年代各国文官改革铺平道路。

### 英国文官制度定型【推演】

- 1850s—1870s：考试取官全面制度化（比现实更早、更彻底）
- 「政治家负责方向，职业官僚负责执行」成为英国政治文化的自觉表述

## 三、俄国：挫折、西移与革命土壤【核心＋推演】

```text
帝国控制外东北、朝鲜半岛（1700s—1860s）
  ↓
俄国东扩被锁死
  ↓
俄国失去远东出海口
  ↓
战略重心全面西移（巴尔干、中亚）
  ↓
对体制的挫败感比现实世界更早积累
```

### 19世纪俄国年表【推演】

| 年代 | 事件 |
| --- | --- |
| 1800s—1820s | 拿破仑战争照常；俄国「欧洲宪兵」角色不变 |
| 1830s—1850s | 克里米亚方向与英法摩擦；中亚「大博弈」被帝国帕米尔驻军压缩空间 |
| 1850s—1860s | 北方边界战争对帝国失败【核心】；农奴制改革的外部刺激多了一个「隔壁成功样板」 |
| 1870s—1890s | 民粹派与马克思主义传播；知识分子讨论「为什么帝国能改革而沙皇不能」 |
| 1900s | 1905革命前夜——帝国模式成为俄国反对派与改革派共同引用的参照 |

## 四、美国的崛起【核心】

美国照常独立、西进、内战、工业化。

> **帝国不阻止美国发展，反而与美国贸易**——太平洋两岸形成「帝国制造＋美国资源农业」的互补循环。

| 年代 | 帝美关系 |
| --- | --- |
| 1780s—1810s | 美国独立与建国；帝国中立观望，贸易开始 |
| 1820s—1840s | 太平洋商路扩展；条约口岸 |
| 1840s—1860s | 美国内战；帝国照常贸易，不介入 |
| 1860s—1890s | 19世纪末美国成为**西半球霸主与太平洋经济重要一极** |
| 1860s | 帝国—美国太平洋海底电缆敷设（与帝国编年史互证） |

## 五、日本：明治维新（变形版）【核心】

```text
帝国工业压力（不可战胜的邻居）＋西方殖民压力（不可信任的来客）
  ↓
日本「明治维新」提前且变形：学习对象是中华帝国制度＋西方技术
  ↓
日本没有「殖民扩张求生存」的战略焦虑（大陆是帝国的，抢不了）
  ↓
日本路线：精密制造、材料、船舶、消费电子的「小而精」工业立国
  ↓
日本成为帝国最大的工业竞争对手＋最大的贸易伙伴
```

### 日本弧线详表（1850—1900）【推演】

| 阶段 | 弧线 |
| --- | --- |
| 1850s—1870s | 开国压力下幕府倒台；「明治维新」以帝国制度为参照（考试选官＋国家主导工业），以西方技术为工具 |
| 1880s—1900s | 精密制造立国：纺织机械→光学→化工；对帝国出口原材料与初级品，进口成套设备——「学徒期」 |

**【核心】**：日本近代化学习对象受帝国影响；仍进行类似明治维新的改革，但时间路径不同；现代化动力从「避免被西方殖民」变为「如何在中欧两个巨大工业文明之间保持独立和竞争力」。

## 六、印度与东南亚【核心＋推演】

### 印度

```text
英国殖民统治照常建立
  ↓
但帝国贸易站网络使印度洋不再是英国内湖
  ↓
印度民族主义同时从欧洲启蒙与帝国「功绩政治」两个源头汲取养分
```

### 东南亚

| 区域 | 状态【核心】 |
| --- | --- |
| 海岛（荷属东印度、菲律宾） | 欧洲殖民地照常存在 |
| 越北、老挝 | **帝国领土** |
| 暹罗（泰国） | 在帝国与英属缅甸之间保持缓冲独立 |
| 柬埔寨 | 帝国势力范围 |
| 缅甸 | 高强度贸易伙伴 |

## 七、社会主义思想的提前变形【核心】

```text
帝国福利制度（1780年代养老/失业保险）、工会制度（1790）
比欧洲早半个多世纪
  ↓
马克思（19世纪中叶）观察到的「最发达工业社会」不是英国而是中华帝国
  ↓
马克思主义从诞生起就包含「帝国变量」：
  国家主导工业化＋社会保障＋皇权宪制，能否通向社会主义？
  ↓
马克思主义分化为两支：
  欧洲支（阶级革命论）
  与「东方支」（国家主导＋民生保障渐进论）
```

**【核心】** 马克思主义的发展受到中华帝国政治经济制度影响。

### 思想史细节【推演】

| 问题 | 欧洲支答案 | 东方支答案 |
| --- | --- | --- |
| 革命主体 | 无产阶级政党 | 国家机器自我更新 |
| 过渡阶段 | 无产阶级专政 | 功绩官僚＋福利国家＋渐进改革 |
| 对帝制态度 | 必须打碎 | 可以改造（大革命后更明确） |
| 主要地理 | 西欧、后来的俄国 | 帝国、后来的中苏共同现代化 |

## 八、19世纪末世界格局【推演】

| 力量 | 地位 |
| --- | --- |
| 中华帝国 | 制造业、基建、贸易、人口、制度输出 |
| 英国 | 海权、金融、殖民帝国 |
| 德国 | 陆权、化工、电气 |
| 美国 | 资源、农业、快速工业化 |
| 法国 | 殖民、文化、金融 |
| 俄国 | 陆权、资源、内部危机积累 |
| 日本 | 精密制造追赶中 |
| 奥斯曼 | 衰落中 |

**没有单极霸权。** 帝国与欧洲两大体系并立，美国在西半球上升。

# 第四编：20世纪前半——两次世界大战（1900—1949）

## 一、第一次世界大战（1914—1918）

### 起因与帝国角色

**起因**：欧洲列强矛盾照常积累（德英海权竞争、法德世仇、奥塞冲突）——**帝国不阻止欧洲打欧洲**。

| 阶段 | 事件 |
| --- | --- |
| 1914 | 战争爆发，同盟国vs协约国 |
| 1914—1918 | **帝国宣布武装中立**：向双方出售民用物资、海军护航全球商路、边境设防 |
| 1917 | 俄国革命照常爆发（战争加剧了俄国的体制挫败感） |
| 1918 | 战争结束，欧洲残破 |

### 1919年凡尔赛体系【推演细化】

| 维度 | 内容 |
| --- | --- |
| 帝国身份 | 「战胜国＋中立调停国」双重身份 |
| 山东问题 | **不存在**——帝国自1720年代起已收回列强一切在华租界企图；凡尔赛仅确认帝国对德属西太平洋岛屿处置的优先发言权与对德贸易索赔权 |
| **第二凡尔赛** | 帝国在长安另设**「万国东方和平会议」（1919.08）**，邀请暹罗、安南、缅甸代表与英法谈判——凡尔赛覆盖欧洲，**长安体系覆盖亚洲** |
| 国联 | 帝国与英法美同为创始常任理事国的提议虽被英法否决，但帝国事实上成为国联在亚洲的执行支柱 |
| 经济 | 帝国黄金时代开启（1919—1930大投资期） |
| 长远影响 | 凡尔赛的「殖民地委任统治」在亚洲名存实亡；亚洲民族主义者此后赴长安留学 |

## 二、战间期（1919—1939）

| 年代 | 事件 |
| --- | --- |
| 1920s | 欧洲恢复与不稳定和平；帝国大投资；美国繁荣与泡沫 |
| 1929—1933 | **大萧条**：美国与欧洲重创；帝国以「以工代赈＋国家投资」软着陆——政府主导型市场模式的全球声誉确立 |
| 1930s | 欧洲法西斯主义崛起（德国、意大利） |
| 1930s | **日本未走向军国主义的「理论可能」被再次否定**——见下节 |
| 1930s | 苏联成立并工业化（斯大林模式照常，但多一个参照系：隔壁帝国的福利国家模式） |

### 日本为何仍然走向军国主义【推演细化】

> 大陆无扩张空间（是帝国的），资源可通过对帝国贸易获得，军部没有现实世界中的「大陆生命线」叙事。

但：

- 1937年起军部少壮派以「南方资源自给」为由压倒文官政府
- 与现实不同，日本**无需发动侵华战争即可「南进」**
- 参谋本部认为「只要控制南海，即可切断帝国对美英的贸易脐带，帝国将不战自屈」——**这是致命误判**

**史臣曰**：日本军部看见的是帝国的贸易依赖，看不见的是帝国的工业纵深与战争动员能力。1941年12月8日之后，他们看见了。

## 三、第二次世界大战（1939—1945）【推演细化·日本参战版】

> **核心逻辑**：无中国战场牵制 → 日军全力南进西攻 → 太平洋战争烈度倍增 → 帝国与同盟国在「无缓冲」状态下迎战。

### 第一阶段：欧洲开战，帝国中立红利（1939—1941.06）

| 时间 | 事件 |
| --- | --- |
| 1939.09.01 | 德国入侵波兰，英法对德宣战 |
| 1939.09.03 | **帝国宣布武装中立**，颁布《战时中立法》：禁止交战国军舰进入帝国领海，对双方均等出售民用物资，军火禁运 |
| 1939—1940 | 假战期：欧洲订单暴增，江南、华北工厂三班倒 |
| 1940 | 日本与德意缔结三国同盟 |
| 1940—1941 | 不列颠空战期：帝国经缅甸—印度航线向英国输送橡胶、钨、桐油；**拒绝英方「请帝国对日宣战以牵制德国」的请求**——高层仍幻想以贸易约束日本 |
| 1941 | 日本《帝国国防方针》将「夺取南洋—澳洲—夏威夷」列为国策 |

**帝国高层误判**【推演】：

> 「欧洲战争是欧洲列强体系的自我清算，帝国的任务是确保亚洲不被拖入。」

### 第二阶段：太平洋惊雷（1941.12—1942.06）

| 时间 | 事件 |
| --- | --- |
| 1941.12.07 | 日本偷袭珍珠港（全部6艘航母＋2艘超战列舰）；美太平洋舰队几乎全灭 |
| 1941.12.08—12 | 日军登陆**帝国南海诸岛、曾母暗沙**，炮击河内湾、珠三角外海；递交「最后通牒」 |
| 1941.12 | 帝国皇帝发布《讨倭诏书》，**对日宣战** |
| 1941.12—1942.05 | **南洋狂潮**（约85个师团、4000架战机、18艘航母级舰艇）：菲律宾陷落、印尼陷落、空袭达尔文、兵临澳洲 |
| 1942.02 | 泗水海战：英荷澳联军溃败；巴厘巴板油田落入日手 |
| 1942.05 | 珊瑚海海战：帝国—澳—美联军险胜，勉强阻止日军登陆澳洲本土 |
| 1942.06 | 中途岛（美军惨胜）＋南海海战（帝国岸基航空兵重创日舰队）——太平洋战场首次止住日军攻势 |

### 第三阶段：同盟国最黑暗的一年（1942—1943）

#### 为何同盟极其挣扎而帝国仍显强韧【核心因果】

| | 现实世界 | 本世界线 |
| --- | --- | --- |
| 中国战场 | 牵制约80—100万日军 | **无中国战场，日军零牵制** |
| 同盟压力 | 可集中力量太平洋 | 每一岛皆以少敌多 |
| 亚洲大陆支点 | 中国苦苦支撑 | **帝国云贵—华南防线岿然不动** |

**帝国的底气**【推演】：

- 战前GDP达美国82%、钢产量世界第一、三舰队合计18艘航母级舰艇在建
- 遭突袭后**全国总动员仅用11天**
- 八大军区同步一级战备；「长安式」坦克月产逾千辆
- 南海诸岛失守但河内湾封锁仅4个月即被撕开（1942.04）
- 珠三角遭轰炸但防空体系使日机战损率高达17%

#### 1942—1943拉锯【推演】

| 域 | 内容 |
| --- | --- |
| 陆上 | 云贵军区在中南半岛北部与日军对峙；万象—河内拉锯战「以空间换消耗」；机械化步兵师与武装直升机先驱 |
| 海上 | 三舰队与美澳「跳岛＋潜艇绞杀」；北海舰队封锁鄂霍次克海；东海舰队护航西太；南海舰队争夺南沙制空权 |
| 1943.07 | **阿拉伯海海战**：帝国双航母编队击沉德舰「科隆」号；「长安」号当日恢复战力——「不沉的移动机场」 |

**美国的至暗时刻**：1942年夏，日军潜艇游弋加州外海；洛杉矶防空警报夜夜拉响。

### 第四阶段：转折与反攻（1943—1945）

| 时间 | 事件 |
| --- | --- |
| 1943.11 | **长安会晤**：皇帝与罗斯福首次元首会晤；帝国以「陆止日军、海断德援、陆路输苏」三承诺换取美国承认帝国对琉球—南海诸岛战后处置主导权 |
| 1943 | 长安—乌鲁木齐—阿拉木图陆路向苏联输血（运量占苏联外援31%，推演）；斯大林称「第二条生命线」 |
| 1944.03 | **南沙大捷**：三舰队主力「航母诱敌—岸基围歼」，击沉日航母3艘、战列舰2艘——**太平洋战争公认转折点** |
| 1944.06 | 诺曼底登陆（欧洲照常）；帝国海军佯动牵制日军于南海—台湾海峡 |
| 1944.10 | 莱特湾海战；帝国首次战略轰炸机群空袭日本本土九州 |
| 1944—1945 | 缅甸—河内大反攻：15个师机械化集群收复万象、河内；阵亡约9万、歼敌11万 |
| 1945.05.08 | 德国投降 |
| 1945.08 | 美国投下原子弹；日本投降 |
| 1945.09.02 | 东京湾受降：帝国与美、苏、英共同签字 |

### 战争代价与结果【推演】

| 项目 | 内容 |
| --- | --- |
| 帝国阵亡 | 约95万人（含南海守军、商船队、海军航空兵） |
| 本土 | 广州、河内、海口遭轰炸；**无一省会沦陷**；南沙失守4个月即收复 |
| 歼敌比 | 约1:1.2（火力与后勤优势） |
| 同盟代价 | 太平洋战场阵亡比现实高约25%；战争仅延长约3个月 |
| 战后工业 | 产值达美国约91%；海军总吨位世界第二 |
| 联合国 | 五常：美、帝国、苏、英、法 |
| 东京审判 | 帝国法官主审「南海暴行」；「破坏和平罪」与「破坏全球公共航道罪」并列 |

### 日本战后与驻军权【核心】

| 项目 | 内容 |
| --- | --- |
| 宪法 | 1946年《和平宪法》比现实更严苛 |
| 占领 | 美军主占本州东部；**帝国军主占九州—濑户内—琉球**；英联邦协占四国 |
| 管制 | 「盟军日本管制委员会」；帝国对「放弃战争」条文与赔偿方案有一票否决 |
| 驻军 | 1952年后转为「安保协定」框架下常设联队（约1.2万人），与美军构成**双重驻留** |
| 长期 | 2026年岩国—佐世保帝国军港仍是日本国内政治常年议题 |

**史臣曰**：日本战后奇迹，是在「美帝双重驻留—技术输入—朝贡式市场开放」三角中实现的。「战争忏悔」与经济依附并存——此为本世界线日本国家性格的核心张力。

# 第五编：冷战——三极世界（1945—1991）【核心＋推演】

## 一、三极格局

| 极 | 意识形态 | 经济模式 | 阵营 |
| --- | --- | --- | --- |
| **美国** | 自由市场＋民主 | 资本主义＋海洋体系 | 西欧、拉美、日本、东南亚海岛 |
| **中华帝国** | 皇权宪制＋国发主义 | 国家主导市场＋混合经济 | 亚洲大陆（共荣圈） |
| **苏联** | 共产主义一党制 | 计划经济 | 东欧、中亚北部 |

【推演】冷战是「三极」而非两极：帝国不建全球军事同盟，但亚洲大陆国家（暹罗、柬埔寨、缅甸、波斯方向）默认帝国秩序；美国阵营靠海洋；苏联阵营靠陆地。

## 二、中苏关系演变【核心冻结】

```text
1920—1950年代：战略竞争（意识形态对立＋中亚蒙古边界摩擦）
  ↓
1950—1970年代：有限合作（反法西斯记忆＋贸易互补，但政治互疑）
  ↓
1970—1980年代：战略伙伴关系（共同面对美国压力＋经济互补显现）
  ↓
1980年代：帝国向苏联输出改革经验
  ↓
1990年代：「中苏共同现代化」
  → 国家战略部门＋市场机制＋福利国家＋科技现代化
  ↓
苏联未在1991年解体
  ↓
中华帝国—苏联战略共同体形成
```

### 为什么苏联没有解体【核心因果】

1. 隔壁有**活着的成功样板**：强国家、强政府、保民生，同时实现市场效率与科技创新  
2. 帝国1978—1986大革命示范了「体制内自我更新」——**改革不必亡党亡国**  
3. 苏联改革派获得了可抄的作业  
4. 民族问题被共同繁荣软化＋帝国「多民族共治」经验参照

## 四、日本的冷战地位【核心】

> **「安全靠美帝、经济靠帝国」**——比现实世界更早、更彻底且更复杂。

日本成为世界第三极经济力量（精密制造、材料、机器人），但至2026年仍未实现完全自主防卫。

# 第六编：1991—2026——多极全球化【核心＋推演】

## 一、没有「单极时刻」

现实世界1991—2008是美国单极时代。本世界线中：

> **美国军事优势 ＋ 帝国经济制造优势 ＋ 欧洲经济联盟 ＋ 苏联共同体 ＋ 日本先进制造**

共同构成全球体系——**「单极美国时代」从未出现**。

## 二、2000—2026年大事记【推演】

| 时期 | 世界大事 |
| --- | --- |
| 2000—2010 | 互联网全球化；帝国强监管模式与美国自由模式并立；苏联共同体完成市场化转型；**2008金融危机**：帝国率先企稳并提供紧急流动性——「帝国模式」被视为稳定器 |
| 2010—2020 | 帝国成为全球产业中心；美国主导金融与软件；欧洲联盟深化；**亚洲共荣圈制度化**；**2013「欧亚大陆桥」**（一带一路的帝国版） |
| 2020 | 全球疫情：帝国模式（强基层医疗＋统一调度）与美欧模式并立对比；帝国向苏联共同体、非洲提供疫苗与医疗队 |
| 2020年代 | **欧亚共荣体系**成形；2024《欧亚数字主权协定》；世界明确多极化 |

## 三、2026年世界格局【核心】

| 力量 | 优势 |
| --- | --- |
| **中华帝国** | 制造业、工程、人口（17.8亿）、基础设施、贸易、科技 |
| **美国** | 金融、软件、航空航天、军事、创新 |
| **欧洲联盟** | 高端制造、金融、科研、社会福利 |
| **苏联共同体** | 能源、资源、军工、重工业 |
| **日本** | 精密制造、材料、机器人 |
| **印度** | 人口、服务业、软件、快速工业化 |
| **东南亚** | 制造业承接、贸易 |
| **中东** | 能源、金融、物流 |

**没有国家统治全球——多极全球化体系。**

# 第六编之二：印度完整弧线（1850—2026）【推演】

```text
英国殖民（照常）＋帝国贸易站网络＋本土文明
  ↓
独立运动引用三种思想：
甘地式本土主义 / 欧洲共和主义 / 帝国「功绩政治＋强国家」
  ↓
1947年前后独立（略早——二战中英国更虚弱）
  ↓
建国路线大辩论：尼赫鲁式计划经济 vs 帝国式「国家主导市场」
  ↓
印度选择混合路线：计划色彩更重、执行更弱（联邦制＋种姓拖累）
  ↓
20世纪末起「学帝国改革」：经济自由化＋基建追赶
  ↓
2026：人口第一大国、服务业与软件强国、制造业承接者
——「下一个帝国」叙事与「永远差一步」现实并存
```

**印帝关系**：边界（喜马拉雅—藏南）已由条约划定；21世纪是「最大民主国家 vs 最古老帝制国家」的意识形态对照组＋紧密贸易伙伴。

## 非洲

- 20世纪60年代独立浪潮：三选项——**美国道路／苏联道路／帝国道路**

- 拉美在美帝国两大体系间长期摇摆——多一个选项，也多一分撕裂

# 第七编：思想史因果链【核心】

## 一、「现代化＝西方化」公式的死亡

本世界线最深远的思想后果：

> **存在一个非西方、非殖民、非共和的成功现代化样本，且它已经运行了三百年。**

- 殖民地独立运动有了新选项：「帝国道路」与「美国道路」「苏联道路」并列  
- 后发国家的教科书里，现代化不等于全盘西化  

## 二、马克思主义的东方支

- 经典马克思主义观察的「最发达社会」包含帝国  
- 「国家主导＋民生保障＋渐进演化」路线获得三百年实践背书  
- 苏联改革直接引用帝国经验——**「中苏共同现代化」成为20世纪末最重要的意识形态事件**  

## 三、民主理论的变形

- 欧洲式「选举授权」理论之外，存在帝国式**「绩效＋选拔＋监督」**合法性理论  
- 政治学必须回答：为什么一个世袭皇权国家能比多数共和国更稳定、更廉洁、更有社会流动？  
- **「西安体制」成为比较政治学的专门研究对象**  

## 四、五重合法性如何被世界学界解读【推演】

| 层 | 内容 | 西方学界的常见误读 |
| --- | --- | --- |
| 血统 | 皇室继承传统 | 「就是君主专制」 |
| 历史 | 1700开国、明统继承、三百年连续 | 忽略 |
| 宪制 | 皇权依法行使、受宪法约束 | 「宪法是装饰」 |
| 能力 | 皇储国家筛选培养 | 「还是看血统」 |
| 绩效 | 安全、教育、医疗、补贴、基建、科技 | **这一层无法否认** |

帝国学界的回应：

> 「你们用选举解决合法性，我们用绩效；你们用政党轮替纠错，我们用监察审计宪法法院加皇权冻结程序。**工具不同，问题相同。**」
