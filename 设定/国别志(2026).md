# 《国别志（2026）》

> **性质**：本卷为**外部世界现状表**，回答"2026 年世界上有哪些国家、谁在执政、与帝国是什么关系"。
> **时点**：继文十一年（2026）。**口径来源**：《世界近代史推演》第六编（2026 世界格局、日本／印度／中东非拉三条弧线）、《疆域与省界表(2026)》六（对外口岸与节点）、主数据表 J 组。
> **与卷三十七的关系**：卷三十七列的是**帝国驻外的 12 个重点邦国使节岗**，本卷列的是**邦国本身的现状**；卷三十七"国名与关系以后续《国别志》为准"一句，自本卷起生效，其"俄罗斯帝国／奥斯曼帝国／朝鲜王国"三行已按本卷更正（见 §四）。
> **符号**：凡政体、在位者、近况无史实依据者，一律标【推演】；外邦人名不入《命名登记》，不参与帝国名录校验。

### 说明三条

1. **帝国本土不列本表**：朝鲜省、河内省、滨海省等均为帝国行省（见《疆域与省界表(2026)》），**不是邦国**；卷三十七原"朝鲜王国（附庸）"一行已删（见 §四）。
2. **无邦交者不列**：与本帝国无使节关系、亦无贸易站的政治实体（如若干内陆小国）不在本表，计入 §三 的"其他政治实体"。
3. **在位者一律只记"职务＋名"**：不记生年与履历（外邦人物不立传），需要时在正文里另行交代。

## 二、欧亚共荣体系（2026）

> 前身"亚洲共荣圈"（1950s 起），2020 年代扩为"欧亚共荣体系"（《世界近代史推演》第六编）。**帝国为核心之一，按「一国一票、重大事项一致通过」参与决策**：体系只管关税减让、本币结算、基建互联与技术标准互认，成员国内政由各国自决。

| 项 | 内容 |
| --- | --- |
| 正式名称 | 欧亚共荣体系（简称共荣体系） |
| 成立 | 亚洲共荣圈 1954 年成形；欧亚共荣体系 2020 年代改组而成 |
| 成员 | **34 个**（帝国、日本、暹罗、柬埔寨、缅甸、南洋群岛联邦、菲律宾、朝鲜省特别席位、波斯、土耳其、埃及、东非六邦、南美四国等）【推演】 |
| 宗旨 | 关税减让、本币结算、基建互联、技术标准互认——**只管生意，不碰政体** |
| 决策机制 | 年度部长级会议（贸易／交通／金融三轨）＋轮值主席（两年一换）；**一国一票，重大事项须一致通过**；无强制裁决权 |
| 帝国角色 | 最大出资方与最大市场；提供铁路、港口、电力与数字元结算；**从不投票否决成员的内政议案** |
| 与苏联共同体的关系 | 两体系不重叠、不对抗；帝国—苏联为双边"战略共同体"，共荣体系不含苏联成员国 |
| 摩擦点 | 日本要求把"高端材料出口管制"列入议程，帝国主张"技术不设墙"；印度以观察员身份要求入体系，遭巴基斯坦方向成员反对【推演】 |

## 五、写作口径（怎么用这张表）

1. **写外交戏先看"关系"列**：竞合（美）／战略共同体（苏）／传统邦交（英法）／共荣圈（日暹等）／商路（土波埃）／接壤（南圻）——六种关系决定这场戏的"话可以说到多硬"。
2. **写冲突不要写"帝国 vs 某国"**：帝国以邦交与商约为主要对外手段，冲突通常表现为**关税、船期、标准、贷款条件**四件事。
3. **写"世界格局"只引三句**：多极、两大贸易体系、没有全面脱钩；不要写"新冷战"。
4. **驻使只记岗位不记人**：需要具体大使时，先在《命名登记》占号，再回填卷三十七，不在本卷具名。
