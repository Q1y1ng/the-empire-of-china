# 附录二：帝国军队层级与军衔表（2026修订版·独立于文官品级）

> **修订沿革**：军衔体系为十四等——帅官三级（元帅、中帅、准帅）、将官三级（上将、中将、少将）、校官四级（大校、上校、中校、少校）、尉官四级（上尉、中尉、少尉、准尉）；准尉为军校学员衔。2026 年 9 月，陆军层级改为「军区→军→旅→营→连→班」（集团军改称军，排／团／师三级撤并；排可作营属分队，岸防团仍为正团级编成），海军细化至舰种与舰内班／连，空军细化至小队，统一「军区」称谓；旅部机关 400 人，旅满编 15,250 人。详细编制见《全国军事编制设定(2026)》。

## 指挥层级

```
中央军事委员会（皇帝主席）
  │
  ├─ 陆军八大军区（京畿/东北/蒙古/西北/华北/江南/云贵/青藏，对应八州）
  │     ├─ 军（约2个/军区）
  │     │     └─ 旅（10个/军，标准重装旅15,250人）
  │     │           └─ 营（10个/旅）→ 连（10个/营）→ 班（10个/连，15人）
  │     └─ 州军区（军区政委担任州人民政治委员会常务委员会第7席委员，无调兵权；可调动次一级武警式部队，事后补批）
  ├─ 海军：北海舰队/东海舰队/南海舰队（各辖6个支队）
  │     ├─ 支队（40艘主力舰＝护卫舰28＋驱逐舰4＋巡洋舰8）
│     ├─ 护航舰队（西太平洋/印度洋/大西洋，共600艘＝高速巡洋舰120＋驱逐舰480，每洋区5个护航支队）
  │     │     └─ 舰艇（舰员：护卫舰45人/驱逐舰75人/巡洋舰150人；舰内：水兵班5人→连3班）
  │     └─ 航母（水兵5,000人＋舰载航空兵：小队→中队→大队）
  ├─ 空军：八军区空军（每军区1个空军军）→ 旅（4个/军）→ 大队（5个/旅）→ 中队（4个/大队）→ 小队（15人≈5机）
  ├─ 战略力量（火箭军，直属军委，二次打击基石·防御性威慑）
  └─ 院校·科研·联勤保障体系
```

武警式次一级部队由州军区依双钥匙原则（军委＋地方行政）调动。

**中央警卫局**：中央军委直属；局部与精锐分队驻皇城紫光阁旁，主力营区在内城东北；局长品级随编制定（建议三品）；任务以点位警卫为单位，可与地方武警联合行动。

**指挥岗位标准衔（2026 冻结）**：班长＝少尉、连长＝上尉、营长＝中校、旅长＝大校、军长＝中将、军区司令＝准帅（三品）、军委副主席（非常务）／军种司令／总政治部主任＝中帅、军委主席（皇帝）／军委常务副主席＝元帅；主链从元帅到少尉逐阶错开，副职与下一级正职的重合由帅官三级拆开。政工主官同衔：总政治部主任＝中帅、军区政委＝准帅、军政委＝中将、旅政委＝大校、营教导员＝中校、连指导员＝上尉。

**军事政治委员会（军政委会）**：军区、军、旅三级设军政委会，政委任主席、军事主官任副主席；政委主政（管人）、军事主官主战（管事），军政主官同衔，待遇与排序平权。管人链：总政治部主任（中帅）→军区政委（准帅）→军政委（中将）→旅政委（大校）→营教导员（中校）→连指导员（上尉）。军区政委任州人民政治委员会常务委员会第 7 席。

**级别待遇对照（2026 冻结）**：一品↔元帅、二品↔中帅、三品↔准帅、四品↔上将、五品↔中将、六品↔少将、七品↔大校、八品↔上校、九品↔中校、十品↔少校、吏一↔上尉、吏二↔中尉、吏三↔少尉、表外↔准尉（学员津贴）——**军职待遇以军衔确认**（军长中将五品、旅长大校七品、营长中校九品、舰队司令中将五品）；普通高校主官按岗位品级：中央政治学院三品、重点国立总校四品、重点分校五品、州立/非重点总校六品、非重点分校七品、省立八品、专科市立十品；军校与警校校长按军衔。全表见第四编「级别待遇对照」。

## 军官军衔（14等）

| 等级 | 军衔 |
| --- | --- |
| 帅官 | **元帅** — 中帅 — 准帅 |
| 将官 | 上将 — 中将 — 少将 |
| 校官 | 大校 — 上校 — 中校 — 少校 |
| 尉官 | 上尉 — 中尉 — 少尉 — 准尉 |

> 准尉为军校学员衔与实习军官衔：入学记军籍、授准尉，本科毕业实习通过授少尉；准尉为链外学员衔，待遇走表外学员津贴。军官经军委直属军校培养；志愿兵役为主。

## 士官/士兵军衔（9等）

| 类别 | 军衔 |
| --- | --- |
| 军士长 | **一级军士长 — 二级军士长 — 三级军士长** |
| 军士 | 上士 — 中士 — 下士 |
| 士兵 | 上等兵 — 中等兵 — 下等兵 |

> 士官经士兵中选拔产生，与军官分途；优秀士官可考入军校提拔为军官。
