# 附录二：帝国军队层级与军衔表（2026修订版·独立于文官品级）

> **修订沿革**：本附录原为2026冻结版；2026年9月按作者新编制草案解冻修订——陆军层级改为「军区→军→旅→营→连→班」（集团军改称军，撤销排/团/师层级；排可作营属分队、岸防团为正团级编成保留），海军细化至舰种与舰内班/连，空军细化至小队，统一「军区」称谓。**军衔两表维持冻结不变。**详细编制、装备核算与待定清单见《全国军事编制设定(2026)》分卷。

## 指挥层级

```
中央军事委员会（皇帝主席）
  │
  ├─ 陆军八大军区（京畿/东北/蒙古/西北/华北/江南/云贵/青藏，对应八州）
  │     ├─ 军（约2个/军区）
  │     │     └─ 旅（10个/军，标准重装旅15,000人）
  │     │           └─ 营（10个/旅）→ 连（10个/营）→ 班（10个/连，15人）
  │     └─ 州军区（司令担任州人民政治委员会常务委员会委员，无调兵权；可调动次一级武警式部队，事后补批）
  ├─ 海军：北海舰队/东海舰队/南海舰队（各辖6个支队）
  │     ├─ 支队（40艘主力舰＝护卫舰28＋驱逐舰4＋巡洋舰8）
  │     │     └─ 舰艇（舰员：护卫舰45人/驱逐舰75人/巡洋舰150人；舰内：水兵班5人→连3班）
  │     └─ 航母（水兵5,000人＋舰载航空兵：小队→中队→大队）
  ├─ 空军：八军区空军（每军区1个空军军）→ 旅（4个/军）→ 大队（5个/旅）→ 中队（4个/大队）→ 小队（15人≈5机）
  ├─ 战略力量（火箭军，直属军委，二次打击基石·防御性威慑）
  └─ 院校·科研·联勤保障体系
```

武警式次一级部队由州军区依双钥匙原则（军委＋地方行政）调动。

**指挥岗位标准衔（2026冻结）**：班长＝少尉、连长＝上尉、营长＝少校、旅长＝大校、军长＝中将、军区司令＝中将（职位三品）、军委＝上将/元帅（元帅＝皇帝特授）。

**级别待遇对照（2026.12 副国级改定·作者表）**：一品↔元帅、二品↔上将、三品↔中将、四品↔少将、五品↔大校、六品↔上校、七品↔中校、八品↔少校、九品↔上尉、十品↔中尉、吏一↔少尉、吏二↔少尉/准尉、吏三↔准尉——**以军衔来确认职级待遇**（军区司令、舰队司令职位三品，授中将；**旧「授上将者按二品高配」作废**——三品岗位不得按二品待遇计）；高校主官等位：中央政治学院校长/国防大学校长三品（可由二品以上者高配兼任）、重点国立总校/其余军校/国立警察大学校长四品、重点分校/警官学院五品、州立/非重点总校六品、非重点分校七品、省立八品、专科市立十品。全表见第四编「级别待遇对照」。

## 军官军衔（12等）

| 等级 | 军衔 |
| --- | --- |
| 将官 | **元帅** — 上将 — 中将 — 少将 |
| 校官 | 大校 — 上校 — 中校 — 少校 |
| 尉官 | 上尉 — 中尉 — 少尉 — 准尉 |

> 军官经军委直属军校基层训练一年授衔；志愿兵役为主。

## 士官/士兵军衔（9等）

| 类别 | 军衔 |
| --- | --- |
| 军士长 | **一级军士长 — 二级军士长 — 三级军士长** |
| 军士 | 上士 — 中士 — 下士 |
| 士兵 | 上等兵 — 中等兵 — 下等兵 |

> 士官经士兵中选拔产生，与军官分途；优秀士官可考入军校提拔为军官。
