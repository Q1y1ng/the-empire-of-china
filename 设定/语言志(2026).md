# 《语言志（2026）》

> **性质**：本卷补"这个国家的人说什么话、写什么字"。此前全库只有一句"推广官话、汉字"（编年史 225、《总设定》第一编），方言、文字改革、外语教育**全库 0 命中**——17.8 亿人说得一模一样。
> **时点**：继文十一年（2026）。口径依《编年史》1711—1725 基础教育革命（官话、汉字、帝国法律、算术列入县乡学校）。
> **总纲一句**：**官话通行全国，方言活在乡里，正体字用于公事，简笔字留在手上。**

---

## 一、官话（全国通用语）

| 项 | 内容 |
| --- | --- |
| 名称 | 官话（对外称"帝国官话"） |
| 标准音 | **长安音**（京畿直隶州城区）——1720 年《国政六策》定"以京音为正" |
| 地位 | 行政、法律、教育、军队、媒体的通用语；**不是"唯一合法语言"**，方言与民族语言在家、在乡、在自治地方照用 |
| 推行史 | 1711—1725 年基础教育革命起，县乡学校教官话；1900 年代电报与铁路加速统一；1986 年后广播电视普及，官话成为第一语言的人首次过半 |
| 使用人口 | 以官话为第一语言者约 **9.8 亿**（55%）；能听懂者约 **16.4 亿**（92%）【推演】 |
| 等级考试 | **官话等级考试**分三级六等（一级甲等—三级乙等）；公务员录用要求**二级甲等以上**，教师要求一级乙等以上，播音要求一级甲等 |
| 媒体 | 广播电视一律官话，方言节目限额（地方台每日不超过 30%） |

## 二、八大方言区（与八州对应）

| # | 方言区 | 范围 | 特点 | 写作提示 |
| --- | --- | --- | --- | --- |
| 1 | **关中片** | 京畿直隶州 | 官话核心，声调硬、入声存；长安城内口音即"标准音" | 官腔最重，干部说话自带"文件味" |
| 2 | **东北片** | 东北州（含朝鲜语区） | 调值平、语速快；大量工业词与俄语借词 | 写工厂、写边防 |
| 3 | **晋蒙片** | 蒙古州（含蒙古语区） | 鼻音重、保留古词；牧区汉语与蒙古语混用 | 写草原、写贸易站 |
| 4 | **西北片** | 西北州（含突厥语族区） | 卷舌重、借词多；丝绸之路旧词留存 | 写商队、写口岸 |
| 5 | **华北片** | 华北州 | 与官话最近，儿化多 | 写京畿周边的"半个老乡" |
| 6 | **江南片** | 江南州 | **五支并存**：吴、闽、粤、赣、湘；彼此不通 | 写江南：城里官话、家里方言、生意场上英语 |
| 7 | **西南片** | 云贵州 | 川滇黔一体，语调软；多民族杂居区双语普遍 | 写山城、写赶集 |
| 8 | **青藏片** | 青藏州 | 藏语为主，汉语为第二语言；寺院教育用藏文 | 写高原：翻译是常设岗位 |

> **一句实话**：一个江南州的农民与一个东北州的农民，见面说官话；各自回家说方言。**官话是"公家的语言"，方言是"自己的语言"**——这条分层，比任何政策条文都更能解释帝国的统一。

## 三、文字

| 项 | 内容 |
| --- | --- |
| 正字 | **汉字（正体）**：公文、法律、教科书、报刊、碑刻一律用正体 |
| 简笔字 | 民间手写长期并行"简笔字"（省笔、连笔、俗字）；**不进公文与印刷** |
| 简化改革 | 1975 年曾拟《汉字简化方案（草案）》，1978 年大革命起搁置，1986 年宪法未涉文字，**至今未颁行**——帝国因此是"正体用于公事、简笔留在手上"的双轨 |
| 注音 | **官话注音字母**（1913 年制，37 字母）为小学识字工具；1986 年后与拉丁转写并用，护照与人名对外用拉丁转写 |
| 标点 | 沿用新式标点；公文用「、」「，」「。」，不用「·」作顿号 |
| 数字 | 公文用汉字数字（壹贰叁），统计表用阿拉伯数字 |
| 竖排 | 仅书法、碑刻、匾额、请柬竖排；书籍横排 |

### 3.1 少数民族文字

| 文字 | 使用 | 制度地位 |
| --- | --- | --- |
| 藏文 | 青藏州、藏南省 | 自治地方**公务双语**（藏汉并列），学校双语教学 |
| 蒙古文（回鹘式） | 蒙古州 | 同上；盟旗公文蒙汉并列 |
| 维吾尔文（阿拉伯字母） | 西北州南部 | 同上 |
| 朝鲜文 | 东北州朝鲜语区 | 同上；与官话并用 |
| 彝文、壮文等 | 云贵、岭南局部 | 文化保护，非公务文字 |

> 口径：**自治地方的"双语"是法定义务，不是照顾**——公文缺一种文字，本身就是可诉的程序瑕疵。

## 四、外语

| 语种 | 地位 | 学习渠道 | 说明 |
| --- | --- | --- | --- |
| 英语 | 第一外语 | 中学必修、大学必修 | 19 世纪对英贸易留下的底子；科技文献与外贸通用 |
| 俄语 | 第二外语 | 北方省份中学选修、军校必修 | 对苏战略共同体；能源与军工技术文献 |
| 日语 | 第三外语 | 沿海与共荣圈相关专业选修 | 精密制造与材料文献；竞争对象也是学习对象 |
| 其他 | 阿拉伯语、波斯语、西班牙语、法语 | 外语院校与外交系统 | 按商路与使节需要设 |

**制度**：公务员外语**不作硬性要求**；外交、外贸、军队情报与海关四个系统有分级外语考试（一级至三级），与官话等级并列记入履历。

## 五、姓名与称谓

| 项 | 规则 |
| --- | --- |
| 姓名 | 姓在前、名在后；单姓为主，复姓少数；公民自由取名（1986 年《户籍条例》） |
| 皇族字辈 | 承→载→翊→弘→昭→启（《编年史》附三）；皇族成员名中嵌字辈，不入普通户籍 |
| 敬称 | **先生／女士／职衔**：下级称上级用职衔（"部长""州长""主任"），平级用"先生"；**不用"同志"**（帝国无政党，此词不入公务用语） |
| 自称 | 公务场合自称"我"；书面用"本人"；皇帝自称"朕"仅用于制诏与觐见 |
| 忌讳 | 直呼上级姓名是失礼；对皇帝不得直呼名讳，须称"陛下"或"皇上" |
| 外邦人 | 称"某国某先生／女士"，加国名以示区别 |

## 六、写作口径（四条）

1. **写方言用词，不用音**：写"他说话带了点江南腔"，不要用谐音字堆句子。
2. **官话等级是履历的一栏**：干部档案里"官话二级甲等"与"品级""学历"并列，写提拔时可用。
3. **写外邦人说话，写通译**：帝国不假定人人会说官话；外交场合的翻译是制度性岗位（中央外事委员会下属通译处）。
4. **不要写"文字改革"**：帝国没有简化字，也没有拼音方案——这是本世界线与现实最容易被忽略的一处差别，写错即穿帮。
