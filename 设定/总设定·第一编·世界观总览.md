# 第一编：世界观总览

## 一、基本定位

**世界名称**：中华帝国（Empire of China）

**时间线**：1700年—至今

**核心国家**：中华帝国

**政治性质**：制度化君主制 + 国家主导型混合经济 + 技术官僚体系 + 有限代议政治

**文明特征**：传统东亚政治文化与近代科学、工业制度结合的现代文明体

## 二、世界线分叉点

本世界观最大的历史分叉在于：

**1700年出现了一个主动进行制度现代化的中国型帝国。**

这导致：

- "西方=现代化、东方=传统"的二元格局从根本上没有形成
- 帝国自主工业化，与欧洲同时现代化
- 全球形成多极竞争格局：帝国自由贸易体系与欧洲殖民体系长期并立

## 三、核心政治理念

作者确立的六条核心政治信念：

1. **权力可以集中，但必须能够被制度纠错。**
2. **官职归于能力，不归于阶级、家族、政党或圈子。**
3. **贫穷可以存在，但贫穷不能意味着没有未来。**
4. **富裕可以存在，但财富不能购买政治权力。**
5. **国家应该强大，但强大的目的应该是让普通人的生活变好。**
6. **制度不能停在开国皇帝设计的那一天，必须随着时代不断改革。**

## 四、帝国政治哲学核心原则

1. **皇权至上**：皇帝是国家最终权威。但"皇帝拥有最高权力"≠"所有事情都必须皇帝亲自决定。"核心理念："天子亲统大政，不亲治细务。"
2. **任官以才**：皇族可以拥有爵位，但爵位不能直接转化成政治权力。皇族不得凭爵位直接担任行政官，必须经过正常选拔程序。
3. **多民族共治**：帝国以汉文化和皇室为核心，各民族理论上都是帝国臣民。不强迫短期内改变民族身份。理念："使其同政，不必使其同俗。"
4. **教化优先于强制**：推广官话、汉字、帝国法律、帝国教育、帝国行政制度，但不强迫改变民族身份。经过几代人自然融合。
5. **富国而不固阶，集权而不壅民，崇学而不贵门**：允许财富增长但不能让财富自动变成政治权力；中央拥有很强权力但社会有正常表达和晋升渠道；以知识与能力为凭。

## 五、国家精神

### 【核心正式设定】

帝国的国家精神可以用一句话概括：

> **"让每一代人，都有改变自己命运的机会。"**

更完整的古典表述：

> **"天下非一人之天下，亦非一时之天下；君以定其向，臣以行其政，民以成其业。"**

## 六、现代国家理念

### 【核心正式设定】

到了现代，帝国的官方政治哲学逐渐形成：

> **君主定国之大方向，政府行国家之政，法律约束公权，人民参与政治，社会创造财富。**

可以概括为四个词：**秩序、发展、公平、流动**

- **秩序**：国家必须保持统一和基本稳定
- **发展**：科技、工业、教育和生产力必须持续进步
- **公平**：不要求结果完全相同，但不能让权贵垄断资源
- **流动**：一个人的出生不能决定他一生的上限

## 七、国家意识形态（冻结版）

正式名称：**中华国家发展主义**，简称**国发主义**。

理论核心：**统一、秩序、发展、公平、流动、责任、选贤、监督、改革、绩效**。

四大支柱：

1. **国家**：统一、主权、文明连续性
2. **政治**：皇权、制度、责任、选拔、监督
3. **经济**：发展、科技、效率、市场、国家调节
4. **社会**：公平、福利、教育、社会流动

## 八、政治思想坐标

| 维度 | 设定倾向 |
| --- | --- |
| 国家权力 | **强** |
| 皇权 | **强，但制度化** |
| 地方权力 | **中等** |
| 军权 | **高度中央化** |
| 经济 | **国家主导的混合经济** |
| 私人资本 | **允许，但严格监管** |
| 社会福利 | **较高** |
| 税收再分配 | **较强** |
| 教育 | **高度公共化** |
| 政治参与 | **有限但真实** |
| 政党 | **帝国无政党；只有非正式圈子（不入册、不承认、以圈谋官即犯罪）** |
| 官员选拔 | **高度功绩主义** |
| 基层民主 | **较强** |
| 中央民主 | **偏审议/监督型** |
| 司法 | **独立性较高** |
| 监察 | **非常强** |
| 民族政策 | **渐进融合 + 地方文化保留** |
| 外交 | **贸易主义 + 不干涉内政** |
| 军事 | **防御性强国** |
| 社会目标 | **阶层流动 + 中产化** |

**学术命名**："制度化贤能帝制"——或更完整地称为"功绩主义、福利国家与基层民主相结合的制度化帝制"。如果给它一个这个世界里的学术名称，可称为"西安体制"。
