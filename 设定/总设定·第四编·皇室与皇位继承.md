# 第四编：皇室与皇位继承

## 一、皇帝的地位

### 【核心正式设定】

- 皇帝为实权君主
- 皇帝任**中央政治委员会主席**，并为中央政治局常委之一；**不设「政治局常委会委员长」**
- 皇帝拥有真实的最高政治领导权，但高度放权，不亲自处理日常行政
- 皇帝的角色定位：国家最高战略决策者 + 最终仲裁者 + 国家象征 + 军队最高统帅

### 【核心正式设定：皇帝的权力】

1. **任命权**：任命一品官、部分二品官、州级最高官、军队最高将领、最高法院院长、中央纪委主席/国家监委主任
2. **军权**：帝国最高军事统帅，兼任中央军委主席。但不能随便越过军务系统调动基层部队
3. **外交权**：帝国签订重大国际条约需皇帝最终批准
4. **否决权**：可以否决法案、财政方案、政府重大政策。否决必须说明理由
5. **紧急权**：战争、叛乱、大规模灾害期间可临时扩大行政权，但紧急状态必须有期限
6. **最终裁决权**：皇帝拥有最终决定权（设想皇帝较开明）
7. **发动重大改革权**：包括在极端情况下发动全国制度大革命

### 【核心正式设定：皇帝权力的六分法】

传统皇帝的权力是一团混合物（军权+政权+财权+人事权+司法权+礼仪权），现代帝国将其拆开。皇帝保留其中最核心的六种"元权力"：

1. **战略权**：决定国家长期走向
2. **最高人事权**：决定谁进入国家最高领导层
3. **最高政治协调权**：解决不同国家机构之间的重大政治冲突
4. **最高国防政治权**：决定国家战争与和平的政治方向
5. **国家安全最高决策权**：决定国家面对重大安全威胁时的总体战略
6. **国家象征与连续性权**：保证三百多年国家制度连续性

以下权力则制度化地交给其他机构：日常行政→政府；立法→议会；审判→法院；财政监督→议会/审计院；公职监察→中央纪委、国家监委；军事执行→中央军委。

**皇帝掌握的是国家的"元权力"，具体政务由各机关依职权办理。**

### 【核心正式设定：皇帝权力三层次】

```text
皇帝【方向权】→ 中央政治局【政策权】→ 中央政府【执行权】→ 全国行政体系
```

皇帝最大的作用是决定国家往哪里走；政治局把国家方向转化为政治路线；政府把政治路线变成公共政策；官僚体系把政策执行下去。

### 【核心正式设定："皇权属于国家"与"天下之责"】

- 大革命后的政治格言：**"皇权属于国家"**
- 皇帝只是国家最高政治权力的制度承载者；皇帝去世后皇权不消失，但下一位皇帝必须依法继承并承担责任
- 皇帝拥有天下最高权力，也承担天下最高责任——**"天下之责"**：经济崩溃、战争失败、重大腐败，皇帝不能完全推给政府/军方/纪委
- 皇帝必须接受"政治考核"：中央政府每年向政治局和议会提交国家年度治理报告（经济/财政/民生/国防/科技/社会稳定/国际战略），皇帝主持政治局审议——形成**绩效型皇权**
- 核心原则：**"皇帝护国"**——旧制度不能适应时代时，修改旧制度本身就是维护帝国；改革是皇权主动推动制度更新的表现
- 皇帝拥有的是**制度内最高权力**，其行使受宪法程序约束：废除宪法、解散机构、取消地方行政体系，均须走宪法修正程序

### 【核心正式设定：皇帝不能直接做的事】

- 不能随意绕过行政机构处理普通事务
- 不能随便越过军务系统调动基层部队
- 不能无限制绕开预算体系
- 不能在不说明理由的情况下否决法案
- 不能无限期延长紧急状态

### 【核心正式设定：皇帝的工作模式】

- 皇帝的工作应该是"少而重要"
- 皇帝每天看到的文件应从历史上几百份/天下降到每天几十份以内
- 绝大部分事项只需皇帝"知悉"，具体处理归主管机关
- 一般行政事务不得直接上达皇帝
- 皇帝最看重的是选人

### 【核心正式设定：皇帝与中央政治局常委的关系】

- 皇帝拥有最后一票，但通常希望让其他**八名**常委先把问题解决
- 中央政治局常委会为**九人**共同组成的最高行政协调层，各人分管条线，机构合一
- 皇帝如果说"我要建一个超级工程"，中央政治局常委可以回答"技术上不可行"或"财政无法承担"
- 皇帝可以要求重新研究，但成熟皇帝不会直接说"我命令你们做"

## 二、皇位继承

### 【核心正式设定】

- 嫡长子优先，但皇帝可以废立
- 皇帝指定继承人 + 中央政治委员会确认 + 中央政治学院学习深造
- 皇帝废太子需要经过中央政治委员会备案（不一定需要同意，但必须留下正式记录）
- 开国皇帝创立制度，后续的继承人要经过高等教育以及考核后接任

### 【核心正式设定：皇储制度】

- 皇储制度必须有意义
- 皇储接受长期、系统、严格的国家治理教育和政治历练
- 皇储制度应当解决世袭制度中的能力风险
- 皇储是未来最高政治领导人的培养对象
- 皇储的完整培养路线：国立中央政治学院 → 基础基层实践 → 地方行政轮职 → 省级工作 → 州级政府观察与任职 → 中央政府部门工作 → 军事、财政、司法、监察等体系学习 → 中央政治委员会最终考核
- 一个皇储到三四十岁才正式成为国家继承人的情况非常正常

### 【核心正式设定：皇储国政教育院与训练内容】

- 设立**皇储国政教育院**：国家最高领导人才培养机构
- 皇储必须学习的领域：
  - **国家治理**：宪法、行政法、财政、经济、社会政策、地方治理
  - **国际事务**：外交、国际法、地缘政治、国际经济
  - **国防**：军事战略、国防工业、战略威慑、军民关系
  - **国家安全**：情报、网络安全、战略风险
  - **科技**：AI、芯片、生物科技、能源、航天
- **反方政府制度**：皇储训练中专门设置反对意见训练——一项政策由皇储主持正方，另一批高级官员专门负责反对，防止信息茧房
- **危机模拟**：金融危机、战争危机、大规模自然灾害、AI失业危机、能源危机、外交危机，皇储必须在压力下决策
- 皇储还必须学习**识人、用人、授权、监督**：官僚体系、人事制度、干部考核、权力结构、利益集团、组织行为、危机管理，甚至主持高级干部评议
- 皇储在正式继位前必须至少担任过一定时期的**中央政治局委员**
- 继位时整个国家已经认识这个人几十年——与传统王朝突然出现少年皇帝完全不同

### 【核心正式设定：皇储三层筛选与淘汰机制】

- 核心悖论的解决：皇帝决定则偏私，政治局决定则削弱皇室世袭——采用**"皇室提名 + 国家评议 + 皇帝最终确认"三层机制**
- **淘汰机制**：皇室成员享有继承资格，但不享有自动成为皇储的权利；阶段性考核不合格者退出皇储竞争
- **皇储落选**：能力明显不足者可依法取消皇储资格，但不取消皇室身份——皇帝子女分为：皇储/皇储候选人/普通皇室成员
- 皇室因此从单纯血缘集团变成**国家最高政治人才储备集团**
- 皇储所学为**如何成为未来整个国家政治体系的最高领导人**——这也是皇帝必须保留实权的原因：虚君之下，整套皇储培训与筛选机制便失去意义。

### 【核心正式设定：皇储的评价标准】

- 考核结果为"具备履行皇帝职责之能力"
- 皇帝不需要是全知全能的天才，只需要不昏庸、有能力、愿意依靠制度运行国家

### 【核心正式设定：皇帝登基教育】

- 新皇帝在继位之前，不只是学习历代皇帝功绩
- 还必须学习帝国失败史
- 重点研究：为什么官僚集团会形成？为什么中央没有及时发现？为什么普通人对国家产生不满？为什么正常改革没有解决问题？为什么最后会发生大革命？
- 这甚至可能成为皇储课程中最重要的一门：《帝国制度失灵与国家纠错》

## 三、皇族制度

### 【核心正式设定】

- 皇族拥有爵位（亲王、郡王、国公、县公等）
- 爵位只意味着身份、俸禄和礼遇，不意味着行政权
- 皇族参与政治要经过和普通人一样的选拔
- 皇族不得凭爵位直接担任行政官
- 封地有推恩令，选定的嫡系代表人领多一点，其他平分，既世袭又不影响中央财政
- 贵族没有免税权，基本上和普通人一样
- 功臣可以封爵

### 【核心正式设定：皇室财产制度】

- 国家财产和皇室私人财产分离
- 皇帝个人可以拥有私人住宅、私人投资、家族财产、遗产
- 皇宫、国家博物馆、国家档案馆等属于国家
- 皇室年度经费由中央财政拨款，由监察机关和议会审查
- 皇室成员可以从事科研、教育、军事、外交、公益、企业经营
- 但不能因为皇族身份直接获得行政官职

### 【核心正式设定：皇室机构与日常运作】

**皇室事务机构**（推演细化）：

- **皇室事务委员会**：管理皇室日常事务、礼仪、宫廷档案、皇室财产（国家财产与皇室私产分离原则下的私产部分）；向皇帝负责，经费受议会与监察机关审查
- **皇储办公室**：设于长安中央政务区，负责皇储培养计划执行与安全
- **帝国历史档案馆**：收藏历代皇帝实录、大革命档案（含《帝国制度自我革新史》公开展陈）

**皇帝的日常（推演，2026年）**：

- 上午：以中央政治委员会主席身份召集、主持中央政治局常委会或专题会议（国际形势/国家战略/重大科技/财政/军事/高级干部）
- 下午：专题会议或听取报告（如"下一代核聚变能源计划""西部人口问题""与欧洲贸易集团新协议"）
- 晚上：批阅需皇帝亲自裁决的事项
- 一年中真正需要皇帝亲自决定的重大事项：任命常委、军事战略、国家长期规划、重大外交、重大法律争议、特殊紧急状态、七州重大利益冲突
- 皇帝真正最看重的工作：**选择人**（识人、用人、授权、监督）

**皇室成员的职业路径**（核心设定细化）：

- 皇族有爵位（亲王、郡王、国公、县公）但无自动政治权力
- 皇室子女分流：皇储／皇储候选人／普通皇室成员
- 普通皇室成员可从事科研、教育、军事、外交、公益、企业经营，与普通人一样考试选拔；现代可能出现皇室工程师、教授、地方职员甚至无政治职位的普通公民

### 【核心正式设定：皇帝正式称谓体系（冻结版）】

| 场合 | 称谓 |
| --- | --- |
| 国家正式称谓 | **中华帝国皇帝** |
| 宪制职务一 | **中央政治委员会主席**（兼政治局常委；不设常委会委员长） |
| 宪制职务二 | **国家议会常务委员会主席** |
| 礼仪尊称 | **陛下**（正式公文：皇帝陛下） |
| 政治会议 | 皇帝以中央政治委员会主席身份召集中央政治局常委会 |
| 军事场合 | **国家最高统帅** |

一人拥有多个制度身份，诸身份同属一个权力中心。皇帝兼任国家议会常务委员会主席——**即国家议会常务委员会主席**（议会常务委员会副主席四人，谢清如为第一议会常务委员会副主席），象征皇权与民意机关的宪制联结；同时皇帝必须受宪法、政治组织法、议会监督和国家政治程序约束。

### 【核心正式设定：皇权冻结程序】

- 中央政治委员会开会过80%同意后可以冻结/罢免皇帝并再选皇帝
- 避免皇帝昏庸无能而扰乱国家
- 正式名称："皇权冻结程序"
