# 第七编：地方行政制度

## 〇、地方制度的根本原则

### 【核心正式设定：中央集权型单一制】

- 中华帝国为**中央集权型单一制帝国**
- 核心原则：**下级服从上级，上级接受中央领导**
- 七个常规州的州政府与州议会均为**国家行政体系在地方的制度化组织**，权力源于国家授权
- 宪法性表述："中华帝国是统一的国家。国家主权属于全国人民，由中央国家机关统一行使。地方行政机关接受中央及上级行政机关领导。"

### 【核心正式设定：权力不下放，事务可以下沉】

- **中央负责**：国防、外交、货币、国家财政、国家安全、全国法律、重大基础设施、全国社会保障、全国教育标准、全国医疗体系、国家工业战略
- **地方负责**：城市管理、地方交通、地方公共设施、地方经济执行、地方文化事务、基层公共服务、中央政策的具体实施
- 核心概括：**中央统一决策，地方负责执行与具体治理**；政策统一，执行多样
- 政治哲学总结：**"统而不乱、集而不专、分事而不分权"**——全国统一领导，地方不得形成独立政治中心；国家权力集中到中央但中央内部分工（政治/行政/立法/司法/监察/军事/情报）；地方负责具体事务但没有国家主权

### 【核心正式设定：地方议会重新定义】

- **地方议会是地方人民参与地方治理的代表机构**
- 可以拥有：地方预算审议、地方行政质询、地方公共项目监督、地方政策建议、地方官员问责、地方公共事务调查
- 地方选举与地方议会选举合二为一，减少工作量；州议会产生或确认州政府，省/市/区（县）政府同样由本级议会产生或确认；**产生或确认的具体程序依《地方政府法》第三章**（上级政委会提名—本级议会同意—任命，基层为受控差额选举）
- 地方行政长官来源：**上级政委会提名 + 本级议会同意 + 任命 + 地方考察 + 议会监督**；州长由中央政委会提名、州议会同意、皇帝任命，省长市长由上一级政委会提名、本级议会同意、上一级任命；地方议会可质询州长、审议州预算、调查地方行政问题；任内罢免须本级议会三分之二多数并经上级政委会确认，地方议会不得自行任免或单方面罢免州长

### 【核心正式设定：地方机构正式名称】

| 层级 | 政治机构 | 行政机构 |
| --- | --- | --- |
| 州 | 州人民政治委员会常务委员会 | 州政府 |
| 省 | 省人民政治委员会常务委员会 | 省政府 |
| 市 | 市人民政治委员会常务委员会 | 市政府 |
| 区 | 区人民政治委员会常务委员会 | 区政府（县级市为市政府） |
| 街道 | 街道委员会 | 街道行政机构 |

### 【核心正式设定：三条纵向体系】

帝国有三条相互交叉但不互相隶属的纵向体系，在地方汇合：

1. **行政纵向体系**：中央 → 州 → 地 → 县 → 基层
2. **监察纵向体系（纪检与监察双轨独立）**：中央纪委 → 州纪委 → 地方纪委 → 基层纪检；国家监委 → 州监委 → 地方监委 → 基层监察
3. **军事纵向体系**：中央军委 → 军区 → 军 → 旅 → 营 → 连 → 班（编制详见《全国军事编制设定(2026)》分卷）

地方政府既接受上级政府领导，又接受上级监察机关监督；地方行政无权干涉军队指挥。

### 【核心正式设定：多源信息原则】

- 传统王朝的致命问题是皇帝不知道真实情况（报喜不报忧）
- 大革命后建立**多源信息原则**：任何重大问题不能只依赖一个部门的数据
- 信息来源：国家统计、议会调查、审计系统、纪委与监委、国安系统、学术机构、社会舆情、社会红利系统数据——多源交叉验证
- 帝国建立了一套让皇帝能够尽可能知道真实情况的制度，这比"皇帝什么都知道"更重要

## 一、六级行政体系

### 【核心正式设定】

**中央 → 州 → 省 → 市 → 区 → 街道办**

| 层级 | 地位 | 大致职责 |
| --- | --- | --- |
| 中央 | 帝国政府 | 全国外交、军事、财政、法律、重大工程 |
| 州 | 一级行政区 | 治理下属各省、跨省统筹、区域军事、经济、交通 |
| 省 | 主要地方行政单位 | 财政、司法、教育、治安 |
| 市 | 城乡综合行政单位 | 城市及周边地区治理 |
| 区 | 基层行政单位 | 社区、乡村、基层公共服务 |
| 街道办 | **区政府的派出机构**（不是一级政府；不设议会、不设代表会议） | 户籍、治安、民政、基层税务等 |

### 【核心正式设定：层级功能定位】

- **中央 = 战略**
- **州 = 统筹治理（直接领导下属各省）**
- **省 = 治理**
- **市 = 基层城市治理**
- **区 = 公共服务**
- **街道 = 社区治理**

## 二、州级制度

### 【核心正式设定】

- **州人民政治委员会常务委员会**是州级最高政治机构
- 常委会固定为**九人**（继文改制，原"7～11人"口径作废），由主席主持
- 常委不区分排序，以职务分工为准，集体讨论决定本州重大政治问题
- **副主席二人，均称副主席，不分第一、第二**；含权量序为：主席＞副主席（政府首长）＞副主席（政法委员会主任）＞委员
- 州军区司令为常委会委员，但不负责地方行政
- **三长归口**：州高院、州检察归口州政法委员会，州审计厅归口州议会（主席由州政委会主席兼）；按议题特邀到会

**州人民政治委员会常务委员会组成（9 人标准）**：

| 序 | 常委会职务 | 兼任职务 |
| --- | --- | --- |
| 1 | 主席 | 州议会常务委员会主席 |
| 2 | 副主席 | 州政府州长（政府首长·含权量第二） |
| 3 | 副主席 | 州政法委员会主任（兼管公安·含权量第三） |
| 4 | 委员 | 州组织部部长 |
| 5 | 委员 | 州纪律检查委员会主席 |
| 6 | 委员 | 州监察委员会主席 |
| 7 | 委员 | 州军区司令 |
| 8 | 委员 | 州人民政治委员会秘书长、州政府办公厅主任 |
| 9 | 委员 | 州委常委（兼州府所在省的省人民政治委员会主席·该职高配州委常委级） |

> 京畿直隶州无省，第 9 席适配为**长安市委主席**（州委常委）。

### 【核心正式设定：州长权力】

1. **行政统筹权**：领导、监督省级政府，治理所辖各省，处理跨省事务
2. **财政审核权**：州人民政治委员会常务委员会审议 → 州长批准省级预算
3. **干部考核权**：考察省级官员、评价省级政府、推荐干部
4. **危机处理权**：直接协调多个省处理洪水、饥荒、大型瘟疫等

### 【核心正式设定：州长权力的边界】

- 征税、货币发行、外交、建军与省界变更由**中央统一行使**；州内相关事项由州长报请中央批准后执行
- 省长任免依「上级政治委员会提名—省议会同意—任命」三段式办理，州长在州政治委员会内提出人事意见

### 【核心正式设定：州长述职】

- 每年一次正式述职：七州州长全部入京
- 每半年一次可以书面述职
- 述职内容：财政报告、人口报告、农业报告、军政报告、官员报告

## 三、省市级制度

### 【核心正式设定：地方选举制度】

- 基层（区、县议会）：区（县）议会议员由选民直接选举；街道办为区政府派出机构，其主任由区政委会委派、区议会同意
- 区级：代议人选举（由选举人选举产生）
- 市级及以上：间接选举

### 【核心正式设定：地方议会】

- 地方议会选举可以与地方政治选举合并
- 直隶州议会：规模不大，由各市、各区代议人组成
- 负责州预算、粮政监督、水利工程监督、州级政策讨论、对州政府质询
- 州长由中央政委会提名、州议会同意后任命——州议会就此行使同意权

### 【核心正式设定：地方条例】

- 地方条例不能违反中央旨意
- 设立地方条例由地方委员会通过后上报中央审批

## 四、官员品级与选拔

- 官员从一品到十品，品级对应"官阶"，官职 ≠ 品级，人数尽可能精简

### 【核心正式设定·吏制】

十品以下**非官而是吏**，设三等：

| 吏等 | 对应 | 典型职务 |
| --- | --- | --- |
| **一级吏长** | 正科级 | 街道办主任、乡镇长 |
| **二级吏长** | 副科级 | 街道办副主任、乡镇副职 |
| **三级吏长** | 科员 | 一般科员、办事员 |

- 官吏有别：官经科举—政治学院—选举产生，吏经事务考试/聘任产生
- **优秀提拔需考试**：吏中优秀者可经考核＋政治学院/考试晋升为官（十品），非自动转任
- **选培生（1986 新制）**：中选与州选为本科应届生的直通轨——中选三年直博、定一级吏长；州选三年硕士、定二级吏长

> 注：政治局常委身兼多职时（如常委兼总理/兼议会常务委员会主席/兼京畿州州长），以最高职务品级计；帝国审计院等二级机构高配二级，体现监督独立性高于被监督的三级部委。
>
> 注：中央政治委员会是「全体会议层」，成员下限三品（京畿与江南两州州委主席为政治局委员，其余六州州委主席、州长、部委主官、议会专门委主任等为委员），皇帝任主席；其级别不按「一把手品级」推算，单列于三级。**2026.12 起构成改为列举式**（原「不超过八十人」已从宪法第十一条删去）。
>
> 注（2026.12 副国级改定）：**政委会委员 ≠ 二品**。政委会委员共 **79 人**（含主席皇帝在内计 1 席，故委员 78 人），其中二品以上 **51 人**（一品 9＋二品 **42**），三品 **29 人**；九名议会专门委员会主任、统计局长是「岗位升格、人随岗」，在任三品干部一个未动。军事系统在政委会保留六席。

> 注（2026.12 副国级改定·级别待遇对照）：中央政治学院、帝国国防大学为**三品级单位**（校长三品·中将），列三级；现由程慕松（常委）、何秉毅（军委委员·二品）**高配兼任**——人高岗低，岗位仍三品，二人待遇按其本人品级计。皇家理工等重点国立校总校（四品）列四级、其分校（五品）列五级；州立大学与国立非重点总校（六品）列六级、国立非重点分校（七品）列七级；省立/行政区立大学（八品）列八级；行业专科与市立各校（十品）列十级；军校/警校按校长军衔对应（其余军校与国立警察大学少将·警官学院与省立警察学校大校）。

### 【核心正式设定·新制（1986 定制）：官员晋升年限与最低要求】

**总基准**：一届＝5 年（全国统一任期基准）。最低任职年限按**副正交替**定：**副职升本级正职 2 年；正职升上级副职 3 年**；二品以上另须「任政治局委员满 5 年方可议一品」。四品及以上禁止破格，未满法定期限一律不得升迁。

> 十品、八品、六品、四品是**副职**品级，九品、七品、五品、三品是**正职**品级——官阶本身就是副正交替，所以「2 年／3 年」是一换挡，规则简单到不必背表。

**吏级晋升（十品以下行政执行层）**：

| 级别 | 典型职位 | 最低年限 | 最低要求 |
| --- | --- | --- | --- |
| 吏三（科员） | 一般科员、办事员 | 入职（≥22岁） | 帝国公职资格考试（行政资格）＋政审＋试用一年 |
| 吏二（副科） | 街道办副主任、乡镇副职 | ≥2年 | 年度考核合格 |
| 吏一（正科） | 街道办主任、乡镇长 | ≥3年 | 考核优秀；街道办主任为基层政治官，按选举产生，任满一届 |

**吏→官（十品）转轨**：吏一（正职）任满 **3 年**＋考核优秀＋州级考试＋**州立政治学院（省学区）一年**＋两年以上基层公共事务履历（可与任职并行）——必须经考试晋升，非自动转任。

**官级晋升（十品～一品）**：

| 品级 | 类型 | 典型职位 | 最低年限 | 最低要求 |
| --- | --- | --- | --- | --- |
| 十品 | 副职 | 副县、副区长 | 任满 **2 年**（副→正） | 州级考试合格＋政治学院结业；出仕约 28～30 岁 |
| 九品 | 正职 | 县／区长 | 任满 **3 年**（正→副） | 届终考核优良；任内负责过公共工程或民生项目 |
| 八品 | 副职 | 副市长、副厅局长 | **2 年** | 省级考核举荐；须有跨县任职经历 |
| 七品 | 正职 | 普通地级市主官、省厅正职 | **3 年** | 帝国考试（高等级）＋中央组织委员会备案——正式进入高级干部序列 |
| 六品 | 副职 | 副省长、副省级市主官 | **2 年** | 中央年度考核累计优良；履历档案完整 |
| 五品 | 正职 | 省长 | **3 年** | 须有跨省任职经历（≥2年）；中央考核优良 |
| 四品 | 副职 | 州副职、京畿直辖市市委主席 | **2 年** | 高级干部强制轮岗（外地任职累计≥3年） |
| 三品 | 正职 | 州长、中央部长 | **3 年** | 中央组织提名＋中央政治考核＋皇帝任命；须有跨州轮岗 |
| 二品 | 副国 | 政治局委员、**副总理（非常务）、议会常务委员会副主席、议会专门委主任、统计局长、二级机构主官** | **3 年** | 中央政治委员会全体会议选举＋皇帝任命；**三品岗位一律不得按二品待遇计** |
| 一品 | 正国 | 政治局常委、议会常务委员会主席、军委主席 | **任政治局委员满 5 年** | 中央政治委员会全体会议选举＋皇帝任命 |

**正常路径平均节奏**：22 岁入职 → 约 30 岁前后升十品 → 理论最快 55 岁至一品；**实际因岗位空缺（每级岗位约为下级一半）与选举，平均 4～6 年一阶**，一品多在 58～65 岁。

**提前升迁**：未满一届可以升，原职由副职代理至届满或补选，代理期计入新职最低年限。破格（低于 2／3 年）四品以上禁止，四品以下须政委会三分之二＋皇帝批准——1986 年至今仅 3 例。

**四条特殊通道**：

1. 事务官转政治官：持资格证＋政治学院一年＋选举，进入十品起步
2. 军队/科技/外交/司法/议会入政治局：以系统代表身份进入，但任政治领导职仍需考核
3. **中央选培生／地方（州）选培生**（1986 新制首批）：中选三年直博，毕业定**一级吏长（正科）**；州选三年授硕士，毕业定**二级吏长（副科）**。中选**免基培、中培**，州选**免基培**；两者均免「吏→官」的学院一年。详见本编「政治学院·选培生」
4. 皇储：独立培养体系（见第四编），不受本表约束

**防守机制（呼应大革命历史教训）**：

- 任何一级连任封顶 10 年，到点必轮岗或离任
- 州级以上（四品起）强制跨区轮岗；直系亲属回避同部门
- 高级干部财产与利益申报；御史与巡视定期评价

### 【核心正式设定：干部选拔制度】

标准路径（以A为例）：

1. 地方省级科举选拔
2. 获得政治人才资格
3. 选择：州立大学深造 或 地方任职
4. 州立政治学院（省学区）学习一年
5. 市级政府决定这一批人统一进入地方就任
6. 地方直接选举决定官职
7. 街道办委员会，专管某个事项
8. 五年任期
9. 政绩考核
10. 市级干部选拔
11. 区级干部候选库
12. 区级代议选举
13. 区级政府部门任职
14. 继续考核、晋升

### 【核心正式设定：科举考试内容（推演细化）】

**中央统一规定科目**：法律、行政、财政、历史、政治理论、基础数学、公文写作、地方治理。

**省级自选加试**：本地区经济、地方法律、地理、民族语言、地方历史。

**三级考试体系**：地方科举（省组织，筛基层人才）→州级考试（中高级行政人才）→帝国考试（中央高级人才）。

**现代演化**：科举已演变为"帝国公职资格考试"——分文科资格（法律政治经济历史）、理工资格（工程数学医学）、行政资格（基层治理）；政治官必须持有政治资格证。

### 【核心正式设定：科举制度】

- 科举不直接授官
- 科举决定你有没有资格做官，选举决定你具体担任什么政治职位
- 地方科举由省组织，考试标准由中央统一规定
- 科举成为"帝国公职资格考试"
- 地方科举 → 获得政治人才资格 → 多种培养路径 → 政治实践 → 再选拔

### 【核心正式设定：政治学院（1986 新制）】

**两级九所**：国立中央政治学院 1 所（三品级单位·校长三品，长安市**灞桥区**）；州立政治学院 8 所（四品，与各州州委同城；京畿直隶州立政治学院与中政**同校区**）。原 44 所省立政治学院于 1986 年一律改设为州立政治学院的「**省学区**」——不独立建制、不单独挂牌，主任七品，只作教学点，不入院校统计。
- **本科（1986 首设）**：四年制，授**学士**。四组十专业：甲组治理（行政学、地方治理、民族与边疆治理、政书学）、乙组法政（政制法、监察学）、丙组财经（财政学、政治统计）、丁组理论文献（政治理论、政治史学）。中政四组全开（240／届），州院开甲、乙、丙三组（320／届）。
- **三级培训班**：**基层干部培训班**（基培，硕士研究生学历，州立政院承办，各学区授课）、**中级干部培训班**（中培，博士研究生学历，中政承办）、**高级干部培训班**（高培，博士后，中政承办）。帝国学位序列四级：**学士—硕士—博士—博士后**（「博士后」在帝国为学位）。
- **选培生**：**中选**面向 C9 九校与中政本科毕业生，一届 25 人左右（C9 各 2～3 名＋中政 5 名），三年直博、半任职半读、灞桥区基层轮值，毕业定一级吏长（正科），免基培与中培，人称「半只脚踏进四品」；**州选**面向本州州立重点大学与州立政院，一州一年 25 人，三年授硕士、本地轮职，毕业定二级吏长（副科），免基培，人称「一只脚踏进七品」。两轨均过「七道闸」：考试、政审（直系三代）、背调、征信、体检、面试、公示。
- **校长与副校长**：校长统筹定方向（中政三品，现由程慕松以常委身份高配兼任；州院四品，由州委常委组织部长兼）；教学、学工、基培编排、人事、财务由分管副校长主抓——「校长是位子，副校长是权力」。
- **口径**：政治学院属干部教育，不入普通高校招生口径，学位由帝国学位委员会认定；皇储培养主渠道仍在中政（宪法第四十二条），走「本科→高培」独立通道，不受选培与年限约束。

### 【核心正式设定：政治官与事务官二元体系】

**政治官**：

- 通过科举资格 + 政治学院 + 选举获得职位
- 负责制定政策、分配资源、政治决策、对选民负责、对上级委员会负责

**事务官**：

- 通过专业考试 + 大学教育进入政府
- 负责执行政策、财政核算、工程、教育行政、医疗、法律事务、技术工作
- 不直接参与政治竞争

### 【核心正式设定：干部履历档案】

- 从第一天进入政治学院（含中选、州选）开始就建立"官籍"
- 记录：科举成绩、政治学院成绩、任职地点、任期、政绩、财政责任、居民评价、同僚评价、御史评价、是否受过处分、参与过什么大型工程、管理过多少人口

### 【核心正式设定：官员任期】

- 基层政治官统一五年一届
- 可以连任一次（5年 + 最多5年）
- 之后必须离任
- 避免地方官员长期经营自己的势力

### 【核心正式设定：政治失败不等于人生失败】

- 政绩优秀 → 晋升
- 政绩普通 → 继续担任普通行政职位
- 居民评价差 → 不再担任政治职务，但可进入事务官体系
- 违法/严重失职 → 御史调查/司法程序

- 各县（县级市）等同区级设置；州军区司令为州级特例（军事委员在省及以下按国防动员口径适配）

> **【决策层九人、执行层依法选举】继文改制后的层级原则**：中央与州为决策层，各设九席；省、市、区（县）为执行层，成员依法选举产生（本届实有十一席）。理由：层级越低，需要在一张桌上对齐的机构越多，席位应越宽——这与真实世界"中央核心圈小于地方党委常委会"的道理一致。由此留下一处不对称：**省市区三级三长均已改为归口（法院、检察归口政法委，审计归口议会），与中央、州两级同制**，这成为改革没做完的那一半，长期为改革派与稳健派所争论。

## 十、司法、监察、审计、情报纵向体系（2026确认版）

### 【核心正式设定·2026确认版】

- **法院**：最高法院 → 州高级法院 → 省法院 → 市法院 → 区法院（基层） → 街道巡回法庭
- **检察院**：最高检察院 → 州高级检察院 → 省检察院 → 市检察院 → 区检察院
- **监察（垂直）**：中央纪委/国家监委 → 州纪委/州监委 → 省纪委/省监委 → 市纪委/市监委 → 区纪委/区监委 → 基层监察站
- **审计（对议会线）**：帝国审计院 → 州审计厅 → 省审计署 → 市审计局 → 区审计科
- **情报（垂直）**：国家安全委员会 → 国安局 → 州国安局 → 市国安支局
- **议会**：国家议会 → 州议会 → 省议会 → 市议会 → 区议会（代议）；各级议会设常务委员会及其办公室
