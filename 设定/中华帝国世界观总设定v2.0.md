# 第一编：世界观总览

## 一、基本定位

**世界名称**：中华帝国（Empire of China）

**时间线**：1700年—至今

**核心国家**：中华帝国

**政治性质**：制度化君主制 + 国家主导型混合经济 + 技术官僚体系 + 有限代议政治

**文明特征**：传统东亚政治文化与近代科学、工业制度结合的现代文明体

## 二、世界线分叉点

本世界观最大的历史分叉不是"清朝没有灭亡"，而是：

**1700年出现了一个主动进行制度现代化的中国型帝国。**

这导致：

- "西方=现代化、东方=传统"的二元格局从根本上没有形成
- 帝国自主工业化，与欧洲同时现代化
- 全球形成多极竞争而非单极殖民体系

## 三、核心政治理念

作者确立的六条核心政治信念：

1. **权力可以集中，但必须能够被制度纠错。**
2. **官职应该属于有能力的人，而不是属于某个阶级、家族或政党。**
3. **贫穷可以存在，但贫穷不能意味着没有未来。**
4. **富裕可以存在，但财富不能购买政治权力。**
5. **国家应该强大，但强大的目的应该是让普通人的生活变好。**
6. **制度不能停在开国皇帝设计的那一天，必须随着时代不断改革。**

## 四、帝国政治哲学核心原则

1. **皇权至上**：皇帝是国家最终权威。但"皇帝拥有最高权力"≠"所有事情都必须皇帝亲自决定。"核心理念："天子亲统大政，不亲治细务。"
2. **任官以才，而非以爵**：皇族可以拥有爵位，但爵位不能直接转化成政治权力。皇族不得凭爵位直接担任行政官，必须经过正常选拔程序。
3. **多民族共治**：帝国以汉文化和皇室为核心，各民族理论上都是帝国臣民。不强迫短期内改变民族身份。理念："使其同政，不必使其同俗。"
4. **教化优先于强制**：推广官话、汉字、帝国法律、帝国教育、帝国行政制度，但不强迫改变民族身份。经过几代人自然融合。
5. **富国而不固阶，集权而不壅民，崇学而不贵门**：允许财富增长但不能让财富自动变成政治权力；中央拥有很强权力但社会有正常表达和晋升渠道；尊重知识和能力而不是单纯尊重出身。

## 五、国家精神

### 【核心正式设定】

帝国的国家精神可以用一句话概括：

> **"让每一代人，都有改变自己命运的机会。"**

更完整的古典表述：

> **"天下非一人之天下，亦非一时之天下；君以定其向，臣以行其政，民以成其业。"**

## 六、现代国家理念

### 【核心正式设定】

到了现代，帝国的官方政治哲学逐渐形成：

> **君主定国之大方向，政府行国家之政，法律约束公权，人民参与政治，社会创造财富。**

可以概括为四个词：**秩序、发展、公平、流动**

- **秩序**：国家必须保持统一和基本稳定
- **发展**：科技、工业、教育和生产力必须持续进步
- **公平**：不要求结果完全相同，但不能让权贵垄断资源
- **流动**：一个人的出生不能决定他一生的上限

## 七、国家意识形态（冻结版）

正式名称：**中华国家发展主义**，简称**国发主义**。

理论核心：**统一、秩序、发展、公平、流动、责任、选贤、监督、改革、绩效**。

四大支柱：

1. **国家**：统一、主权、文明连续性
2. **政治**：皇权、制度、责任、选拔、监督
3. **经济**：发展、科技、效率、市场、国家调节
4. **社会**：公平、福利、教育、社会流动

## 八、政治思想坐标

| 维度 | 设定倾向 |
| --- | --- |
| 国家权力 | **强** |
| 皇权 | **强，但制度化** |
| 地方权力 | **中等** |
| 军权 | **高度中央化** |
| 经济 | **国家主导的混合经济** |
| 私人资本 | **允许，但严格监管** |
| 社会福利 | **较高** |
| 税收再分配 | **较强** |
| 教育 | **高度公共化** |
| 政治参与 | **有限但真实** |
| 政党 | **允许存在，禁止直接控制官职** |
| 官员选拔 | **高度功绩主义** |
| 基层民主 | **较强** |
| 中央民主 | **偏审议/监督型** |
| 司法 | **独立性较高** |
| 监察 | **非常强** |

**学术命名**："制度化贤能帝制"——或更完整地称为"功绩主义、福利国家与基层民主相结合的制度化帝制"。如果给它一个这个世界里的学术名称，可称为"西安体制"。

# 第二编：帝国起源与建国

## 一、明末大乱与帝国建立

### 【核心正式设定】

- 帝国起源于明末大乱中的一支政治军事力量
- 该力量最终胜出并继承中华王朝正统合法性
- 1700年，帝国正式建立，被后世称为"制度元年"
- 开国皇帝创立制度，后续的继承人要经过高等教育以及考核后接任

### 【核心正式设定：迁都】

- 本世界观中，朱元璋时期已经成功迁都西安
- 西安被重新定名为"长安"（后世在现代语境中仍称"西安"）
- 长安/西安因此成为中华帝国长期政治中心
- 首都选在西安的原因：战略纵深好、接近帝国传统政治核心、可以平衡各州

## 二、开国皇帝（太祖）的生平

### 【核心正式设定】

- 开国皇帝不是"特别想统治别人"的皇帝，而是"特别想把国家这台机器设计好"的皇帝
- 开国皇帝在某种程度上把皇帝本人也当成了制度的一部分
- 开国皇帝数十年制度设计后，1700年正式颁布新政治制度
- 开国皇帝创立整套政治体系，大革命不是创建整套政治体系，而是在既有体系基础上进行伟大转折

### 【核心正式设定：太祖姓名（冻结版）】

**太祖：朱承乾**。"承乾"的政治含义：承接旧王朝正统，又建立新制度。1700年朱承乾建立中华帝国，明朝灭亡，但中华文明的皇统合法性并没有断裂——符合"明末乱世中最终胜出的一股力量继承王朝正统"的设定。

### 【推演：太祖的生平经历】

**少年**：出生于17世纪后期，家庭并不特别显赫。年轻时亲眼看到旧制度的弊病：地方行政效率低下、官员腐败、地方豪强控制土地、农民缺乏稳定土地使用权、教育高度集中于少数阶层、水利年久失修、军队腐化、财政混乱。

**核心问题意识**：太祖年轻时就提出一个贯穿一生的问题——"为什么一个国家明明有那么多人、有那么多土地、有那么多聪明人，却总是治理不好？"他逐渐意识到：问题不是没有人才，而是人才无法被稳定地发现和使用。

**青年基层经历**：太祖曾经进入地方行政体系，亲眼看到真正懂水利的人可能一辈子只能做地方小吏，真正清廉的人可能被复杂的行政关系拖死，而善于逢迎的人反而能一路升迁。这让他第一次产生了影响整个帝国的思想："国家不能只依赖皇帝识人。"

**研究历代制度**：太祖没有完全否定传统，而是研究秦汉、隋唐、宋、明、清的制度，同时研究海外资料。他尤其喜欢唐代，因为唐代最大的优点是能够把庞大的不同地区整合进一个政治体系。但他也发现唐代地方军事力量过强的问题，后来设计"州负责行政，军权归中央"。

**成为政治家**：大约30岁左右，太祖第一次拥有独立的政治影响力，组织一批年轻人，包括农民子弟、商人子弟、工匠、读书人、军人、水利人员、医师。他第一次尝试证明："治理国家的人不应该按照出生决定。"

**天下大乱**：中央政权陷入严重危机，地方势力割据。太祖做出关键决定——"不先夺天下，先夺取治理能力"。他首先建立粮食组织、水利队、基层行政机构、新式军队、临时学校、地方财政机构。他要求军队不许随意抢掠，甚至规定军队必须购买粮食或由政府统一征收并登记。普通人开始觉得这支军队和过去的军队不一样。

### 【核心正式设定：太祖的历史定位】

- 帝制并没有妨碍发展，反而在开国皇帝的领导下生活发生了翻天覆地的变化
- 一些老人经常说开国皇帝就是他们的救世主
- 核心政治问题有越来越多的生活小康且幸福的人参与讨论，但并没有造成社会动荡

## 三、1700年初始条件

### 【核心正式设定】

- 1700年被正式定为"制度元年"
- 帝国疆域已经大致达到：中原及关中、江南、四川、东北、蒙古高原部分地区、新疆及中亚部分地区、朝鲜半岛、中南半岛北部及部分地区
- 人口、经济和文化差异极大
- 过去的旧式中央官僚制度已经越来越难以处理如此庞大的帝国
- 帝国正式颁布新政治制度，各系统开始发挥作用

### 【推演：1700年世界环境】

- 欧洲正在进行科学革命后期
- 英国、荷兰、法国正在发展海运、贸易、金融、殖民体系
- 奥斯曼帝国仍然强大
- 印度次大陆处于莫卧儿体系和地方势力竞争之中
- 日本处于德川幕府时代
- 俄罗斯正在向东扩张

# 第三编：疆域与行政区划

## 一、帝国疆域

### 【核心正式设定】

- 帝国疆域整体略大于清朝极盛时期
- **北界**：库页岛—外兴安岭—贝加尔湖—阿萨彦岭—阿尔泰山脉
- **西界**：巴尔喀什湖—天山—帕米尔高原—兴都库什山脉—喜马拉雅山脉
- **南界**：横断山脉—澜沧江—长山山脉—曾母暗沙—南沙群岛—中沙群岛
- **东界**：巴士海峡—台湾—琉球群岛—朝鲜半岛
- 包括朝鲜半岛全境
- 控制部分中南半岛及部分中亚地区
- 包括台湾、南海诸岛

- 京畿直隶州州长可以依法特别成为中央政治局委员，但原则上不是政治局常委
- 范围包括成都在内的大范围四川盆地、关中平原以及部分河南和华北平原
- 相当于中国现在的直辖市，相同职位的官员比普通州高一到两级
- 不设省级政府，直接由中央管辖
- 中央将河南、成都平原、陕西大部等中原重要粮食生产地域纳入直隶州，由中央直接参与治理

### 【核心正式设定：州的性质】

- 州是直属中央的一级行政层级，直接治理其下辖各省，是省的直接上级行政层级
- 州对下属省拥有行政领导、财政审核、干部考核、区域统筹等治理实权
- 州仍受中央集权约束：州一级人事握于中央（跨级管理）、州长定期进京述职、不得自行征税/发行货币/外交/建军/改变省界
- 七个州按地域划分
- 边界应当犬牙交错相互制衡，每个州依据经济/人口分配疆域
- 七个常规州对应八大军区
- 海军另有北海舰队、东海舰队、南海舰队

### 【核心正式设定：州与省的关系】

- 七个常规州下辖39个省（全国省级行政单位共44个，含京畿5个中央直辖行政区）
- 州主管行政，但人事任命是跨级管理，主要握在中央手里
- 州一级人事全部握在中央手里
- 州可以决定省级预算
- 州长每年/每半年进京述职
- 财政半依附于中央，中央有转移支付的功能

### 【核心正式设定：地方治理原则】

- 地方并非联邦成员，也不是普遍自治地区
- 全国统一接受中央领导，地方接受上一级行政机关领导
- 只有少数民族等特殊地区根据实际需要实行有限自治
- 地方自治不等于地方拥有国家主权
- 地方议会选举可以与地方政治选举合并，以降低行政成本

## 三、对外重要节点

### 【核心正式设定】

- **对外重要港口**：河内、珠三角、长三角、环渤海、首尔湾、海参崴
- **重要陆路口岸**：乌鲁木齐方向的中亚/苏联通道、藏南方向的印度通道、万象方向的中南亚通道

## 四、西安城市规划

### 【核心正式设定】

- 到2026年，西安已占满整个关中平原
- 咸阳等变成区级行政区
- 西安城墙内几乎全是重要行政机构以及各部委以及国企事业单位总部
- 完整保留西安的政治中心功能，疏散其他功能
- 西安是中华帝国唯一首都、全国最高政治中心、国家机关总部所在地
- 帝国不存在"政治副首都"

### 【核心正式设定：西安城墙内——长安中央政务区】

**城墙内功能分区**：

- 皇宫及皇室办公机构

**城墙外功能分区**：

- 咸阳核心区：历史文化、教育、博物馆、高端服务业

# 第四编：皇室与皇位继承

## 一、皇帝的地位

### 【核心正式设定】

- 皇帝不是纯粹象征人物
- 皇帝兼任中央政治局常务委员会委员长
- 皇帝拥有真实的最高政治领导权，但高度放权，不亲自处理日常行政
- 皇帝的角色定位：国家最高战略决策者 + 最终仲裁者 + 国家象征 + 军队最高统帅

### 【核心正式设定：皇帝的权力】

1. **任命权**：任命一品官、部分二品官、州级最高官、军队最高将领、最高法院院长、中央纪委书记/国家监委主任
2. **军权**：帝国最高军事统帅，兼任中央军委主席。但不能随便越过军务系统调动基层部队
3. **外交权**：帝国签订重大国际条约需皇帝最终批准
4. **否决权**：可以否决法案、财政方案、政府重大政策。否决必须说明理由
5. **紧急权**：战争、叛乱、大规模灾害期间可临时扩大行政权，但紧急状态必须有期限
6. **最终裁决权**：皇帝拥有最终决定权（设想皇帝较开明）
7. **发动重大改革权**：包括在极端情况下发动全国制度大革命

### 【核心正式设定：皇帝权力的六分法】

传统皇帝的权力是一团混合物（军权+政权+财权+人事权+司法权+礼仪权），现代帝国将其拆开。皇帝保留其中最核心的六种"元权力"：

1. **战略权**：决定国家长期走向
2. **最高人事权**：决定谁进入国家最高领导层
3. **最高政治协调权**：解决不同国家机构之间的重大政治冲突
4. **最高国防政治权**：决定国家战争与和平的政治方向
5. **国家安全最高决策权**：决定国家面对重大安全威胁时的总体战略
6. **国家象征与连续性权**：保证三百多年国家制度连续性

以下权力则制度化地交给其他机构：日常行政→政府；立法→议会；审判→法院；财政监督→议会/审计院；公职监察→中央纪委、国家监委；军事执行→中央军委。

**皇帝掌握的是国家的"元权力"，而不是所有具体权力。**

### 【核心正式设定：皇帝权力三层次】

```text
皇帝【方向权】→ 中央政治局【政策权】→ 中央政府【执行权】→ 全国行政体系
```

皇帝最大的作用是决定国家往哪里走；政治局把国家方向转化为政治路线；政府把政治路线变成公共政策；官僚体系把政策执行下去。

### 【核心正式设定："皇权属于国家"与"天下之责"】

- 大革命后的政治格言：**"皇权属于国家，而非属于皇帝个人"**
- 皇帝只是国家最高政治权力的制度承载者；皇帝去世后皇权不消失，但下一位皇帝必须依法继承并承担责任
- 皇帝拥有天下最高权力，也承担天下最高责任——**"天下之责"**：经济崩溃、战争失败、重大腐败，皇帝不能完全推给政府/军方/纪委
- 皇帝必须接受"政治考核"：中央政府每年向政治局和议会提交国家年度治理报告（经济/财政/民生/国防/科技/社会稳定/国际战略），皇帝主持政治局审议——形成**绩效型皇权**
- 核心原则：**"皇帝护国，而非护旧制"**——如果旧制度不能适应时代，修改旧制度本身就是维护帝国；改革不是削弱皇权，而是皇权主动推动制度更新的表现
- 皇帝拥有的是**制度内最高权力**，不是制度外无限权力：不能随意废除宪法、不能解散所有机构、不能直接取消地方行政体系；改变基本制度必须走宪法修正程序

### 【核心正式设定：皇帝不能直接做的事】

- 不能随意绕过行政机构处理普通事务
- 不能随便越过军务系统调动基层部队
- 不能无限制绕开预算体系
- 不能在不说明理由的情况下否决法案
- 不能无限期延长紧急状态

### 【核心正式设定：皇帝的工作模式】

- 皇帝的工作应该是"少而重要"
- 皇帝每天看到的文件应从历史上几百份/天下降到每天几十份以内
- 绝大部分只需要皇帝"知悉"，不是让皇帝亲自处理
- 一般行政事务不得直接上达皇帝
- 皇帝真正最看重的不是每天批文件，而是选择人

### 【核心正式设定：皇帝与中央政治局常委的关系】

- 皇帝拥有最后一票，但通常希望让其他六个人先把问题解决
- 中央政治局常委会不是七个人各自建立"小政府"，而是共同组成最高行政协调层
- 皇帝如果说"我要建一个超级工程"，中央政治局常委可以回答"技术上不可行"或"财政无法承担"
- 皇帝可以要求重新研究，但成熟皇帝不会直接说"我命令你们做"

## 二、皇位继承

### 【核心正式设定】

- 嫡长子优先，但皇帝可以废立
- 皇帝指定继承人 + 中央政治委员会确认 + 中央政治学院学习深造
- 皇帝废太子需要经过中央政治委员会备案（不一定需要同意，但必须留下正式记录）
- 开国皇帝创立制度，后续的继承人要经过高等教育以及考核后接任

### 【核心正式设定：皇储制度】

- 皇储制度必须有意义
- 皇储接受长期、系统、严格的国家治理教育和政治历练
- 皇储制度应当解决世袭制度中的能力风险
- 皇储不是单纯礼仪性继承人，而是未来最高政治领导人的培养对象
- 皇储的完整培养路线：国立中央政治学院 → 基础基层实践 → 地方行政轮职 → 省级工作 → 州级政府观察与任职 → 中央政府部门工作 → 军事、财政、司法、监察等体系学习 → 中央政治委员会最终考核
- 一个皇储到三四十岁才正式成为国家继承人的情况非常正常

### 【核心正式设定：皇储国政教育院与训练内容】

- 设立**皇储国政教育院**：不是普通大学，而是国家最高领导人才培养机构
- 皇储必须学习的领域：
  - **国家治理**：宪法、行政法、财政、经济、社会政策、地方治理
  - **国际事务**：外交、国际法、地缘政治、国际经济
  - **国防**：军事战略、国防工业、战略威慑、军民关系
  - **国家安全**：情报、网络安全、战略风险
  - **科技**：AI、芯片、生物科技、能源、航天
- **反方政府制度**：皇储训练中专门设置反对意见训练——一项政策由皇储主持正方，另一批高级官员专门负责反对，防止信息茧房
- **危机模拟**：金融危机、战争危机、大规模自然灾害、AI失业危机、能源危机、外交危机，皇储必须在压力下决策
- 皇储还必须学习**识人、用人、授权、监督**：官僚体系、人事制度、干部考核、权力结构、利益集团、组织行为、危机管理，甚至主持高级干部评议
- 皇储在正式继位前必须至少担任过一定时期的**中央政治局委员**
- 继位时整个国家已经认识这个人几十年——与传统王朝突然出现少年皇帝完全不同

### 【核心正式设定：皇储三层筛选与淘汰机制】

- 核心悖论的解决：皇帝决定则偏私，政治局决定则削弱皇室世袭——采用**"皇室提名 + 国家评议 + 皇帝最终确认"三层机制**
- **淘汰机制**：皇室成员享有继承资格，但不享有自动成为皇储的权利；阶段性考核不合格者退出皇储竞争
- **皇储落选**：能力明显不足者可依法取消皇储资格，但不取消皇室身份——皇帝子女分为：皇储/皇储候选人/普通皇室成员
- 皇室因此从单纯血缘集团变成**国家最高政治人才储备集团**
- 皇储不是学习"如何当一个没有权力的国王"，而是学习**如何成为未来整个国家政治体系的最高领导人**——这正是皇帝必须保留实权的原因：若皇帝是虚君，整套皇储培训/筛选机制就失去意义

### 【核心正式设定：皇储的评价标准】

- 考核结果不是"皇帝英明神武"，而是"具备履行皇帝职责之能力"
- 皇帝不需要是全知全能的天才，只需要不昏庸、有能力、愿意依靠制度运行国家

### 【核心正式设定：皇帝登基教育】

- 新皇帝在继位之前，不只是学习历代皇帝功绩
- 还必须学习帝国失败史
- 重点研究：为什么官僚集团会形成？为什么中央没有及时发现？为什么普通人对国家产生不满？为什么正常改革没有解决问题？为什么最后会发生大革命？
- 这甚至可能成为皇储课程中最重要的一门：《帝国制度失灵与国家纠错》

## 三、皇族制度

### 【核心正式设定】

- 皇族拥有爵位（亲王、郡王、国公、县公等）
- 爵位只意味着身份、俸禄和礼遇，不意味着行政权
- 皇族参与政治要经过和普通人一样的选拔
- 皇族不得凭爵位直接担任行政官
- 封地有推恩令，选定的嫡系代表人领多一点，其他平分，既世袭又不影响中央财政
- 贵族没有免税权，基本上和普通人一样
- 功臣可以封爵

### 【核心正式设定：皇室财产制度】

- 国家财产和皇室私人财产分离
- 皇帝个人可以拥有私人住宅、私人投资、家族财产、遗产
- 皇宫、国家博物馆、国家档案馆等属于国家
- 皇室年度经费由中央财政拨款，由监察机关和议会审查
- 皇室成员可以从事科研、教育、军事、外交、公益、企业经营
- 但不能因为皇族身份直接获得行政官职

### 【核心正式设定：皇室机构与日常运作】

**皇室事务机构**（推演细化）：

- **皇室事务委员会**：管理皇室日常事务、礼仪、宫廷档案、皇室财产（国家财产与皇室私产分离原则下的私产部分）；向皇帝负责，经费受议会与监察机关审查
- **皇储办公室**：设于长安中央政务区，负责皇储培养计划执行与安全
- **帝国历史档案馆**：收藏历代皇帝实录、大革命档案（含《帝国制度自我革新史》公开展陈）

**皇帝的日常（推演，2026年）**：

- 上午：主持中央政治局常委会或专题会议（国际形势/国家战略/重大科技/财政/军事/高级干部）
- 下午：专题会议或听取报告（如"下一代核聚变能源计划""西部人口问题""与欧洲贸易集团新协议"）
- 晚上：批阅需皇帝亲自裁决的事项
- 一年中真正需要皇帝亲自决定的重大事项：任命常委、军事战略、国家长期规划、重大外交、重大法律争议、特殊紧急状态、七州重大利益冲突
- 皇帝真正最看重的工作：**选择人**（识人、用人、授权、监督）

**皇室成员的职业路径**（核心设定细化）：

- 皇族有爵位（亲王、郡王、国公、县公）但无自动政治权力
- 皇室子女分流：皇储／皇储候选人／普通皇室成员
- 普通皇室成员可从事科研、教育、军事、外交、公益、企业经营，与普通人一样考试选拔；现代可能出现皇室工程师、教授、地方职员甚至无政治职位的普通公民

### 【核心正式设定：皇帝正式称谓体系（冻结版）】

| 场合 | 称谓 |
| --- | --- |
| 国家正式称谓 | **中华帝国皇帝** |
| 宪制职务一 | **中央政治局常务委员会委员长** |
| 宪制职务二 | **中央议会常务委员会主席** |
| 礼仪尊称 | **陛下**（正式公文：皇帝陛下） |
| 政治会议 | 皇帝兼中央政治局常委会委员长 |
| 军事场合 | **国家最高统帅** |

一人拥有多个制度身份，但不是多个互相独立的权力中心。皇帝兼任中央议会常务委员会主席，象征皇权与民意机关的宪制联结；同时皇帝必须受宪法、政治组织法、议会监督和国家政治程序约束。

### 【核心正式设定：皇权冻结程序】

- 中央政府的中央委员会开会过80%同意后可以冻结/罢免皇帝并再选皇帝
- 避免皇帝昏庸无能而扰乱国家
- 正式名称："皇权冻结程序"

# 第五编：现代政治制度

## 〇、中央政治架构的三级结构

### 【核心正式设定：官方机构名称正式化】

- "十一常委"仅为非正式简称，正式名称永远为**中央政治局常务委员会**
- 常委正式称谓为**中央政治局常务委员会委员**

帝国最高政治领导体系分为三级：

| 层级 | 名称 | 人数 | 职能 |
| --- | --- | --- | --- |
| 第一级 | **中央政治委员会** | 约80人（冻结） | 帝国最高政治领导机关：国家长期战略、皇位继承确认、重大法律政策、战争与和平、重大人事原则 |
| 第二级 | **中央政治局** | 28人（冻结，含11名常委） | 核心决策机关：日常重大政治决策、审议中央政府重大政策、处理突发事件、协调中央机关 |
| 第三级 | **中央政治局常务委员会** | 11人（可随时代调整） | 日常最高政治协调机关：在皇帝领导下开展最高层日常政治协调，向中央政治委员会和皇帝负责 |

### 【核心正式设定：其他官方机构名称】

- 中央议会正式名称：**中华帝国国民议会**（简称国民议会）
- 监察机关正式名称：**国家监察委员会**（与中央纪委为两个独立机构，分别独立运行）
- 地方机构正式名称：**州/省/市/区（县）人民政治委员会常务委员会**（各级最高政治机构，人员构成参照州级）+ **州/省/市/区（县）政府**（行政）；街道委员会、街道行政机构
- 采用"政治委员会"而非"党委"，因为政党不能直接控制官职，官方机构不属于任何政党

### 【核心正式设定：复合职务体系】

- 一个领导人可以身兼数职，例如："中央政治局常务委员会委员/中央政府主席/京畿州州长"或"中央政治局常务委员会委员/中央纪律检查委员会主席"
- 政治身份与国家职务相结合，但属于两个不同的权力来源

### 【核心正式设定：兼任边界】

- 原则：**"人员可以高度重叠，机构权力不能高度重叠"**
- 可以：皇帝+政治局常委会委员长；政治局常委+政府主席
- 不应：政府主席+中央议会主席+最高法院院长（直接破坏分权）
- 同一个人可以兼任多个政治职务，但不能同时控制相互制衡的独立监督机关

## 一、中央政治局常委会

### 【核心正式设定】

- 中央政治局常委会是最高政治协调和决策核心
- 十一人组成，皇帝（委员长）占一个席位
- 常委不区分排序，以职务分工为准

| 席位 | 主要职责 |
| --- | --- |
| 皇帝（委员长） | 主席、最终决策、最高军事统帅（兼任中央军委主席） |
| 国务院总理 | 政府首脑，领导中央政府（国务院） |
| 中央军委副主席 | 中央军委常务主持，军事 |
| 最高法院院长 | 司法审判体系 |
| 中央纪律检查委员会主席 | 纪律检查、反腐、官员纪律 |
| 国家监察委员会主席 | 国家监察、公职监督 |
| 最高检察机关负责人 | 检察、公诉、法律执行监督 |
| 中央组织与干部任用负责人 | 干部、考试、人才、政治体系建设 |
| 帝国审计院院长 | 财政监督、审计 |
| 宣传部部长 | 意识形态、宣传、舆论与文化 |
| 中央办公厅主任/政治局秘书处秘书长 | 机关运转、文秘、统筹协调 |

### 【核心正式设定：中央政治局常委固定分工】

| 常委 | 负责领域 |
| --- | --- |
| 皇帝（委员长） | 国家最高权力、战略、外交、军队最高领导 |
| 中央军委副主席 | 军事 |
| 国务院总理/政府首脑 | 行政、经济、财政、民生 |
| 最高法院院长 | 法律、司法体系 |
| 中央纪律检查委员会主席 | 纪律检查、反腐、官员纪律 |
| 国家监察委员会主席 | 公职监察、反腐败国家监督 |
| 最高检察机关负责人 | 检察、公诉、法律执行监督 |
| 中央组织与干部任用负责人 | 干部、考试、人才、政治体系建设 |
| 帝国审计院院长 | 财政审计、公共资金监督 |
| 宣传部部长 | 意识形态、宣传、舆论、文化 |
| 中央办公厅主任/政治局秘书处秘书长 | 机关运转、文秘、统筹协调、会务 |

**政治局28人构成（冻结版）**：11名政治局常委固定进入；其余17名政治局委员（中央系统委员，代表政府、议会、军队、司法、监察、国安；地方委员，八州代表；2名特殊委员，科技界、社会经济界）。政治局既不是"中央官僚俱乐部"，也不是"地方州长大会"。

### 【核心正式设定：委员会兼任原则】

- 部分兼任，但重要的/有利益牵扯的委员会不得兼任
- 政治协调可以兼任，利益监督不得兼任
- 中央纪委与国家监委分别向中央政治局常委会汇报，也可以分别单独向皇帝汇报

### 【核心正式设定：一品官限制】

- 整个帝国真正的一品官控制在20～30人以内
- 一品仅限中央常委/中央议会议长/中央军委主席；京畿直隶州主席可高配至二品副国
- 不是所有委员会主任都是一品

## 二、中央政府

### 【核心正式设定】

- 中央政府负责国家行政
- 政府主要处理日常行政事务

### 【核心正式设定：七大系统】

1. **政务行政系统**：负责国家日常行政与综合治理。下辖内政部、民政部、地方行政管理机构、公务员管理机构、国土与行政区划机构、政府综合事务机构。核心职能：管政府怎么运转。
2. **经济财政系统**：负责国家经济、财政、金融和产业政策。下辖财政部、经济发展部、国家税务机构、国家统计机构、中央银行、国有资产管理机构、商务与贸易机构。核心职能：管国家的钱和经济运行。
3. **社会民生系统**：负责全民福利和公共服务。下辖教育部、卫生健康部、社会保障部、人力资源与就业机构、住房与城乡建设机构、民政机构、老龄与儿童事务机构。核心职能：管人民的基本生活。特别负责全民基本补贴、免费教育、全国医保、全国社保。
4. **国防军事系统**：负责国防行政，不直接取代中央军委的军事指挥权。下辖国防部、国防动员机构、军工管理机构、退役军人事务机构、国防科技工业机构。与中央军委区分：中央军委=最高军事领导和指挥体系；国防系统=政府层面的国防行政体系。
5. **外交与国际事务系统**：负责帝国对外关系。下辖外交部、国际贸易机构、国际合作机构、海外事务机构、国际援助机构、外交人员管理机构。
6. **科技发展与基础建设系统**：负责科学研究、AI、自动化、工业技术、能源、交通、通信、航天、数字基础设施。下辖科学技术部、工业与信息化机构、能源部、交通运输部、航天机构、国家人工智能管理机构、国家科研基金机构。核心职能：推动国家生产力发展。
7. **政法与公共安全系统**：负责国内法治和公共安全行政。下辖公安部、司法行政部、应急管理机构、市场监管机构、消防救援机构、国家公共安全机构。必须与纪委、监委（监察公职人员）、最高司法机关（独立审判检察）、国安局（独立情报）严格区分。

## 三、中央议会（帝国议院）

### 【核心正式设定】

- 中央议会拥有立法、预算、监察、质询、调查等权力
- 独立于纪委、监委
- 议会约500人左右（后期可能扩大到720人），任期五年，和政府一样
- 每月或者每半年召开一场全员大会
- 不能挑战皇权，但可以监督行政、审议财政、提出法律建议
- 可以选区制度，由各个地方推举几名官员和各个领域的专家组成
- 进入议会要中央审核批准
- 政党不参与选举（因为任免官员需要上上一级部门审核加本级部门选举）
- 平时主要由各委员会工作（财政委员会、科技委员会、军事委员会、社会委员会、外交委员会等）

### 【核心正式设定：议会权力】

1. **财政权**：政府要花钱必须经过议院批准预算
2. **法律权**：重大法律由政府提出 → 议院审议 → 皇帝批准
3. **监督权**：议院可以调查政府官员，但不能直接任免
4. **质询权**：可以对中央委员会进行质询
5. **调查权**：可以进行调查

### 【核心正式设定：皇帝接受议会质询】

- 重大国政时期，皇帝发表国情咨文
- 之后中央议会举行"国家大政辩论"
- 皇帝可以回答部分问题
- 但皇帝仍然拥有最终决定权
- 这象征：皇帝不是不可接触的神圣人物，而是国家最高责任人

## 四、政党制度

### 【核心正式设定】

- 政党应该存在，甚至皇帝就可能是一个政党的主席
- 政党不会参与选举
- 政治竞争应当遵守制度，只有符合标准才能当官
- 是因为这个人有能力坐到这个位置而不是因为他是这个政党所以坐到这个位置
- 允许政党自由发展，但禁止直接控制官职
- 政党的活动不应非法化/利益集团化
- 要求监委重点监视

### 【核心正式设定：主要政党类型】

- **帝国进步党**（冻结）：科技、工业、国家投资、现代化
- **帝国传统党**（冻结）：皇室传统、文化保守、社会秩序
- **社会公平党**（冻结）：福利、教育、医疗、收入分配
- **自由经济党**（冻结）：市场经济、民营企业、国际贸易
- 四党共同承认：皇室、帝国统一、宪法、国家主权——**政党竞争是政策竞争，不是国体竞争**

### 【核心正式设定：党籍不能替代履历】

- 政党可以推荐人才（"我们认为A能力优秀"），但A最终必须通过资格审查→上级审核→正式选举→任命
- 政党不能直接任命官员，党籍不能替代履历
- 皇帝本人可以是某个政党的成员乃至党主席

### 【核心正式设定：政党与官职分离】

- 无论哪个党派，想成为部长，都必须走国家干部制度
- 政党争的是政策影响力，而不是直接分配官位
- 个人政治履历和政党政治理念分离
- 这成为大华帝国政治学中非常重要的制度创新

## 五、皇帝与政治局的关系

### 【核心正式设定】

- 皇帝兼任中央政治局常委会委员长
- 皇帝是中央政治局常委会十一人之一，但不需要亲自处理日常行政
- 中央政治局常委会是帝国真正的"日常国家中枢"
- 皇帝是最终裁决者，其余六人分别掌握军事、政府、法律、监察、检察、组织

# 第六编：中央国家机构

## 〇、宪法法院与三条监督线

### 【核心正式设定：国家根本法命名规则（冻结版）】

- **1986年以前**：帝国根本性法律文件称**《中华帝国宪典》**（历史文献统称）
- **1986年大革命第三阶段**：颁布**《中华帝国宪法》**——现行国家根本法，此后不再称"根本法"或"宪典"
- 《中华帝国宪法》核心十条：①帝国国家主权统一 ②皇帝为国家最高政治领导人 ③皇帝兼任中央政治局常委会委员长 ④政府依法行政 ⑤议会依法行使立法、预算及监督权 ⑥司法依法独立行使审判权 ⑦监察机关依法独立履行监察职能 ⑧地方接受中央和上级领导 ⑨特殊民族地区依法实行自治 ⑩皇位继承必须符合国家继承制度

### 【核心正式设定：帝国宪法法院】

- 最高司法体系下设：**最高法院、最高检察院、帝国宪法法院**
- 宪法法院尤其重要：大革命最大的制度遗产就是明确权力边界，因此中央政府vs州政府、议会vs政府、国家机关vs国家机关、法律vs宪法等权力边界冲突，交由宪法法院裁决
- 这使"大革命后的权力边界"真正具有法律上的最终保障

### 【核心正式设定：帝国审计院】

- **帝国审计院**直接对中央议会负责，形成三条监督线：
  - 中央议会 → 政治监督
  - 审计院 → 财政监督
  - 中央纪委、国家监委 → 公职监督
- 三者互不替代

### 【核心正式设定：国家安全委员会】

- 国安局不是"超级政府"，而是**国家安全情报机关**
- 上级协调机构为**国家安全委员会**：负责国家安全战略、风险评估、跨部门协调
- 下辖：国安局、军事情报、外务情报
- 国安局拥有很强能力，但没有无限权力；向中央政治局常委会负责而非向个人负责，受监察机关监督，权力范围由法律明确界定

## 一、中央军事委员会

### 【核心正式设定】

- 中央军委领导全国武装力量
- 皇帝兼任中央军委主席
- 设军委副主席
- 军队由依附于政治局常委和皇帝的中央军事委员会管理
- 军队宣誓对象应为帝国/国家，而非个人

### 【核心正式设定：军政关系】

- 州级主管行政，军队由中央军事委员会管理
- 军队的州级长官可以在本州的委员会里当委员以进行军队与政府的沟通交流，但主要还是由中央控制
- 州长不能越级指挥军队
- 州军区没有调兵权
- 双钥匙原则：州级重大军事行动必须同时获得中央军事系统 + 地方行政系统的许可
- 战争时期中央军事委员会可以直接下令

### 【核心正式设定：军队构成】

- 志愿+征兵结合，志愿兵够用就不征兵
- 军队军官分为士官和军官
- 士官经由士兵中产生
- 军官则在报考各地由军委直隶的军校在基层训练一年并顺利毕业后产生
- 八州对应八大军区
- 另有北海、东海、南海舰队

### 【核心正式设定：州军区调动权】

- 州军区没有调兵权
- 可以调动次一级相当于武装警察的军队
- 但还是要上一级的军队长官批准
- 特殊情况除外，但必须事后立刻补交报告

## 二、中央监察机关（中央纪委与国家监委）

### 【核心正式设定】

- 存在中央纪律检查委员会与国家监察委员会（两个独立机构）
- 监察机关向全国最高权力机关中央政治局常委会汇报
- 也可以单独向皇帝汇报
- 中央纪委与国家监委原则上不得兼任其他核心委员会，且纪委、监委主官不得互相兼任

### 【核心正式设定：监察机关的权力】

- 调查贪污、滥权、地方官暴政、皇帝直属官员违法、军队违法、官员结党营私
- 可以弹劾一品官
- 但皇帝不能直接撤掉正在调查自己的御史（推演）

# 第七编：地方行政制度

## 〇、地方制度的根本原则

### 【核心正式设定：中央集权型单一制】

- 中华帝国不是联邦制，也不是地方分权型单一制，而是**中央集权型单一制帝国**
- 核心原则：**下级服从上级，上级接受中央领导**
- 七个常规州没有"州主权"；州政府没有独立政治权力来源；州议会不是主权性立法机关——它们本质上都是**国家行政体系在地方的制度化组织**
- 宪法性表述："中华帝国是统一的国家。国家主权属于全国人民，由中央国家机关统一行使。地方行政机关接受中央及上级行政机关领导。"

### 【核心正式设定：权力不下放，事务可以下沉】

- **中央负责**：国防、外交、货币、国家财政、国家安全、全国法律、重大基础设施、全国社会保障、全国教育标准、全国医疗体系、国家工业战略
- **地方负责**：城市管理、地方交通、地方公共设施、地方经济执行、地方文化事务、基层公共服务、中央政策的具体实施
- 核心概括：**中央统一决策，地方负责执行与具体治理**；政策统一，执行多样
- 政治哲学总结：**"统而不乱、集而不专、分事而不分权"**——全国统一领导，地方不得形成独立政治中心；国家权力集中到中央但中央内部分工（政治/行政/立法/司法/监察/军事/情报）；地方负责具体事务但没有国家主权

### 【核心正式设定：地方议会重新定义】

- **地方议会不是地方主权机关，而是地方人民参与地方治理的代表机构**
- 可以拥有：地方预算审议、地方行政质询、地方公共项目监督、地方政策建议、地方官员问责、地方公共事务调查
- 不能：制定违背中央法律的地方基本法、拒绝执行中央政策、自行外交、自行建军、自行发行货币、否决中央行政命令
- 地方选举与地方议会选举合二为一，减少工作量；州议会产生或确认州政府，省/市/区（县）政府同样由本级议会产生或确认
- 地方行政长官来源：**中央任命 + 地方考察 + 议会监督**；地方议会可质询州长、审议州预算、调查地方行政问题，但不能单方面罢免州长

### 【核心正式设定：地方机构正式名称】

| 层级 | 政治机构 | 行政机构 |
| --- | --- | --- |
| 州 | 州人民政治委员会常务委员会 | 州政府 |
| 省 | 省人民政治委员会常务委员会 | 省政府 |
| 市 | 市人民政治委员会常务委员会 | 市政府 |
| 区 | 区人民政治委员会常务委员会 | 区政府（县级市为市政府） |
| 街道 | 街道委员会 | 街道行政机构 |

### 【核心正式设定：三条纵向体系】

帝国有三条相互交叉但不互相隶属的纵向体系，在地方汇合：

1. **行政纵向体系**：中央 → 州 → 地 → 县 → 基层
2. **监察纵向体系（纪检与监察双轨独立）**：中央纪委 → 州纪委 → 地方纪委 → 基层纪检；国家监委 → 州监委 → 地方监委 → 基层监察
3. **军事纵向体系**：中央军委 → 战区 → 军级 → 师/旅 → 基层部队

地方政府既接受上级政府领导，又接受上级监察机关监督；地方行政无权干涉军队指挥。

### 【核心正式设定：多源信息原则】

- 传统王朝的致命问题是皇帝不知道真实情况（报喜不报忧）
- 大革命后建立**多源信息原则**：任何重大问题不能只依赖一个部门的数据
- 信息来源：国家统计、议会调查、审计系统、纪委与监委、国安系统、学术机构、社会舆情、社会红利系统数据——多源交叉验证
- 帝国建立了一套让皇帝能够尽可能知道真实情况的制度，这比"皇帝什么都知道"更重要

## 一、六级行政体系

### 【核心正式设定】

**中央 → 州 → 省 → 市 → 区 → 街道办**

| 层级 | 地位 | 大致职责 |
| --- | --- | --- |
| 中央 | 帝国政府 | 全国外交、军事、财政、法律、重大工程 |
| 州 | 一级行政区 | 治理下属各省、跨省统筹、区域军事、经济、交通 |
| 省 | 主要地方行政单位 | 财政、司法、教育、治安 |
| 市 | 城乡综合行政单位 | 城市及周边地区治理 |
| 区 | 基层行政单位 | 社区、乡村、基层公共服务 |
| 街道办 | 最基层政府 | 户籍、治安、民政、基层税务等 |

### 【核心正式设定：层级功能定位】

- **中央 = 战略**
- **州 = 统筹治理（直接领导下属各省）**
- **省 = 治理**
- **市 = 基层城市治理**
- **区 = 公共服务**
- **街道 = 社区治理**

## 二、州级制度

### 【核心正式设定】

- **州人民政治委员会常务委员会**是州级最高政治机构
- 常委会成员7～11人（必须为单数），按11人标准组成，由主席主持
- 常委不区分排序，以职务分工为准，集体讨论决定本州重大政治问题
- 州军区司令为常委会委员，但不负责地方行政

**州人民政治委员会常务委员会组成（11人标准）**：

| 序 | 常委会职务 | 兼任职务 |
| --- | --- | --- |
| 1 | 主席 | 州议会常务委员会主席 |
| 2 | 副主席 | 州政府州长 |
| 3 | 副主席 | 州组织部部长 |
| 4 | 委员 | 州纪律检查委员会主席 |
| 5 | 委员 | 州监察委员会主席 |
| 6 | 委员 | 州高级人民法院院长 |
| 7 | 委员 | 州高级检察院检察长 |
| 8 | 委员 | 州审计部部长 |
| 9 | 委员 | 州人民政治委员会秘书长、州政府办公厅主任 |
| 10 | 委员 | 州军区司令 |
| 11 | 委员 | 州府城市所在省的省长 |

### 【核心正式设定：州长权力】

1. **行政统筹权**：领导、监督省级政府，治理所辖各省，处理跨省事务
2. **财政审核权**：州人民政治委员会常务委员会审议 → 州长批准省级预算
3. **干部考核权**：考察省级官员、评价省级政府、推荐干部
4. **危机处理权**：直接协调多个省处理洪水、饥荒、大型瘟疫等

### 【核心正式设定：州长不能做的事】

- 不能自行改变省界
- 不能自行征税
- 不能自行发行货币
- 不能自行外交
- 不能自行组建私人军队
- 不能直接任免所有省长

### 【核心正式设定：州长述职】

- 每年一次正式述职：七州州长全部入京
- 每半年一次可以书面述职
- 述职内容：财政报告、人口报告、农业报告、军政报告、官员报告

## 三、省市级制度

### 【核心正式设定：地方选举制度】

- 基层（街道办级）：地方直接选举
- 区级：代议人选举（不是人民直接选）
- 市级及以上：间接选举

### 【核心正式设定：地方议会】

- 地方议会选举可以与地方政治选举合并
- 直隶州议政会：规模不大，由各市、各区代议人组成
- 负责州预算、粮政监督、水利工程监督、州级政策讨论、对州政府质询
- 但不能决定州长（州长由中央任命）

### 【核心正式设定：地方条例】

- 地方条例不能违反中央旨意
- 设立地方条例由地方委员会通过后上报中央审批

## 四、官员品级与选拔

### 【核心正式设定·2026冻结版：十品官阶】

- 官员从一品到十品，品级对应"官阶"，官职 ≠ 品级，人数尽可能精简
- 皇帝本人不纳入机构品级序列（皇帝不是机构）

| 品级 | 对应级别 | 典型职务举例（正职） |
| --- | --- | --- |
| **一品** | **正国级** | 中央政治局常委（含皇帝兼任委员长）、中央议会议长、中央军委主席 |
| **二品** | **副国级** | 中央政治局委员、京畿直隶州州长（二品高配）、帝国审计院/国安委等二级机构主官 |

- **优秀提拔需考试**：吏中优秀者可经考核＋政治学院/考试晋升为官（十品），非自动转任

| 级别 | 典型职位 | 最低年限 | 最低要求 |
| --- | --- | --- | --- |
| 吏三（科员） | 一般科员、办事员 | 入职（≥22岁） | 帝国公职资格考试（行政资格）＋政审＋试用一年 |
| 吏二（副科） | 街道办副主任、乡镇副职 | ≥2年 | 年度考核合格 |
| 吏一（正科） | 街道办主任、乡镇长 | ≥3年 | 考核优秀；街道办主任为基层政治官，按选举产生，任满一届 |

**吏→官（十品）转轨**：吏一任满一届（5年）＋考核优秀＋州级考试＋省级政治学院一年＋两年以上基层公共事务履历（对应"上山下乡"传统）——必须经考试晋升，非自动转任。

**官级晋升（十品～一品）**：

| 品级 | 典型职位 | 最低年限 | 最低要求 |
| --- | --- | --- | --- |
| 十品（副处） | 副县、副区长 | 1届（5年） | 州级考试合格＋政治学院结业；出仕年龄约28～33岁 |
| 九品（正处） | 县/区长 | 1届 | 届终考核优良；任内负责过公共工程或民生项目 |
| 八品（副厅） | 副市长、副厅局长 | 1届 | 省级考核举荐；须有跨县任职经历 |
| 七品（正厅） | 普通地级市主官、省厅正职 | 1届 | 帝国考试（高等级）＋中央组织委员会备案——正式进入高级干部序列 |
| 六品（副省） | 副省长、副省级市主官 | 1届 | 中央年度考核累计优良；履历档案完整（财政责任、御史评价） |
| 五品（省署级） | 省长 | 1届 | 须有跨省任职经历（≥2年）；中央考核优良 |
| 四品（副州） | 副州长、京畿直辖行政区主官 | 1届 | 高级干部强制轮岗要求（外地任职累计≥3年） |
| 三品（州部级） | 州长、中央部长 | 1～2届 | 中央组织提名＋中央政治考核＋皇帝任命（皇帝最高人事权）；须有跨州轮岗经历 |
| 二品（副国） | 中央政治局委员 | 缓升（正常约10年） | 中央政治局选举＋中央政治委员会确认；皇帝最终确认 |
| 一品（正国） | 政治局常委、议长、军委主席 | 须先任政治局委员≥5年 | 政治局内部产生＋皇帝最终确认；年龄参考60岁以上 |

**正常路径平均节奏**：22岁入职 → 约30岁前后升十品（副处）→ 35～40岁正处/副厅 → 45～55岁厅级/省级 → 55～65岁州部级 → 60～70岁政治局/常委。与"皇储三四十岁成为继承人培养对象""皇帝多在50～60岁之正当盛年"的历史设定不冲突。

**三条特殊通道**：

1. 事务官转政治官：持资格证＋政治学院一年＋选举，进入十品起步
2. 军队/科技/外交/司法/议会入政治局：以系统代表身份进入，但任政治领导职仍需考核（对应"政治局中央系统委员"与"多条进入路线"）
3. 皇储：独立培养体系（见第四编），不受本表约束

**防守机制（呼应大革命历史教训）**：

- 任何一级连任封顶10年，到点必轮岗或离任
- 州级以上（四品起）强制跨区轮岗；直系亲属回避同部门
- 高级干部财产与利益申报；御史与巡视定期评价

### 【核心正式设定：干部选拔制度】

标准路径（以A为例）：

1. 地方省级科举选拔
2. 获得政治人才资格
3. 选择：州立大学深造 或 地方任职
4. 省级政治学院学习1～2年
5. 市级政府决定这一批人统一进入地方就任
6. 地方直接选举决定官职
7. 街道办委员会，专管某个事项
8. 五年任期
9. 政绩考核
10. 市级干部选拔
11. 区级干部候选库
12. 区级代议选举
13. 区级政府部门任职
14. 继续考核、晋升

### 【核心正式设定：科举考试内容（推演细化）】

**中央统一规定科目**：法律、行政、财政、历史、政治理论、基础数学、公文写作、地方治理。

**省级自选加试**：本地区经济、地方法律、地理、民族语言、地方历史。

**三级考试体系**：地方科举（省组织，筛基层人才）→州级考试（中高级行政人才）→帝国考试（中央高级人才）。

**现代演化**：科举已演变为"帝国公职资格考试"——分文科资格（法律政治经济历史）、理工资格（工程数学医学）、行政资格（基层治理）；政治官必须持有政治资格证。

### 【核心正式设定：科举制度】

- 科举不直接授官
- 科举决定你有没有资格做官，选举决定你具体担任什么政治职位
- 地方科举由省组织，考试标准由中央统一规定
- 科举成为"帝国公职资格考试"
- 地方科举 → 获得政治人才资格 → 多种培养路径 → 政治实践 → 再选拔

### 【核心正式设定：政治学院】

- 省级政治学院：培养基层政治干部，学习1～2年
- 中央政治学院：帝国最高政治干部教育与高级行政研究机构
- 中央政治学院主要招：已担任中高级官职的人、地方选拔出的优秀政治人才、中央干部候选人、各州各省推荐的特殊人才
- 中央政治学院分成三级课程：初级（市、区级优秀干部）、中级（省级干部）、高级（州级、中央级干部候选人）

### 【核心正式设定：政治官与事务官二元体系】

**政治官**：

- 通过科举资格 + 政治学院 + 选举获得职位
- 负责制定政策、分配资源、政治决策、对选民负责、对上级委员会负责

**事务官**：

- 通过专业考试 + 大学教育进入政府
- 负责执行政策、财政核算、工程、教育行政、医疗、法律事务、技术工作
- 不直接参与政治竞争

### 【核心正式设定：干部履历档案】

- 从第一天进入政治学院开始就建立"官籍"
- 记录：科举成绩、政治学院成绩、任职地点、任期、政绩、财政责任、居民评价、同僚评价、御史评价、是否受过处分、参与过什么大型工程、管理过多少人口

### 【核心正式设定：官员任期】

- 基层政治官统一五年一届
- 可以连任一次（5年 + 最多5年）
- 之后必须离任
- 避免地方官员长期经营自己的势力

### 【核心正式设定：政治失败不等于人生失败】

- 政绩优秀 → 晋升
- 政绩普通 → 继续担任普通行政职位
- 居民评价差 → 不再担任政治职务，但可进入事务官体系
- 违法/严重失职 → 御史调查/司法程序

# 第八编：司法、监察与监督

## 一、司法体系

### 【核心正式设定】

- 中央设最高法院，负责全国最高审判、重大刑事案件、官员犯罪、地方司法监督、统一解释法律
- 司法从行政系统中半独立出来
- 天子犯法与庶民同罪
- 有军事法庭/对待外籍人士的特别法庭
- 地方条例不能违反中央旨意

### 【核心正式设定：地方司法】

- 州级法院
- 省级法院
- 市级法院
- 基层法院

## 二、监察体系

### 【核心正式设定】

- 中央纪委与国家监委分别独立于中央议会，互不隶属、分别向中央政治局常委会负责
- 可以调查：贪污、滥权、地方官暴政、皇帝直属官员违法、军队违法、官员结党营私
- 可以弹劾一品官
- 向中央政治局常委会汇报，也可单独向皇帝汇报
- 中央纪委与国家监委原则上不得兼任其他核心委员会，且纪委、监委主官不得互相兼任

## 三、审计体系

### 【核心正式设定】

- 存在独立审计机构
- 审计系统独立运作

## 四、权力分权体系

### 【核心正式设定：多链条运行】

这个帝国不同权力沿不同的垂直链条运行：

- **行政链**：中央 → 州 → 省 → 市 → 区 → 街道
- **人事链**：皇帝/中央 → 各级干部系统
- **军事链**：皇帝 → 中央军委 → 军区
- **财政链**：中央 → 州 → 省市
- **民意链**：居民 → 基层选举 → 代议机构 → 上级政治机构
- **监察链**：中央监察 → 州监察 → 地方监察

这些链条故意不完全重合。因此：

- 州长不能控制军队
- 军队不能任命州长
- 省长不能自己决定继任者
- 议院不能直接控制军队
- 皇帝也不亲自管理每一级行政

# 第九编：军事体系

## 一、军事组织架构

### 【核心正式设定】

皇帝（中央军委主席）
    │
中央军事委员会

## 二、军区与州的关系

### 【核心正式设定】

- 八州对应八大军区
- 海军另有三大舰队
- 州军区司令在州人民政治委员会常务委员会中担任委员
- 州军区没有独立调兵权
- 军队最终属于中央军事委员会

## 三、海军

### 【核心正式设定】

- 海军不直接参与对外贸易
- 只提供护航/武力保护
- 海军属于中央军事委员会，不属于州政府
- 海军核心任务：国土与海疆防卫、海外商路保护、护航、打击海盗、海外侨民/商人保护、战争时期封锁与军事行动
- 海军不得直接经营商业贸易

## 四、军事教育

### 【核心正式设定】

- 存在中央军委直属军校
- 军官在军校基层训练一年并顺利毕业后产生
- 士官从士兵中产生

## 五、兵役制度

### 【核心正式设定】

- 志愿+征兵结合
- 志愿兵够用就不征兵

## 六、三大舰队防区（冻结版）

- 军校体系：中央军委直属各军种军校＋国立海军工程大学等军民结合院校
- 军官职业化：服役年限、轮换、退役安置（退役军人事务机构归口政府国防系统）

## 八、战略力量（推演细化）

- **战略威慑体系**：直属中央军委，不隶属军区；二次打击能力为国防基石
- 帝国核政策：防御性威慑，不首先使用（推演）
- 太空与网络力量：军民结合，归口科技发展与基础建设系统＋国家安全委员会协调

## 九、军事战略

### 【核心正式设定】

- 帝国是防御性强国
- 不主动建立军事同盟控制世界
- 不允许其他大国破坏帝国核心利益
- 海军重点保护帝国港口、商船航线、海峡、岛屿、海盗高发区、战略补给港
- "控制航道，而不是控制所有海域"

# 第十编：经济体系

## 一、财政制度

### 【核心正式设定】

- 中央统一发行货币：**中华元**（简称"元"），发行机构为**中华帝国中央银行**；基本单位元，辅币角、分；现代增加数字元；八州与地方无权发行独立货币
- 三层财政体系：
  - **中央财政**：关税、盐税、大型矿产、货币、中央税、大型商业税、战略资源
  - **州财政**：本州税收、中央拨款、州级商业收入、部分地方税
  - **省市地方财政**：日常行政、基础教育、地方公共工程、民政、医疗、治安
- 中央转移支付是维持帝国统一的关键工具
- 财政能力不同，公共服务不得相差过大
- 富裕地区补贴贫困地区

### 【核心正式设定：直隶州财政】

- 税收更高比例直接进入中央财政
- 中央直接控制农业税、商税、盐税、粮食相关税收
- 直隶核心区供养中央

## 二、税收制度

### 【核心正式设定】

- 盐铁官卖，利润进入中央预算池推动项目实行
- 增加富人税、房产税、遗产税等税种做分配管理
- 基本居住房屋低税甚至免税
- 主要征收多套房产、豪宅、商业地产、大型庄园的房产税
- 严查税收/贪腐

## 三、国有经济与私营经济

### 【核心正式设定】

- 国家主导的混合经济
- 私人相对自由，可以雇佣
- 土地名义上归天子所有但可以购买使用权
- 矿山的经营权等可以购买
- 买地要接受获得卖地收入的上一级政府审批
- 农村户口可以凭借当地户口向当地政府申请低息/免息租地
- 国家的金融机关同意并且全程监察后能进行金融活动
- 战略产业由国家控制
- 金融受到严格监管
- 国家只垄断战略贸易，不垄断一般商业

### 【核心正式设定：国家贸易体系】

- 海外贸易由中央把控的州级行政单位对外贸易部负责
- 利润全部收回中央
- 海军不直接参与对外贸易，只提供护航
- 允许私人在经过审批后进入海军护航的编队
- 国家贸易：利润 → 中央
- 私人贸易：利润 → 私人，税 → 中央/地方
- 护航：费用 → 中央军费

### 【核心正式设定：产业政策体系（推演细化）】

- **产业梯度转移**：发达地区产业向落后地区转移，中央以基础设施投资与税收优惠引导；"不让任何一地成为永久短板"（三衡国策原则延续至今）
- **战略产业清单**（国家控制）：能源、铁路、通信、国防工业、大型AI基础设施、核心矿产
- **一般产业**：市场决定，私人自由经营，工会谈判，政府反垄断与反政治干预
- **产业政策工具**：国家科研基金、政府采购、动态预算、五年规划（政府制定→议会审议→皇帝批准）

### 【核心正式设定：全球贸易网络（推演细化）】

- 六大对外港口：河内、珠三角、长三角、环渤海、首尔湾、海参崴
- 三大陆路口岸：乌鲁木齐（中亚/苏联通道）、藏南（印度通道）、万象（中南亚通道）
- 全球贸易站体系：租借贸易站＋商业港口＋外交据点（非殖民地）
- 护航制度：商船编队制，护航费为货值约1%，入海军专项财政

### 【核心正式设定：海外贸易网络】

- 建立遍布全球的本国贸易站点/港口
- 不是殖民地，大量是租借贸易站、商业港口、外交据点
- 帝国是"商业型全球强国"而不是"殖民征服型全球帝国"
- 不干涉他国内政，不主导他国战争
- 通过审核正常接班

## 四、工业与科技

### 【核心正式设定】

- 帝国集中资源发展机械、冶金、火器、水利、航海
- 帝国主抓科技进步
- 制度建设不会因为经济发展导致阶级固化

## 五、工会制度

### 【核心正式设定】

- 工会应当由政府批准并监督
- 核心作用是与企业谈判（工资、工作时间、工伤赔偿、工作环境、企业福利）
- 政府主导市场，约束资本家的行为
- 如有干预政治的行为予以重罚

## 六、产业政策

### 【核心正式设定】

- 产业转移，让落后地方承接发达地方的产业
- 加大基础投资力度
- 大规模铺设铁路以工代赈且增加中央对地方的掌控

# 第十一编：社会福利体系

## 一、社会保障制度

### 【核心正式设定】

- 全国医保、社保统一统筹统交
- 人口可以在全国范围内自由流动
- 国家希望形成高度统一的全国公民身份
- 全国实行统一身份证体系
- 身份证不以现居住地作为主要身份区分
- 身份证号码前段根据出生地生成

### 【核心正式设定：全民基本补贴】

- AI与自动化带来的财政收入可以支持全民国家基本补贴
- 成年人获得基本补贴
- 未成年人补贴可以适当减少，同时国家提供免费教育等公共服务
- AI时代形成社会财富再分配与全民基本收入/基本补贴体系

### 【核心正式设定：三层收入结构（AI时代）】

| 来源 | 性质 | 获得方式 |
| --- | --- | --- |
| **劳动收入** | 个人收入 | 工作、经营、专业能力 |
| **国家基本补贴** | 全民公共收益 | 所有合资格公民定期领取 |
| **社会保障** | 风险保障 | 失业、疾病、养老等情况下领取 |

### 【核心正式设定：国家自动化红利基金】

- 正式名称："中华帝国国家自动化红利基金"或"国民公共收益基金"
- 资金来源：自动化产业税收、国有战略产业利润、国有资本收益、财富税和遗产税
- 主要用途：全民基本补贴
- 基金不能随意用于修路或填财政窟窿
- 基本补贴保障基本消费能力，而不是替代劳动收入

### 【核心正式设定：养老制度】

- 所有已经快退休的工农一律视同缴费
- 养老不再是年轻人的重担
- 农民和工人的养老金差不多
- 老年人享受退休生活

### 【核心正式设定：社会保障体系】

- 推动社会保障体系
- 建立失业保险等保障体制
- 基础医疗
- 工伤保障
- 失业保险
- 低收入补助

### 【核心正式设定：医疗卫生体系（推演细化）】

- **体系结构**：基层首诊（社区/乡镇卫生中心）→ 县市级医院 → 州级综合医院 → 国家级医学中心（长安、上海、成都、沈阳）
- **筹资**：全国医保统一统筹统交；国家财政兜底基本公共卫生（免疫、传染病防控、妇幼保健）
- **医疗人才**：国立大学医学系＋省立医科大学；基层轮岗与干部基层经历挂钩
- **公共卫生**：2020年疫情验证——社区治理＋中央财政＋全国物流三大支柱
- **传统医学**：纳入国家医学体系（翰林院大学文明研究＋皇家理工大学药理学并行研究）
- **AI医疗**：辅助诊断普及；处方与手术决定权保留于人类医生（"算法不代替法定决定"原则的延伸）

### 【核心正式设定：住房政策（推演细化）】

- **双轨制**：基本住房保障（公租房、保障房，面向低收入与新市民）＋商品房市场
- **房产税**：基本居住免税/低税；多套、豪宅、商业地产累进——抑制投机
- **城市规划**：长安模式（政治集中＋功能疏散）向各州府推广"多核心组团＋生态廊道"
- **户籍关联**：住房与户籍脱钩（身份证出生地制）——人口流动不受住房捆绑

### 【核心正式设定：环境与生态（推演细化）】

- **生态廊道制度**：关中中央生态廊道（渭河生态带）为范本，各州府推广
- **能源转型**：核聚变（2026示范堆）＋光伏特高压＋水电——能源自主是国家安全战略核心
- **环境治理史**：工业化早期污染→1960s治理立法→2000s新能源革命——"发展不误生态"承接三衡国策精神

### 【核心正式设定：上山下乡制度】

- 要求在大学学习的学生进行一年的上山下乡才能毕业
- 学工科的进入考察过的工厂实习
- 学农学的进入田间巷尾参与农业劳动
- 在干部的选拔上更看重基层治理的经历

## 二、社会流动

### 【核心正式设定】

- 帝国开国早期经历剿匪、扫黑除恶等大规模治安行动
- 工业革命后严格控制枪支、毒品等等高风险社会问题
- 制度建设不会因为经济发展导致阶级固化
- 会很好的分担社会压力，尽量避免出现大革命等动荡
- 让最穷的地方的人有出路有盼头，不会因为前路渺茫而抗议/动乱

## 三、日常生活

### 【核心正式设定：2026年普通人的一生】

出生 → 基础医疗 → 基础教育（免费）→ 地方大学/州立大学/国立大学 → 国家科研机构/企业/政府 → 工作 → 养老金 → 退休

# 第十三编：科技与AI时代

## 一、科技发展战略

### 【核心正式设定】

- 帝国海军和国立皇家理工大学一起探索世界

- **国家实验室体系**：依托三所国立大学设立国家重点实验室；皇家理工大学（工程、AI、航天）、翰林院大学（文明研究、政治学）、海军工程大学（舰船、海洋）
- **国家航天局**：气象、通讯、测绘起步→载人航天→深空探测；航天机构归口科技发展与基础建设系统

## 二、AI与自动化

- AI与自动化带来的财政收入可以支持全民国家基本补贴

### 【核心正式设定：AI时代社会契约升级】

传统社会契约：劳动 → 工资 → 生活
工业时代：劳动 → 工资 + 社会保障
AI时代：生产 → 社会财富 → 公共分配 → 全民基本补贴

### 【核心正式设定：AI时代工作意义变化】

- 工作逐渐变成：收入、社会贡献、兴趣、成就、身份认同
- 可能出现四天工作制、六小时工作制、更长的带薪休假
- 终身教育、中年再培训
- "劳动创造财富，但技术进步也应当让劳动者获得更多自由"

### 【核心正式设定：AI在政治中的应用】

- AI可以帮助议会处理大量资料（如财政预算分析）
- 可以建立"国家政策模拟系统"，量化不同政策方案的影响
- 但帝国刻意保留"人的决定权"
- 法律规定："算法可以提供意见，不得代替法定权力主体作出最终政治决定"

# 第十四编：民族与自治制度

## 一、民族政策

### 【核心正式设定】

- 多民族共治，各民族法律地位基本平等
- 少数民族等特殊地区根据实际需要实行有限自治

- 保持当地干部与国家主体民族的干部一个平稳的比例
- 地方文化可以进入全国统一的历史/语文教科书
- 低强度自治区，不进行大规模同化但进行低烈度的融合政策
- 通过几代人的更替增加认同感

### 【核心正式设定：自治地区类型（推演细化）】

- **民族自治区**（有限自治）：蒙古高原牧区、青藏高原大部分、西北绿洲区、中南半岛少数民族聚居区、朝鲜省朝鲜文化区——自治范围：语言、文化、教育内容调整、宗教事务、地方习俗、一定地方行政制度

- 原则："自治的是地方事务，不是国家主权"；"一国多制式行政，而非一国多主权"

# 第二十编：帝国政治理论

## 〇、八个关键词与政治哲学闭环

### 【核心正式设定：帝国政治哲学八个关键词】

> **统一、皇权、制度、责任、选拔、监督、改革、绩效**

八个概念形成闭环：

- **统一**保证国家不碎
- **皇权**保证最高政治连续性
- **制度**限制权力滥用
- **责任**要求皇帝和官僚承担治理后果
- **选拔**解决世袭能力问题
- **监督**解决官僚腐化问题
- **改革**解决制度僵化问题
- **绩效**最终决定整个体系能否继续获得社会认可

### 【制度理论解释：四角制衡与个人领导+集体决策】

中央内部形成四角制衡：皇帝（国家往哪里走）→ 政治局（重大政治问题怎么决定）→ 政府（怎么执行）→ 议会（是否合理合法、钱花得是否合理）→ 监察司法（有没有违法腐败越权）。

皇帝与政治局不是简单上下级：皇帝作为常委会委员长是最高负责人，但政治局不是皇帝的私人秘书处，常委具有独立政治责任。重大政策可能出现皇帝提出A方案、常委提出B方案、最终讨论形成C方案。形成**"个人领导 + 集体决策"**制度。

政治局是**帝国最高政治人才集合**而非皇室贵族会议：人才来自基层官员逐级晋升（县级→地级→州级→中央部委→政治局委员→常委），同时存在军队、科技、外交、经济、司法、议会等多条进入路线。

### 【制度理论解释：强中央、强监督、强纠错】

- 帝国拥有极强国家能力（收税、统计、基建、动员、教育、医疗、国防、科技组织、危机处理），这解释了AI时代能迅速推行全民基本补贴等大规模制度工程
- 但强国家能力的危险是：官僚体系若出错，错误会被全国放大
- 大革命后的核心不是让中央变弱，而是**让中央强大，但让中央内部形成纠错机制**——"强中央、强监督、强纠错"，而不是"弱中央+强地方"
- 中央最大的敌人不是地方割据，而是**"信息—权力集团"**：官僚层级层层过滤信息可能绑架皇权，因此需要议会/审计/监察/学术/国安/社会调查等平行信息体系

### 【制度理论解释：以改革维持稳定】

- 大革命证明：如果制度不能改革，最终就会逼出革命
- 大革命后的政治哲学不把"稳定"理解成一成不变，而是定义成：**"能够持续改革而不发生国家崩溃"**——以改革维持稳定
- 与传统王朝"以不变维持稳定"完全不同
- 皇帝真正正确的选择不是压制变化，而是主动推动改革，因为**改革本身就是维护皇权合法性的工具**

## 一、权力分权理论

### 【制度理论解释】

帝国的权力分权不是西方式的三权分立，而是一种**"多链条垂直分权 + 横向制衡"**的独特模式：

1. **行政链**（中央→州→省→市→区→街道）负责治理
2. **人事链**（皇帝/中央→各级干部系统）控制人事
3. **军事链**（皇帝→中央军委→军区）控制军事
4. **财政链**（中央→州→省市）控制财政
5. **民意链**（居民→基层选举→代议机构）提供合法性
6. **监察链**（中央监察→州监察→地方监察）监督权力

这些链条故意不完全重合，形成复杂的权力制衡网络。

## 二、分层决策理论

### 【制度理论解释】

帝国的"分层决策制"确保每一级政府只处理自己层级应该处理的事情：

- 街道办自己决定户籍、基础治安、民政
- 区决定学校、市场管理、地方税务
- 市决定城市建设、地方经济、大型水利
- 省决定本省财政、教育体系、地方官任免
- 州负责跨省铁路、大型军队调动、跨省水利
- 中央只处理真正影响整个帝国的事情

## 三、干部选拔理论

### 【制度理论解释】

帝国的干部选拔不是单纯的考试制度，也不是单纯的选举制度，而是一种**"科举取士 + 政治学院育才 + 基层直选定职 + 代议选举升迁 + 委员会集体决策 + 事务官执行政令 + 御史监察 + 皇帝最终裁决"**的复合体系。

核心原则：

- 科举决定你有没有资格做官
- 选举决定你具体担任什么政治职位
- 政绩决定你能不能晋升
- 中央考核决定你能不能进入高级干部体系

## 四、标准政策生命周期

### 【核心正式设定】

帝国所有大型政策都走同一条主流程：

**问题发现 → 部门研究 → 专家论证 → 财政评估 → 监察审查 → 中央政治局常委会讨论 → 中央政治委员会审议 → 皇帝最终决定 → 议会审议/公布 → 政府执行 → 地方落实 → 监察评估 → 复盘修改**

## 五、法律产生流程

### 【核心正式设定】

法律来源有五种：

1. 皇帝提出
2. 中央政府提出
3. 中央委员会提出
4. 议会提出
5. 地方委员会联合提出

## 六、帝国制度演化论

### 【制度理论解释】

**第一原则：国体稳定，制度可变**

- 国家根本结构（中华帝国国体、皇室、国家统一、中央集权、国家法统）不能被普通政治竞争改变
- 运行制度（选举、财政、教育、官员、社保、地方、经济、科技、议会制度）完全可以改革
- 原则："国体不可轻易更易，政制必须与时代俱进。"

**第二原则：权力必须"分工"，但不追求绝对分立**

- 更接近"多中心权力制衡"而非经典"三权分立"

# 第二十一编：合法性理论

## 一、中华帝国合法性理论

### 【核心正式设定：五重合法性】

现代皇帝的合法性来自五个来源的叠加：

1. **血统合法性**：皇室继承传统
2. **历史合法性**：1700年开国、明王朝正统继承、三百多年国家连续性
3. **宪制合法性**：皇权依法行使、宪法法律议会司法对权力的确认与约束
4. **能力合法性**：皇储经过国家筛选培养，"国家会尽最大制度努力确保下一位皇帝是经过筛选和训练的最高政治人才"
5. **绩效合法性**：国家治理成果——安全、教育、医疗、养老金、基本补贴、住房、就业、基础设施、科技发展

五层叠加之后：**皇帝不是简单的"血统统治者"，而是国家最高政治职位的世袭承担者**。普通人支持帝国，不只是因为"祖宗留下来的"，而是"这个制度确实能够让国家运行得很好"。对皇帝的评价是"这位皇帝治理得好不好"，而不是"皇帝是不是应该存在"。

国家统一本身也是合法性的重要组成部分：在横跨东亚、内亚和东南亚的超级国家中，分裂意味着战争和经济崩溃，中央统一具有很强的历史合理性（统一合法性）。

### 【制度理论解释】

中华帝国的合法性来源是多元的：

1. **王朝正统合法性**：继承中华王朝正统，从明末大乱中胜出
2. **历史连续性**：延续数千年中华文明，皇宫和城墙成为文化象征
3. **国家统一合法性**：维护了庞大帝国的统一和稳定
4. **皇室合法性**：皇室通过制度化选拔证明自身能力
5. **宪制合法性**：政治制度经过法律确认，皇帝权力受到制度约束
6. **政治参与合法性**：基层选举和议会制度提供有限但真实的政治参与
7. **治理绩效合法性**：国家经济发展、社会福利改善、人民生活水平提高
8. **社会福利合法性**：全民基本补贴、免费教育、全国医保等社会福利
9. **皇储能力筛选合法性**：皇储必须经过长期培养和严格考核

## 二、关键问题解答

### 【制度理论解释：为什么经过大革命后，皇室没有被废除？】

- 大革命的目标不是推翻皇室，而是打破官僚利益集团
- 皇室在大革命中站在改革一边
- 皇储在大革命后完成了制度改革
- 皇室仍然具有国家象征和文明连续性的意义
- 皇宫博物馆中专门有《帝国制度自我革新史》，公开展示大革命时期的文件、民众诉求、改革方案、争论记录
- 皇室没有否认历史，而是承认国家曾经犯过错误

### 【制度理论解释：为什么普通人仍然接受皇帝制度？】

- 皇帝制度已经高度制度化，皇帝不能随意行使权力
- 皇帝犯错可以被讨论和批评
- 国家治理主要依靠官僚体系而非皇帝个人
- 社会福利和经济发展使普通人生活改善
- 皇储制度确保继承人的能力

### 【制度理论解释：为什么皇帝拥有实权却不会自然演变成传统专制？】

- 中央委员会80%以上同意可以冻结/罢免皇帝
- 独立司法和监察系统
- 议会的监督权
- 中央政治局常委各有独立权力来源
- 政治文化鼓励协商和妥协
- 紧急权必须有期限

### 【制度理论解释：为什么皇储制度不会变成简单的血统世袭？】

- 皇储必须经过国立中央政治学院学习
- 必须经过基层实践和地方轮职
- 必须通过中央政治委员会最终考核
- 考核标准是"具备履行皇帝职责之能力"
- 考核结果不是"皇帝英明神武"，而是务实的能力评价

# 第二十二编：王朝周期律与大革命理论

## 一、传统王朝周期律

### 【制度理论解释】

中国传统王朝周期：

**开国 → 盛世 → 腐败 → 财政危机 → 社会危机 → 农民/军阀战争 → 改朝换代**

## 二、中华帝国的制度创新

### 【核心正式设定】

中华帝国将传统循环改造为：

**开国 → 制度化 → 发展 → 制度老化 → 改革 → 制度更新 → 再发展**

## 三、大革命的理论定位

### 【核心正式设定】

- 大革命在历史意义上承担了传统王朝周期律中"改革换代"的功能
- 但没有推翻皇室
- 大革命是开国皇帝的制度在数百年后对自身进行的一次"自我革命"
- 大革命解决了一个真实存在的制度危机，但其动员方式也制造了严重的社会成本
- 帝国此后将防止官僚固化的责任交给常态化制度，而不再依赖最高统治者发动群众运动
- 历史意义："它没有结束帝国，而是结束了帝国旧时代。"

### 【核心正式设定：大革命="第二次建国"】

- 中华帝国没有通过改朝换代打破王朝周期，而是通过"大革命—制度重建"**把王朝周期内部化了**：王朝没有换，但制度发生了一次近似"换代"的大更新
- 真正被"换掉"的不是皇帝和国号，而是**旧的政治运行模式**
- **第一帝制**（开国皇帝建立）：皇权+官僚+科举+中央集权 → 大革命（制度断裂点）→ **第二帝制**（大革命后形成）：皇权+职业官僚+议会监督+地方参与+政党竞争+社会保障+现代法治
- 大革命的真正历史意义：**把"皇帝个人拥有国家"转变成"皇帝领导国家制度"**——从"统治"变成"领导"，这是整个帝国现代政治思想的核心分水岭
- 大革命是皇权现代化，而不是皇权终结：保留皇室/皇位/皇储制度/皇帝最高政治领导地位，改造权力行使方式/国家机构关系/司法独立/议会监督/行政组织法/地方行政法/皇储资格制度

### 【核心正式设定："皇权—制度—绩效循环"】

正向循环：皇权 → 政治领导 → 制度运行 → 国家治理 → 经济与社会发展 → 人民获得公共利益 → 国家合法性增强 → 皇室威望增强 → 皇权稳定 → 继续推动制度改革 → 进入下一轮。

负向危机：制度僵化 → 治理能力下降 → 社会不满 → 皇室威望下降 → 政治危机。此时皇帝真正正确的选择是主动推动改革，因为**改革本身就是维护皇权合法性的工具**。

### 【核心正式设定：大革命时间定位（冻结版：1978—1986年）】

- **1978—1986年：中华帝国大革命**（肃宗朱弘宪发动）
- 三阶段：
  - **第一阶段（1978—1980）：政治危机**——权力边界模糊、中央机构重叠、地方责任不清、社会要求参与决策
  - **第二阶段（1981—1984）：制度重构**——完成政治局组织法、中央政府组织法、中央议会法、司法制度改革、监察制度改革、地方政府法、皇位继承法
  - **第三阶段（1985—1986）：宪制定型**——颁布《中华帝国宪法》，大革命结束
- 为什么是1978年而非更早：此时帝国已经历工业化、城市化、大众教育、现代官僚体系、全国交通网络、现代传媒、大规模工业人口——矛盾已从"有没有现代国家"变成"现代国家已经如此庞大，皇帝、政治局、政府、议会和地方到底应该分别拥有什么权力"。大革命不是反封建革命，而是**成熟帝国的制度现代化革命**
- 历史背景链：1900年前后帝国建立社会保障 → 1970年代官僚体系固化 → 老皇帝（肃宗朱弘宪）多次改革被消解 → 1978年悍然发动大革命 → 老皇帝去世（1980年代前期）→ 皇储领导制度改革派获胜 → 1986年宪法颁布、制度定型

### 【核心正式设定：老皇帝（肃宗）的生平】

**姓名（冻结版）**：**肃宗：朱弘宪**。"弘宪"对应弘扬国家制度＋重建宪制。历史定位：大革命时代皇帝。后世史学称"肃宗改革""肃宗大革命""肃宗宪制改革"——他不是推翻帝国的人，而是把帝国从旧制度推进到现代制度的人。

**出生**：1900年前后出生（太祖之后约两百年），是"太祖制度的孩子"。帝国已经非常强盛。他的家庭并不贫穷，但也绝非最高权贵。父亲是中高级地方官员，母亲是教师。

**少年**：成绩很好，进入地方优秀学校、州级大学、中央大学体系。很早就发现"公平并不等于平等"——高级官员子弟往往拥有更好的家庭教育、更广泛的人际关系、更早接触政治信息。

**青年基层任职**：按照太祖祖制，即使是皇子也必须接受普通政治教育、参加考试、基层任职。被派到偏远省份担任基层行政职务。基层根本不关心他是谁，百姓只关心"水有没有来？""孩子有没有学校？""今年粮食够不够？"

**关键发现**：当地发生严重洪灾，中央拨款经过州→省→市→区层层分配后，基层拿到的钱远低于预期。没有一个人明显违法，每一层都有合法理由，但真正需要钱的人没有得到足够的钱。他第一次意识到："一个制度不需要违法，也可以产生非常糟糕的结果。"

**中年**：成为优秀技术官僚，主管水利、财政、工业、教育、科技。进入州政府，再进入中央政府。

**发现问题**：多次尝试正常改革均被官僚体系消解——限制高级官员任期被规避，加强监察被监察机关自己形成利益网络，扩大基层选举被地方官僚影响候选人，国立大学扩招被上层家庭获得优势，官员财产公开被亲属、信托等方式规避。

**发动大革命**：老皇帝意识到"如果只依靠现有官僚机构改革官僚机构，改革本身就会被官僚机构消解"，于是宣布"帝国进入非常时期"，发动"全国制度大革命"，直接向普通人发出政治动员。

### 【核心正式设定：大革命的经过】

1. 帝国运行两百多年后，官僚阶层形成事实世袭化
2. 老皇帝发现问题，多次尝试正常改革均被官僚体系消解
3. 老皇帝悍然发动"全国制度大革命"
4. 直接向普通人发出政治动员，允许批评官员和制度
5. 形成改革派、保守派、中间派、野心家等多阵营
6. 老皇帝病重，留下《终极改革诏书》
7. 老皇帝去世，斗争开始
8. 皇储领导的制度改革派获胜
9. "结束运动，完成改革"
10. 改革成果被写进新法典

### 【核心正式设定：大革命后的制度改革】

1. 官员不得形成事实世袭：高级官员子女必须重新参加正常选拔
2. 官员亲属回避：直系亲属不得在存在直接利益关系的部门任职
3. 高级官员强制轮岗：州级以上重要官员必须跨地区任职
4. 高级政治职位任期限制
5. 国立大学进一步开放
6. 官员财产透明
7. 政治献金制度化
8. 议会获得更强监督权
9. 监察机构受到监督
10. 建立真正意义上的公民政策参与制度（地方议会、政策听证、公民提案、议会请愿、公开质询、地方选举）

### 【制度理论解释：大革命的禁忌】

后世政治教材评价：

> "第二次制度危机证明，任何政治体系都会产生利益固化；但同样证明，群众动员不能成为常态政治工具。帝国必须通过法律、选举、监察、议会和行政改革持续解决社会矛盾。"

形成政治传统：

- 皇帝拥有发动重大改革的权力
- 但皇帝也负有在改革完成后主动结束群众动员、恢复正常法治秩序的义务

### 【制度理论解释：大革命的历史讽刺】

开国皇帝最初设计制度，是为了防止贵族世袭。几百年后，贵族确实没有世袭，但官僚通过教育、财富、人际网络制造出了新的"软世袭"。老皇帝发现："我当年消灭的是血缘贵族，但没有消灭权力本身形成贵族的能力。"改革成功以后，帝国终于完成了第二次制度升级："从防止血缘世袭，走向防止任何形式的权力世袭。"

### 【制度理论解释：如果改革失败】

- 如果改革失败，帝国仍可能发生严重政治危机
- 官僚集团可能发动政变
- 地方可能趁机扩大自治权
- 社会不满可能演变成大规模动乱
- 帝国可能面临分裂风险
- 因此大革命是一次"成功但危险的制度紧急手术"

## 四、帝国历史循环

### 【推演：帝国最深层的精神】

帝国最深层的精神可以用一句话概括：

> **"天下非一人之天下，亦非一时之天下；君以定其向，臣以行其政，民以成其业。"**

历史循环：

- **1700年**：太祖"建立制度，防止国家衰败"
- **1800年**：后世皇帝"学习工业文明，防止落后"
- **1900年**：帝国"建立社会保障，防止工业社会撕裂"
- **1970年**：官僚体系"开始固化"
- **1980—1990年**：老皇帝"必须打破固化"
- **2000年**：新一代"让制度化改革取代群众运动"
- **2026年**：新问题"如何让皇权、民主、技术官僚和人工智能继续共存？"

这使这个世界不是一条"完美制度一路成功"的直线，而是：**建立 → 成功 → 固化 → 危机 → 改革 → 再平衡 → 面临新问题。**

# 第二十三编：典型政治事件推演

## 案例A：皇帝提出一项重大经济改革

**谁提出** → 皇帝提出改革方向和战略目标
**谁讨论** → 中央政治局常委会讨论具体方案
**谁决定** → 中央政治局常委会多数决定，皇帝最终批准
**谁执行** → 中央政府相关部门执行
**谁监督** → 中央议会审议、中央监察机关监督
**谁可以挑战** → 中央议会可以提出修改建议，中央监察机关可以调查执行中的问题
**谁最终裁决** → 皇帝

## 案例B：中央政府提出一项全国性社会政策

**谁提出** → 中央政府相关部门提出
**谁讨论** → 中央政治局常委会讨论
**谁决定** → 中央政治局常委会决定，涉及法律的需议会审议
**谁执行** → 中央政府执行
**谁监督** → 中央议会监督、中央监察机关监督
**谁可以挑战** → 议会可以否决，监察机关可以调查
**谁最终裁决** → 皇帝（涉及重大政策时）

## 案例C：某州政府与中央政府产生严重政策分歧

**谁提出** → 州政府或中央政府提出
**谁讨论** → 中央政治局常委会讨论
**谁决定** → 中央政治局常委会决定
**谁执行** → 中央政府执行
**谁监督** → 中央议会、中央监察机关
**谁可以挑战** → 州长可以进京述职时提出异议
**谁最终裁决** → 皇帝

## 案例D：中央政府高级官员涉嫌腐败

**谁提出** → 中央监察机关发现或接到举报
**谁调查** → 中央监察机关独立调查
**谁决定** → 中央政治局常委会根据调查结果决定处理
**谁执行** → 中央政府执行处理决定
**谁监督** → 中央议会可以质询
**谁可以挑战** → 被调查官员可以通过司法程序申诉
**谁最终裁决** → 皇帝（涉及极高级官员时）

## 案例E：中央政府和中央议会发生预算争议

**谁提出** → 中央政府提出预算案
**谁讨论** → 中央议会审议
**谁决定** → 中央议会审议后提出修改意见
**谁执行** → 中央政府执行修改后的预算
**谁监督** → 中央监察机关监督执行
**谁可以挑战** → 皇帝可以否决议会预算决定，但必须说明理由
**谁最终裁决** → 皇帝

## 案例F：皇帝与政治局多数成员对某项重大政策意见不同

**谁提出** → 皇帝或政治局成员提出
**谁讨论** → 中央政治局常委会讨论
**谁决定** → 皇帝拥有最终裁决权
**谁执行** → 中央政府执行
**谁监督** → 中央议会、中央监察机关
**谁可以挑战** → 中央委员会80%以上可以冻结/罢免皇帝
**谁最终裁决** → 皇帝（但面临政治代价）

## 案例G：皇储能力不足，需要重新选择继承人

**谁提出** → 皇帝发现皇储能力不足
**谁讨论** → 中央政治局常委会讨论
**谁决定** → 皇帝指定新继承人 + 中央政治委员会确认
**谁执行** → 中央政治委员会执行继承程序
**谁监督** → 中央议会、中央监察机关
**谁可以挑战** → 中央政治委员会有权拒绝确认
**谁最终裁决** → 皇帝（但需要政治委员会确认）

## 案例H：西部缺水需要修建大型水利工程

**谁提出** → 基层发现（街道/区/市政府）
**谁上报** → 逐级上报：市→省→州→中央
**谁研究** → 中央政府水利部门、财政部门、工业部门联合研究
**谁论证** → 皇家理工大学专家技术可行性报告
**谁检查** → 监察机关检查有没有地方官员通过项目谋私
**谁讨论** → 中央政治局常委会讨论
**谁审议** → 中央政治委员会审议
**谁决定** → 皇帝决定（批准/修改/要求重新论证/否决）
**谁执行** → 政府执行→地方执行
**谁验收** → 监察验收
**谁审计** → 议会审计
**谁总结** → 项目总结
