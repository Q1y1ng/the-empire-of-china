# 附录一：帝国机构品级总表（按一把手品级算·2026冻结版）

> 皇帝不纳入机构序列；高配指“机构二级、主官一品”等人员与机构级别分离现象。

| 级别 | 品级 | 机构举例 | 一把手职务举例 |
| --- | --- | --- | --- |
| **一级** | 一品 正国 | 中央政治局常委会、中华帝国国家议会、中央军事委员会 | 皇帝召集；议会常务委员会主席、军委主席（一品） |
| **二级** | 二品 副国 | 中央政治局（27人，含9名常委）、国务院、最高人民法院、最高人民检察院、中央纪律检查委员会、国家监察委员会、中央组织委员会、中央宣传部、中央办公厅、中央政法委员会、中央财政经济委员会、中央外事委员会、中央民族与宗教委员会、中央网信与人工智能委员会、中央巡视委员会、国家议会九个专门委员会、帝国宪法法院、帝国审计院、国家统计局、国家安全委员会 | 政治局委员、副总理、议会常务委员会副主席、专门委员会主任、院长、纪委主席、宣传部长、办公厅主任、审计长、统计局长等（常委兼任时高配一品） |
| **三级** | 三品 州部级 | 中央政治委员会（全体会议层，79 人，成员三品以上）、七个常规州（东北/蒙古/西北/华北/江南/云贵/青藏）、普通中央部委（外交部、国防部、财政部、国家发展改革委员会、教育部、科学技术部、工业和信息化部、公安部、司法部、民政部、人力资源和社会保障部、自然资源部、生态环境部、住房与城乡建设部、交通运输部、水利部、农业农村部、商务部、文化和旅游部、卫生健康委员会、应急管理部、退役军人事务部，共22个组成部门）、中央直属特设机构、中央政治学院与帝国国防大学（三品级单位） | 州长、部长（三品）；政治委员会委员（三品） |
| **四级** | 四品 副州 | 州副职、长安市委主席（州委常委）、其余五市市委主席（省级） | 副州长、市委主席（四品） |
| **五级** | 五品 省署级 | 省（39个）、京畿6直辖市人民政府（市长＝省级）、中央部委副职对应执行机构、省直属重要机构（"○○署"） | 省长、直辖市市长（五品） |
| **六级** | 六品 副省级 | 副省、副省级市（上海/北京等州府、特大城市） | 副省长、副省级市长 |
| **七级** | 七品 正厅局 | 普通地级市、省直厅局 | 市长、厅长 |
| **八级** | 八品 副厅局 | 副市、副厅局、副省级市副职 | 副市长 |
| **九级** | 九品 正处 | 区/县、县级市 | 区长/县长 |
| **十级** | 十品 副处 | 副区/副县 | 副区长 |
| **吏一级** | 正科 | 街道办、乡镇 | 街道办主任、乡镇长 |
| **吏二级** | 副科 | 街道办/乡镇副职 | 副主任 |
| **吏三级** | 科员 | 一般办事机构 | 科员 |

> **地方链条示例**：华北州（三级/三品州部级·北京）→ 河南省（五级/五品省署级）→ 郑州市（六级副省级高配/或七级地级）→ 中原区（九级正处）→ 街道办（吏一级正科）。京畿州不设省：州委主席二品副国、直辖市市长五品·省署级。

> **高校机构级别（2026.12 副国级改定）**：中央政治学院、帝国国防大学为**三品级单位**（校长三品），列三级，现由二品以上者高配兼任；皇家理工等重点国立校总校列四级（分校五级）；州立大学、国立非重点总校列六级（非重点分校七级）；省立/行政区立大学列八级；行业专科与市立各校列十级；军校/警校按校长军衔对应。一把手品级＝机构级别，高配者人高岗低、岗位不变，全表见第四编「级别待遇对照」。
