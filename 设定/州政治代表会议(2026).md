# 《中华帝国州政治代表会议（2026）》

> **性质**：州级治理者代表会议专卷，对应中央的全国政治代表会议。**不是州议会，不是州政委会**。条文取自《设定集·对话推演比对与替换方案(2026-11)》§5.2（P-02 十条）与 §5.3 产生链，可随作者调整。
> **时点**：继文十一年（2026）。正式名**州政治代表会议**，简称**州代会**；八州各设一个，档案编号用「第 X 届〈州名〉州政治代表会议第 X 次会议」。
> **一句话**：州代会解决的是州级「人从哪来」——**选举**州政委会新任文职委员、**确认**其续任文职委员、**确认**中央政委会提名的州委主席候选人；规模留白，每州一届，与州政委会、州议会同步换届，首届 1986 年。

---

## 一、沿革：1986 年首届，八州同步

| 时期 | 届次 | 说明 |
| --- | --- | --- |
| 帝国早期（1700—1985） | — | **无对应机构**。州级人事由中央直接任命，治理者本身没有自己的代表会议 |
| **1986 年（宪制定型后）** | **第一届** | 宪制定型后**八州同步**召开首次会议，与首届全国政治代表会议、州政委会、州议会同期举行；此后每五年一届 |
| 2026 年（继文十一年） | **第九届** | 现行 |

**八州**（见主表 F-05 与《疆域与省界表(2026)》）：京畿直隶州（无省，首都圈）、华北州、江南州、东北州、云贵州、蒙古州、西北州、青藏州。八州各设一个州代会，互不隶属，也不设跨州的联合会议。

> **届次口径**：州代会届次自 1986 年首届起算，与全国政代会、州议会同届编号（2026 年为第九届）。八州届次同步，但会议分别召开、分别立卷。

## 二、性质

1. **州级治理者代表会议**：全国政代会在州一级的对应体，性质相同——既非立法机关，亦非行政机关。
2. **不是州议会（议政会）**：不立法、不审预算、不质询州政府。
3. **不是州政委会**：不决策、不指挥行政、不任免干部（只作确认或选举，不自行提名）。
4. **职能只有四件事**：选人、确认人、听报告、示方向。
5. **代表以个人身份参加**：无党团、无党鞭，表决按议题临时结盟。
6. **与全国政代会不是上下级领导关系**：两者是同一套程序在两个层级的展开。全国政代会不会代行州代会的确认权，州代会也不选举全国政委会委员。

## 三、组成与代表产生

> **规模留白（2026 口径）**：代表名额按州人口分档推选，**具体名额由本会议组织法附表规定**。八州人口差异极大（京畿直隶州与江南州远多于青藏州，见《疆域与省界表(2026)》），故必须分档、不能一刀切；本轮先立机构与职能，规模待作者定，本卷不写人数。主表 **G-11** 为州政治代表会议预留序号，人数栏留白待补。

代表来源分六类，比例为本轮建议值（合计 100%）：

| # | 代表来源 | 建议比例 | 产生方式 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 州内各省、市、区（县）政委会推选 | 50% | 州内各级政委会分档推选 | 州域治理者的主渠道 |
| 2 | 州级部门 | 15% | 州政府组成部门与直属机构推选 | 州级执行层 |
| 3 | 驻军 | 10% | 由州军区系统推选 | **有表决权**，但不参与军区司令席位的产生（见§六） |
| 4 | 州议会（议政会） | 10% | 由州议会选举团产生 | 两会之间的通气渠道 |
| 5 | 基层优秀治理者 | 10% | 州内各级考核前列者推选 | 「从下面挑人」 |
| 6 | 科教与民族界 | 5% | 州立政治学院学区、科教机构与民族自治地方推选 | 专业与民族口径 |
| | **合计** | **100%** | | |

**代表资格**：全部为现职或曾任公职的治理者；无党派；不以组织名义提名。**任期**：五年，与州政委会、州议会同步换届。

## 四、职权

1. **选举**州政委会新任文职委员——当选者称**选举委员**。
2. **确认**州政委会续任文职委员——经确认者称**当然委员**；续任确认**反对票过三分之一**者退回重审一次。
3. **确认州委主席候选人**——州委主席由**中央政委会提名**，州代会**确认**（不是自由选举）；确认后按§五链条完成选举与任命。
4. **确认**州政委会换届；州政委会常委会选举结果**报中央政委会批准**。
5. **审议**州政委会工作报告。
6. **宣示**本州治理方向。
7. **确认**中央政委会提名的州政法委主任、组织部长、纪委主席、监委主席、秘书长人选（确认后由州政委会任命）。

> **不含的一席**：州政委会常委会九席中，**军区司令那一席随军职取得，不由州代会选举或确认**（报州政委会备案），详见§六。

## 五、与中央政委会、州政委会、州议会的关系

**（一）三条人事链（写死）**

| 职位 | 链条 |
| --- | --- |
| **州委主席** | 中央政治委员会提名 → **州政治代表会议确认** → 州政治委员会全体会议选举 → 中央政治委员会批准 → 皇帝任命 |
| **州长** | 中央政治委员会提名 → **州议会同意** → 中央政治委员会任命（不经州代会） |
| **州政法委主任、组织部长、纪委主席、监委主席、秘书长** | 中央政治委员会提名 → **州代会确认** → 州政委会任命 |
| **军区司令** | 中央军委提名 → 皇帝以军委主席身份任命 → 报中央政委会备案（**不经州代会、不经州政委会选举**） |

**（二）边界表**

| 主体 | 不做的事 |
| --- | --- |
| **州代会** | 不审议州预算与州法规；不确认州议会组成；不自行提名州委主席；不质询州政府；不干预个案；不选举或确认军区司令 |
| **州议会（议政会）** | **不确认**州政委会组成；不选举州政委会委员 |
| **州政委会** | **不代行**州代会的选举与确认职能；不得自行补缺；常委会选举结果未报中央政委会批准前不生效 |
| **中央政委会** | 提名州委主席候选人、批准州政委会常委会选举结果、确认州代会组织法修正；**不代行**州代会的确认职能 |
| **全国政代会** | 不代行州代会的确认权 |
| **皇帝** | 任命州委主席与经确认的委员；州代会不表决皇帝事项 |

## 六、军区司令席位的特殊处理

1. **一席，随军职取得**：州政委会常委会九席中，军区司令占一席（其余八席为文职），该席**不由州代会选举或确认**，报州政委会备案。
2. **产生链独立**：中央军委提名 → 皇帝以军委主席身份任命 → 报中央政委会备案；不经州代会、不经州政委会选举。
3. **理由**：军职属武装力量序列，与地方治理者「内行选内行」不同轨；此与中央政委会的军职席位同一规则（军职随职务取得、不由政代会选举或确认）。
4. **驻军代表不等于军区司令**：§三第 3 类「驻军 10%」的代表由州军区系统推选，有表决权，但他们的表决不构成对军区司令席位的选举或确认。
5. **一岗一人**：军区司令兼任州政委会委员时不另计席，亦不得以兼任填补其他空缺。

## 七、文号

- **文号**：州代会决议与行文用「**州政发〔年〕X号**」；中央政代会用「全政发〔年〕X号」，两者分列，不得混用（八州同格式，以州名冠首区分）。
- **文书三类**：决议；确认书（选举委员、当然委员、州委主席候选人分别出具）；公报。
- **公报**：会后两小时内公布议题与结论；涉密事项只公布存在与范围，不公布内容。
- **档案**：按「第 X 届〈州名〉州政治代表会议第 X 次会议」立卷，与州议会同届。

## 八、不设州代会的层级说明

- **省、市、区（县）一律不设政代会**，也没有「省代会」「市代会」「县代会」这类机构；遇有文书如此使用，一律视为非规范用语。
- **理由**：政代会的功能是「州级以上人事的正当性授予」。省级以下是**执行层**，其人事走「上级政委会提名＋本级议会确认＋组织部任命」三步即可，再往下每级都设一套代表会议，程序成本高于收益。
- **执行层的三步链**：上级政委会提名 → 本级议会确认 → 组织部任命；不经任何代表会议。
- **街道办**为最基层政府，更不设。
- 因此帝国只有**两级**政代会：全国（政代会）与州（州代会）；州以下是执行层，不是代表层。

> **本轮待定**：州代会由谁召集主持（可参照全国政代会「政委会推举主席、皇帝任命」之例另定）、代表总数、主席团、会期日程、代表连任限制。原方案 4.2 条五所拟的常设机关，按作者口径**一律不设**；州代会闭会期间亦不另设常设机关，届中出缺由中央政委会提名、提请州代会临时会议确认。
