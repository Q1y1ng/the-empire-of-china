# 《中华帝国州政治代表会议（2026）》

> **性质**：州级治理者代表会议专卷，对应中央的全国政治代表会议。**州代会为**州最高领导机关**，由州内治理者推选代表组成，行使州级人事的选举与确认之权；闭会期间其职责由州人民政治委员会代行；州法规、州预算的审议归州议会（议政会）**。条文取自《设定集·对话推演比对与替换方案(2026-11)》§5.2（P-02 十条）与 §5.3 产生链，可随作者调整。
> **时点**：继文十一年（2026）。正式名**州政治代表会议**，简称**州代会**；八州各设一个，档案编号用「第 X 届〈州名〉州政治代表会议第 X 次会议」。
> **一句话**：州代会是**州最高领导机关**，解决的是州级「人从哪来」——**选举**州政委会新任文职委员、**确认**其续任文职委员、**确认**中央政委会提名的州委主席候选人；规模留白，每州一届，与州政委会、州议会同步换届，首届 1986 年。

---

## 一、沿革：1986 年首届，八州同步

| 时期 | 届次 | 说明 |
| --- | --- | --- |
| 帝国早期（1700—1985） | — | **无对应机构**。州级人事由中央直接任命，治理者本身没有自己的代表会议 |
| **1986 年（宪制定型后）** | **第一届** | 宪制定型后**八州同步**召开首次会议，与首届全国政治代表会议、州政委会、州议会同期举行；此后每五年一届 |
| 2026 年（继文十一年） | **第九届** | 现行 |

**八州**（见主表 F-05 与《疆域与省界表(2026)》）：京畿直隶州（无省，首都圈）、华北州、江南州、东北州、云贵州、蒙古州、西北州、青藏州。八州各设一个州代会，互不隶属，也不设跨州的联合会议。

> **届次口径**：州代会届次自 1986 年首届起算，与全国政代会、州议会同届编号（2026 年为第九届）。八州届次同步，但会议分别召开、分别立卷。

## 二、性质

1. **本会议是州级治理者代表会议**：为全国政代会在州一级的对应体，性质与中央相同，行使州级人事的选举与确认之权。
2. **本会议行使选人与确认之权**：选举州政委会新任文职委员、确认其续任文职委员、确认中央政委会提名的州委主席候选人（详见§四）。
3. **州规与州务的归口**：州法规与州预算的审议归州议会（议政会），决策与行政归州政委会；本会议职权限于§四所列七项，以会议形式行使。
4. **职能四项**：选人、确认人、听报告、示方向。
5. **代表以个人身份参加**：无党团、无党鞭，表决按议题临时结盟。
6. **与全国政代会各自行使职权**：两者是同一套程序在两个层级的展开；全国政代会行使中央级选举与确认之权，州代会行使州级选举与确认之权；本会议闭会期间，州级日常领导职责由州人民政治委员会代行。

## 三、组成与代表产生

> **规模留白（2026 口径）**：代表名额按州人口分档推选，**具体名额由本会议组织法附表规定**。八州人口差异极大（京畿直隶州与江南州远多于青藏州，见《疆域与省界表(2026)》），故必须分档、不能一刀切；本轮先立机构与职能，规模待作者定，本卷不写人数。主表 **G-11** 为州政治代表会议预留序号，人数栏留白待补。

代表来源分六类，比例为本轮建议值（合计 100%）：

| # | 代表来源 | 建议比例 | 产生方式 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 州内各省、市、区（县）政委会推选 | 50% | 州内各级政委会分档推选 | 州域治理者的主渠道 |
| 2 | 州级部门 | 15% | 州政府组成部门与直属机构推选 | 州级执行层 |
| 3 | 驻军 | 10% | 由州军区系统推选 | **有表决权**，但不参与军区司令席位的产生（见§六） |
| 4 | 州议会（议政会） | 10% | 由州议会选举团产生 | 两会之间的通气渠道 |
| 5 | 基层优秀治理者 | 10% | 州内各级考核前列者推选 | 「从下面挑人」 |
| 6 | 科教与民族界 | 5% | 州立政治学院学区、科教机构与民族自治地方推选 | 专业与民族口径 |
| | **合计** | **100%** | | |

**代表资格**：全部为现职或曾任公职的治理者；无党派；不以组织名义提名。**任期**：五年，与州政委会、州议会同步换届。

## 四、职权

1. **选举**州政委会新任文职委员——当选者称**选举委员**。
2. **确认**州政委会续任文职委员——经确认者称**当然委员**；续任确认**反对票过三分之一**者退回重审一次。
3. **确认州委主席候选人**——州委主席由**中央政委会提名**，州代会**确认**（提名权在中央政委会，本会议只作确认）；确认后按§五链条完成选举与任命。
4. **确认**州政委会换届；州政委会常委会选举结果**报中央政委会批准**。
5. **审议**州政委会工作报告。
6. **宣示**本州治理方向。
7. **确认**中央政委会提名的州政法委主任、组织部长、纪委主席、监委主席、秘书长人选（确认后由州政委会任命）。

> **军区司令一席**：州政委会常委会九席中，该席依军职取得，报州政委会备案，本会议不作选举、确认，详见§六。

## 五、与中央政委会、州政委会、州议会的关系

**（一）三条人事链（写死）**

| 职位 | 链条 |
| --- | --- |
| **州委主席** | 中央政治委员会提名 → **州政治代表会议确认** → 州政治委员会全体会议选举 → 中央政治委员会批准 → 皇帝任命 |
| **州长** | 中央政治委员会提名 → **州议会同意** → 中央政治委员会任命（不经州代会） |
| **州政法委主任、组织部长、纪委主席、监委主席、秘书长** | 中央政治委员会提名 → **州代会确认** → 州政委会任命 |
| **军区司令** | 中央军委提名 → 皇帝以军委主席身份任命 → 报中央政委会备案（**不经州代会、不经州政委会选举**） |

**（二）边界表**

| 主体 | 职权范围 |
| --- | --- |
| **州代会** | 选举、确认州政委会文职委员；确认州委主席候选人；确认州政委会换届；审议州政委会工作报告；宣示本州方向 |
| **州议会（议政会）** | 审议州法规与州预算；质询州政府；同意州长人选（依§五人事链） |
| **州政委会** | 决策与行政；任免干部（依§五人事链）；向州代会提出工作报告；常委会选举结果报中央政委会批准；州政委会文职委员的选举与确认职能由本会议行使 |
| **中央政委会** | 提名州委主席候选人；批准州政委会常委会选举结果；确认州代会组织法修正 |
| **全国政代会** | 行使中央级选举与确认之权（见《全国政治代表会议(2026)》§四） |
| **皇帝** | 任命州委主席与经确认的委员 |

下列事项不列入本会议职权范围：州法规与州预算之审议；州议会组成之确认；州政委会组成之确认（属本会议职权）；州委主席之提名；对州政府之质询；具体个案之处理；皇帝事项之表决；军区司令席位之选举与确认（依军职取得，报州政委会备案）。

## 六、军区司令席位的特殊处理

1. **一席依军职取得**：州政委会常委会九席中，军区司令占一席（其余八席为文职）；该席依军职取得，报州政委会备案，本会议不作选举、确认。
2. **产生链独立**：中央军委提名 → 皇帝以军委主席身份任命 → 报中央政委会备案；不经州代会、不经州政委会选举。
3. **理由**：军职属武装力量序列，与地方治理者「内行选内行」不同轨；此与中央政委会的军职席位同一规则（军职随职务取得，报政委会备案）。
4. **驻军代表的表决范围**：§三第 3 类「驻军 10%」代表由州军区系统推选，对§四所列事项有表决权；军区司令席位的产生依上列链条办理，不经本会议表决。
5. **一岗一人**：军区司令兼任州政委会委员时不另计席，亦不得以兼任填补其他空缺。

## 七、文号

- **文号**：州代会决议与行文用「**州政发〔年〕X号**」；中央政代会用「全政发〔年〕X号」，两者分列，不得混用（八州同格式，以州名冠首区分）。
- **文书三类**：决议；确认书（选举委员、当然委员、州委主席候选人分别出具）；公报。
- **公报**：会后两小时内公布议题与结论；涉密事项只公布存在与范围，不公布内容。
- **档案**：按「第 X 届〈州名〉州政治代表会议第 X 次会议」立卷，与州议会同届。

## 八、政代会的层级：全国、州两级，州以下为执行层

- **帝国政代会分全国、州两级**：全国政代会与八州州代会。省、市、区（县）为执行层，不设政治代表会议；文书中的「省代会」「市代会」「县代会」为非规范用语。
- **理由**：政代会的功能是「州级以上人事的正当性授予」。省级以下是**执行层**，其人事走「上级政委会提名＋本级议会确认＋组织部任命」三步即可，再往下每级都设一套代表会议，程序成本高于收益。
- **执行层的三步链**：上级政委会提名 → 本级议会确认 → 组织部任命；不经任何代表会议。
- **街道办**为最基层政府，更不设。
- 因此帝国政代会分为**全国、州两级**：全国政代会与州代会；州以下为执行层，其人事依「上级政委会提名＋本级议会确认＋组织部任命」办理。

> **会议主持（2026 定）**：州代会**不设主席、不设主席团**。会议由**上一届州人民政治委员会主席（即上一届州委主席）**召集并主持，直至本会议完成下一届州委主席的确认或选举、新任州委主席宣誓就职为止——主持权随职位交接，不随届次中断。
>
> **理由**：州委主席本身就是州代会人事议程的对象，若由在任者自行安排主持人，等于让被审议者安排审议程序；由上一届主席主持、至新任产生为止，主持权有明确起止，会议全程有人在位，不出现程序真空。此与全国政代会由皇帝（中央政治委员会主席）主持同构：主持人不随届次更替，故不存在交接问题。
>
> **本轮待定**：代表总数、会期日程、代表连任限制。原方案 4.2 条五所拟的常设机关，按作者口径**一律不设**；州代会闭会期间亦不另设常设机关，届中出缺由中央政委会提名、提请州代会临时会议确认。
