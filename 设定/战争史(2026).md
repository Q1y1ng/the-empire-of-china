# 《战争史（2026）》

> **时点**：继文十一年（2026）。本卷为**战争专卷**：帝国参与的战事、战役进程与战争代价，按时间排列；疆域四至见《疆域与省界表(2026)》，军制见《全国军事编制设定(2026)》，世界战局见《世界近代史推演》。

## 一、统一战争（1610s—1690s）

### 1.1 明末的战场与社会

| 维度 | 状况 |
| --- | --- |
| 气候 | 小冰期：北方连年旱蝗，流民四起 |
| 朝政 | 党争白热化，内阁与六部权责不清 |
| 军备 | 辽东战事拖欠军饷，内地卫所空额严重 |

### 1.2 太祖的战法

太祖与一般枭雄的分别只有一条：**先建治理能力，再取地盘**——粮食组织、水利队、基层行政、新式军队、临时学校与地方财政先行；军队买粮或由政府统一征收登记，攻下城池之前就先想好怎么治（对照表见《中华帝国编年史》序章）。

当时人第一次觉得：**「这支军队和过去的军队不一样。」**

### 1.3 结局

- 1690s 统一战争胜利，太祖凭治理能力优势在明末大乱中最终胜出。
- **继承中华王朝正统**：明朝法统终结，中华文明皇统未断。
- 胜利时疆域已大致包含：中原及关中、江南、四川、东北、蒙古高原部分地区、新疆及中亚部分地区、朝鲜半岛、中南半岛北部及部分地区。

> **史臣曰**：历代开国多以「马上得天下」，太祖独以「治理得天下」。故其登基之后，首要难题是**「制度本身会老化」**——他把皇帝本人也设计成制度的一部分，此为三百年帝国最深的原创性。

## 三、疆域定型战争（1700—1770）【核心＋推演】

| 战争 | 结果 |
| --- | --- |
| **南方战争（中南半岛整合）**（1750s—1760s） | **老挝全境并入**（澜沧省）；**越南北部及中部大部并入**（河内省）；柬埔寨、缅甸为受支配邻国 |
| **海上疆域整合**（1720s） | 台湾（江南州）、琉球群岛、南海诸岛（含曾母暗沙这一战略极点）完成行政化 |
| **西征与准噶尔—哈萨克战争**（1730s—1750s） | 边界推进至**巴尔喀什湖—天山—帕米尔**；设新疆省与帕米尔方向军政体系 |
| **黑龙江流域定界战争（对俄）**（1700—1720） | 逐俄人于雅克萨、尼布楚一线的据点；界约以**额尔古纳河—格尔必齐河—外兴安岭**为界；海参崴设滨海省 |

太祖、太宗两朝以这三场陆上战争与海上整合，把帝国疆域推到 2026 年的形状：45 个省级单位的**边界**在 18 世纪中叶走完实地勘定；**省制**则到宪宗靖远朝（1836—1868）随边疆军府改省才最终收口。

> **外东北的归属**：黑龙江以北、乌苏里江以东是女真故地，土著为女真（满洲）、赫哲、鄂温克、鄂伦春、达斡尔等族；俄人系 17 世纪中叶以后的据点移民，定界战争把他们逐回外兴安岭以北。

## 四、日俄仲裁（1904—1905）【推演】

- 俄国在朝鲜半岛无立足点，又与强大的帝国相邻。
- 日本在帝国海军威慑下**暂时**放弃大陆扩张。
- 军部「南进论」由此埋下种子——仲裁延缓了日本的扩张，根除则未能做到。

## 五、第一次世界大战（1914—1918）【推演】

### 5.1 战局与帝国位置

| 阶段 | 事件 |
| --- | --- |
| 起因 | 欧洲列强矛盾照常积累（德英海权竞争、法德世仇、奥塞冲突）——欧洲的战和由列强自理 |
| 1914 | 战争爆发，同盟国对协约国 |
| 1914—1918 | 帝国**宣布武装中立**：向双方出售民用物资、海军护航全球商路、边境设防 |
| 1917 | 俄国革命照常爆发（战争加剧了俄国的体制挫败感） |
| 1918 | 战争结束，欧洲残破 |

### 5.2 战争红利

- 欧洲大规模消耗，美国与帝国成为两个超大型经济中心。
- 帝国黄金时代开启（1919—1930）：铁路、电网、高等教育、化工、汽车、航空、无线电全面大投资。

## 六、第二次世界大战（1939—1945）【推演细化·日本参战版】

> **核心逻辑**：本世界线的东亚大陆由帝国本身构成支点，日军因此得以全力南进西出——太平洋战争烈度倍增，帝国与同盟国在「无缓冲」状态下迎战。

### 6.1 日本参战的由来

- 大陆扩张空间归帝国所有，资源可经对帝国贸易获得，军部缺少现实世界中的「大陆生命线」叙事。
- 1937 年起，军部少壮派以「南方资源自给」为由压倒文官政府。
- 1940 年与德意缔结三国同盟；1941 年《帝国国防方针》将「夺取南洋—澳洲—夏威夷」列为国策。
- 参谋本部判断：控制南海即可切断帝国对美英的贸易脐带，帝国将不战自屈——**这是致命误判**。

> **史臣曰**：日本军部看见的是帝国的贸易依赖，看不见的是帝国的工业纵深与战争动员能力。1941 年 12 月 8 日之后，他们看见了。

### 6.2 第一阶段：欧洲开战，帝国中立红利（1939—1941.06）

| 时间 | 事件 |
| --- | --- |
| 1939.09.01 | 德国入侵波兰，英法对德宣战 |
| 1939.09.03 | 帝国宣布武装中立，颁《战时中立法》：交战国军舰禁入帝国领海，对双方均等出售民用物资，军火禁运 |
| 1939—1940 | 假战期：欧洲订单暴增，江南、华北工厂三班倒 |
| 1940 | 日本与德意缔结三国同盟 |
| 1940—1941 | 不列颠空战期：帝国经缅甸—印度航线向英国输送橡胶、钨、桐油；英方请帝国对日宣战以牵制德国，帝国高层仍以贸易约束日本为期 |
| 1941 | 日本《帝国国防方针》将「夺取南洋—澳洲—夏威夷」列为国策 |

### 6.3 第二阶段：太平洋惊雷（1941.12—1942.06）

| 时间 | 事件 |
| --- | --- |
| 1941.12.07 | 日本偷袭珍珠港（全部 6 艘航母＋2 艘超战列舰）；美太平洋舰队几乎全灭 |
| 1941.12.08—12 | 日军登陆帝国南海诸岛、曾母暗沙，炮击河内湾与珠三角外海，递交最后通牒 |
| 1941.12 | 皇帝发布《讨倭诏书》，**对日宣战**；同日对德、意宣战（履行同盟义务） |
| 1941.12—1942.05 | **南洋狂潮**（约 85 个师团、4,000 架战机、18 艘航母级舰艇）：菲律宾、印尼陷落，空袭达尔文，兵临澳洲 |
| 1942.02 | 泗水海战：英荷澳联军溃败，巴厘巴板油田落入日手 |
| 1942.05 | 珊瑚海海战：帝国—澳—美联军险胜，阻住日军登陆澳洲本土 |
| 1942.06 | 中途岛（美军惨胜）＋南海海战（帝国岸基航空兵重创日舰队）——太平洋战场首次止住日军攻势 |

### 6.4 第三阶段：同盟国最黑暗的一年（1942—1943）

| | 现实世界 | 本世界线 |
| --- | --- | --- |
| 中国战场 | 牵制约 80—100 万日军 | 中国战场缺席，日军零牵制 |
| 同盟压力 | 可集中力量于太平洋 | 每一岛皆以少敌多 |
| 亚洲大陆支点 | 中国苦苦支撑 | **帝国云贵—华南防线岿然不动** |

**帝国的底数**：

- 战前 GDP 达美国 82%，钢产量世界第一，三舰队合计 18 艘航母级舰艇在建。
- 遭突袭后**全国总动员仅用 11 天**；八大军区同步一级战备。
- 「长安式」坦克月产逾千辆；珠三角遭轰炸，但防空体系使日机战损率高达 17%。
- 南海诸岛失守，河内湾封锁仅 4 个月即被撕开（1942.04）。

**三域拉锯（1942—1943）**：

| 域 | 内容 |
| --- | --- |
| 陆上 | 云贵军区在中南半岛北部与日军对峙；万象—河内以空间换消耗；机械化步兵师与武装直升机先驱投入 |
| 海上 | 三舰队与美澳「跳岛＋潜艇绞杀」：北海舰队封锁鄂霍次克海，东海舰队护航西太，南海舰队争夺南沙制空权 |
| 1943.07 | **阿拉伯海海战**：帝国双航母编队击沉德舰「科隆」号；「长安」号当日恢复战力，得名「不沉的移动机场」 |

### 6.5 第四阶段：转折与反攻（1943—1945）

| 时间 | 事件 |
| --- | --- |
| 1943.11 | **长安会晤**：皇帝与罗斯福首次元首会晤；帝国以「陆止日军、海断德援、陆路输苏」三承诺，换取美国承认帝国对琉球—南海诸岛战后处置的主导权 |
| 1943 | 长安—乌鲁木齐—阿拉木图陆路向苏联输血，运量占苏联外援 31%，斯大林称「第二条生命线」 |
| 1944.03 | **南沙大捷**：三舰队主力以「航母诱敌—岸基围歼」击沉日航母 3 艘、战列舰 2 艘——太平洋战争公认转折点 |
| 1944.06 | 诺曼底登陆；帝国海军佯动，牵制日军于南海—台湾海峡 |
| 1944.10 | 莱特湾海战；帝国战略轰炸机群首次空袭日本本土九州 |
| 1944—1945 | 缅甸—河内大反攻：15 个师机械化集群收复外围要点，日军退守万象与河内；帝国阵亡约 9 万，歼敌 11 万 |
| 1945.05.08 | 德国投降 |
| 1945.08 | 美国投下原子弹；日本投降 |
| 1945.09.02 | 东京湾受降：帝国与美、苏、英共同签字 |

### 6.6 战争代价与结果

| 项目 | 内容 |
| --- | --- |
| 帝国阵亡 | 约 95 万人（含南海守军、商船队、海军航空兵） |
| 本土 | 广州、河内、海口遭轰炸；省会全部保全；南沙失守 4 个月即收复 |
| 歼敌比 | 歼敌∶己方阵亡约 1.2∶1（火力与后勤优势） |
| 同盟代价 | 太平洋战场阵亡比现实高约 25%；战争延长约 3 个月 |
| 战后工业 | 产值达美国约 91%，海军总吨位世界第二 |
| 联合国 | 五常：美、帝国、苏、英、法 |
| 占领与审判 | 帝国法官主审东京审判的「南海暴行」项；「破坏和平罪」与「破坏全球公共航道罪」并列；帝国军主占九州—濑户内—琉球 |

## 七、战后：三极对峙与局部战争

- **1950—1991 三极格局**：美国（自由市场＋民主）、中华帝国（皇权宪制＋国发主义）、苏联（共产主义一党制）；三方战略竞争，以非军事手段展开。
- **核时代**：三强先后拥核；帝国的核力量为防御性威慑，遭核打击后反击。
- **1990 海湾战争**：帝国同期进行查贪查腐专项斗争，并向外部输出改革经验，未派兵参战。
- **1991—2026 多极全球化**：大国竞争落在关税、船期、标准与贷款条件四件事上。
