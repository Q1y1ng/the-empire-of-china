# 《国家象征物（2026）》

> **性质**：本卷是"图样与歌词"的落地卷——《长安城市志》卷五与《总设定》第二十六编此前只定了**名称与元素**，并两处注明"图样／歌词另卷"；本卷即那一卷。
> **时点**：继文十一年（2026）。**冻结口径**：国旗形制、国徽构成、国歌三段歌词（1986 年宪法确认，沿用至今）。
> **写法**：只定"规格与文字"，不定"画法"——画师依本卷规格书即可作业；本卷不自带位图。

## 一、国旗（红底金龙旗）

### 1.1 形制规格

| 项目 | 规格 |
| --- | --- |
| 名称 | 红底金龙旗（简称帝国旗） |
| 形制 | 长方形，**长宽比 3:2** |
| 旗面 | 深赤（帝国红）：C0 M100 Y100 K10，近似 `#C8102E` |
| 主体纹样 | **金蟠龙一条**，五爪；龙身作 S 形盘绕，龙首向旗杆侧上方（近左上），龙尾卷向旗脚；龙身占旗宽 **约 62%**，龙头高占旗面高度 **约 1/4** |
| 四角纹样 | 四角各一组「**齿轮承稻穗**」：齿轮 **8 齿**在下、稻穗 **3 穗**在上；每组直径约旗高 **1/8**，与龙身不接触 |
| 金色 | C0 M20 Y100 K10，近似 `#C9A227` |
| 旗杆套 | 白色，宽约旗长 1/50；不设金边、不设字 |
| 尺寸序列 | 1 号 288×192、2 号 240×160、3 号 192×128、4 号 144×96、5 号 96×64（厘米）；室内桌面旗 15×10 |

### 1.2 寓意（释义口径，不得改写成"龙＝皇帝"）

- **红底**：开国以来"以血立国、以法守国"的连续叙事；
- **金蟠龙**：文明连续性与国家元首身份合一——龙是**国家**的符号，不是某个人的符号（宪法法院 1991 年释例）；
- **五爪**：沿用帝制礼制中的最高等级，但 1986 年后不再与"天子"叙事绑定；
- **四角齿轮稻穗**：工与农，即"这个国家由谁供养"。

### 1.3 升挂场合

| 场合 | 规格 |
| --- | --- |
| 常设 | 皇宫、国家大会堂、国家议会大厦、中央各部委、州／省／市／区县政府、驻外使馆与总领馆 |
| 仪式 | 开国纪念日（1700 年制度元年）、宪法日（1986）、皇帝登基与元旦、换届周开幕 |
| 民间 | 允许个人悬挂，**不得倒挂、不得污损、不得裁剪改作他用**；丧事降半旗须依《国旗使用规范》 |

## 二、国徽

### 2.1 构成规格

| 项目 | 规格 |
| --- | --- |
| 形制 | 圆形徽章，直径记作 D |
| 中心 | **长安城墙**剪影（瓮城形制，取永宁门段），城墙宽 **0.42 D**，居于圆心偏下 |
| 主体 | **金蟠龙**盘于城墙之上，龙首向观者右前方，高 **0.50 D** |
| 环抱 | 稻穗左右各 **5 穗**，自下方成环，上端交于齿轮 |
| 底部 | **齿轮**（8 齿）居下正中，宽 **0.26 D** |
| 绶带 | 城墙基座下方横绶带，书 **「金瓯永固」** 四字（隶书，阴文） |
| 色 | 红底金纹白绶带，与国旗同色值 |

### 2.2 使用

- 用于国书、条约正本、勋章正面、护照封面、中央机关门楣与公文骑缝章；
- **不得**用于商业标识、广告、装饰纹样；**不得**倒置、旋转、加色；
- 与国旗同列时，国徽居右（面向观者右侧），国旗居左。

## 三、国歌《金瓯曲》

### 3.1 曲式规格

| 项目 | 规格 |
| --- | --- |
| 曲名 | 《金瓯曲》 |
| 拍号与速度 | 4/4，进行曲速度 ♩≈84 |
| 结构 | 三段体（A—A′—B—A″），铜管前奏 8 小节，尾句长音 4 小节 |
| 正式奏唱 | **第一段与第四段**（约 1 分 30 秒）——升旗、迎宾、会议开幕用此版 |
| 全奏 | 四段全奏（约 3 分 10 秒）——开国纪念日、皇帝登基、换届周开幕 |
| 器乐版 | 允许单独演奏，不得改编旋律、不得改配器为电声 |

### 3.2 歌词（四段）

**第一段**

> 金瓯永固，九域攸同。
> 山河表里，日月当中。
> 耕凿有序，工贾相通。
> 亿万斯民，共此苍穹。

**第二段**

> 天下非一人之天下，
> 社稷乃兆民之社稷。
> 权有所归，法有所立，
> 贤者在位，能者在职。

**第三段**

> 龙起长安，风被四裔。
> 舟车所至，商旅相继。
> 不耀兵威，不贪人地。
> 以信相交，以利相济。

**第四段**

> 维我子孙，无忘厥初。
> 老者得养，幼者得书。
> 有过可谏，有罪必诛。
> 金瓯永固，万世不渝。

### 3.3 白话大意（供课本与对外说明，不用于演唱）

| 段 | 大意 |
| --- | --- |
| 一 | 国家完整、天下同心；山河为表里，日月照中央；耕织工商各安其业，万民共此一片天。 |
| 二 | 天下不是一个人的天下，国家是万民的国家；权力有归属，法律有根据，贤能者在其位。 |
| 三 | 龙起于长安，教化及于四裔；舟车所到之处，商旅相接；不炫耀武力，不贪图别人的土地，以信相交、以利相济。 |
| 四 | 子孙不要忘记最初的样子：老人有养、孩子有书读；有过可以谏，有罪必须罚；国家完整，万世不变。 |

### 3.4 奏唱礼仪

- 奏唱时**立正、不鼓掌、不举械**；着制服者行举手礼，便服者行注目礼；
- 不得截取片段作铃声、背景音乐或商业广告；
- 外邦奏其国歌时，帝国人员同礼，**不因邦国大小而降格**。

## 四、其他国家级象征（2026 补齐）

| 象征 | 定名 | 说明 |
| --- | --- | --- |
| 国家格言 | **「让每一代人，都有改变自己命运的机会」** | 1986 年宪法序言；刻于国家大会堂中厅门厅 |
| 国花 | **梅** | 开于寒时，喻"制度可以在坏年景里立住"；皇宫御花园与各州府衙前皆有 |
| 国树 | **柏** | 长安城墙内外行道树；"柏不改柯"，喻制度连续性 |
| 国鸟 | **鹤** | 见于渭河生态带与皇家园林；外交礼品常用鹤纹 |
| 纪年 | 公历行政、农历文化、皇帝年号用于历史／礼仪／皇室文书（如"公元 2026 年／继文十一年"） | 见《编年史》附三 |

### 4.1 勋章体系（三级）

| 等级 | 名称 | 授予对象 | 授予者 | 形制 |
| --- | --- | --- | --- | --- |
| 一等 | **金瓯勋章** | 于国家存续、宪制存续有极大功勋者；每年不超过 3 人 | 皇帝亲授 | 国徽缩小版＋金绶，佩于左胸 |
| 二等 | **龙纹勋章** | 军政、外交、抢险救灾中的卓著功勋 | 皇帝依政委会呈请授予 | 蟠龙纹章＋赤绶 |
| 三等 | **城垣勋章** | 基层治理、教育、医疗、工艺满二十年且考核优异者 | 州长／部长呈请，皇帝核准 | 城墙纹章＋素绶 |

> 三条口径：①**勋章与爵位脱钩**（爵位只意味身份、俸禄与礼遇，勋章只意味功勋）；②勋章不带来任何俸禄与职权，只带来礼遇与年金（一等年金另由《品级工资法》附表定）；③**不得买卖、不得继承**，受勋者身故后勋章由皇室典礼局收回存档。

## 五、三条禁令（写作用）

1. **不要把国旗写成"皇帝的旗"**：宪法法院 1991 年释例明确龙是国家的符号；写"这面旗是他家的"是政治错误，会被监察线盯上。
2. **不要给国歌改词**：可以写有人跑调、有人不开口、有人偷偷改一句——但制度上只有宪法修正案能改歌词，改动本身即政治事件。
3. **不要给勋章加权力**：受勋者不会因此升品级；写"他戴着金瓯勋章，所以能进常委会"是硬错。
