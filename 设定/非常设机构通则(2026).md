# 《非常设机构通则（2026）》

> **依据**：《中央政府组织法》第五条、《中央政治局组织法》第二条、《地方政府法》第二条。
> **适用**：专项工作组、联合调查组、指挥部、领导小组、规划编制组等一切跨部门、跨州、有期限的临时机构。
> **一句话**：非常设机构是「借用常设机构的权力，办一件常设机构办不成的事」，办完即散。

## 一、通则七条

| 条 | 事项 | 规定 |
| --- | --- | --- |
| 第一条 | **设立条件** | 四要件齐备方可设立：①事项跨两个以上部门或州；②任一常设机构无权独立完成；③任务可界定、可结项；④有明确期限。**不得以非常设机构替代常设机构日常职能**，不得设立无期限的工作组。 |
| 第二条 | **审批** | 中央层面由国务院、中央纪委、中央军委或八州政委会提出，报**中央政治局常委会**审议批准，以「中发〔年〕X号」或「国发〔年〕X号」行文；州级由州人民政治委员会常委会批准，报中央备案。**未经常委会批准的工作组，其调查与处分建议一律无效。** |
| 第三条 | **组长产生** | 一般由**归口常委**出任组长，对常委会直接负责；皇帝可**特派**他人出任组长（称「皇帝特派组长」），特派组长不受品级限制，但须指定一名归口常委为「联系常委」。经批准可「低配」：由归口部门正职（三品）或专案主办（四品）任组长，同时设联系常委。 |
| 第四条 | **成员抽调** | 从常设机构抽调，**原单位保留职务、编制、工资**，任务结束回原岗；抽调名单报中央组织委员会备案，一案一档，不对外公开。成员对组长负责，同时保留对本单位法定职责的独立报告权。 |
| 第五条 | **期限与撤销** | 一般六个月，最长十二个月；可延期一次，不超过六个月。到期未结项须书面说明，由常委会决定延期或撤销。**撤销即解散**：印章缴销、档案移交、经费决算，人员回原单位。 |
| 第六条 | **与常设机构关系** | 不设独立编制、不另立预算（经费由牵头部门列支）、不对外行文、不得代行常设机关职权；其结论须由有权机关依法定程序作出，**工作组本身无权处分、无权判决、无权批钱**。 |
| 第七条 | **监督** | 国家监委监督其成员履职，审计院审计其经费，国民议会可质询；工作组内部实行**多源交叉、互相制约**（审计、监察、检察、国安各走各的线，不得合并办案）。 |

**附则**：名称规范化——「××专项工作组」「××联合调查组」「××指挥部」「××领导小组」「××规划编制组」；**「委员会」为常设机构专用名，非常设机构不得称委员会**。

## 二、设立、延期与撤销流程

| 步 | 环节 | 谁来做 | 产出 |
| --- | --- | --- | --- |
| 1 | 立项 | 国务院、中央纪委、军委或州政委会 | 《设立请示》：事由、范围、期限、拟任组长 |
| 2 | 归口审核 | 中央办公厅＋中央组织委员会 | 是否与常设机构职能重叠、人员能否抽调 |
| 3 | 审议批准 | 中央政治局常委会 | 会议纪要＋文件号（中发／国发） |
| 4 | 行文 | 中央办公厅 | 红头文件，抄送政委会全体、议会专门委员会、两高、审计院、监委 |
| 5 | 组建进驻 | 组长 | 抽调名单备案、经费列支、印章启用（限内部） |
| 6 | 结项／撤销 | 常委会 | 结项报告、审计决算、档案移交、印章缴销 |

> 延期只走第 3 步（重新上会），不走第 1、2 步；撤销由常委会直接决定，组长无权自行解散。

## 三、实例：中发〔1990〕7号·华北专项工作组

> 出自小说《华北风暴》，作为**体例样板**收录，只列结构、不展开剧情。

| 项目 | 内容 |
| --- | --- |
| 文件 | 中发〔1990〕7号《关于开展扫黑除恶、查贪查腐专项斗争的决定》 |
| 时点 | 承宪十年（1990）三月；政治局常委会审议通过，中央政治委员会全票通过 |
| 性质 | 中央专项工作组（跨部门、跨州、有期限），适用本通则第一、二条 |
| 组长 | **顾峥**，中央纪委第五审查调查室主任（四品／正厅级）——**低配组长**体例 |
| 联系常委 | **秦简**（归口常委），工作组重大事项直接报其决定，不越级上会 |
| 成员 | **叶昭**（帝国审计院驻华北特派办）、**周以安**（最高人民检察院公诉厅）、**苏锐**（国家安全局第三局，明面身份为经济发展部借调） |
| 授权 | 中纪委调查权、审计院审计权、最高检公诉权在华北州境内合法行使；成员有自行调研权、紧急越级报告权 |
| 期限 | 原定六个月，经常委会批准延期（小说线未结项，故不写撤销日期） |
| 撤销 | 任务完成由常委会决定撤销；人员回原单位，档案移交中央档案馆 |
| 样板价值 | 四线并列（纪检、审计、检察、国安）＋低配组长＋联系常委，是「多源交叉」原则的标准编成 |

**为什么这样配**：顾峥品级不足以压住州长（三品），所以配联系常委补权威；四名成员分属四个互不隶属的系统，谁也不能单独结案，谁也不能单独压案——这正是通则第七条要防的事。

## 四、常用非常设机构类型表

| 类型 | 设立主体 | 组长 | 期限 | 典型成员 |
| --- | --- | --- | --- | --- |
| 专项工作组 | 中央政治局常委会（中发／国发） | 归口常委，或低配组长＋联系常委 | 6—12 个月 | 纪委、审计院、最高检、公安部、国安局、行业主管部门 |
| 联合调查组 | 国务院或中央纪委，报常委会备案 | 牵头部门主官（三品） | 3—6 个月 | 应急管理部、公安部、检察机关、纪检监察、技术专家 |
| 救灾指挥部 | 国务院；特别重大灾害经常委会 | 总理或分管副总理 | 至应急响应终止 | 应急管理部、军委联指、卫健委、交通运输部、民政部、财政部 |
| 换届领导小组 | 中央政治局常委会 | 中央组织委员会负责人（常委） | 6 个月（一个选举周期） | 中央组织委员会、中央纪委、国家监委、国民议会、地方政委会 |
| 规划编制组 | 国务院／中央财政经济委员会 | 国家发展改革委员会主任（三品） | 12—18 个月 | 发改委、财政部、国家统计局、科技部、工信部、地方代表 |

## 五、写作提示

1. **权力感来自授权范围，不来自人数**：写工作组，先写「它能调什么、不能调什么」，比写它有多少人有效。
2. **期限是悬念装置**：六个月到期、延期一次，天然形成倒计时；撤销日期一旦写明，故事就收尾了。
3. **组长品级决定他能压住谁**：三品组长压得住省，压不住州；四品组长必须配联系常委，这就是「低配」的戏眼。
4. **成员来源决定信息流**：四线并列时，每一条线都能独立发现一件事，但合起来才成证据链——这是帝国官场戏的基本结构。
5. **撤销与延期是政治表态**：延期＝上面还要查；撤销＝上面认为查完了；提前撤销＝上面不想查了。三种都能写成一章。

## 六、三条禁忌

- 不得让工作组直接抓人、封账、免职——那是公安、法院、任免机关的事，工作组只能「建议」。
- 不得让工作组自己审自己——成员涉案须由原单位另行立案，本人回避（《监察制度改革法》第四条）。
- 不得让工作组长期化——超过十二个月仍无结项报告，议会可依《中央议会法》第五条质询。

## 七、速查五问（写设定或写戏前自问）

| 问 | 答不上来说明 |
| --- | --- |
| 这件事为什么不能由某个部、某个州直接办？ | 设立条件第一条不成立，工作组没有存在理由 |
| 谁批准的？文号是什么？ | 授权链断裂，后面所有行动都不合法 |
| 组长几品？上面还有没有联系常委？ | 压不住人，戏就假 |
| 成员来自哪几条线？谁不能和谁合并办案？ | 丢掉「多源交叉」，变成单线办案 |
| 什么时候到期？到期会怎样？ | 没有倒计时，故事没有压力 |
