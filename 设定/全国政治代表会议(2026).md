# 《中华帝国全国政治代表会议（2026）》

> **性质**：治理者代表会议专卷。本会议为帝国治理者代表的全国会议，行使选举、确认中央政治委员会文职委员之权；代表以个人身份参加，不以组织名义提名或约束（与帝国「无党派」一致，见主表 G-08）。条文取自《设定集·对话推演比对与替换方案(2026-11)》§4.2（P-01 十二条），可随作者调整。
> **时点**：继文十一年（2026）。正式名**全国政治代表会议**，简称**政代会**；档案与届次编号用「第 X 届全国政治代表会议第 X 次会议」。
> **一句话**：政代会是帝国治理者的全国代表会议——**选举**中央政治委员会新任文职委员、**确认**其续任文职委员，并审议工作报告、确认换届；**不设委员长、不设常委会**，设主席一人，由中央政治委员会推举、皇帝任命。首届于 1986 年召开，与国民议会、中央政委会同步换届，每五年一届。

## 一、沿革：1986 年首届

| 时期 | 届次 | 说明 |
| --- | --- | --- |
| 帝国早期（1700—1985） | — | **无对应机构**。全国层只有中央政治委员会与旧制议会（约 440 席，见主表 G-05），治理者本身没有自己的代表会议 |
| **1986 年（宪制定型后）** | **第一届** | 大革命第三阶段宪制定型后召开首届会议，与第一届依宪国民议会、第九届中央政委会同期举行；此后每五年一届 |
| 2026 年（继文十一年） | **第九届** | 现行 |

> **届次口径**：政代会的届次自 1986 年首届起算，与依宪国民议会同届编号（2026 年为第九届，与第九届国民议会同年）；中央政治委员会另有其届次序列，两者不同源，不可混用。
>
> **宪法依据**：1986 年宪法原文列有专条，为不扰动既有引用，编次为**第十一条之二**（见《法律要目》宪法第三章）。组织法为《全国政治代表会议组织法》（1986）。

## 二、性质与定位：治理者的全国会议，行使选人与续期之权

1. **本会议是「治理者代表会议」**：与会者限于现职或曾任公职的治理者，以个人身份参加；选人的人本身就是被选出来做事的人——即所谓「内行选内行」。
2. **本会议行使选人与续期之权**：选举中央政治委员会新任文职委员、确认其续任文职委员，并审议工作报告、确认换届、审议组织法修正案、宣示国家方向（八项职权详见§四）。
3. **本会议以会议形式行使职权**：职权限于§四所列八项；法律、预算、条约事项依宪法归国民议会（720 席，见主表 G-04），行政事务依宪法归国务院。
4. **本会议的定位是人事正当性的授予与续期机关**：政委会文职委员第一次由本会议选举产生，第二次由本会议确认续期；本会议与中央政治委员会各依宪法行使职权。
5. **代表以个人身份参加**：不以组织名义提名，也不受组织约束；无党团、无党鞭；表决按议题临时结盟，跑票不算背叛（同议会惯例，见《国民议会(2026)》§三）。
6. **与议会的分工**：议会管「事」（法律、预算、条约），政代会管「人」（政委会文职委员的选与续）；两条线互不代行。

## 三、组成与代表产生

> **规模留白（2026 口径）**：代表名额按州人口分档推选，**具体名额由本会议组织法附表规定**。本轮先立机构与职能，规模待作者定，本卷不写人数。

代表来源分七类，比例为本轮建议值（合计 100%）：

| # | 代表来源 | 建议比例 | 产生方式 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 州政委会推选 | 40% | 八州政委会各自按州人口分档推选 | 州级治理者的主渠道 |
| 2 | 中央部委与直属机构 | 20% | 国务院组成部门与直属机构推选 | 中央执行层 |
| 3 | 军队系统 | 10% | 由中央军委系统推选 | **有表决权**，但不参与军职委员的产生（见§六） |
| 4 | 国民议会 | 10% | 由议会选举团产生 | 两会之间的通气渠道 |
| 5 | 基层优秀治理者 | 12% | 省、市、区（县）三级考核前列者推选 | 「从下面挑人」 |
| 6 | 科技教育界 | 5% | 政治学院系统与科教机构推选 | 专业口径 |
| 7 | 民族地区 | 3% | 民族自治地方政委会推选 | 保证民族地区有声 |
| | **合计** | **100%** | | |

**代表资格**：全部为现职或曾任公职的治理者；无党派；不以组织名义提名。**任期**：五年，随会议换届；连任限制另由组织法定（本轮未定）。

## 四、职权（八项）

1. **选举**中央政治委员会新任文职委员——当选者称**选举委员**。
2. **确认**中央政治委员会续任文职委员——经确认者称**当然委员**，续任确认须过半数。
3. **审议**中央政治委员会工作报告。
4. **确认**中央政治委员会换届。
5. **审议**《中央政治委员会组织法》修正案（须三分之二，见§五）。
6. **宣示**国家长期战略方向——皇帝出席并发表方向性讲话，不参与表决。
7. **背书**皇位继承确认程序（程序性背书，不代替宪法规定的确认程序）。
8. **审核**委员资格、**确认**届中出缺补选——出缺由中央政治委员会提名，提请政代会确认。

> **席位取得规则**：军事席位随军职取得，报政委会备案（见§六）；委员资格须挂在一项实职上，「一岗一人」，兼职不另计席。

## 五、会议与表决

| 项 | 规则 |
| --- | --- |
| 会期 | 每五年至少一次全体会议（换届会议）；必要时召开临时会议 |
| 法定人数 | 过半数代表到会方得开会 |
| 一般事项 | 出席代表过半数通过 |
| 续任确认 | 出席代表过半数通过 |
| 特别事项 | 《中央政治委员会组织法》修正案须**三分之二**通过 |
| 表决方式 | **秘密投票**（人事事项一律秘密投票，不记名、不留档个人票向） |
| 主席 | 一人，由中央政治委员会推举、皇帝任命；**不设委员长** |
| 常设机关 | **不设常委会**；闭会期间不另设常设机关 |
| 会址 | 长安国家大会堂（与议会全体会议同一殿堂，会期错开） |
| 届次 | 与国民议会同届编号，如「第九届全国政治代表会议第一次会议」 |

## 六、与政委会、议会、皇帝的职权划分

**（一）三方职权范围**

| 主体 | 职权范围 |
| --- | --- |
| **政代会** | 选举中央政治委员会新任文职委员；确认其续任文职委员；审议政治委员会工作报告；确认政治委员会换届；审议《中央政治委员会组织法》修正案；宣示国家长期战略方向；皇位继承确认程序之背书；委员资格审核与届中出缺补选之确认 |
| **国民议会** | 审议法律、预算、条约；质询与调查；审计归口（帝国审计院向议会常务委员会负责）；地方行政长官及重要部门正职之同意 |
| **中央政委会** | 决定日常政策；领导国务院；确定长期战略与五年规划；修宪确认；推举本会议主席、提名届中出缺补选人选 |

下列事项不列入本会议职权范围：法律、预算、条约之审议；国民议会组成之确认；日常政策之决定；对政府之质询；具体个案之处理；军职席位之选举与确认（依军职取得，报政委会备案）。

**（二）皇帝的位置**：出席政代会并发表方向性讲话，**不参与表决**；任命政代会主席、任命经选举或确认的委员。讲话属方向性宣示，不构成对个别人事表决的指示。

**（三）军事席位的特殊处理**：中央政委会军事席位（**陆海空三军种负责人 3、总政治部主任 1**）依军职取得，报政委会备案，本会议不作选举或确认。

| 席位类别 | 人数 | 资格来源 | 取得程序 |
| --- | --- | --- | --- |
| 陆海空三军种负责人 | 3 | 随军职取得 | 中央军委提名 → 皇帝以军委主席身份任命 → 报政委会备案 |
| 总政治部主任 | 1 | 随军职取得 | 中央军委提名 → 皇帝以军委主席身份任命 → 报政委会备案 |
| 军委副主席 | 2 | 凭政治局委员身份，经中央政委会选举 | 经中央政委会选举，与政代会无涉 |
| 八大军区司令 | — | **不任委员、不列席** | — |
| 三大舰队司令 | — | **不任委员、不列席** | — |
| 文职委员 | 按政委会列举式编制（共 74 席） | 选举／续任确认 | 经本会议选举或确认 |

> 军事系统在中央政治委员会**合计六席**：军委副主席二人＋三军种负责人三人＋总政治部主任一人。其中军种与总政四席随军职取得（中央军委提名 → 皇帝以军委主席身份任命 → 报政委会备案），**不经政代会选举或确认**；副主席二人的委员资格来自政治局委员身份，经中央政委会选举。**八大军区司令与三大舰队司令自 1986 年建制起既不任委员、亦不列席。**
>
> 人数合计：政代会选举/确认 74 ＋ 军委副主席 2 ＋ 军职自带 4 ＝ **政委会 80 席**（含主席皇帝在内计 1 席，故委员 79 人）。

## 七、文号与公报

- **文号**：政代会决议与行文用「**全政发〔年〕X号**」，与中央政委会的「政发〔年〕X号」、国务院文号分列，不得混用。
- **文书三类**：决议；确认书（选举委员、当然委员分别出具）；公报。
- **公报**：会后两小时内公布议题与结论；涉密事项只公布存在与范围，不公布内容（沿用政委会通报惯例）。
- **档案**：按「第 X 届全国政治代表会议第 X 次会议」立卷，与国民议会同届。

## 八、附则

1. **修正程序**：《全国政治代表会议组织法》由政代会**三分之二**通过、中央政委会**三分之二**确认、皇帝批准；修正程序同。
2. **主表登记**：主表 **G-10** 为全国政治代表会议预留序号；本轮仅立机构与职能，人数栏留白待补。
3. **与旧口径的关系**：《中央政治委员会组织法》第四条已于 2026 年 11 月按本卷口径改写——当然委员＝上一届选举委员经本届政代会确认续任者，职务只是取得选举委员身份的原因，委员资格不因职务自动取得（军职四席除外）。旧「当然委员资格随职务」之表述作废。
4. **闭会期间的空缺（补白）**：原方案曾拟设「全政会常务委员会」代行紧急人事空缺的提名与确认，作者本轮决定不设。故届中出缺只能由中央政委会提名、提请政代会**临时会议**确认，不得由政委会自行代行。此条为补白，待作者定。
5. **本轮未定事项**：代表总数、主席团、会期日程、表决方式的技术细节、代表连任限制。
