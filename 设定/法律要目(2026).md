# 《法律要目（2026）》

> **性质**：要目／摘要体例。本卷为条文要点摘编，供写作引用；条号为逻辑编号，全文另编。
> 体系：1986 年《中华帝国宪法》（十章四十二条）＋1981—1984 年七部组织法＋**2026 年《中央政治委员会组织法》**＋部门法与地方条例。
> **2026 修正**：继文十一年三月《政制调整案》修正宪法第六、十一、十二、十三条与《中央政治局组织法》第一、五条——皇帝不再兼任常委会委员长，改任中央政治委员会主席；政治委员会定为三品以上主官的全体会议。
> 标记：**【核心】**＝与《总设定 v2.0》《编年史》一致；**【推演】**＝按作者口径补足，可调整。

## 一、《中华帝国宪法》（1986）十章要点

### 第一章 总纲

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第一条 | 中华帝国是统一的国家；国家主权属于全国人民，由中央国家机关统一行使。 | 【核心】 |
| 第二条 | 帝国为中央集权型单一制；地方行政机关接受中央及上级行政机关领导，不享有主权性权力。 | 【核心】 |
| 第三条 | 皇帝为国家最高政治领导人；皇权为国家所有，皇帝依宪法行使。 | 【核心】 |
| 第四条 | 国家权力分政治、行政、立法、司法、监察、军事六系，各依法行使，不得兼任相互制衡之职。 | 【核心】 |
| 第五条 | 宪法为最高法；一切组织法、部门法、地方条例不得与宪法抵触，抵触者无效。 | 【核心】 |

### 第二章 皇帝

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第六条 | 皇帝为国家元首、最高政治领导人、武装力量最高统帅，兼任中央政治委员会主席、中央军事委员会主席；不设中央政治局常务委员会委员长，皇帝为政治局常委之一。 | 【核心】 |
| 第七条 | 皇帝行使六项元权力：战略权、最高人事权、最高政治协调权、最高国防政治权、国家安全最高决策权、国家象征与连续性权。 | 【核心】 |
| 第八条 | 皇帝对议会法案有否决权；否决应于十日内书面说明理由，议会得以三分之二多数再议。 | 【核心】 |
| 第九条 | 战争状态、紧急状态由皇帝依中央政治委员会审议宣布；紧急状态一次不超过六个月，延长须重新审议。 | 【核心】 |
| 第十条 | 皇帝不得绕过行政机关处理日常事务，不得越过军务系统调动基层部队，不得无理由否决法案。 | 【核心】 |

### 第三章 中央政治委员会与政治局

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第十一条 | 中央政治委员会由中央二品以上职务人员及三品以上主官组成，**具体构成由《中央政治委员会组织法》列举确定，不设数字上限**，为全国政治代表会议的常设机关，在政代会闭会期间代行其职责，皇帝任主席；职权含国家长期战略、五年规划、皇位继承确认、修宪确认、战争与和平、重大人事原则，并选举政治局委员；政治局选举常委，均报皇帝任命；每年至少举行一次全体会议。**委员资格由本会议选举（新任者称选举委员）或全国政治代表会议确认（续任者称当然委员）取得；军事系统代表（军委副主席二人、三军种负责人三人、总政治部主任一人）随军职取得，不经选举或确认。**（**2026.12 第三次修正**：删去"总数不超过八十人"；2026 年 12 月在任**八十人**） | 【核心】 |
| 第十一条之二 | **全国政治代表会议（1986 年宪法原文，为不扰动既有引用，本条编次于第十一条之后）**：全国政治代表会议是**国家最高领导机关**，由全国治理者代表组成；闭会期间其职责由中央政治委员会代行，每五年与国家议会、国务院、中央政治委员会同步换届（**首届 1986 年**）。职权：选举中央政治委员会新任文职委员（当选者称选举委员）、确认其续任文职委员（经确认者称当然委员）、审议政治委员会工作报告、确认其换届、审议《中央政治委员会组织法》修正案、宣示国家长期战略方向，并在皇位继承确认程序中提供广泛背书。**不审议法律、预算与条约，不确认国家议会组成。** 军事系统席位随军职取得，不由本会议选举或确认。州设**州政治代表会议**，每州一届，确认州委主席候选人、选举并确认州政治委员会文职委员；省、市、区（县）不设。 | 【核心】 |
| 第十二条 | 中央政治局由**二十七人**组成（含**九名**常委），为中央政治委员会的常设机关，在政委会闭会期间代行政委会职责（核心决策机关），审议政府重大政策、处理突发事件；六州州委主席不入局，京畿与江南两州州委主席与外交、国防、财政三部长入局。（继文改制：原"二十五人，含十一名常委"） | 【核心】 |
| 第十三条 | 中央政治局常务委员会是中央政治局的常设机关，在政治局闭会期间代行政治局职责，由**九人**组成，不设委员长；皇帝为常委之一，以中央政治委员会主席身份召集并主持常委会会议，**议程由皇帝确定**；**皇帝缺席时由国务院总理代为主持**，皇帝保留最终决定权；**六人到会方得开会，到会者过半数通过，因缺席平票时由皇帝裁定**；常委不排序，按职务分工，向中央政治局、中央政治委员会和皇帝负责； | 【核心】 |
| 第十四条 | 三级会议均以过半数为决议原则；宪法事项、皇位继承、重大人事依宪法特别多数。 | 【推演】 |

### 第四章 中央政府

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第十五条 | 中央政府（国务院）为最高国家行政机关，设二十二个组成部门（二十部、二委）。 | 【核心】 |
| 第十六条 | 国务院总理由皇帝提名、国家议会同意后任命；每年向议会提交国家年度治理报告。 | 【推演】 |
| 第十七条 | 国务院设**副总理四人、秘书长一人**；副总理按"块"分管（常务、政务·地方、经济、基建·社会），秘书长为三品·州部级。各部设部长一人、副部长二至四人；部长按三品州部级；入政治局者为政治局委员（二品），部长岗位为兼任三品岗；常委兼任者按一品。**（2026.12 第三次修正：副总理由"若干"定额为四人，增设秘书长）** | 【核心】 |
| 第十八条 | 机构增设、撤并、改名须经国家议会立法；不得以内部文件变更编制。 | 【推演】 |

### 第五章 国家议会

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第十九条 | 国家议会由七百二十名议员组成，席次按全国人口比例分配（最高余数法），任期五年；**帝国不设政党**，议员以个人身份当选、以个人名义表决。 | 【核心】 |
| 第二十条 | 议会行使立法权、预算审议权、监督权、调查权、质询权。 | 【核心】 |
| 第二十一条 | 议会设九个专门委员会；委员会有权要求政府官员到会说明、调阅不涉密材料。 | 【核心】 |
| 第二十二条 | 一般法案以过半数通过；宪法修正案须三分之二多数。 | 【核心】 |
| 第二十三条 | 议员在会期内言论与表决不受追究；非经议会许可不受逮捕，现行犯除外。 | 【推演】 |

### 第六章 司法

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第二十四条 | 司法权由法院依法独立行使，不受行政机关、社会团体和个人干涉。 | 【核心】 |
| 第二十五条 | 设最高法院、州高级法院、省（市）法院、区（县）法院四级；最高法院为终审机关。 | 【核心】 |
| 第二十六条 | 设帝国宪法法院，裁决法律合宪性、中央与地方权限争议、机构间权限争议；裁决为终局。 | 【核心】 |
| 第二十七条 | 检察机关依法独立行使公诉权，实行垂直领导，不受地方行政机关干涉。 | 【推演】 |

### 第七章 监察与审计

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第二十八条 | 中央纪律检查委员会与国家监察委员会为两个独立机关，分掌纪律检查权与公职监察权。 | 【核心】 |
| 第二十九条 | 监察机关依法独立履行监察职能，不受行政机关、社会团体和个人的干涉。 | 【核心】 |
| 第三十条 | 帝国审计院为最高财政监督机关，对国家议会负责，年度审计报告提交议会审议。 | 【核心】 |
| 第三十一条 | 审计院在八州设驻州特派办，垂直管理；被审计单位不得拒绝、拖延、谎报。 | 【核心】 |

### 第八章 地方制度

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第三十二条 | 全国设八州（含京畿直隶州）、四十五个省级行政单位（三十九省、六直辖市）。 | 【核心】 |
| 第三十三条 | 州、省、市、区（县）设人民政治委员会常务委员会与同级政府；街道设委员会与行政机构。 | 【核心】 |
| 第三十四条 | 州长、省长、市长由**上级政治委员会提名、本级议会同意**后任命；州长由中央政治委员会提名、州议会同意，皇帝任命；省长、市长由上一级政治委员会提名、本级议会同意，上一级政治委员会任命。任期内本级议会得以**三分之二多数**提出不信任案，报上级政治委员会确认，由上级决定免职或解散本级议会。地方议会不得自行任免地方行政长官。（2026.11 修正，原"地方行政长官由中央任命…不得单方面罢免"作废） | 【核心】 |
| 第三十五条 | 地方不得自行外交、建军、发行货币、征税设关或变更省界；地方条例不得抵触中央法律。 | 【核心】 |

### 第九章 民族自治

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第三十六条 | 少数民族聚居地区依法实行区域自治，设自治机关，行使自治权。 | 【核心】 |
| 第三十七条 | 自治条例、单行条例须报中央批准；自治不得损害国家统一与领土完整。 | 【推演】 |
| 第三十八条 | 国家对民族地区实行差别化财政转移支付与干部培养制度。 | 【推演】 |

### 第十章 修宪与皇位继承

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第三十九条 | 宪法修正案由议会三分之二多数通过，经中央政治委员会三分之二确认，皇帝批准后生效。 | 【核心】 |
| 第四十条 | 皇位继承以嫡长子优先，皇帝得废立；废立须经中央政治委员会备案并留下正式记录。 | 【核心】 |
| 第四十一条 | 皇储经「皇室提名—国家评议—皇帝最终确认」三层筛选；考核不合格者退出竞争，保留皇室身份。 | 【核心】 |
| 第四十二条 | 皇储继位前须完成国立中央政治学院与皇储国政教育院培养、担任过中央政治局委员；继位由宪法法院院长监誓。 | 【推演】 |

## 二、七部组织法各五条要点（1983—1984）

### 1.《中央政治局组织法》（1983）

| 条 | 要点 |
| --- | --- |
| 第一条 | 政治局由**二十七人**组成，含常委**九人**；政治局是中央政治委员会的常设机关，在政委会闭会期间代行政委会职责；不设委员长，政治局会议由皇帝以中央政治委员会主席身份召集并主持，常委会由皇帝召集，常委会是政治局的常设机关，在政治局闭会期间代行政治局职责。（2026.12 京畿、江南两州州委主席入局后为二十七人；旧稿"二十六人"作废） |
| 第二条 | 职权：审议政府重大政策、处理突发事件、协调中央机关、提出法律案、决定重大人事原则。 |
| 第三条 | 常委会每周例会，由皇帝召集并主持；皇帝缺席时由国务院总理代为主持。**六人到会方得开会，决议以到会者过半数通过**，可否决政府重大政策并书面说明理由；**议程由皇帝确定**。 |
| 第四条 | **不兼**：中央纪律检查委员会主席、国家监察委员会主席、帝国审计院院长、最高法院院长、最高检察院检察长、帝国宪法法院院长，**左列六职一人只得任其一，不得互相兼任**；所谓"兼任"，包括代理、署理与临时主持。 |
| 第五条 | 政治局委员与常委由中央政治委员会全体会议选举、皇帝任命，任期五年，连续任职不超过两届。**一品正国仅限常委会委员九人（含皇帝）**。 |
| 第六条 | 提名：委员候选人由皇帝提名，或十名以上中央政治委员会委员联名提名；全体会议无记名投票，过半数当选。 |
| 第七条 | 罢免与辞职：委员可书面辞职；罢免须政委会三分之一提议、三分之二通过，报皇帝批准；任内被监察立案者暂停出席。 |
| **第八条** | **归口（继文改制新增）**：最高法院、最高检察院的政治工作与干部协管归**中央政法委员会**领导，**个案审判与公诉不受干预**；帝国审计院对国家议会负责，归口**议会常务委员会**（主席由皇帝兼任）。常委会**不设常设列席**，需三长陈述时召开扩大会议，或由对应常委单独会见传达。 |

### 2.《中央政府组织法》（1983）

| 条 | 要点 |
| --- | --- |
| 第一条 | 国务院由总理、副总理四人、秘书长一人、各部部长、各委员会主任组成（**不设国务委员**，2026.12 定）；国务院常务会议由总理、副总理、秘书长组成。 |
| 第二条 | 设二十二个组成部门（二十部、二委），直属机构依法律另定。 |
| 第三条 | 总理提名、议会同意、皇帝任命；总理对议会负责并报告工作。 |
| 第四条 | 部委职责边界由本法附表规定；跨部门事项由国务院常务会议协调。 |
| 第五条 | 机构增设、撤并、改名须经议会立法，不得以内部文件变更编制。 |

### 3.《中央议会法》（1983）

| 条 | 要点 |
| --- | --- |
| 第一条 | 议会七百二十席，**按全国人口比例分配**：每州席次＝州人口÷全国人口×720，最高余数法取整；州内按省、省内地市逐级同法分配。 |
| 第二条 | 任期五年，每年会期不少于一百八十日；**议会常务委员会主席由皇帝兼任**（即国家议会常务委员会主席，不另计一品），议会常务委员会副主席四人**一律二品**，由全体会议选举、皇帝任命；**帝国审计院向议会常务委员会负责并报告工作**（继文改制归口条款）。 |
| 第三条 | 预算案须于财年开始前三十日通过；未通过者按上年预算十二分之一逐月执行。 |
| 第四条 | 议会常务委员会副主席为中央政治委员会**当然委员**（2026.12 修正，原为"列席"）；**议会不设党团**，专门委员会席次按州代表团人数比例分配，主任委员由全体会议选举、皇帝任命。**九个专门委员会主任自 2026.12 起为二品副国级**（岗位升格、称谓仍为"主任"），列席议会常委会。 |
| 第五条 | 议会可质询、组织调查委员会、传唤证人；调查权不得侵入司法个案。 |

### 4.《司法制度改革法》（1984）

| 条 | 要点 |
| --- | --- |
| 第一条 | 法院分四级，两审终审，最高法院为终审机关。 |
| 第二条 | 宪法法院法官九人，议会选举、皇帝任命，任期十二年，不得连任。 |
| 第三条 | 法官依法独立审判，**不受政法委个案干预**；非经弹劾或法定事由不得免职，薪酬不得削减。 |
| 第四条 | 检察机关垂直领导，检察官由最高检统一管理、统一调配；**其政治工作与干部协管受同级政法委领导，公诉个案不受干预**。 |
| 第五条 | 司法预算单列，由议会直接审议，不并入行政部门预算。 |

### 5.《监察制度改革法》（1984）

| 条 | 要点 |
| --- | --- |
| 第一条 | 中央纪委与国家监委分立：前者管纪律，后者管公职监察。 |
| 第二条 | 监察机关垂直领导，地方监察机关对上级监察机关负责。 |
| 第三条 | 可留置、调查、建议处分；限制人身自由须在四十八小时内报同级检察院备案。 |
| 第四条 | 监察人员实行回避与轮岗，不得在曾任职务的辖区办案。 |
| 第五条 | 年度监察报告向议会公开，涉密部分可闭门审议。 |
| 第六条 | **以组织形态干预任免、分配官位者，按「谋官」论处**；国家监委设关系图谱审查，可要求当事人就荐举关系、同乡同学关系作出书面说明，拒不如实说明者依情节处分。 |

### 6.《地方政府法》（1983）

| 条 | 要点 |
| --- | --- |
| 第一条 | 层级为州—省（市）—地级市—区（县）—街道，共五级。 |
| 第二条 | 各级设人民政治委员会常务委员会（政治领导）与政府（执行）。**州级常委会九席**：主席、副主席（政府首长）、副主席（政法委员会主任）、组织、纪委、监委、军区司令、秘书长、州委常委（兼州府所在省政委会主席，高配）；**副主席二人均称副主席，不分第一第二**；州高院、州检察归口州政法委员会，州审计厅归口州议会；省、市、区（县）各十一席：主席、副主席（政府首长）、副主席（政法委员会主任）、组织、纪委、监委、**宣传、统战**、秘书长、国防动员、府所在市（区、街道）主官；**三长归口同州级**——法院、检察归口政法委员会，审计归口议会，不占席位、不设常设列席。 |
| 第三条 | 地方行政长官的产生实行「**政治代表会议／上级政治委员会提名—本级议会同意—任命**」三段式（详见本章第三章第六条至第十三条），任期五年，定期进京述职。 |
| 第四条 | 地方预算经本级议会审议、报上级备案；中央有转移支付权与预算否决权。 |
| 第五条 | 京畿直隶州不设省级政府；其六直辖市为省级组织，由中央直管。 |

**第三章 任免程序（2026.11 新增，与宪法第三十四条配套）**

| 条 | 要点 |
| --- | --- |
| 第六条 | **提名**：上级政治委员会提名**差额二至三人**，随提名书附履历、考核结论、财产申报与提名理由；提名权专属上级政治委员会，组织部门只办手续，不得自行提名。 |
| 第七条 | **同意**：本级议会秘密投票，**过半数同意者当选**；议会可以拒绝，须于七日内书面说明理由；第一次拒绝后上级政治委员会十日内重新提名；**连续两次拒绝**，由上级政治委员会会同上级议会常务委员会裁决——或解散本级议会重选，或任命过渡首长至本届届满。 |
| 第八条 | **任命与备案**：任命书由有权机关颁发，报上级备案，任前公示七日；未走完同意程序的任命无效。 |

| 第十条 | **任内罢免**：本级议会得以**三分之二多数**通过对政府首长的不信任案，报上级政治委员会确认后免职；重要部门正职罢免同程序；一般部门领导罢免走组织部＋监察程序。 |
| 第十一条 | **空缺补选**：政府首长出缺，**必须由本级议会补选**，不得由组织部直接任命；重要部门正职出缺，仍走「上级提名＋议会同意」。 |
| 第十二条 | **垂直例外**：监察、审计、法院、检察、统计、税务、军队、国安不纳入地方提名选举，保持垂直或独立。 |
| 第十三条 | **基层受控差额选举**：最基层政府首长由上级提出**差额二至三名**候选人，公开政见书、接受选民质询、秘密投票过半数当选；无人过半则二轮投票；基层议会同步直选；任期五年，连任不超过两届；罢免须选民联署并经上级政治委员会确认。 |

## 二·补、《中央政治委员会组织法》（2026，十四条）

> 依据宪法第十一条制定；2026 年 3 月与《政制调整案》同日颁布。要点如下（要目，非全文）。

| 条 | 要点 |
| --- | --- |
| 第一条 | **性质与规模**：中央政治委员会是全国政治代表会议的常设机关，在政代会闭会期间代行其职责（全体会议层），由中央二品以上职务人员及三品以上主官组成，**具体构成依本法第二条列举，不设数字上限**（2026.12 修正，原"不超过八十人"删去）。 |
| 第二条 | **组成（列举式）**：政治局全体（27 人，含军委副主席二人）；副总理（非常务，3 人）；议会常务委员会副主席（非局，3 人）；国务院秘书长；六州州委主席（未入局）；京畿直隶州州长；国务院组成部门主官未入政治局者；中央政治口与直属机构主官（民宗委、网信委、巡视委、外事委四主任、统计局长——**财经委、政法委两主任已入政治局，不再另计**）；议会九专门委员会主任；**陆海空三军种负责人（3 人）；总政治部主任（1 人）**；帝国中央银行行长。**共 80 人**（2026.12；含主席皇帝在内计 1 席，故委员 78 人）。**军事系统代表合计六席**：军委副主席二人（委员资格来自政治局委员身份，经政治委员会选举）＋三军种负责人三人＋总政治部主任一人（后四席随军职取得）。 |
| 第三条 | **列席**：副职、专门委员会副主任、审计院特派办、七州州长、军事法院院长与军事检察院检察长列席全体会议，无表决权。**八大军区司令与三大舰队司令自 1986 年建制起既不任委员、亦不列席**（军方在政治委员会只保留六席：副主席二人、三军种负责人三人、总政治部主任一人）；原"三大舰队司令由列席改委员"之表述作废。 |
| 第四条 | **委员资格的取得（2026.11 口径）**：委员资格**不随职务自动取得**。新任者由全国政治代表会议**选举**其担任该职务，同时取得委员资格，称**选举委员**；上一届选举委员经本届全代会**确认续任**者，称**当然委员**。**军事系统四席（三军种负责人、总政治部主任）例外**：随军职取得，报政治委员会备案即可。**一岗一人**：兼职不另计席，亦不得以兼任填补新设岗位。**适用范围**：本条选举/确认二分仅适用于中央与州两级政治委员会；省、市、区（县）政治委员会不设政治代表会议，委员资格随职务，其职务按《地方政府法》第三章产生。 |
| 第五条 | **任期**：当然委员与选举委员任期均为五年，**同一职务连续任职不超过两届**；政治局委员、常委任期五年，连续任职不超过两届。**届满再选**：两届届满者卸去职务与委员席位，得以**普通候选人**身份参与当届原职位或更高职位的差额选举，当选者任期**重新起算**；不享受现任者特权（不优先发言、不自动列入候选人名单）。 |
| 第六条 | **主席**：皇帝任主席，召集并主持；皇帝出访、病重或皇位空缺时，由国务院总理代为主持；皇帝保留最终决定权。 |
| 第七条 | **会议**：全体会议每年至少一次（春季）；必要时召开临时会议；皇帝可召集扩大会议，列席范围由主席决定。 |
| 第八条 | **法定人数与表决**：过半数委员到会方得开会；一般事项过半数；修宪确认、皇位继承确认、重大人事原则须三分之二。**续任确认**：全国政治代表会逐一表决，出席代表过半数同意即续任；反对票超过三分之一者退回政治委员会重新提名审议一次。 |
| 第九条 | **递补**：委员席位因届满、退休、晋升、辞职、罢免而**出缺时，由本届全国政治代表会议补选，任期至本届届满**；闭会期间由中央政治委员会提名，提请政代会临时会议确认，下届追认。政治局委员出缺由政委会全体会议补选，常委出缺由政治局补选，均报皇帝任命。 |
| 第十条 | **回避**：审议涉及本人所在州、本部门、本军区之预算、人事、案件时回避表决，可陈述意见；回避不计入法定人数。 |
| 第十一条 | **文号与公开**：决议以「政发〔年〕X号」行文；《中央政治委员会通报》用于重大案件与人事；公报公布议题与结论，涉密事项不公布内容。 |
| 第十二条 | **办事机构**：会务由中央办公厅承办，不另设独立编制。 |
| 第十三条 | **与议会的关系**：议会常务委员会主席（皇帝兼）主持政委会；**议会常务委员会副主席为当然委员**（2026.12 修正，原为"列席"）；政委会每年听取议会年度报告，议会可书面质询委员（涉密除外）。 |
| 第十四条 | **修正**：本组织法由议会过半数通过、政委会三分之二确认、皇帝批准；修正程序同。 |
| 第十五条 | **候选人资格**（2026.11 新增）：委员候选人须先通过《高级职务任职资格法》的履历与品行门槛，由中央组织委员会与中央政治委员会联合审核；候选人名单于选举前公示七日，并报全国政治代表会议备案。 |
| 第十六条 | **差额选举**（2026.11 新增）：每一空缺职位须有**二至三名**候选人（含届满者以普通候选人身份参选），秘密投票、过半数当选；无人过半则二轮投票。 |
| 第十七条 | **军事席位**（2026.11 新增）：军委副主席二人、陆海空三军种负责人三人、总政治部主任一人，合计**六席**；其中军种与总政随军职取得（中央军委提名、皇帝以军委主席身份任命、报政治委员会备案），**不经全国政治代表会议选举或确认**；军委副主席的委员资格来自政治局委员身份，经政治委员会选举。八大军区司令与三大舰队司令**不任委员、不列席**。 |

## 二·补三、《政治学院法》（1986）要点

> 大革命宪制定型后第一部单行法。政委会 76:4 通过法律案 → 第一届议会 668:52 通过（1986.07.15）→ 穆宗批准公布（07.28）→ 09.01 施行。四十一年未经修正，与七部组织法并称「不动的法」。

| 条 | 要点 |
| --- | --- |
| 第一条（建制） | 政治学院分**中央、州立两级**：国立中央政治学院一所、州立政治学院八所。**省不设院**；原省立政治学院一律改设为州立政治学院的**省学区**，不具独立建制、不单独挂牌。 |

| 第三条（本科与学位） | 本科四年，授**学士**；设甲（治理）、乙（法政）、丙（财经）、丁（理论文献）四组十专业。 |
| 第四条（三级培训班） | 设基层干部培训班（**硕士**）、中级干部培训班（**博士**）、高级干部培训班（**博士后**）。帝国学位序列四级：学士、硕士、博士、博士后——「博士后」在本法为学位层级，与研究岗位分属不同序列。 |
| 第五条（选培生） | 设**中央选培生**与**地方（州）选培生**两轨。央选由中央组织委员会主持，一届二十五人左右，**三年直博**；州选由州委组织部主持，一州一年二十五人，三年授**硕士**。 |
| 第六条（程序） | 选培生须过**七关**：考试、政审（直系三代）、背调、征信、体检、面试、公示。 |
| 第七条（定级与免培） | 央选毕业定**一级吏长**，免基培、中培；州选毕业定**二级吏长**，免基培。二者均免「吏→官」的学院一年。 |
| 第八条（分配与服务期） | 央选按**原籍州优先**分配，州选在本州任职；均须服务满**八年**。 |
| 第九条（员额与级别） | 中央政治学院校长**三品**（可由二品以上者高配兼任）；州立政治学院校长**四品**，由州委常委（组织部长）兼任；省学区主任**七品**。
| 第十条（与宪法之关系） | 皇储依宪法第四十二条完成中央政治学院与高培培养，**不受选培与年限条款约束**。 |

## 二·补四、《品级工资法》（2026）要点

> 定位：把「品级待遇」从等位对照落成工资口径，与品级职权彻底分开。适用于文官十品、吏三等及比照执行的人员；武官按军衔另表比照。

| 条 | 内容 |
| --- | --- |
| 第一条（构成） | 工资由**月薪、年终绩效、津补贴**三部分构成；另有**综合工资**口径，＝年薪加单位缴纳的五险一金与职业年金（约 30%），用于统计与预算，不作为发放科目。 |
| 第二条（发放） | 月薪按月发放，年终绩效全员**统一两个月**薪额，津补贴限住房、交通、通讯办公三项；**取消专车**，公务出行按品级发车补，仅机要、警卫两类保留特种用车。 |
| 第三条（级差） | 相邻两级月薪约 1.1 倍；一品与吏三之比不超过 6 倍；**吏三实发不低于当地社会平均工资**，每两年随社平工资调整一次。 |
| 第四条（调整） | 具体数额由本法附表逐年核定，随年度预算一并公布；调整须经国家议会审议、中央政治委员会确认、皇帝批准。 |
| 第五条（待遇与权力分离） | 工资待遇只定用度与保障，**不含任何职权**。享受某品待遇而不具该品职权者（议会议员、荣誉职等），文书只写「享受某品待遇」，不得称「某品官」，不着官服、不入品级排序。 |
| 第六条（不可折现） | 周转公寓、公务用车、办公用房与秘书配置属履职条件，离任即退；不得折现、继承、转让或抵押。 |
| 第七条（兼职与议员工资） | 国家议会议员按**五品**待遇，州议会**七品**，省议会**九品**且可半专职（按 60% 计发）；市、区（县）议会议员为兼职，只发**议员补贴＋会议与差旅津贴**，不计入社保缴费基数，缺席不补。议员离任即停发，不设议员退休金。 |

## 二·补五、《刑法》（2026 汇编）要点

> 定位：帝国第一部完整刑法典（1987 年施行，2026 年汇编本）。此前全库只有"有法院、有死刑"这样的机构事实，没有一部管老百姓的法。全典 452 条，此处列八条骨节。

| 条 | 内容 |
| --- | --- |
| 第一条（罪刑法定） | 法无明文规定不为罪、不处罚；**禁止类推**；空白罪状须有法律或行政法规依据。 |
| 第二条（刑罚种类） | 主刑：管制、拘役、有期徒刑、无期徒刑、死刑；附加刑：罚金、剥夺政治权利、没收财产。有期徒刑单罪上限 15 年，数罪并罚不超过 25 年。 |
| 第三条（死刑） | **保留但极窄**：限于故意杀人、叛国与武装叛乱、数额特别巨大且情节特别严重的贪腐、危害国家安全造成特别严重后果四类；**复核权专属最高法院**；不公开处决、不示众；年适用数逐年下降，2026 年全年核准不足百人【推演】。 |
| 第四条（贪腐罪） | 受贿、贪污、挪用公款、私分国有资产、**以圈谋官**（以非正式关系谋取职务）五罪并列；按数额与情节分三档；一律并处追缴与罚金，**不得以退赃免刑**。 |
| 第五条（危害国家安全） | 煽动暴力推翻宪制、分裂国家、间谍、泄露国家秘密四类入罪；**批评政策、批评皇帝、主张进一步议会化不构成犯罪**（宪法第二条例外条款：公民有批评国家机关与公职人员的权利）。此条界线由宪法法院 1991 年释例划定。 |
| 第六条（未成年人） | 不满 14 周岁不负刑事责任；14—16 周岁仅对八类重罪负责；16 周岁以上全责；**未成年人不适用死刑、不公开审理、犯罪记录封存**。 |
| 第七条（单位犯罪） | 企业行贿、数据造假、环境违法、重大安全责任事故可罚单位：罚金、停业、吊销许可，并罚直接责任人。 |
| 第八条（时效与赦免） | 追诉时效 5—20 年（最高刑为无期、死刑者 20 年）；**特赦由皇帝依议会决议发布**，1986 年后仅两次（1990 年经济案、2016 年建国纪念）。 |

## 二·补六、《民法典》（2026）要点

> 定位：民事基本法，七编（总则、物权、合同、人格权、婚姻家庭、继承、侵权责任），共 1,264 条。列十条骨节。

| 条 | 内容 |
| --- | --- |
| 第一条（平等与自愿） | 民事主体地位平等；财产权受平等保护；自愿、公平、诚实信用、公序良俗四原则。 |
| 第二条（主体） | 自然人权利能力始于出生、终于死亡；法人为营利法人、非营利法人、特别法人（机关、自治地方、皇室财产管理法人）；非法人组织含合伙与个人独资。 |
| 第三条（物权） | 所有权、用益物权（土地承包经营权、建设用地使用权、宅基地使用权、**居住权**）、担保物权；不动产登记生效。 |
| 第四条（土地） | 城市土地国家所有；农村与牧区土地集体所有；承包经营权 30 年、到期可续；宅基地一户一宅、不得向城市居民出售。 |
| 第五条（合同） | 契约自由与强制缔约例外（公用事业、医疗急救）；电子合同与数字元支付具同等效力；格式条款不利解释。 |
| 第六条（人格权） | 姓名、肖像、名誉、荣誉、隐私、**个人信息**独立成编；处理个人信息须告知—同意，国家机关处理须有法律依据。 |
| 第七条（婚姻家庭） | 一夫一妻、男女平等；婚龄男 22、女 20（实际初婚年龄男 29、女 27，见主表 K-06）；夫妻共同财产；**离婚冷静期 30 日**；子女最佳利益原则。 |
| 第八条（继承） | 法定继承两顺序；遗嘱形式五种（自书、代书、打印、录音录像、公证）；**遗产管理人**制度；特留份保护未成年与无劳动能力继承人。 |
| 第九条（侵权） | 过错责任为原则；无过错责任限于高危作业、产品责任、医疗损害、环境污染、饲养动物；**AI 致害由运营者承担，可向开发者追偿**。 |
| 第十条（算法特别条） | 算法不得代替法定决定；自动化决定须可解释、可人工复核、可申诉；因算法歧视受损的，举证责任倒置。 |

## 二·补七、《刑事诉讼法》《民事诉讼法》要点

> 定位：两大程序法（1987 年施行，2026 年修订）。此处各列五条。

**《刑事诉讼法》**

| 条 | 内容 |
| --- | --- |
| 一（基本原则） | 两审终审、审判公开（涉密、涉未成年、涉隐私除外）、**辩护权自第一次讯问起**、不得强迫自证其罪。 |
| 二（强制措施） | 拘传、取保候审、监视居住、拘留、逮捕；**拘留后 24 小时内须通知家属**；羁押必要性每两个月审查一次。 |
| 三（证据） | **非法证据排除**；仅有口供不得定罪；技术侦查须经省级以上批准。 |
| 四（期限） | 侦查羁押一般 2 个月，可依法延长至 7 个月；一审 3 个月、二审 2 个月。 |
| 五（特别程序） | 未成年人、精神病人强制医疗、缺席审判（贪腐外逃）、**涉案财物追缴**四类特别程序。 |

**《民事诉讼法》**

| 条 | 内容 |
| --- | --- |
| 一（基本原则） | 处分原则、辩论原则、**调解优先**；小额诉讼一审终审。 |
| 二（管辖） | 基层法院管辖一审；中级管辖重大涉外与标的大案；**约定管辖**有效。 |
| 三（程序） | 简易程序 3 个月、普通程序 6 个月；电子送达与在线庭审具同等效力。 |
| 四（执行） | 执行时效 2 年；失信被执行人名单；**执行不能**可申请司法救助。 |
| 五（公益诉讼） | 环境、消费者权益、**数据与个人信息**三类公益诉讼；检察机关可提起。 |

## 二·补八、《选举法》（1986 年制；2026 修订）要点

> 定位：议会 720 席与各级议会选举的基本法。此前只有"按人口比例分配"一句，没有选民资格、提名与争议裁决。

| 条 | 内容 |
| --- | --- |
| 第一条（选举权） | 年满 18 周岁的帝国公民，**除被依法剥夺政治权利者外**，不分民族、性别、职业、财产、教育程度，均有选举权。 |
| 第二条（被选举权） | 议员候选人须年满 25 周岁、无故意犯罪记录、在本选区居住或工作满一年；**不要求任何组织提名**。 |
| 第三条（选区） | 按人口划分，每选区选 1—3 名；720 席按八州人口比例分配（54／128／248／94／113／23／44／16，见主表 G-04）；每十年重划一次。 |
| 第四条（提名） | 选民联署（选区选民 1% 以上）或法定团体提名；**无政党提名、无党团登记**；候选人平等使用公共媒体时段。 |
| 第五条（投票） | 无记名、一人一票；数字元身份验证后电子投票，**纸质选票为最终计票凭证**；投票日放假。 |
| 第六条（计票） | 当场开票、观察员在场、24 小时内公布结果；争议由**选举委员会**裁定，不服可诉至法院，法院裁决为终局。 |
| 第七条（罢免） | 原选区选民 1/3 联署可提罢免案，过半数投票且同意票过半即罢免；**罢免不得在任满前一年内提起**。 |
| 第八条（经费） | 竞选经费公开、单人上限；超过上限者当选无效；**买票入刑**（《刑法》第四条之一）。 |

## 二·补九、《劳动基准法》（1988）要点

> 定位：工时、工资、休假、解雇的最低标准；与《品级工资法》分工——后者管官员，前者管劳动者。

| 条 | 内容 |
| --- | --- |
| 第一条（工时） | 每日 8 小时、每周 40 小时；**四天工作制试点**由国务院授权，限于 AI 替代率高的行业（见《市井与物价(2026)》§六）。 |
| 第二条（加班） | 平日 1.5 倍、休息日 2 倍、法定节假日 3 倍；每月上限 36 小时；**加班须书面同意**。 |
| 第三条（最低工资） | 全国底线 **5,600 元／月**（主表 E-06），各省可上浮不超过 30%；每两年随社平工资调整。 |
| 第四条（休假） | 年假 10／15／20 天（按工龄）；产假 180 天、陪产假 30 天、育儿假每年 10 天至子女 3 岁；**年假不得以工资替代**。 |
| 第五条（解雇） | 须有法定事由；经济性裁员须提前 30 日通知并报劳动部门；违法解雇双倍赔偿。 |
| 第六条（争议） | 协商—调解—仲裁—诉讼四级；仲裁为诉讼前置；**未经程序停工视为违约**，但不得因此追究刑事责任。 |

## 二·附三、大革命配套四法（1986 年制；2026.11 补录要目）

> 与七部组织法同属 1986 年大革命成果，首届均在 1986 年宪制定型后举行。此前本库只记七部组织法，此四法为补录，条文序号沿用各法原序。

### 1.《全国政治代表会议组织法》（1986）

| 条 | 要点 |
| --- | --- |
| 第一条（性质） | 全国政治代表会议为国家最高领导机关，由治理者代表组成，行使选举、确认中央政治委员会文职委员之权；闭会期间其职责由中央政治委员会代行；代表以个人身份参加，不以组织名义提名或约束。 |
| 第二条（任期） | 每五年一届，与国家议会、国务院、中央政治委员会同步换届；**首届 1986 年**。 |
| 第三条（代表产生） | 按系统推选：州政治委员会、中央部委与直属机构、军队系统（由中央军委系统推选，**有表决权，但不参与军职委员的产生**）、国家议会（选举团）、基层优秀治理者、科技教育界、民族地区。**具体名额按州人口分档，由本法附表规定。** |
| 第四条（会议主持） | 职权以全体会议形式行使；会议由皇帝以中央政治委员会主席身份召集并主持，皇帝不参与表决；会务由中央办公厅兼办。 |
| 第五条（职权） | 选举新任文职委员／确认续任文职委员／审议政治委员会工作报告／确认换届／审议《中央政治委员会组织法》修正案／宣示国家方向／皇位继承确认之广泛背书。 |
| 第六条（表决） | 一般事项出席代表过半数；《中央政治委员会组织法》修正案三分之二；续任确认过半数，反对票过三分之一者退回重审一次；秘密投票。 |
| 第七条（边界） | 本会议职权限于选举、确认中央政治委员会文职委员及第五条所列事项；法律、预算、条约之审议归国家议会，日常政策、对政府之质询与个案处理归政治委员会与国务院。 |
| 第八条（文号） | 「全政发〔年〕X号」；公报于会后两小时内公布议题与结论。 |
| 第九条（修正） | 本法由全国政治代表会议三分之二通过、政治委员会三分之二确认、皇帝批准。 |

### 2.《州政治代表会议组织法》（1986）

| 条 | 要点 |
| --- | --- |
| 第一条（性质与届次） | 州级治理者代表会议，八州各设一届，与州政治委员会、州议会同步换届；**首届 1986 年**。 |
| 第二条（代表产生） | 州内各省市县政治委员会、州级部门、驻军、州议会、基层优秀治理者、科教与民族界推选；名额按州人口分档，由本法附表规定。 |
| 第三条（职权） | 选举州政治委员会新任文职委员、确认续任；**确认州委主席候选人**（由中央政治委员会提名）；审议州政治委员会工作报告；宣示本州方向；确认换届。 |
| 第四条（与中央的关系） | 州委主席候选人由中央政治委员会提名、州代会确认，非自由选举；州政治委员会常委会选举结果报中央政治委员会批准。 |
| 第五条（军事席位） | 州军区司令一席随军职取得，不由州代会选举或确认，报州政治委员会备案。 |
| 第六条（不设政代会的层级） | 省、市、区（县）不设政治代表会议，其政治委员会走「上级提名＋本级议会确认＋组织部任命」。 |
| 第七条（边界与文号） | 州预算与州法规之审议归州议会；州政委会组成由州代会确认；文号「州政发〔年〕X号」。 |

| 卫生部长 | 5 年以上医疗卫生管理或临床经历 |
| 政法委员会主任 | 5 年以上政法工作经历；有司法或公安经历者优先 |
| 州委主席／州长 | 5 年以上省级或州级治理经历；有跨省任职经历者优先 |
| **所有高级职务** | 无违法犯罪记录；无未撤销处分；通过政审（直系三代）；财产申报合规 |

> **审核**：中央组织委员会与中央政治委员会联合审核（前者查履历年限与处分，后者查政审与财产申报），结果报全国政治代表会议备案；候选人名单选举前公示七日。本法管"担任某职"的门槛，与《政治学院法》管"成为干部"的入口互为两关。

### 4.《换届程序法》（1986）

| 条 | 要点 |
| --- | --- |
| 第一条（同步换届） | 全国政治代表会议、国家议会、中央政治委员会、国务院**五年一届、同步换届**；州级同。 |
| 第二条（换届周） | 换届于长安国家大会堂集中举行，**七日内完成**：第 1 日双会开幕与皇帝讲话；第 2—3 日政代会确认与提名、议会审议；第 4 日政代会选举并产生政治局与常委；第 5 日皇帝于紫光阁确认与提名；第 6 日议会信任投票；第 7 日联合闭幕、皇帝发表《告国人书》。 |
| 第三条（僵局） | 设**七十二小时加时调解期**：皇帝协调、政委会与议会领导层重提折中名单后再表决；同一人选连续两次被否决，报政委会与议会常委会联合裁决；换届须于三十日内完成，逾期由皇帝径行任命过渡班子。 |
| 第四条（发布） | 闭幕后官方媒体头版发布新一届名单，同步刊发「政发〔年〕X号」「国发〔年〕X号」。 |

## 三、法律位阶与冲突解决

| 位阶 | 规范形式 | 制定／批准 | 冲突时 |
| --- | --- | --- | --- |
| 1 | 宪法 | 议会 2/3＋政治委员会 2/3＋皇帝批准 | 最高，一切下位法不得抵触 |
| 2 | 组织法（七部＋2026 政委会组织法） | 国家议会；**《中央政治委员会组织法》另需政委会 2/3 确认**（其第十四条） | 与部门法冲突时优先 |
| 3 | 部门法 | 国家议会 | 与行政法规冲突时优先 |
| 4 | 行政法规、部门规章 | 国务院 | 不得抵触法律 |
| 5 | 地方条例 | 地方议会通过、报中央批准 | 不得抵触中央法律 |

**冲突解决五规则**

1. 下位法抵触上位法者无效，由宪法法院宣告。
2. 同位阶：特别法优于一般法，新法优于旧法。
3. 中央与地方权限争议（含预算权限）由宪法法院裁决——1988 年「州诉中央预算权限案」为首案。
4. 机构间权限争议（如审计院与财政部、监委与检察院）由宪法法院裁决，政治委员会不代裁。
5. 皇帝否决的法案，议会以三分之二多数再议通过后生效；紧急状态下的特别法令，须于状态终止后六十日内提交议会追认。
