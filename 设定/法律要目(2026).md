# 《法律要目（2026）》

> **性质**：要目／摘要，不是法律全文。条号为逻辑编号，供写作引用；全文另编。
> 体系：1986 年《中华帝国宪法》（十章四十二条）＋1981—1984 年七部组织法＋**2026 年《中央政治委员会组织法》**＋部门法与地方条例。
> **2026 修正**：继文十一年三月《政制调整案》修正宪法第六、十一、十二、十三条与《中央政治局组织法》第一、五条——皇帝不再兼任常委会委员长，改任中央政治委员会主席；政治委员会定为三品以上主官的全体会议；政治局由二十八人减为二十四人，外交、国防、财政三部长入局。
> 标记：**【核心】**＝与《总设定 v2.0》《编年史》一致；**【推演】**＝按作者口径补足，可调整。

## 一、《中华帝国宪法》（1986）十章要点

### 第一章 总纲

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第一条 | 中华帝国是统一的国家；国家主权属于全国人民，由中央国家机关统一行使。 | 【核心】 |
| 第二条 | 帝国为中央集权型单一制；地方行政机关接受中央及上级行政机关领导，不享有主权性权力。 | 【核心】 |
| 第三条 | 皇帝为国家最高政治领导人；皇权属于国家，不属于皇帝个人。 | 【核心】 |
| 第四条 | 国家权力分政治、行政、立法、司法、监察、军事六系，各依法行使，不得兼任相互制衡之职。 | 【核心】 |
| 第五条 | 宪法为最高法；一切组织法、部门法、地方条例不得与宪法抵触，抵触者无效。 | 【核心】 |

### 第二章 皇帝

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第六条 | 皇帝为国家元首、最高政治领导人、武装力量最高统帅，兼任中央政治委员会主席、中央军事委员会主席；不设中央政治局常务委员会委员长，皇帝为政治局常委之一。 | 【核心】 |
| 第七条 | 皇帝行使六项元权力：战略权、最高人事权、最高政治协调权、最高国防政治权、国家安全最高决策权、国家象征与连续性权。 | 【核心】 |
| 第八条 | 皇帝对议会法案有否决权；否决应于十日内书面说明理由，议会得以三分之二多数再议。 | 【核心】 |
| 第九条 | 战争状态、紧急状态由皇帝依中央政治委员会审议宣布；紧急状态一次不超过六个月，延长须重新审议。 | 【核心】 |
| 第十条 | 皇帝不得绕过行政机关处理日常事务，不得越过军务系统调动基层部队，不得无理由否决法案。 | 【核心】 |

### 第三章 中央政治委员会与政治局

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第十一条 | 中央政治委员会由三品以上主官组成，总数不超过八十人（2026 年在任七十九人），为国家最高政治领导机关，皇帝任主席；职权含国家长期战略、五年规划、皇位继承确认、修宪确认、战争与和平、重大人事原则，并选举政治局委员与常委、报皇帝任命；每年至少举行一次全体会议。 | 【核心】 |
| 第十二条 | 中央政治局由二十四人组成（含十一名常委），为核心决策机关，审议政府重大政策、处理突发事件；七州州委主席不入政治局，京畿直隶州州委主席与外交、国防、财政三部长入局。 | 【核心】 |
| 第十三条 | 中央政治局常务委员会由十一人组成，不设委员长；皇帝为常委之一，以中央政治委员会主席身份召集并主持常委会会议；**皇帝缺席时由国务院总理代为主持**，皇帝保留最终决定权；常委不排序，按职务分工，向中央政治局、中央政治委员会和皇帝负责。 | 【核心】 |
| 第十四条 | 三级会议均以过半数为决议原则；宪法事项、皇位继承、重大人事依宪法特别多数。 | 【推演】 |

### 第四章 中央政府

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第十五条 | 中央政府（国务院）为最高国家行政机关，设二十二个组成部门（二十部、二委）。 | 【核心】 |
| 第十六条 | 国务院总理由皇帝提名、国民议会同意后任命；每年向议会提交国家年度治理报告。 | 【推演】 |
| 第十七条 | 各部设部长一人、副部长二至四人；部长按三品州部级，入政治局者按二品高配，常委兼任者按一品高配。 | 【核心】 |
| 第十八条 | 机构增设、撤并、改名须经国民议会立法；不得以内部文件变更编制。 | 【推演】 |

### 第五章 国民议会

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第十九条 | 国民议会由七百二十名议员组成，席次按全国人口比例分配（最高余数法），任期五年；**帝国不设政党**，议员以个人身份当选、以个人名义表决。 | 【核心】 |
| 第二十条 | 议会行使立法权、预算审议权、监督权、调查权、质询权。 | 【核心】 |
| 第二十一条 | 议会设九个专门委员会；委员会有权要求政府官员到会说明、调阅不涉密材料。 | 【核心】 |
| 第二十二条 | 一般法案以过半数通过；宪法修正案须三分之二多数。 | 【核心】 |
| 第二十三条 | 议员在会期内言论与表决不受追究；非经议会许可不受逮捕，现行犯除外。 | 【推演】 |

### 第六章 司法

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第二十四条 | 司法权由法院依法独立行使，不受行政机关、社会团体和个人干涉。 | 【核心】 |
| 第二十五条 | 设最高法院、州高级法院、省（市）法院、区（县）法院四级；最高法院为终审机关。 | 【核心】 |
| 第二十六条 | 设帝国宪法法院，裁决法律合宪性、中央与地方权限争议、机构间权限争议；裁决为终局。 | 【核心】 |
| 第二十七条 | 检察机关依法独立行使公诉权，实行垂直领导，不受地方行政机关干涉。 | 【推演】 |

### 第七章 监察与审计

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第二十八条 | 中央纪律检查委员会与国家监察委员会为两个独立机关，分掌纪律检查权与公职监察权。 | 【核心】 |
| 第二十九条 | 监察机关依法独立履行监察职能，不受行政机关、社会团体和个人的干涉。 | 【核心】 |
| 第三十条 | 帝国审计院为最高财政监督机关，对国民议会负责，年度审计报告提交议会审议。 | 【核心】 |
| 第三十一条 | 审计院在八州设驻州特派办，垂直管理；被审计单位不得拒绝、拖延、谎报。 | 【核心】 |

### 第八章 地方制度

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第三十二条 | 全国设八州（含京畿直隶州）、四十五个省级行政单位（三十九省、六直辖市）。 | 【核心】 |
| 第三十三条 | 州、省、市、区（县）设人民政治委员会常务委员会与同级政府；街道设委员会与行政机构。 | 【核心】 |
| 第三十四条 | 地方行政长官由中央任命，经地方考察、议会监督；地方议会不得单方面罢免。 | 【核心】 |
| 第三十五条 | 地方不得自行外交、建军、发行货币、征税设关或变更省界；地方条例不得抵触中央法律。 | 【核心】 |

### 第九章 民族自治

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第三十六条 | 少数民族聚居地区依法实行区域自治，设自治机关，行使自治权。 | 【核心】 |
| 第三十七条 | 自治条例、单行条例须报中央批准；自治不得损害国家统一与领土完整。 | 【推演】 |
| 第三十八条 | 国家对民族地区实行差别化财政转移支付与干部培养制度。 | 【推演】 |

### 第十章 修宪与皇位继承

| 条 | 要旨 | 性质 |
| --- | --- | --- |
| 第三十九条 | 宪法修正案由议会三分之二多数通过，经中央政治委员会三分之二确认，皇帝批准后生效。 | 【核心】 |
| 第四十条 | 皇位继承以嫡长子优先，皇帝得废立；废立须经中央政治委员会备案并留下正式记录。 | 【核心】 |
| 第四十一条 | 皇储经「皇室提名—国家评议—皇帝最终确认」三层筛选；考核不合格者退出竞争，保留皇室身份。 | 【核心】 |
| 第四十二条 | 皇储继位前须完成国立中央政治学院与皇储国政教育院培养、担任过中央政治局委员；继位由宪法法院院长监誓。 | 【推演】 |

## 二、七部组织法各五条要点（1983—1984）

### 1.《中央政治局组织法》（1983）

| 条 | 要点 |
| --- | --- |
| 第一条 | 政治局由二十四人组成，含常委十一人；不设委员长，常委会由皇帝召集，为日常最高协调机关。 |
| 第二条 | 职权：审议政府重大政策、处理突发事件、协调中央机关、提出法律案、决定重大人事原则。 |
| 第三条 | 常委会每周例会，由皇帝召集并主持；皇帝缺席时由国务院总理代为主持。决议以过半数通过，可否决政府重大政策并书面说明理由。 |
| 第四条 | 政治局委员不得兼任纪委、监委、审计院、最高法院等制衡机关主官。 |
| 第五条 | 政治局委员与常委由中央政治委员会全体会议选举、皇帝任命，任期五年，连续任职不超过两届。 |
| 第六条 | 提名：委员候选人由皇帝提名，或十名以上中央政治委员会委员联名提名；全体会议无记名投票，过半数当选。 |
| 第七条 | 罢免与辞职：委员可书面辞职；罢免须政委会三分之一提议、三分之二通过，报皇帝批准；任内被监察立案者暂停出席。 |

### 2.《中央政府组织法》（1983）

| 条 | 要点 |
| --- | --- |
| 第一条 | 国务院由总理、副总理若干、国务委员若干、各部部长、各委员会主任组成。 |
| 第二条 | 设二十二个组成部门（二十部、二委），直属机构依法律另定。 |
| 第三条 | 总理提名、议会同意、皇帝任命；总理对议会负责并报告工作。 |
| 第四条 | 部委职责边界由本法附表规定；跨部门事项由国务院常务会议协调。 |
| 第五条 | 机构增设、撤并、改名须经议会立法，不得以内部文件变更编制。 |

### 3.《中央议会法》（1983）

| 条 | 要点 |
| --- | --- |
| 第一条 | 议会七百二十席，**按全国人口比例分配**：每州席次＝州人口÷全国人口×720，最高余数法取整；州内按省、省内地市逐级同法分配。 |
| 第二条 | 任期五年，每年会期不少于一百八十日；**议长由皇帝兼任**（即中央议会常务委员会主席），副议长四人，由全体会议选举、皇帝任命。 |
| 第三条 | 预算案须于财年开始前三十日通过；未通过者按上年预算十二分之一逐月执行。 |
| 第四条 | 副议长列席中央政治委员会（议长由皇帝兼任，即政委会主席）；**议会不设党团**，专门委员会席次按州代表团人数比例分配，主任委员由全体会议选举、皇帝任命。 |
| 第五条 | 议会可质询、组织调查委员会、传唤证人；调查权不得侵入司法个案。 |

### 4.《司法制度改革法》（1984）

| 条 | 要点 |
| --- | --- |
| 第一条 | 法院分四级，两审终审，最高法院为终审机关。 |
| 第二条 | 宪法法院法官九人，议会选举、皇帝任命，任期十二年，不得连任。 |
| 第三条 | 法官依法独立审判；非经弹劾或法定事由不得免职，薪酬不得削减。 |
| 第四条 | 检察机关垂直领导，检察官由最高检统一管理、统一调配。 |
| 第五条 | 司法预算单列，由议会直接审议，不并入行政部门预算。 |

### 5.《监察制度改革法》（1984）

| 条 | 要点 |
| --- | --- |
| 第一条 | 中央纪委与国家监委分立：前者管纪律，后者管公职监察。 |
| 第二条 | 监察机关垂直领导，地方监察机关对上级监察机关负责。 |
| 第三条 | 可留置、调查、建议处分；限制人身自由须在四十八小时内报同级检察院备案。 |
| 第四条 | 监察人员实行回避与轮岗，不得在曾任职务的辖区办案。 |
| 第五条 | 年度监察报告向议会公开，涉密部分可闭门审议。 |
| 第六条 | **以组织形态干预任免、分配官位者，按「谋官」论处**；国家监委设关系图谱审查，可要求当事人就荐举关系、同乡同学关系作出书面说明，拒不如实说明者依情节处分。 |

### 6.《地方政府法》（1983）

| 条 | 要点 |
| --- | --- |
| 第一条 | 层级为州—省（市）—地级市—区（县）—街道，共五级。 |
| 第二条 | 各级设人民政治委员会常务委员会（政治领导）与政府（执行）。 |
| 第三条 | 州长、省长、市长由中央任命，任期五年，定期进京述职。 |
| 第四条 | 地方预算经本级议会审议、报上级备案；中央有转移支付权与预算否决权。 |
| 第五条 | 京畿直隶州不设省级政府；其六直辖市为省级组织，由中央直管。 |

### 7.《皇位继承法》（1984）

| 条 | 要点 |
| --- | --- |
| 第一条 | 继承顺序嫡长子优先；皇帝得废立，废立须经中央政治委员会备案。 |
| 第二条 | 皇储资格：皇室成员、年满十八、无重大违法记录、通过资格考核。 |
| 第三条 | 三层筛选：皇室提名—国家评议—皇帝最终确认；政治委员会确认后公告。 |
| 第四条 | 培养路线：国立中央政治学院→基层→地方→州级→中央部门→军事、财政、司法、监察轮训。 |
| 第五条 | 皇帝缺位由皇储摄政；无皇储则由政治委员会推举、议会确认临时摄政，一年内完成继承。**摄政期间由摄政主持政委会与常委会，但不得代行皇位继承确认。** |

## 二·补、《中央政治委员会组织法》（2026，十四条）

> 依据宪法第十一条制定；2026 年 3 月与《政制调整案》同日颁布。要点如下（要目，非全文）。

| 条 | 要点 |
| --- | --- |
| 第一条 | **性质与规模**：中央政治委员会是国家最高政治领导机关（全体会议层），由三品以上主官组成，总数不超过八十人。 |
| 第二条 | **组成**：政治局全体；七州州委主席；京畿直隶州州长；国务院组成部门主官未入政治局者；中央政治口与直属机构主官（财经委、政法委、民宗委、网信委、巡视委五主任、议会秘书长、统计局长）；议会九专门委员会主任；八大军区司令；陆海空三军种负责人；帝国中央银行行长。 |
| 第三条 | **列席**：副职、专门委员会副主任、审计院特派办、七州州长、三大舰队司令列席全体会议，无表决权。 |
| 第四条 | **当然委员**：委员资格随所任职务，职务变则资格变；政治局委员与常委由全体会议选举，报皇帝任命。 |
| 第五条 | **任期**：当然委员无独立任期；政治局委员、常委任期五年，连续任职不超过两届。 |
| 第六条 | **主席**：皇帝任主席，召集并主持；皇帝出访、病重或皇位空缺时，由国务院总理代为主持；皇帝保留最终决定权。 |
| 第七条 | **会议**：全体会议每年至少一次（春季）；必要时召开临时会议；皇帝可召集扩大会议，列席范围由主席决定。 |
| 第八条 | **法定人数与表决**：过半数委员到会方得开会；一般事项过半数；修宪确认、皇位继承确认、重大人事原则须三分之二。 |
| 第九条 | **递补**：当然委员出缺，由继任同一职务者自动递补；政治局委员、常委出缺，由全体会议补选，报皇帝任命。 |
| 第十条 | **回避**：审议涉及本人所在州、本部门、本军区之预算、人事、案件时回避表决，可陈述意见；回避不计入法定人数。 |
| 第十一条 | **文号与公开**：决议以「政发〔年〕X号」行文；《中央政治委员会通报》用于重大案件与人事；公报公布议题与结论，涉密事项不公布内容。 |
| 第十二条 | **办事机构**：会务由中央办公厅承办，不另设独立编制。 |
| 第十三条 | **与议会的关系**：议长（皇帝兼）主持政委会；副议长列席；政委会每年听取议会年度报告，议会可书面质询委员（涉密除外）。 |
| 第十四条 | **修正**：本组织法由议会过半数通过、政委会三分之二确认、皇帝批准；修正程序同。 |

## 三、法律位阶与冲突解决

| 位阶 | 规范形式 | 制定／批准 | 冲突时 |
| --- | --- | --- | --- |
| 1 | 宪法 | 议会 2/3＋政治委员会 2/3＋皇帝批准 | 最高，一切下位法不得抵触 |
| 2 | 组织法（七部＋2026 政委会组织法） | 国民议会 | 与部门法冲突时优先 |
| 3 | 部门法 | 国民议会 | 与行政法规冲突时优先 |
| 4 | 行政法规、部门规章 | 国务院 | 不得抵触法律 |
| 5 | 地方条例 | 地方议会通过、报中央批准 | 不得抵触中央法律 |

**冲突解决五规则**

1. 下位法抵触上位法者无效，由宪法法院宣告。
2. 同位阶：特别法优于一般法，新法优于旧法。
3. 中央与地方权限争议（含预算权限）由宪法法院裁决——1988 年「州诉中央预算权限案」为首案。
4. 机构间权限争议（如审计院与财政部、监委与检察院）由宪法法院裁决，政治委员会不代裁。
5. 皇帝否决的法案，议会以三分之二多数再议通过后生效；紧急状态下的特别法令，须于状态终止后六十日内提交议会追认。
