# 《全国高等教育设定（2026）》

> **依据**：《中华帝国世界观总设定 v2.0》第十三编「三级大学体系」（核心正式设定）与《中华帝国编年史》《长安城市志》互证；总设定未定名部分，按「现实大学名称与层级映射」原则推演补全【推演】。
> **版本**：继文十一年（2026）· 首版。
> **数量基准**：现实中国高等学校 3,167 所（2025 年公报）**×1.3 ＝ 帝国 4,117 所**。
> **符号约定**：※＝推演创作；【推演】＝待作者定夺；【核心】＝总设定冻结项，不可改动；〔现〕＝现实同名院校映射。

## 第一编 总则

### 一、三级大学体系与补充层级【核心＋细化】

| 层级 | 主办 | 说明 |
| --- | --- | --- |
| **国立大学** | 中央教育部门直接出资 | 含**大量分校**【核心】；本部十二所、分校及中央直属院系详见第三编 |
| **州立大学** | 州政府体系支持 | 八州各设旗舰与州属院校 |
| **省立大学** | 省政府建设 | 三十九省；五个中央直辖行政区设**行政区立**大学 |
| **市立·行业办学** | 地级市与行业系统 | 以专科为主 |

- **教育高度公共化**：帝国**不设私立大学**，全部院校由国立／州立／省立／行政区立／市立及行业系统举办。
- 国立大学分校大量存在；**大学之间允许转学和竞争；学位标准统一**【核心】。
- **京畿直隶州立长安大学**属顶尖综合大学【核心】。
- 医疗人才＝国立大学医学系＋省立医科大学【核心·总设定 1635】。
- 特殊院校（军委直属军校、警校、各级政治学院）**并入国立序列**（本设定口径）。

### 二、办学层次、学制与招生批次

| 项 | 设定 |
| --- | --- |
| 本科学制 | 四年＋**毕业前一年基层实践**（国民实践年／上山下乡，编年史 342） |
| 专科学制 | 二至三年；高职专科面向技能与基层技术岗位 |
| 学位 | 学士／硕士／博士三级；**学位标准全国统一**，由国立大学体系主管授予 |
| 招生批次 | **一本**（C9／世界一流／全国一流／全国一流学科／省属重点）、**二本**（其余本科）、**专科** |
| 入学率 | 2026 年大学入学率**超七成**（编年史 861），与 4,117 所规模互证 |
| 政治学院系统 | 国立中央政治学院与各级政治学院属**干部教育**，不计入普通高校招生口径【核心】 |

### 三、联盟五档（本设定核心框架）

| 档 | 联盟 | 数量 | 入列规则 |
| --- | --- | --- | --- |
| 第一档 | **中央科学教育联盟（简称 C9）** | **9** | 学术型九校：全国理工、人文、医学、综合旗舰；党校与警校不入列 |
| 第二档 | **国立大学联合体** | 420 | 全部国立序列（本部＋分校＋军校警校＋中央政治学院系统＋中央直属院系） |
| 第三档 | **世界一流大学联盟** | **45** | C9＋36 所（国立与州立旗舰为主） |
| 第四档 | **全国一流大学联盟** | **95** | 45＋50 所 |
| 第五档 | **全国一流学科联盟** | **230** | 95＋135 所（学科特色型院校为主） |

> 五档为**嵌套关系**：C9 ⊂ 世界一流 ⊂ 全国一流 ⊂ 全国一流学科。国立大学联合体为**平行口径**（按主办划分，不按水平）。

### 四、管理线与衔接

- 管理线：**教育部**（吴玉章）→ 高教司（卫桃李）→ 州教育部 → 省教育署 → 市教育局（官员名录卷一／卷三十六）。
- 公职衔接：官＝科举—政治学院—选举；吏＝专业考试＋大学教育（总设定 1216）。优秀吏可经考核＋政治学院晋升为官。
- 科研衔接：国家实验室体系依托国立皇家理工大学、国立中央翰林院大学、国立海军工程大学【核心】；国家航天局、国家人工智能管理局归口科技系统。

### 七、与现实对照原则

1. **名称沿用**：现实同名院校直接沿用（标注〔现〕），仅调整主办层级前缀——先例：州立北京大学、州立东北大学、州立香港大学【核心】。
2. **异地改名**：现实地名与帝国行政区划冲突者，按帝国地名改名（如西安→长安系、广东→岭南系、中山大学→岭南大学）。
3. **新增疆域**：朝鲜、滨海、蒙古、河内、澜沧、青藏等省，取当地名校名（东北州立平壤大学、东北州立海参崴大学、云贵州立河内大学、云贵州立澜沧大学）。
4. **数量校验**：帝国 4,117 所＝中国 3,167 所×1.3；长安为全国高校最多之城。
5. **教育公共化**：不设私立大学；政治学院系统属干部教育，不计普通招生。
