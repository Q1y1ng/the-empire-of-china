# 皇宫建模（宫城 / 0.72 km²）

把《长安城市志》卷三与《总设定》第十六编里的宫城数字，做成**可复现的 2D 总平面图与 3D 体量白模**。

- 数据唯一来源：[`palace_data.py`](palace_data.py)（每条尺寸标注【设定】/【宫式】/【推定】）
- 2D 出图：[`build_plan.py`](build_plan.py)（matplotlib → PNG + SVG）
- 3D 白模：[`build_massing.py`](build_massing.py)（Blender 5.x 无头 → .blend / .glb / 渲染图）

## 一、口径（先看这个）

| 档 | 内容 | 来源 |
| --- | --- | --- |
| 【设定】 | 宫城 **753 × 961 m**、0.72 km²、墙高 10 m、护城河宽 52 m、四门名、中轴里程、七个分区占地（8/6/7/7/16/4/24 ha）、殿宇名与用途、启门动线 | 《长安城市志》卷三；《总设定》第十六编；《法律要目·三》第五条 |
| 【宫式】 | 院落格局：外朝三殿同台（工字形三台）、内廷后三宫、**东六宫／西六宫各六院（两行三列，每院宫门—前殿—后殿—配殿—后罩房）**、值房沿墙与夹道成排、内金水河五桥、四隅角楼 | 故宫（紫禁城）平面 |
| 【推定】 | 单体面阔进深、殿身高度、台基与月台尺寸、门楼形制、值房排布、现代附楼 | 按明官式比例反推 |

两条必须说清的口径：

1. **"六宫"按东六宫／西六宫各六院读**（共 12 院）。紫禁城的后宫正是这样排的：不是六个院子并成一排，而是两行三列、每院纵深四合。若作者要的是"六院"，把 `COURT_GRID` 的行取一行即可（数据里一行开关），不用改绘图。
2. **分区占地已按院落实测校准**（2026-11-22，与《长安城市志》卷三同步）：前朝正殿 4.6 / 中后殿 3.6 / 东西厢 8.7×2 / 后寝 19.2 / 御花园 3.5 / 门庭巷道值房 24.0 ha，合计 72.36 ha（含城墙墙基）。旧表 8/6/7/7/16/4/24 是按文案切的预算，照院落排必然对不上；现在图与设定同一套数。

全书检索「面阔／进深／庑殿／歇山／斗拱／琉璃瓦／须弥座」= **0 次**，所以任何细部都属新增口径，不属既定设定。

## 二、跑起来

### 2D 总平面

```bash
uv venv "$TEMP/palace-build" --python 3.12
uv pip install --python "$TEMP/palace-build/Scripts/python.exe" \
  --index-url https://pypi.tuna.tsinghua.edu.cn/simple matplotlib
"$TEMP/palace-build/Scripts/python.exe" build_plan.py            # 300 dpi → docs/assets
"$TEMP/palace-build/Scripts/python.exe" build_plan.py --dpi 150 --out "$TEMP/out"
```

> 本机 `python` 是 Anaconda **2.7.3 32 位**，直接 `python build_plan.py` 会报语法错；用 `py -3` 或上面的 venv。

### 3D 体量白模

```bash
"/e/SteamLibrary/steamapps/common/Blender/blender.exe" -b --factory-startup \
  -P build_massing.py -- --out "$TEMP/out" --samples 160 --res 1920
# 只重渲一个机位
... --only 人视
```

实测（RTX 3060 Laptop 6 GB / OptiX）：933 个物体 / 16,180 三角面；1920 宽 160 spp 单张 25~35 s；正射总平面 34 s；glTF 1.6 MB。

## 四、平面怎么排的

- **外朝**：承天门（城台＋门楼＋两雁翅楼，仿午门）→ 前庭（内金水河蜿蜒、五座金水桥、东西朝房、协和／熙和门）→ 宣政门（仿太和门）→ **三台**（工字形高台 8 m）上的金瓯殿、秉衡殿、凝命殿，两侧东庑西庑、体仁阁／弘义阁、中左／中右门。
- **内廷**：内廷门（仿乾清门）→ 乾宁宫、交泰殿、泰宁宫与东西庑、后庑；两侧 **东六宫／西六宫各六院**，两行三列，每院宫门、前殿、后殿、东西配殿、后罩房；院外夹道排库房、值房。
- **外朝两厢**（按驻地功能填实）：东 **紫光阁院**（政治局：正殿＋南北东西配殿）＋ **中央警卫局营区**（营门、六栋营房、器械库、操场）；西 **政枢殿院**（国务院：正殿＋三配殿）＋ **中央办公厅院**（办公厅、东西厢、院门）；两厢另排朝房八列五排。东侧接紫光阁现代附楼（架空混合）。
- **北部**：琼苑（钦安殿、四亭、堆秀山、树点）、顺贞门、北横街值房两排、**乾东五所／乾西五所**（皇子居所各五院）、玄武门。
- **值房**：沿城墙内侧一圈、内廷南班房、北横街两排、外朝两厢朝房，全部经碰撞检测避让院落与殿身。

## 五、已知限制

1. 只有体块：没有开间、斗拱、彩画、门窗；城门是实体城台（未开洞）。
2. 高度为明官式比例推估值（金瓯殿 15 m 殿身 + 约 8 m 屋顶 ≈ 23 m，与太和殿 26.9 m 同量级），不是设定值。
3. 值房、后罩房是示意排布，面积计入"门庭巷道值房"预算内，不单独对账。
4. 琼苑只做绿地与树点，无水体、假山细节。
5. 分区占地已与实排对齐（见 §一第 2 条），图上侧栏列的是实测值。

## 六、踩过的坑

- **相机 `clip_end` 默认 100 m**：753×961 m 场景会被整片裁掉，首版渲染全空。固定 40000。
- **Blender 5.3 的 EEVEE 标识符是 `BLENDER_EEVEE`**，4.x 的 `BLENDER_EEVEE_NEXT` 已不存在。
- **中文字渲染**：`bpy.data.fonts.load(r"C:\Windows\Fonts\msyh.ttc")` 可用；默认 Bfont 无 CJK。
- **AgX 把宫墙红洗成粉色**：改 `view_transform='Standard'` + 曝光 −0.25。
- **叠盒子做三台会 z-fighting**（黑缝）：改成工字形多边形一次挤出。
- **值房不能也用琉璃黄**：金瓦满屏像村庄；值房／院墙用青瓦、廊庑用暗一档琉璃，主殿才用亮金。
- **屋顶顶点是世界坐标**：改用旋转物体改朝向会让屋顶绕原点飞走，按长边直接生成脊线。
- **米制场景里 6 m 院墙会压过 7 m 殿身**：院墙降到 4.2 m，殿宇才立得起来。

## 七、明官式精模（C 档，进行中）

白模看格局，精模看做法。精模不再是盒子加坡顶，而是按明官式排构件：

| 文件 | 作用 |
| --- | --- |
| `precise_lib.py` | 构件库：须弥座台基／踏跺／栏杆、柱网、额枋（青绿彩画分间）、平板枋、斗拱（栌斗＋泥道拱＋华拱＋令拱＋昂，两档 LOD）、椽带、庑殿曲面（举折＋瓦垄＋翼角起翘）、环屋面（重檐下檐）、正脊垂脊鸱吻、隔扇（棂条＋裙板）、整殿装配 `hall()` 与宫门 `gate_house()` |
| `build_precise.py` | 单殿展示：金瓯殿（重檐庑殿，面阔 11 间 90 m、进深 5 间 50 m、总高 37.4 m），出正立面／鸟瞰／檐下／屋顶四张 |
| `build_massing.py --precise` | 整宫精模：同一套院落数据，把殿宇换成构件级建筑（大殿重檐、配殿单檐），其余仍用墙体／值房／河／树 |

规模：整宫 **16,744 个物体 / 125 万三角面**，glb 48 MB；单殿约 600 物体 / 6 万面。

性能提示：构件库全部直接建网格（不走 `bpy.ops`），整宫从「30 分钟跑不完」降到 **约 50 秒**（Cycles 96 spp 另计）。

二轮已改：屋顶举折加陡（指数 1.5）、廊庑改柱廊（两排柱＋阑额＋两坡瓦顶）、三台加深色石与南沿栏杆、光比调强、修掉重檐围脊算成负高的 bug（下檐与上檐终于分得开）。
仍待改：①匾额文字没显示（文字转网格那步要查）；②斗拱被下檐遮住，需把檐口再抬 0.3~0.5 m；③屋顶曝光偏高；④三台栏杆只做了南北两沿；⑤现代改造（紫光阁玻璃附楼、金瓯殿玻璃门厅）未加；⑥成组渲染（正立面／鸟瞰／细部／内廷）与全宫 glb 未出终版。
