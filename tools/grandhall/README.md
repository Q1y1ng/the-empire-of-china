# 国家大会堂 · 中厅 · 万人大礼堂

把《长安城市志》卷二与《总设定·第十六编》里的「中厅：无立柱万人大礼堂，约 10,000 席」
做成**可复现的 2D 平剖图、3D 白模与精模**。

坐标系与 `tools/palace/`、`tools/plaza/` 完全一致：原点取**宫城平面中心**，+x 向东、
+y 向北，单位米。本礼堂是**中厅的内胆**，直接套进广场模型的中厅体块
（x ∈ [−540, −310]、y ∈ [−1155.5, −915.5]、檐高 50 m）。

## 三、视线校核（这是设计的主控条件）

挑台不是随便定的。`sightline.py` 逐排计算「越过本层挑台栏板后，在台口处能看到的最高遮挡下界」：

| 层 | 能看见台面（1.5 m） | 能看见就坐者头部（2.8 m） |
| --- | --- | --- |
| 池座 44 排（含后区） | 44 / 44 | 44 / 44 |
| 二层挑台 15 排 | 4 / 15 | **15 / 15** |
| 三层挑台 9 排 | 4 / 9 | **9 / 9** |

> 挑台后排看不见台面下沿是真实剧场的常态（挑台栏板形成「切口」），
> 关键是**必须看得见主席台上就坐的人**。初版挑台深 22.8 m、坡度仅 5%，
> 两层挑台都只有第 1 排能看见主席台（末排遮挡下界分别到 10.30 / 18.09 m），
> 2026-11-23 已按上表重排：挑台变浅、坡度按几何反算加大到 33% / 46%，
> 并把观众厅加宽到后墙 140 m、净高抬到 44 m，使同样一万席所需排数减少。

跑一遍：

```bash
py -3 sightline.py
```

## 六、口径里的几处改写

- **红五星 → 国徽圆盘**：顶棚中央依《国家象征物（2026）》换成
  「长安城墙剪影＋金蟠龙＋稻穗齿轮」的国徽构图；光芒线由 70 道改为 **72 道**
  （周天 360°／5° 一道）；旗帜用**红底金龙旗**。
- **三环水波灯槽** 保留（人民大会堂「水天一色」的做法），ρ = 0.86 / 0.62 / 0.40。
- **满天星灯** 500 盏保留；**宝相花灯** 40 组。
- 色彩依《国家象征物（2026）》：帝国红 `#C8102E`、金 `#C9A227`。

## 七、与广场、宫城模型的关系

- 三套数据原点相同，可直接叠场景；本目录**只读**引用广场的体块与宫城的关键常数，
